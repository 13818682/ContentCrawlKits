## 一、全书核心观点（贯穿始终的底层逻辑）

1. **文案的本质是"人与人"的沟通**：打动人心靠的不是写作能力而是**换位思考与共情**。所有"自嗨"型文案（自说自话、堆砌高级词、罗列功能）都打不动人。
2. **写任何文案前先立"用户视角的目标"**：不要"我想让用户做什么"，要问"用户在乎什么 / 支持反对什么 / 顾虑什么"；目标 = 让用户从 **A点（现状）→ B点（希望的行动）**，为此要解决什么问题。
3. **文案 = 屏幕背后的销售**：说服链路本质是**"吸引注意 → 激发兴趣/欲望 → 赢得信任 → 促成行动"**（AIDA/4P 的变体），一切模板都是这条链的演化。
4. **给利益，别给功能**：用户不关心产品有什么特点，只关心"这能给我什么好处"。卖点公式 = **产品特点 + 利益点**，且利益要和特点逻辑自洽。
5. **人是被"人性/心理"驱动的**：6种痛点心理（寻求支持/理想自我/避免损失/补偿自己/补偿他人/二者兼得）、9个人性促单技巧、厌恶损失、稀缺、从众、价格锚点等，是打动人心的"开关"。
6. **金句自带传播力**：原创金句 = **熟悉的句式 + 改变关键词（立意）**，9类句式可直接套写。
7. **爆文选题决定流量天花板**：好选题要满足"普遍关注 / 引发共鸣 / 对多数人有用 / 新鲜独特"至少其一。
8. **先完成再完美**：初稿→按自检清单反复修改（整体→局部→细节）；用 **AB测试 + PDCA** 迭代。
9. **内容可一鱼多吃、一份时间卖多次**：公众号/头条/百家号/小红书/知乎一文多发，多平台同步沉淀。

## 二、分章摘要（含全部关键公式/模板/数字）

### 第1章 短文案写作技巧（第1–7课）

**第1课 · 把握"3感"零基础写广告文案**（章之总纲）
- 好文案打动人心靠 3感：
  - **对象感**：心里装着说话对象、说人话。做法：想象对面坐着一个活生生的人；像跟闺蜜/哥们儿说话一样写；"先说后写"（录音转文字成初稿）。反例是"极致柔顺、吸放湿效果更强"这类不说人话的词。
  - **代入感**：让读者觉得"说的就是我"。两个方法：①**描述熟悉的场景**（不要告知，要描述）；②**调用感官和细节写出画面感**（视听触味嗅用得越多越具体）。
  - **共鸣感**：替特定人群发声、说出他们感觉得到却说不出来的话 → 认同你 → 转发/购买。

**第2课 · 产品文案2个关键点**
- 关键点一**了解用户需求痛点**，三个低成本方法：①直接问身边目标用户；②电商/搜索平台搜产品关键词看扩展联想词；③看同类产品真实评价（好评优点/差评缺点 → 形成痛点清单 → 找锚点）。
- 关键点二**提炼卖点**：
  - 公式 **产品卖点 = 产品特点 + 利益点**（先说利益点再摆特点佐证；特点要具体到可感知，如"能插进裤袋"胜过"能装1000首歌"；利益点要与特点有逻辑关联）。
  - 找卖点 8 问：解决什么问题/为什么能解决、与竞品差异、能补竞品什么短板、做工/原料/服务等细节、生产细节、实际结果与用户反馈、名人大牌背书、已购用户评价。
  - 筛选2标准：①是否打中目标人群主要需求；②是否竞品没有或更优（**人无我有、人有我优、人优我特**）。

**第3课 · 戳中6种痛点心理（刷屏海报文案）**
1. **寻求支持**——替用户发声，说出他想说不敢说的话（"你懂我"→转发）。
2. **理想自我**——写出用户想成为的那种人 → 身份认同/优越感（也可反用：不想成为的样子）。
3. **避免损失**——"已错过一次别再错过第二次"（"已经错过大学，别再错过本科"）。
4. **补偿自己**——道出他辛苦付出 → "犒劳一下自己"（"全力以赴的你，今天坐好一点"）。
5. **补偿他人**——点出家人/重要他人为他的付出 → 买来补偿对方（用具体数字强化：第N次…）。
6. **二者兼得**——帮用户解决"鱼和熊掌"两难（"一边学一边赚，赚回学费"）。
- 每种心理均给了"三段思考路径（用户处境→普遍情感→如何与产品结合）"。

**第4课 · 短文案万能模板 AIDA（5分钟写出吸金文案）**
- AIDA：**Attention 注意（开头第一句）→ Interest 兴趣（关联读者/熟悉场景/提问）→ Desire 渴望（理由=卖点利益+证明）→ Action 行动（引导下单+限时优惠）**；500字内推广、朋友圈/微博/微头条等通用。
- 开头吸引注意的4手法：**对比反差 / 反常识 / 悬念好奇 / 讲故事**。
- 3个演化公式：
  1. **直接说出好处 +（效果证明）+ 如何得到好处 + 立即行动**；
  2. **提出用户很想解决的问题 + 给出解决方案 +（证明有效）+ 呼吁行动**；
  3. **痛点场景 +（严重后果）+ 解决方案 + 刺激信息**（场景可从竞品详情页/好评中找）。
- 检查两面：感性（能否戳情绪）+ 理性（利益讲清）。

**第5课 · 9个人性心理促单（打消顾虑 + 给足刺激）**
- 先讲用户掏钱前的**6种风险/成本**：金钱成本、决策风险、心理风险、形象成本、行动成本、健康风险（前3种多在文案中后部用证言/背书打消，金钱/心理/形象多在结尾引导时打消）。
- 打消顾虑 5 法：①**价格锚点**（先给高价参照再给低价）；②**帮顾客算账**（平摊法——每天只要1块钱；等价换算法——"一杯奶茶的钱"；明示依据法——为什么值这个价）；③**给正当消费理由**（"你值得拥有"、为了家庭/成长等正当化）；④**社会认同**（用了之后被夸的形象）；⑤**从众心理**（亮畅销数据：累计销量/短时间销量/名人同款/复购率，数字越具体越可信）。
- 临门一脚 4 法：⑥**占便宜**（对比出来的便宜+罗列附加值福利）；⑦**厌恶损失**（"仅限3天，错过多花500元"）；⑧**营造稀缺**（限时限量限名额，句式：仅限前N名/只剩N个名额/仅剩N小时；前提是真实执行）；⑨**痛点刺激+理想场景对比**（结尾把"现在的痛苦"和"拥有后的美好"并排对比）。
- 提醒：文案/结尾要给明确的**行动指令话术**。

**第6课 · 9个金句模板（爆款金句制造机）**
- 金句特点：简短顺口、朗朗上口、一语中的有哲理。原创法：**熟悉的句式 + 改变关键词**。
- 9句式：①ABBA（没有A可以通向B，B本身就是A）②ABAC（不在乎A，只在乎B）③A是B ④不是A而是B ⑤重复字词（自律给我自由/可坚强不必逞强）⑥押韵 ⑦对比反差 ⑧修辞（比喻/排比/对偶/顶针）⑨利用关联词造句（有多…就有多…、与其…不如…、哪有什么…只是…、我怕…但我更怕…等十几种句式模板）。
- 积累渠道：情感美文公众号标题与黑体、励志书目录、聊天中金句、精准搜索"名人+关键词+名言"。

**第7课 · 1个文案自检清单**
- 站在读者视角问自己 5 问：①**能引起我的注意吗**（有关注点？有反差/反常识？有好奇心？）；②**有戳中并解决我的痛点吗**（用户明确？痛点高频在发生？写得具体有代入？）；③**卖点清晰、能对痛点吗**（主打一个，其余辅助）；④**说服逻辑符合 AIDA**；⑤**我想行动且知道怎么行动吗**（给动机+简单指令）。
- 语言三注意：讲人话（陌生概念给类比）、用事实/细节/证言说服（"非常震撼的电影"→"绘制超20亿个多边形"）、自问自答顺应认知多用短句。
- 迭代：**AB测试**（两稿只改一个变量、同时段发布看数据）+ **PDCA循环**。

### 第2章 爆款长文案写作指南（第8–15课）

**第8课 · 文案写作GPS，告别自嗨**（长文总方法论）
- 写作6步：明确目标 → 确定读者 → 脑暴创意/搜集素材 → 组织大纲 → 写初稿 → 反复修改。
- 有效目标 = 用户视角：**从 A（现状认知）→ B（希望的行动），解决什么阻碍**（AB点理论）。例：自嗨目标"想让更多人买美容仪"→ 用户视角目标"让她们意识到天天护肤该像刷牙洗脸一样高频"。
- 靠**用户画像**（人口/行为/态度数据，想象一个具体的活人）支撑；不追求全表，够在脑中具象一个人即可。
- **文案GPS分层**：功能利益点 → 情感利益点 → 价值观，越往下动机越强；一般文案写到情感层即可，到价值观层最认同。

**第9课 · 营销文案万能模板 4P**
- **Picture 描绘（痛点场景或理想愿景）→ Promise 承诺（我能解决/带来什么）→ Prove 证明 → Push 敦促下单**。描绘与证明是重中之重。
- 描绘痛苦场景模板：在某个地方+客户特征，每天+烦恼。描绘理想状态用"眼耳鼻舌身意6感"写出画面。
- Prove 理性：讲原理 / 靠权威 / 摆数据 / 给事实（至少1–2点）；感性：讲故事 / 说感受 / 晒评价。
- Push：再次对比美好 vs 糟糕 + 限时限量/锚点/算账/正当理由。

**第10课 · 3个万能写作框架（文章骨架）**
- ①**结论先行**（基础：结论→理由→实例→总结；进阶：结论→3~5个并列分论点(各带理由+实例)→结论）。适合观点文。
- ②**问题解决型**：描述痛点(是什么)→分析原因(为什么)→给方案(怎么办)→呼吁行动。适合干货文、销售文。
- ③**故事型**：开端(低谷/阻碍)→转机(意外)→成长(改变)→未来(启示)。好故事低开高走、必须有变化；新媒体故事结尾要点明观点。故事最小套路：目标→阻碍→努力→结果→意外→转弯→结局。
- 三者可组合。

**第11课 · 3个选题策划思路（10W+）**
- 选题 = 文章类型+主题+核心观点，先填空"我的__是关于__的，我要说的是__"。戒"以自我为中心"。
- 好选题 4 标准：**普遍关注度**（长期话题如教育/婚姻 + 周期性话题如高考/开学）、**引发共鸣**（戳痛点或调情绪）、**对多数人有用**（给新知=信息增量）、**新鲜独特**。
- 5 方法：**推己及人**（从自己生活观察上升到群体普适）、**痛点连线**（左列受众标签 × 右列痛点/兴趣两两组合）、**日历选题**（营销日历：节日节气大事件、开学/毕业/中高考季提前铺）、**热点**（用今日热榜/即时热榜/易撰聚合，蹭热点要有自己观点、下手要快）、**对标**（研究同行爆款建选题库，借鉴不抄袭）。

**第12课 · 4个素材秘诀**
- ①取材生活（孕妇效应：你关注什么就看见什么；立天线记灵感）；②主动输入（选优质信源多读书、带问题目标输入）；③高效搜索（关键词层层聚焦 + 在平台/聚合站/微信读书里搜）；④建素材库（印象笔记等统一容器 + 分类打标签定期整理，金句/故事/案例/标题分开存）。

**第13课 · 10个开头结尾（凤头豹尾）**
- 5种吸睛开头：**现象+提问 / 故事+悬念 / 痛点+利益 / 观点+解释（反常识）/ 主题+价值**（尽快让读者知道重点和价值）。
- 5种有力结尾：**总结互动（总结+提问引导评论）/ 升华主题（从小事拔高到精神）/ 共情感召（呼吁行动）/ 美好祝愿（愿我们…）/ 金句结尾**（可叠加：金句+祝愿）。

**第14课 · 13个吸睛标题技巧（点击率翻10倍）**
- 标题底层 4 原理：**与我有关 / 对我有用（马斯洛需求关键词）/ 调动情绪（高唤醒 正/负）/ 让我好奇**。
- 13 技巧：①**直呼受众标签**（身份/年龄/地域/行为标签对号入座）②**多用"你""我"** ③**用数字**（阿拉伯数字；大人物大数字、背书用大数、干货用≤10的小数；盘点类数字别太大；一标题数字≤3个、2个为宜；数字要和卖点相关）④**提问式** ⑤**设问式** ⑥**晒利益好处**（指南/诀窍/清单类）⑦**留悬念**（话说一半；What/Who/Why式悬念）⑧**颠覆常识** ⑨**运用对比**（时间/境遇/立场/心态对比）⑩**痛点+解决方案** ⑪**替受众发声**（用读者原话）⑫**延续不安恐惧** ⑬**傍大款**（借名人名牌权威/类比）。
- 方法：先写"标题原型"（一句话讲清主题价值），再用技巧加工，每次起3~5个选最优；标题本质是条短文案（10~30字）。

**第15课 · 长文案修改（变废为宝）**
- 原则：先整体到局部再到细节；"写时用热情，改时用冷静"；初稿通常是终稿1.5~2倍，敢删。
- 3要点：①**通读理顺核心观点**（内容为观点做减法，没深度的地方做加法）；②**打磨框架与小标题**（3看：与主题强关联 / 独立成观点言简意赅 / 逻辑顺序顺畅）；③**细化修改**（开头看是否快引主题+吸睛+戳痛点；结尾看扣题+能引发分享；正文删无关、拆长句、修错别字（的/地/得）、用转折词、调语序）。
- 4修改方式：写完放一放隔夜再改 / 大声朗读发现问题 / 打印出来读 / 请目标读者看。

### 第3章 投稿变现实操（第16–19课）

**第16课 · 变现准备：3种类型 + 7个渠道**
- 3类型：**投稿赚稿费 → 做自媒体账号（平台收益/广告/带货）→ 个人品牌**（三个阶段递进）。
- 渠道举例：朋友圈卖货/社交新零售；小红书品牌广告+带货（5000粉入蒲公英）；知乎好物推荐+盐选+广告；商家营销文案代写；头条/百家微头条及图文带货；头条/百家文章流量收益（算法平台有阅读就有收益）；付费专栏。
- 自我选择：问兴趣专长 / 个性是否出镜（内向做图文） / 时间精力；投稿与自媒体可兼容分阶段。

**第17课 · 朋友圈文案变现（把握4个度）**
- 核心：**先卖人，再卖货**；卖人设、卖价值观、卖生活方式。广告刷屏 = 被屏蔽。
- 内容 4 类（人设类要占50%+）：①塑造人设（自我提升/专业干货/主题打卡）②产品曝光（软植入/活动直播/服务告知）③好评反馈（晒顾客变化/提炼学员好评截图）④直接销售。
- 销售文案 5 写法：**我用过+我的收获+适合人群**（万能基础版）/ **具体问题+原因+解决方案** / **放大卖点+感性呼吁+理性证明** / **观点+解释+软植入**（最利于立人设）/ **讲故事+晒收获**。
- 运营：每天3~5条、避免刷屏；单条正文≤6行防折叠（更长内容放评论区）；广告与其他内容配比约 **1:2**；定期清理过期广告。

**第18课 · 公众号投稿变现（上稿率+30%）**
- 公众号文章常见5型：观点文（必须有鲜明单一观点）/ 情感文 / 职场文 / 亲子文 / 干货文（可复合）。
- 结构：开篇（名言金句/现象/案例引入，别拖）→ 主体（并列式或递进式）→ 结尾升华（决定转发率）。
- 上稿率3因素：**文章质量**（信息增量 + 鲜明观点 + 逻辑性）、**平台匹配度**（先看10篇以上对标风格调性再模仿）、**人脉圈子**。
- 投稿细节：严格按征稿格式（标题命名/附件/字数）、排版整洁多小标题勤分段、原创首发不洗稿、编辑回复要尽快改、不一稿多投。
- 判断：现在公众号图文图文起号难（新人慎做），但**微信生态私域（公众号+社群+视频号+朋友圈联动）仍可做**；公众号可作为承接 SEO 搜索的窗口（呼应本仓 04A 判断）。

**第19课 · 爆款带货文案变现**
- 带货文 5 要素：**吸睛标题 → 黏性开场 → 激发欲望 → 赢得信任 → 促动下单**（点击看前2，转化靠后3）。
- 12 要点自检清单：逐条罗列优势 / 写实绩用数字 / 权威证言 / 顾客声音(实名+照片) / 营造稀缺 / "之前之后" / 加入问答打消疑虑 / "名人大牌都在用"解释安全 / 明示定价依据 / 便宜用比较法 / 特惠营造特别感 / 售后服务解后顾之忧。
- 2种万能结构：**痛点解决型**（借热点戳痛 → 大方案+论据 → 引产品+多条论据 → 化解疑虑 → 利益凸显促单；适合平台号/痛点产品）；**直接种草型**（小事切入快速引产品 → 产品真好 → 3~4卖点+论据 → 权威背书 → 结论促单；适合有人设强信任的账号）。

### 第4章 自媒体变现实战（第20–23课）

**第20课 · 头条号变现（算法平台范本）**
- 5大变现：**流量收益**（文章/微头条100粉/问答100粉）、**带货**（万粉商品卡；微头条也能带）、**付费专栏**（万粉，70%分成）、**活动征文**、**星图广告**。
- **爆款微头条**：开头前50字（信息流只显示3~4行/50余字）决定点击，4类吸睛开头：对比反差/制造悬念/矛盾冲突/反常识；常见爆款类型：热点新闻(要有自己观点、别搬运) / 故事感悟 / 干货科普。
- **问答选爆题"4看"**：看近30天有无人回答(有人答且赞≥10可考虑)、看数据(剔除假评论假转发群刷)、看整体(回答都超长/大V扎堆/套路化不碰)、看阅读比(回答数:阅读数≈1:1万才答)。优质问答模板：故事体(开头留悬念、故事占2/3、结尾总结+给干货延伸) 或 干货体(提问题给方案、先答案再方法、金句殿后)。
- **爆款文章**：爆文3标准=话题性/共鸣点/奇特性(至少中1)；算法平台一定要**踩关键词**(文中多布目标读者相关词)；追热点=热点简介+别人观点+自己态度，且情绪/价值/新奇至少占1。
- 带货文公式：开头(蹭热点/故事/悬念/反常识/戳痛点) + 配图(高清统一有信息量) → 正文说好处+理性&感性证明 → 结尾算账促单。选品3标准：有竞争优势(畅销+背书)、价格便宜(200元是敏感线，100~130元最易成)、有独特卖点。带货4种选题：名人热点/讲人物故事(低开高走)/直接解决痛点/顺应时节刚需(开学/中高考季!)。专栏标题三要素 **卖点+群体+好处**；单章用1:8:1(钩子开头10%+正文80%+总结引导10%)。

**第21课 · 百家号变现（与头条互通，多一个搜索流量）**
- 与头条最大差异：**百度搜索流量占20~50%** → 标题关键词布局更重要（对应本仓公众号搜一搜逻辑的"多平台版"）。
- 6大变现：流量收益（动态/图文/问答，单价高于头条，8–30元/万阅读起）/ 内容电商（动态+图文挂商品）/ 付费专栏（**仅100粉即可开**，是全平台最低门槛）/ 内容营销(度星选) / 榜单奖励(优选计划/百家榜，月奖金2000–1万) / 付费咨询(百度问一问抢单)。
- 创作技法与头条互通，可直接复用。

**第22课 · 小红书变现（5种商业模式）** —— 详见姊妹篇《5小时吃透小红书》摘要
- 5种：**广告（报备蒲公英/非报备）/ 带货（小清单/关联商品/直播）/ 店铺（号店一体，个人可开店）/ 付费专栏 / 引流私域**。
- 定位与内容要点：简介放2~3关键词；图文是重图片轻文字、干货要"聚合汇总型"最易被收藏；勤更新（一周至少3条，月15条左右）；注意 笔记流量=首页推荐+搜索（长尾）。违禁：黑店踩坑词/药效词/宗教词/引流二维码/同款图文重复。

**第23课 · 知乎变现**
- 等级 Lv1–Lv10，权益随等级解锁；盐值500开付费咨询。8种变现：官方活动/好物推荐(Lv3+90天)/知+自选、知+互选/付费咨询/品牌特邀(Lv7)/知乎Live/盐选专栏(官方收稿)/私域。
- 知乎内容百度收录概率高、长尾长，适合长期沉淀个人品牌。
- 答题技巧：开头20字（信息流折叠只露前两三行）要亮经验与收获；排版多小标题+表格图；善用变现入口；不引导留站外联系方式。选题找高潜：问题关注≥1000人、浏览量50–100万、回答少高赞少的最优。

### 第5章 个人IP打造与变现（第24–28课）

**第24课 · IP打造三部曲**：**定位找标签**（职场/生活/专业三维度挖掘优势 + 结合市场需求，取三圈交集，初期只选1个标签）→ **分享勤输出**（专业知识干货/成长故事/书籍电影观点/愿景，为定位做背书）→ **借势选平台**（平台分三梯队：头条+公众号+微博 / 百家号企鹅号等 / 小红书+知乎；以1~2平台为主其他同步分发"一鱼多吃"）。

**第25课 · IP三件套**：**好名字**（4作用：自带流量/锁用户/降传播成本/体现价值；4特点：简短好记2~5字、简单好写便搜索、贴定位含关键词、有辨识度；6公式：IP名+功能/领域/教你技能/职业身份/地名/兴趣）；**好头像**（真人形象照>生活照>网络人物>非人物；体现职业/价值/风格统一）；**好介绍**（身份+能力(荣誉高光+定语缩小范围)+价值(数据化业绩)）。

**第26课 · IP变现路径（公域私域闭环）**
- **IP成长飞轮**：个人能力→个人品牌→撬动资源→做出成果→成果反哺内容输出→放大品牌；先转最小飞轮再加重。
- **打通公域私域**：公域平台沉淀粉丝 → 引流个人微信 → 私域完成信任与成交；私域用**微信生态4板斧：朋友圈+公众号+微信群+视频号**联动（公众号适合深度干货、是"别人能找到你的窗口"）。

**第27课 · 知识IP"5步成课"**：①**定主题**（问3问：最有价值/乐此不疲/最拿手；关键词收集：系统式/片段式/阅读式；再逆向验证"为什么是我"）；②**列要点**（主题发散聚焦/目标群体需求[谁-做什么-搜什么]/经验兴趣优先）；③**搭框架 333架构**（开场预告3重点→中段3重点→结尾，重点间用并列/线性/循环/层级4逻辑之一串联）；④**填充肉**（经验步骤法/主题阅读法/故事案例法）；⑤**打通关**（4种开场：说目的/提问题/讲故事/摆事实；3种结尾：金句升华/故事启发/重点回顾；中间多用类比、生活案例、图表、数字）。知识IP逐字稿可一鱼多吃发文章/视频。

**第28课 · 读书IP变现**：9种变现层次（免费看书换书 → 流量收益 → 带货卖书 → 读书号/脚本代写 → 拆书稿讲书稿(几百~上万/篇) → 书评链接作者资源 → 付费读书社群 → 付费训练营/专栏 → 个人品牌）。书评结构4段：开头引主题(痛点) → 介绍书和作者 → 围绕主题主体(观点或方法) → 总结升华种草。

## 四、与本仓（深圳中考内容平台）工作的相关度提示

- **标题技巧（第14课）+ 搜一搜/平台 SEO**：与既有 `docs/04A-微信搜一搜优化` 的标题公式可互相印证、扩展——04A 强调"深圳中考＋主题词＋承诺、直接清晰"，本书补充了更多让标题"被点开"的人性技巧（与我有关/数字/提问/悬念），后续做平台规则时可把两者合并成"搜索友好 × 点击驱动"双目标标题法。

- **封面/首图与正文关系（书中标题即短文案、配图=门面）**：印证 C 系列封面规范（封面承载触发点，正文给价值）的合理性。
