深圳中考志愿填报垂直AI自动化内容平台（HSEE ContentCrawlKits），目标受众为深圳初三学生家长（35-45岁）。核心业务：围绕深圳中考志愿填报前期（3-5月政策期）、中期（6-7月填报期）、后期（7-8月录取期）三个阶段，通过AI自动化流水线（多平台素材采集→语义去重分类→AI批量生成→多模态制作→全域分发→数据反馈）实现规模化内容生产。

**Why:** 深圳中考每年约13万+考生，家长面临政策复杂（2026年总分630分新制、走读调剂、指标生规则等）、信息碎片化、官方语言难懂的痛点，信息不对称导致强付费意愿。

**How to apply:** 所有技术方案必须绑定深圳本地特色（历年分数线、高中梯队、指标生分配），不可产出通用化内容。内容需遵守《人工智能生成合成内容标识办法》（2025/9/1生效）。
