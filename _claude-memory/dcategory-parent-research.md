# D类（非深户）中考家长市场调研

## 关键数据

- D类考生约5.9万人，公办学位约1.5万，录取率约26%（深户约88%）
- 2026年D类指标生全覆盖（含民办初中），以区为单位统筹分配
- 2026年新增3+4中本贯通（300名额），是D类低分段新出路
- 部分学校出现AC/D类分数线倒挂（D类低于AC类）
- 2026年总分调整为630分，第一批志愿增至16个

## 四类用户画像

1. **信息饥渴型·新手家长** ⭐核心用户 — 孩子初三，首次面对政策，晚上焦虑刷手机搜索，付费意愿强，决策窗口短
2. **经济务实型·预算敏感** — 450-500分段，纠结公办/民办/中职，价格敏感但怕走错路
3. **高分冲刺型·学霸家长** — 540+分段目标四大八大，焦虑户籍"吃掉"分数优势
4. **躺平观望型·低分段** — 300-400分段基本放弃规划，需用中本贯通等新政策唤醒希望

## 情绪动因

- 痛点: "孩子没书读"恐惧、信息迷宫焦虑、错过窗口恐惧、被收割愤怒
- 痒点: "用信息差赢回户籍劣势"、"精明家长不焦虑"身份认同
- 爽点: "终于搞懂了"通透感、"还有这条路"希望感、"我填对了"成就感

## 差异化机会

- 没有任何竞品系统化服务D类家长（深校家长帮有单篇但不成体系，zkzyw.net无D类筛选）
- HSEE独家数据表可产出AC vs D分差排行榜（竞品没有的数据）
- D类内容是最强差异化入口+最大付费底盘（焦虑最强、决策最需要帮助）

## P0内容方向

1. D类全出路指南（公办/民办/中职/中本贯通全景图）
2. AC vs D分差排行榜（数据驱动型内容）
3. 3+4中本贯通全解读（2026新政策蓝海）
4. D类指标生全攻略

**Why:** D类家长占考生54%但内容供给不到20%，是竞品内容生态调研确认的最大缺口。本次insight+firecrawl调研首次系统化梳理了D类家长的用户画像和情绪动因。

**How to apply:** 所有面向外部平台的内容创作，D类视角应占至少40%的比例。每次选题时先问"这对D类家长有用吗？"P0内容方向可直接用于验证阶段试跑选题。
