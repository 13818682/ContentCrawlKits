# 公众号"精简版"优化规范（S1 系列通用，2026-08-20 定稿）

**Why:** 用户要求对所有公众号终稿输出"精简版"，以适配最大量受众（焦虑求助型+临界求生型，约占60%）的短阅读习惯；先在我方多次返工后才固化成这套规范，避免每次重新摸索。

**How to apply:** 每篇 S1/P 系列公众号文章做精简优化时，严格按下述文件约定、文字要求、图片要求执行。相关进度见 [[content-creation-progress]]。

## 一、流程与文件约定

1. **原终稿绝不动**：只新建精简版，禁止覆盖 `-公众号-终稿.md`。
2. **先提方案后生成**：动手改/生成前，先把优化思路给用户审批，获批后才执行（用户多次强调）。
3. **命名**：与终稿**同编号** + `-公众号-终版-精简.md`（例：终稿 `05-...-终稿.md` → 精简 `05-...-终版-精简.md`）。
4. **frontmatter**：`version: "终版-精简"`、`word_count` 写**实测总字符**（非空白字符数，取整到百，约等于公众号显示字数）、`source: "由{编号}-公众号-终稿精简优化：{压缩手法}"`。article 字段用正确编号（S1-4 精简版已改为 S1-4，终稿旧编号 S1-6 属已知历史问题）。
5. **Markdown `---` 分割线全部保留**（用户曾要求去掉后又回退，最终定案：保留）。

## 二、文字要求

- **结论前置**：每节先给"结论"，再列支撑数据（例：S1-2 每条启示第一行就是结论句）。
- **压缩对象**：过渡引导句、背景铺垫、排比堆叠（例：把"你可能会问……"类反问句合并为一句）。**数字、精华观点、表格、合规尾注一个不删**。
- **数据即内容**：压缩比例受数据密度限制，现实值约 **6%~15%**（S1-4 仅 -6% 属正常，因正文几乎全是数字）。
- **表格承载密度**：大表只列关键年份行（S1-4 例：2018/2020/2022/2024/2026/2027 隔年取点），被删中间年份的关键信息（如2023、2025节点）转入正文要点段落保留。
- **措辞用"风控语言"**（帮家长避坑、消除焦虑），不用"机会语言"（名校冲刺、制造焦虑）；保留"压力虽在高位但方向在好转"这类安抚句。
- **保留 ▍"该怎么做"行动块**（公众号转化关键）；保留文末 HSEE 小程序引流段 + 官方数据来源尾注。
- **极简版三件套（2026-08-21 用户追加要求）**：①兴趣钩子——开篇用"你家孩子可能正好赶上压力最大的几年"类直击痛点句，立刻接"不贩卖焦虑，只给数字"，稳住读者；②承前启后——每个数据节后补一句 **"这意味着什么？"** 把数字拉回自家孩子（个人意义），并把"怎么操作"留给后续文章制造期待；③系列钩子——结尾补"这只是系列第X篇"：列7篇标题清单 + 建议按顺序读 + 给下一篇埋悬念（例：第4篇讲"考生为什么8年翻倍"）。三者都是转化和留存的关键，压缩数据时不可删。

## 三、图片要求（公众号配图 PNG）

- **工具**：PIL + numpy 直出 PNG（cairosvg/svglib 不可用）。
- **尺寸**：封面 900×383；章节条 900×220；数据卡 900×400。
- **配色**：背景深蓝渐变 顶部#1b3a5c(27,58,92)→底部#0d1e30(13,30,48)；白色WHITE(255,255,255)；主数据金 GOLD(245,198,107)；次级浅蓝 LIGHT(157,184,212)；次文字 SUB(201,217,232)；卡片底 CARD(31,66,106)；卡片描边 EDGE(58,100,148)。
- **字体**：`C:/Windows/Fonts/msyhbd.ttc`（粗，主标题/数据）、`msyh.ttc`（常规，说明文字）。
- **命名**：`{NN}-{文章标题}-公众号-封面/插图-NN-描述.png`；编号接在目录已有文档号之后（目录 01-06 文档 → 配图从 07 起）。
- **版式类型**：
  - 封面：主标题大字 + 核心数据条（2-3 格卡片）。
  - 章节条：金色竖条 + 编号 + 章节标题 + 副题。
  - 数据卡：柱状时间线（隔年6点，末两年金色高亮）、三引擎/三信号/三类人群并列卡、双组柱状对比（考生 vs 学位）。
- **校验**：生成后必须程序化校验——用 textbbox 逐元素检查文本是否越界/重叠（Read 工具在此环境无法预览图片，不可依赖目检）。
