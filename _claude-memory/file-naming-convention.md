## 文件命名格式

```
{序号}-{文章编号}-{文章标题}-{类型}.md
```

### 格式说明

| 组件 | 说明 | 示例 |
|------|------|------|
| `{序号}` | 两位数字，按工作流步骤排序 | `01`=写作简报, `02`=公众号初稿, `03`=平台变形, `04`=核验清单 |
| `{文章编号}` | 系列-编号 | `S1-1`, `S1-6`, `P3-2` |
| `{文章标题}` | 完整文章标题（中文） | `2027深圳中考家长必读：一张图看懂竞争格局` |
| `{类型}` | 文件种类 | `写作简报`, `公众号-初稿`, `小红书-数据冲击篇`, `抖音-60秒脚本`, `数据核验清单` |

### 完整示例

```
01-S1-6-2026年中考已结束，2027届家长现在该做什么？-写作简报.md
02-S1-6-2026年中考已结束，2027届家长现在该做什么？-公众号-初稿.md
03-S1-6-2026年中考已结束，2027届家长现在该做什么？-抖音-60秒脚本.md
04-S1-6-2026年中考已结束，2027届家长现在该做什么？-数据核验清单.md
```

### 类型枚举

| 类型 | 说明 |
|------|------|
| `写作简报` | Step 0 generate_brief 输出 |
| `公众号-初稿` | 公众号平台首发版本 |
| `公众号-终稿` | 人工润色后的最终版本 |
| `小红书-数据冲击篇` | 小红书变形版 |
| `小红书-出路全景篇` | 小红书变形版 |
| `抖音-60秒脚本` | 抖音口播版 |
| `抖音-三组数字版` | 抖音口播版 |
| `B站-教程大纲` | B站教程版 |
| `知乎-深度问答` | 知乎问答版 |
| `数据核验清单` | Step 5 数据核验对照表 |
| `合规检查清单` | Step 8 合规检查 |
| `写作方法论参考` | 通用参考文档 |
| `平台发布规则参考` | 通用参考文档 |

### 通用框架文件（无文章标题）

跨文章复用的框架文档，不使用文章标题字段：
```
00-系列创作规划方案.md
02-平台发布规则参考.md
03-写作方法论参考.md
09-AI内容发布风险评估与应对方案.md
```

**Why:** 2026年8月9日S1系列7篇文章全部创建完毕后统一确立。统一命名后，不打开文件即可从文件名中识别所属文章、类型和用途，便于批量管理和检索。

**How to apply:** 以后创建任何新内容文件时，严格遵循 `{序号}-{文章编号}-{文章标题}-{类型}.md` 格式。[[content-strategy]]
