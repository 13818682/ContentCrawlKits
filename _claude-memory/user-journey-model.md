## 用户旅程增强模型

原始八阶段线性模型存在问题（寻找信任锚点、使用体验、升级、分享在后继环节均有交织），修订为"一主线四贯穿"：

- **主线**: 知晓 → 注册并体验 → 订阅付费 → 升级付费 → 确定结果
- **四贯穿层**: 寻找信任锚点（全程验证）、使用体验反馈（每触点积累）、持续升级动力（价值感知驱动）、分享传播意愿（后期释放为主）

## 家长分享心理

- 主动分享意愿**低**（中考是竞争性事件，信息保密倾向）
- 分享对象限于亲人/同班家长小群，不做公开朋友圈转发
- 分享时机集中在**考试结束后**分享给低年级家长
- 优先引导评论区互动而非直接要求转发
- 所有案例需匿名化处理

**Why:** 中考志愿填报是高度竞争性事件，家长天然保护心理。强推"转发有奖"会适得其反。

**How to apply:** 内容互动设计优先引导收藏和评论区讨论；后期（7-8月）集中投放"复盘经验"类内容引导传播；全平台使用匿名化真实案例模板。[[project-overview]]
