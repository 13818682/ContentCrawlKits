# 学校介绍内容变形指南

## 文档概述

本文档定义如何将已有的学校介绍MD文件（位于 `E:\1.HSEE\1.HSEE-Prj\4.数据导入模板\学校介绍MD文档\`）变形为适合各外部平台发布的内容，同时利用HSEE数据表补充最新结构化数据。

---

## 一、已有资产说明

### 1.1 文件组织结构

```
学校介绍MD文档/
├── 普高/
│   ├── 完整详细版/    ← 每所学校约8000字，7部分深度报告
│   └── 简版速览版/    ← 每所学校约2000字，家长速览版
└── 中职技工/
    ├── 完整详细版/
    └── 简版速览版/
```

### 1.2 完整版内容结构（约8000字）

每所学校的完整详细版MD文件包含7个部分：

| 章节 | 内容 | 适合直接发布 | 适合变形 |
|------|------|:---:|:---:|
| 1. 学校概况 | 名称/类型/区域/创办时间/占地面积 | ✅ 公众号长文 | ✅ 各平台 |
| 2. 招生录取 | 历年AC/D类分数线、招生计划 | ✅ 需HSEE数据表更新 | ✅ |
| 3. 教学特色 | 师资/课程体系/社团/特色项目 | ✅ | ✅ |
| 4. 高考成绩 | 高优率/本科率/知名升学去向 | ⚠️ 需标注数据来源 | ✅ |
| 5. 分班设置 | 分班考/重点班/平行班 | ✅ | ✅ |
| 6. 校园生活 | 宿舍/食堂/校风/校园环境 | ✅ | ✅ |
| 7. 报考建议 | 适合什么样的学生 | ✅ | ✅ |

### 1.3 简版内容结构（约2000字）

从完整版各章节提取核心要点，适合快速浏览。

## 三、五平台变形公式

以"深圳中学"为例：

### 3.1 公众号深度长文（完整版直接发布+数据增强）

**变形操作**：
1. 取完整版MD的全文
2. 从HSEE数据表补充最新数据：
   - `admission_scores` → 更新近3年AC/D类分数线
   - `enrollment_plans` → 更新2026年招生人数
   - `quota_allocations` → 补充各初中分配到的深中指标生名额数
3. 文末添加引导："本文为完整版，更多学校数据可在HSEE小程序查看。下一期想看哪所学校？评论区回复校名。"

**发布节奏**：每周二一篇，建"名校巡礼"系列。

### 3.2 小红书图文（从简版变形）

**变形操作**（耗时15分钟/篇）：
1. 取简版MD
2. 提取3-4个"亮点信息点"：
   - 信息点1：核心数据（录取线、排名）→ 首图
   - 信息点2：特色（"深中的XX项目全国有名"）→ 正文第1段
   - 信息点3：适配人群（"适合自律性强、理科突出的孩子"）→ 正文第2段
   - 信息点4：一个让人记住的细节（"深中图书馆开到晚上11点"）→ 正文结尾
3. 配图：首图用Canva做数据卡片（校名+核心数据），2-3张校园照片（如无版权图可用AI生成示意配图）
4. 标题模板："{数字}{学校名}{亮点}" 如 "574分进深中？2026录取线+分班考+宿舍全揭秘"
5. CTA："完整版（含近3年分数线、分班考详情、指标生名额）→ 主页小程序码"

### 3.3 抖音口播（从完整版提炼）

**变形操作**（耗时10分钟/条）：
1. 从完整版中找1个"让人惊讶的数据或事实"
   - "深圳中学的图书馆，开到晚上11点"
   - "深中2025年AC类住宿生录取线574分，比第二名高出2分"
2. 以此为Hook写300字口播脚本：
   ```
   Hook(0-3秒): "深圳最好的高中到底是哪所？"
   展开(3-40秒): 3个代表性数据点+1个特色
   结尾(40-60秒): "想查看深中完整数据（含分班考、宿舍、指标生）→ 去我主页"
   ```
3. 配AI生成素材或数字人口播
4. 标题："深圳中学到底有多强？3个数据告诉你 #深圳中考 #深圳中学 #2026中考"

### 3.4 B站长视频（多校合辑）

**变形操作**（耗时30分钟/条）：
- 不是单校介绍，而是3-5所学校合成一个主题视频
- 例如"四大名校全方位对比"、"宝安区三所公办高中怎么选"
- 取各校完整版MD的关键数据，做成对比表格和可视化
- 章节结构：①数据总览 ②逐校拆解 ③横向对比 ④适合什么学生 ⑤报考建议

### 3.5 学校速览卡片（通用素材）

**变形操作**（耗时5分钟/篇）：
从简版MD生成一张标准化的"学校速览卡片"：
```
┌─────────────────────────┐
│  🏫 深圳中学              │
│  📍 罗湖区 · 公办普高      │
│  📊 2025录取线 AC:574 D:574│
│  📈 2026招生: AC类1798人   │
│  🏆 梯队: 四大(第1位)      │
│  🎯 特色: 科技创新/学科竞赛 │
│  🏠 宿舍: 4人间/独立卫浴    │
│                           │
│  完整版→ 扫码查看           │
└─────────────────────────┘
```
可直接作为小红书配图、公众号插图、朋友圈转发图。

## 四、数据增强流程

每篇学校介绍发布前，从HSEE数据表补充以下数据（确保比竞品的内容更新、更准）：

| 数据项 | HSEE数据表 | 查询方式 |
|--------|-----------|---------|
| 近3年录取分数线 | `admission_scores` | `WHERE school_name='深圳中学' ORDER BY year DESC LIMIT 3` |
| 2026年招生计划 | `enrollment_plans` | `WHERE school_name='深圳中学' AND year=2026` |
| 指标生名额分配 | `quota_allocations` | `WHERE high_school_name='深圳中学' AND year=2026` |
| 学校基础信息 | `schools` | `WHERE name='深圳中学'` |

> 验证阶段人工查询后粘贴到MD文件中。自建阶段这部分自动化——生成时自动从数据表读取并注入Prompt。

## 五、学校介绍发布优先级

按家长关注度排序，优先发布：

### 第一梯队（四大名校，第1-2周集中发布）
1. 深圳中学
2. 深圳实验学校（高中部）
3. 深圳外国语学校
4. 深圳市高级中学中心校区

### 第二梯队（八大其余四所+热门区属名校，第3-5周）
5-8. 红岭中学、宝安中学、育才中学、深大附中
9-12. 南山外国语高级中学、翠园中学、科学高中、人大附中深圳学校

### 第三梯队（二十大及新校，持续产出）
- 按热度排序，每周2-3所
- 2026年7所新办公办高中优先（新校是家长关注热点）

### 第四梯队（民办、中职，按需产出）
- D类家长和低分段家长最需要的内容
- 中职3+4中本贯通试点校优先

## 六、单所学校发布内容组合

以每所学校为单位，标准输出组合：

| 平台 | 内容 | 频次 | 同校复用 |
|------|------|------|---------|
| 公众号 | 完整版深度长文（更新数据后发布） | 1篇 | 主阵地 |
| 小红书 | 简版图文（3-4个亮点） | 1-2篇 | 不同角度（数据篇/特色篇/适合谁） |
| 抖音 | 60秒口播 | 1条 | 最吸引人的数据点 |
| B站 | —— | — | 不做单校视频，做多校合辑 |
