# 深圳中考内容吸引力与点击率 · 专题调研主报告

## 〇、一句话结论

> **深圳中考内容能不能被点开，不取决于标题写得多"炸"，而取决于标题和正文里有没有一份"能拿走的东西"——总表、名额分配表、排名、换算方法。**
>
> 同一个平台上、同一个题材里，**带可操作数据表的样本，互动量是纯公告复述型的 6~96 倍**（J1 三组同题材对照）。
>
> 这与本号 09-11 实测到的现象**完全一致**：数字型题材点击率 **9.32%**，政策规则型 **4.93%**——**腰斩的原因不是标题，是题材从"数据型"漂移到了"政策型"。**

---

## 一、先划边界：什么是这次调研**能**回答的

| 你的问题 | 能否回答 | 说明 |
|---|---|---|
| 哪些文章**阅读量/点击率高** | 🟡 **部分** | 各平台几乎不公开单篇阅读量与 CTR；只能拿到**替代信号**（知乎赞同/收藏、B站播放、搜狐阅读、腾讯收藏分享） |
| 这些文章的**标题**有什么特点 | ✅ **完整** | 标题 100% 公开 |
| 这些文章的**内容**有什么特点 | ✅ **完整** | 形态、结构、是否含表格均可观测 |
| 这些文章的**长度**有什么特点 | ✅ **完整** | 字数区间可观测 |
| **平台机制/流量池阈值** | ❌ **官方未公开** | ⚠️ 见下方警告 |

### ⚠️ 重要负面结论（J2）

> **8 个平台（头条/公众号/小红书/抖音/知乎/B站/视频号/百家号）无一公开：**
> 流量来源占比、冷启动流量池量级、CTR 阈值、完播阈值、搜索权重公式。
>
> **网上流传的"CTR>3%""完播>40%""四级流量池"全部是第三方经验，不是平台规则。**
> **本仓对外内容与内部 SOP 中不得把这类数字写成平台规则。**

## 二、核心发现（五条）

### 发现 1｜高传播的共性不是"标题党"，是"可操作资产"

J1 对 30 篇样本归纳出的**唯一贯穿性差异**：

| 维度 | 高传播样本 | 低传播样本 |
|---|---|---|
| 形态 | 含**总表 / 名额分配表 / 排名 / 折算方法** | 单一公告复述 |
| 人群 | 明确点名（家长 / 新初三 / **非深户**） | 泛化 |
| 风险 | 可感知（滑档 / 避坑 / 控制线飙升） | 无 |
| 结尾 | 有**下一步行动** | 复述完即止 |

**同题材三组对照（可验证）：**

| 平台 | 高传播 | 低传播 | 倍数 |
|---|---|---|---|
| B站·志愿 | 「预估分数线**可信吗**」播放 **398** | 「志愿填报主要变化」播放 **69** | **5.8×** |
| 知乎·分数线 | 「录取分数线和**数据分析**」赞同 **34**/喜欢 61 | 「志愿填报建议，可作参考」赞同 **1** | **34×** |
| 搜狐·分数线 | 「志愿填报**攻略**（附指标生名额分配表）」阅读 **4,122** | 「第二批分数线公布」阅读 **43** | **96×** |

> ⚠️ 差距可能含账号权重与平台红利，不全是形态功劳。但三组同向，与"可操作资产"假设一致。

**最强单条样本（腾讯新闻·阿莫说择校，2026-06-04）**：
《2026深圳中考指标生数据出炉！控制线飙升，今年又是最难中考年？》
→ **收藏 283 / 分享 51 / 点赞 2 / 评论 2**

> 🔴 **收藏与分享是点赞的 140 倍和 25 倍。** 这说明深圳中考内容的本质是**"工具"**，不是"观点"——家长**存下来备用**，而不是"点赞表达态度"。**衡量这类内容好不好，要看收藏和转发，不是点赞。**

### 发现 2｜长度：高互动长文多在 3000—8000 字

- 高互动长文样本区间：**3000—8000 字**（知乎数据分析类 5000-8000；志愿攻略类 2500-4500）
- 低互动样本：1000—2500 字

> ⚠️ **口径提醒**：上述样本来自知乎/搜狐/网易，**本号头条长文目前约 1850 字**。跨平台不能直接照搬（头条阅读节奏本就更快）。
> **建议**：不直接加长，而是**在现有长度内提高"资产密度"**（表格化、清单化）；若要测长度，用单变量 A/B。

**标准结构（外采归纳）**：
`开头节点/焦虑钩子 → 规则解释 → 分数/学校数据表 → 清单式建议 → 风险提醒`

### 发现 3｜平台分工（本次外采可验证的部分）

| 平台 | 更容易起量的形态 |
|---|---|
| **知乎** | 政策、分数线、志愿策略的**长文与数据汇总** |
| **搜狐号 / 网易号** | **填报节点、录取公布、指标生名额**等时效内容 |
| **B站** | **短视频解释规则和排位** |
| **腾讯新闻创作者** | **指标生数据 + 紧张感 + 表格**（收藏/分享 ≫ 点赞） |
| **抖音** | 家长痛点标题 + **可领取资料**（→ 私域入口） |
| **微信公众号** | 搜一搜是**延迟资产位**：官方答复新发布内容**最长需 48 小时**才能被搜到 |
| **小红书 / 视频号** | 本次未获可核验数据（见 §六） |

### 发现 4｜🔴 D类/非深户：**一个月后再次确认，仍无系统性供给**

J3 结论原文：

> **"尚未看到一个公开数据足够完整、专门只服务 D 类/非深户家长的头部账号。"**

现有供给 = 「官方规则 → 本地宝解释 → 机构/老师咨询 → 贴吧讨论」的**拼接形态**。

**明确缺口（5 项）**：
1. 按**家庭户籍/学籍组合**的个性化资格判断
2. **历年 D 类录取数据库**
3. **跨区/转学情形案例库**
4. **政策变更提醒**
5. 可验证的咨询结果

> ✅ 与 `memory/dcategory-parent-research`（2026-08-08）判断一致。**这不是一次性的观察，是持续一个月的结构空白。**

### 发现 5｜赛道没有绝对头部 —— 这是机会，不是劣势

| 账号 | 平台 | 可核验体量 |
|---|---|---|
| 韩佳奇+7 | 抖音 | 单条 61.7 万喜欢 |
| 深圳升学指南 | 抖音 | **粉丝 6,000** |
| 深圳中考升学老张 | 抖音 | **粉丝 6,000** |
| 深圳初升高莫老师 | 抖音 | 单条 110 喜欢 |
| 中科附高菌 | B站 | 单条播放 723 |

> **抖音垂类账号粉丝普遍在 6,000 量级**，B站垂类播放多在百量级。
> **含义**：深圳中考是个**高度分散、没有垄断者**的赛道。
> 这解释了为什么我们 56 粉能做到单日 4.4 万展现——**平台在给这个赛道放量，而供给端还没接住。**

## 三、📌 标题公式库（可直接套用）

来源：J1 样本归纳 + 外采标题实证。**每条都过合规红线（见 §七）。**

### 公式 1｜节点 + 数字 + 身份提醒
```
【2027届】深圳中考将迎【N】个变化，家长务必先搞清这几件事
```
实证原型：《2025深圳中考的四个变化，家长一定要了解清楚！》

### 公式 2｜结果数字 + 设问（制造"我够不够"的自我对号）
```
深中【570+】！2027年深圳指标生控制线和名额分配表（附全表）
```
实证原型：《深中570+！2026深圳中考指标生控制线和名额分配表重磅发布！》

### 公式 3｜反常识对比 + 真相
```
分数线降【5】分！深中居然和实验同分？深圳中考排位的真相
```
实证原型：《分数线降5分！深中居然和实验同分？2024中考排位真相》

### 公式 4｜清单体 + 附赠资产（**收藏钩子，最推荐**）
```
深圳未来5年要建10万公办高中学位！新建/改扩建完整清单（附各校学位数）
```
实证原型：本次对标文《深圳又要建10万高中学位！2026-2030新建高中完整清单来了》

### 公式 5｜结果焦虑 + 方法（搜索型，长尾最稳）
```
深圳中考：最低多少分能上公办普高？这份路径表照着走
```
实证原型：《深圳中考：最低多少分能读公办普高？怎么冲刺普高？》

### 公式 6｜避坑 + 强地域
```
深圳中考【N】大坑：志愿顺序填错，分数再高也可能滑档
```
实证原型：《深圳中考四大坑》《深圳中考志愿滑档怎么办？不用慌！这些"退路"为孩子兜底！》

### 🔧 组合规则
> **时间节点 + 数字/结果 + （家长风险 | 利益点） + （设问 | 强提醒）**
> 四项不必全占，**但"数字/结果"和"风险/利益"至少要有一项**——两者皆无的标题，在本次样本中全部落入低互动组。

## 四、🔗 与本号数据的交叉验证（本报告最硬的部分）

本号头条数据（2026-09-11 实测，数据源 `docs/15-运营数据/20260908/`）：

| 时段 | 主题材 | 日均点击率 |
|---|---|---|
| 08-22~08-28 | 630／学费差／滑档（**数字冲击型**） | **9.32%** |
| 09-05~09-10 | 政策规则／流程（**政策复述型**） | **4.93%** |

**外采证据**：高传播 = 数据表/资产型；低传播 = 公告复述型。

> ✅ **两条独立证据指向同一结论。**
> **本号点击率腰斩，不是标题能力退化，是选题从"数据型"漂移到了"政策型"。**

**推论（待验证，别当结论）**：
- 09-10 双条实验的低读数（展现 10,798 / 涨粉 0），主因更可能是**账号处于「展现缩量 + 点击率低位」的双重逆风**，而不是"发了 2 条"。
- 但 J2 有一条**官方依据**必须记账：头条明确把"**短时高密度发文**"列为治理对象（2025 年处置投机账号 60 万+）。→ **09-10 双条的结算，仍需 09-11 数据（见 `20260911-09-10双条发布策略评估与同题对标.md`）。**

## 五、内容资产化改造清单（**最高优先级行动**）

把"文章"改成"可收藏的资料"：

| # | 改造项 | 具体动作 |
|---|---|---|
| 1 | **每篇必有一张表** | 长文正文中至少 1 张可截图的表格（分数线表 / 学位数表 / 对比表 / 时间表） |
| 2 | **每篇必有一个"附"** | 标题或结尾承诺可拿走的东西：「附全表」「附名额分配表」「附清单」 |
| 3 | **每篇必点名人群** | 明写"非深户/深户""新初三""边缘生""2027届" |
| 4 | **每篇必有下一步** | 结尾给可执行动作，不停在"信息已完成" |
| 5 | **收藏钩子进标题** | 「完整清单」「收藏版」「一张表搞定」 |
| 6 | **把已有资产表格化** | 本号独占的**录取线数据库**还没变成可截图资产 → 这是最大未开发项 |
| 7 | **拉长到 2500-3500 字** | 头条长文从 ~1850 提上来（**单变量测**，别一次改多个） |

## 六、下一步：需要你补的三块（外采拿不到）

| # | 缺口 | 为什么外采拿不到 | 建议动作 |
|---|---|---|---|
| 1 | **小红书 / 视频号 / 抖音 垂类账号** | 公开网页不展示粉丝与作品数据 | 在各 App 内搜"深圳中考"，人工记 10-20 个账号的粉丝量 + 单篇赞藏 |
| 2 | **本号评论区的高频问题** | 头条评论外采抓不到 | 从后台导出评论，与 J4 的 52 问对照，看**真实用户**与**外部样本**差在哪 |
| 3 | **本号逐条题材点击率** | 只有后台有 | 周日数据出后，给近 30 天内容打题材标签，算逐条 CTR，形成**本号题材 CTR 排行榜** |

> 第 3 项是本次调研的**闭环关键**：外采告诉我"什么形态看起来有效"，只有本号数据能告诉我"在本号、在本平台，什么真的有效"。

## 七、⚠️ 合规红线（写进标题公式的硬约束）

各平台**均明确禁止**以下行为（J2 官方来源）：

| 红线 | 依据 |
|---|---|
| **标题/封面与内容不符** | 头条（标题党/封面党→停止推荐）、视频号（标题误导）、百度（标题须真实） |
| **夸大诱导点击** | 知乎社区规范明确列为限制流通情形 |
| **短时高密度发文** | 头条官方治理对象 |
| **站外导流 / 恶意营销** | 知乎、抖音、视频号均明确禁止 |
| **绝对化用语** | （广告法）"最""第一""百分百""包录取" |

> **标题公式库中的每一条，都不得越过以上五条。**
