## 二、🔴 D类 / 非深户方向的供给评估（本次最重要的发现）

> **有账号在做，但公开可核验的系统性供给主要来自官方和本地信息服务号——尚未看到一个公开数据足够完整、专门只服务 D 类/非深户家长的头部账号。**

| 在做的人 | 做到什么程度 |
|---|---|
| **深圳本地宝 / 本地宝深圳升学** | **相对最系统**：政策解释 + 逐校数据 + 节点更新；偏工具型信息服务 |
| **深圳市招考办 / 深圳教育** | **最权威、覆盖最完整**；但不是围绕 D 类运营的内容品牌 |
| **深圳中高考提分丁老师** | 以深户/非深户分数差异为切口；样本视频播放 36，**不能称头部** |
| **深圳职校通** | 面向中职路径，覆盖低分与非传统升学路线；更像咨询线索型供给 |

**现有供给形态 = 「官方规则 → 本地宝解释 → 机构/老师咨询 → 贴吧讨论」的拼接。**

**明确缺口：**
1. 按**家庭户籍/学籍组合**的个性化资格判断
2. **历年 D 类录取数据库**
3. **跨区/转学情形案例库**
4. **政策变更提醒**
5. 可验证的咨询结果

## 三、官方内容的传播规律（推断，非核验）

官方账号公开页面**几乎不提供**阅读/点赞/转发数据，因此**不能严谨地说哪篇传播量最高**。只能按**家长需求强度 + 传播结构**判断：

| 高价值内容类型 | 为什么 |
|---|---|
| **成绩查询与录取结果** | 时间刚性强、家长必须行动 |
| **志愿填报问答/流程** | 规则复杂且直接影响录取；"20个问答"适合收藏转发 |
| **非深户/D类资格与分数线** | 身份差异带来高焦虑和高搜索，需逐条核对 |
| **分批次录取、自招、指标生与补录节点** | 错过节点成本高，官方信息具唯一权威性 |
| **学校招生简章/考核安排** | 目标学校家庭有明确行动需求，招生季集中传播 |

**值得监控的官方号**：深圳教育、深圳市招生考试办公室、各区教育局政务矩阵、目标高中官方公众号。
