## 三、用户分层的关注差异

| 分层 | 关注差异 |
|---|---|
| **深户(AC) vs 非深户(D)** | 深户问"户籍优势是否还在、指标生校内竞争怎么避"；**D类问报名资格、社保/学籍审核、D类单独录取线、公办机会、保底路线**。公开讨论反复以 AC/D 类分数线与"**同校不同线**"为核心比较对象。 |
| **高分段（冲四大八大）** | 关注"稳不稳"、名额分配能否低分录取、**校内排名与指标生撞车**、名校普通班 vs 次名校重点班。情绪=怕"差几分"+怕进名校跟不上。 |
| **中分段** | 去年线与模考如何换算、学校梯度、管理与高考出口；"能否上十五大/二十大"与稳妥性并列考虑。 |
| **边缘生** | **有没有公办保底、填高会不会滑档、第二次划线与民办/中职补录能否兜底**；会细问新高中、走读调剂、最低线。 |
| **职校或国际路线** | 中职三二分段、3+4 中本贯通、专业就业与升学通道、学费；国际路线关注课程体系、费用、海外申请、是否需提前转轨。 |
| **初三家长** | 短期决策密集：报名、体育/听说/实验、模考定位、志愿梯度、录取与补录。 |
| **初一初二家长** | 更早问**生地会考、三年学籍/名额分配资格、自主招生与特长方向、体育长期训练**。 |
| **小学高年级家长** | 公开可核验的直接发言较少；可确认的准备方向是户籍与学籍规则、初中选择、体育习惯、长期学科基础。**不能据此断言真实搜索量。** |

## 四、情绪点

**焦虑点**
- "564分，深中有希望吗？"——典型的差几分/是否稳录焦虑。
- 体育中等偏下，"根本不敢想满分"，担心体育拖总分。
- 模考发挥失常、志愿全填高，担心"孩子无学可上"。
- D类担心同校竞争却面对不同计划和录取线。

**愤怒点**
- 对深户/非深户分数线差异、个别年份出现**倒挂**的质疑。
- 对**志愿填报复杂、信息不对称、付费"大神"是否可靠**的不满。
- 对学校管理、住宿条件与宣传信息不透明的抱怨。

**希望点**
- 相信按要求持续锻炼，体育中等生也可能从焦虑走到满分。
- 滑档后仍希望通过第二次划线、民办普高、中职、国际路线找到 **Plan B**。
- 希望通过指标生、自主招生和合理避开校内竞争进入更合适的学校。

## 五、内容供给缺口（6 个）

| # | 缺口 | 为什么被反复问 |
|---|---|---|
| 1 | **按 AC/D 类、区、学校、年份统一维护的录取线与招生计划数据库**，并能解释分数线倒挂原因 | 家长反复问"同校不同线"和 D 类到底多难，但公开内容常是单年表格或经验判断 |
| 2 | **基于校内排名分布的名额分配模拟器**，而不只是公布控制线 | 公开经验明确提醒"达到控制线不等于一定录"，但家长缺校内竞争情景测算 |
| 3 | **模考分数 → 中考分数的分段、学科组合与不确定性换算方法** | 家长会问一模二模能否直接对应学校线，但可复核的长期样本少 |
| 4 | **把学校管理强度、班型、住宿/通勤、学费、高考出口放在同一张可比表** | 志愿问答提醒要考虑这些因素，却很少提供统一、可验证、可按家庭情境筛选的资料 |
| 5 | **体育、英语听说、理化实验的官方评分细则 + 低风险训练方案** | 家长既担心分值又担心报班和运动损伤；媒体案例能安抚情绪但不是逐项目操作指南 |
| 6 | **滑档后的真实时间线、可报学校清单、费用和学籍限制的一站式 Plan B** | 官方给出补录规则，但家长仍要在多个页面间拼接民办、中职、复读和国际路线信息 |

> **缺口 1 / 2 / 4 正是本号独占优势所在**（自有录取线数据库 + 跨校可比数据表），与 `memory/dcategory-parent-research` 的判断一致。
