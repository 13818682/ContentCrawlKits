## 二、四条形态结论

### 结论 1｜高传播标题 = 时间节点 ＋ 数字/结果 ＋ 风险或利益 ＋ 设问/强提醒

可套用公式（原样引自样本归纳）：
- ①「【时间】深圳中考【数字】个变化，家长一定要了解清楚！」
- ②「【学校/指标生】控制线【结果数字】！今年会不会更难？」
- ③「志愿填报【必看/避坑】：附【表格/名额分配表】。」

**实际样本印证**：
- 「满分610分！想上名校要多少分？」= 硬信息 + 追问
- 「分数线降5分！深中居然和实验同分？…真相」= 数字 + 对比 + 悬念
- 「深中570+！…控制线和名额分配表重磅发布！」= 结果数字 + 重磅 + 表
- 「最低多少分能读公办普高？怎么冲刺普高？」= 结果焦虑 + 方法

### 结论 2｜长度与结构

- **长文高互动样本多为 3000—8000 字**
- 标准结构：**开头节点/焦虑钩子 → 规则解释 → 分数/学校数据表 → 清单式建议 → 风险提醒**
- 短视频用**标题设问或冲突点**承载信息；页面通常不公开口播字数

> 🔴 **对本号的直接提示**：本号头条长文目前约 **1850 字**，**低于外采高互动样本区间**。

### 结论 3｜平台题材倾向

| 平台 | 更容易起量的形态 |
|---|---|
| 知乎 | 政策、分数线、志愿策略的**长文与数据汇总** |
| 搜狐号 / 网易号 | **填报节点、录取公布、指标生名额**等时效内容（可见阅读/跟贴） |
| B站 | **短视频解释规则和排位** |
| 腾讯新闻创作者 | **指标生数据 + 紧张感 + 表格**；公开**收藏/分享显著高于点赞** |

### 结论 4｜低传播 vs 高传播的形态差异（**最重要**）

> 同为分数线/志愿题材，**高传播样本通常增加三样东西**：
> 1. **可操作资产**：总表、名额分配表、排名、折算方法
> 2. **明确人群**：家长 / 新初三 / 非深户
> 3. **可感知风险**：滑档、避坑、控制线飙升
>
> **低互动样本**多为**单一公告复述**或**标题泛化**，缺少表格 / 比较 / 下一步行动。
