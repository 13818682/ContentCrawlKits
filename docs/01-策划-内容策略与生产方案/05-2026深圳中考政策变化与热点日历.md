# 2026深圳中考政策变化与内容热点日历

## 文档概述

本文档按月梳理2026年深圳中考相关的政策发布时间节点和对应的内容热点选题。作为全年选题排期的基础参考，确保内容生产和政策节奏同步。

数据来源：深圳市教育局官网（szeb.sz.gov.cn）、深圳招考网、历年政策发布时间规律。

---

## 一、2026年关键政策变化速览

| 变化项 | 旧规则 | 新规则（2026年） | 内容关键词 |
|--------|--------|----------------|-----------|
| 总分调整 | 610分 | **630分**（理化实验操作各+10分） | 多出来的20分、理化实验 |
| 道法考试 | 闭卷合卷 | **开卷分科**（历史/道法分开考） | 开卷怎么复习 |
| 体育中考 | 考两项 | **考三项**（耐力+技能+球类，过程性评价14分） | 体育改革、新增项目 |
| 第一批志愿 | 12个普高 | **12个普高+4个中职试点**（共16个） | 16个志愿怎么填 |
| 走读调剂 | 无 | **新增选项**（7,455个走读计划） | 走读勾不勾 |
| 3+4中本贯通 | 无 | **试点启动**（一职/二职，300个名额） | 中职直通本科 |
| 新公办高中 | — | **7所首次招生** | 新学校解读 |
