# 内容发布合规检查清单

## 文档概述

本文档是HSEE内容创作平台的内容发布合规底线手册。每篇内容发布前必须通过本清单检查。

### 适用范围

所有发布到外部平台（小红书/抖音/B站/公众号/头条）的内容，以及同步到HSEE小程序的内容。

---

## 一、AI生成内容标识（硬性法规要求）

**法规依据**：《人工智能生成合成内容标识办法》（2025年9月1日施行），国家互联网信息办公室、工业和信息化部、公安部、国家广播电视总局联合发布。

### 1.1 显式标识（第4条）

| 内容类型 | 标识方式 | 示例 |
|---------|---------|------|
| **图文内容**（小红书/公众号/头条） | 文末添加文字提示 | "⚠️ 本文由AI辅助生成，数据经人工核验" |
| **短视频**（抖音/B站） | 视频末尾画面或评论置顶 | "本内容由AI辅助制作" |
| **音频内容** | 音频末尾语音提示 | —（验证阶段不涉及） |

**位置要求**：
- 文本类：文末最后一行，字号不小于正文
- 视频类：结尾画面停留≥2秒

### 1.2 隐式标识（第5条）

发布到HSEE小程序的内容在存入数据库时自动注入元数据：

```json
{
  "ai_generated": true,
  "provider_code": "HSEE-CCP-001",
  "content_id": "{自动生成}",
  "generation_model": "doubao-pro-32k",
  "created_at": "{自动生成}"
}
```

验证阶段人工发布到外部平台时，平台自身不会记录隐式标识。自建阶段通过蚁小二API分发时，在文件元数据中注入。

### 1.3 禁止行为（第10条）

- ❌ 不得删除、篡改、伪造、隐匿AI生成标识
- ❌ 不得为他人删除标识提供工具或服务
- ❌ 不得通过不正当标识手段损害他人合法权益

违反后果：网信、电信、公安、广电四部门联合执法，按各自职责处罚。

## 二、内容红线（禁止事项）

### 2.1 预测类禁止

| 禁止 | 正确做法 |
|------|---------|
| "今年XX学校的录取线应该在575分左右" | "2025年该校录取线为574分（AC类住宿生），今年数据以教育局公布为准" |
| "你家孩子这个分数肯定能上XX学校" | "你的分数在这个区间，近3年录取线在这个范围内的学校有XX、XX、XX" |
| "今年指标生大概能降20分" | "2025年XX学校指标生录取线比正取低18分，今年情况可能会有所不同" |

**核心原则**：只引用已发生的、官方已公布的数据。不对未来结果做任何形式的预测或承诺。

### 2.2 承诺类禁止

| 禁止 | 正确做法 |
|------|---------|
| "保证录取""100%上岸" | 全文绝对不出现这种词汇 |
| "按照这个方案填，稳进" | "这个方案基于近3年数据设计，可以作为参考，最终决策请结合最新官方信息" |
| "内部渠道""特殊名额" | 绝对不出现。你的数据全部来自公开信息 |

### 2.3 虚假信息禁止

- 不得编造学校名称、分数线、招生人数
- 不得编造"某家长""某学生"的真实经历（可以匿名化案例，但必须基于真实事件改编）
- 引用政策时必须标注来源和发布时间，不得引用已废止的政策

### 2.4 免责声明（每篇必加）

```
免责声明：本文内容仅供参考，不构成任何录取承诺。文中数据来源于深圳市教育局公开信息及HSEE数据平台整理。志愿填报最终决策请以深圳市招生考试办公室发布的最新官方文件为准。
```

## 三、采集合规

### 3.1 采集行为规范

| 规则 | 具体要求 |
|------|---------|
| 采集目的 | 仅用于选题调研和行文结构参考，不得直接搬运商用 |
| 采集频率 | 间隔≥12秒/条，不突破平台反爬机制 |
| 采集范围 | 仅抓取公开可见内容，不抓取付费/私密内容 |
| 反爬声明 | 如平台或账号明确设置了反爬声明，不抓取其内容 |
| 内容时效 | 仅抓取近3个月内容 |

### 3.2 使用规范

- 采集内容与发布内容的语义相似度必须<30%
- AI改写后必须进行"深度重构"——同义词替换不够，需要换结构、换角度、换观点
- 采集的每一篇素材都保留操作日志：来源URL、采集时间、用途（哪个选题参考）、改写后内容ID

## 四、个人信息保护

你的平台不收集用户个人信息（用户数据在HSEE侧），但内容中引用的案例需要注意：

| 规则 | 具体做法 |
|------|---------|
| 案例匿名化 | 不出现真实姓名、具体学校班级、可识别身份的信息 |
| 引用家长反馈 | 必须获得授权，且做脱敏处理 |
| 评论区互动 | 不要求用户在评论区留下个人信息（如分数、学校），用私信或HSEE小程序处理 |

## 五、发布前检查清单

每条内容发布前对照：

### A. AI标识检查
- [ ] 文末/视频末尾有AI辅助生成标识
- [ ] 标识文字清晰可见，未被裁切或遮挡

### B. 内容红线检查
- [ ] 无"保证录取""100%""一定"等绝对化表述
- [ ] 无预测分数线、预测录取结果的表述
- [ ] 无"内部渠道""特殊名额"等违规话术
- [ ] 所有引用的数据来自HSEE数据表或官方公开信息
- [ ] 免责声明已添加

### C. 数据准确性检查（抽查）
- [ ] 文中引用的学校名称正确
- [ ] 文中引用的分数线与HSEE数据表一致
- [ ] 文中引用的招生人数与HSEE数据表一致
- [ ] 文中引用的政策规则为当前有效版本

### D. 原创性检查
- [ ] 与竞品原文对比，结构和表述明显不同
- [ ] 有自己的差异化观点或独家数据
- [ ] 没有直接搬运竞品的大段文字

### E. 转化合规检查
- [ ] HSEE引导入口自然嵌入，不强制、不诱导
- [ ] 不虚假宣传HSEE的服务能力
- [ ] 追踪参数配置正确
