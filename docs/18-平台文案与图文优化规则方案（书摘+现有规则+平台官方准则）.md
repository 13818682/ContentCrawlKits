## 一、总纲：四平台统一优化框架

### 1.1 每个平台只回答四个问题（对齐北极星）

| 问题 | 对指标的杠杆 | 主战场 |
|---|---|---|
| ① 让平台**愿意推** | 点击率 / 完播(读)率 / 互动率 / 原创度 / 无违规 | 算法友好层 |
| ② 让用户**愿意点** | 标题 + 封面（含首图） | 点击层 |
| ③ 让用户**读得完、存得住** | 开头钩子 + 信息结构与密度 + 排版 | 完读/收藏层 |
| ④ 让用户**关注并回访** | 人设/价值/系列/确定性 CTA | 信任层 |

### 1.2 跨平台共性提升点（四平台都适用）

1. **标题/封面必须"表里如一"**：四平台官方均把"标题党、标题与正文严重不符"列为治理对象（官：微信运营规范4.11、头条"标题低质"、小红书"首图标题党/图文不符"、抖音"夸张标题"）。→ 我们封面 C 系列"一句话触发点"（记忆 C1/C5）方向正确，但须补一条：**触发句必须能在正文前 100 字/首屏兑现**，防"封面承诺-正文不接"被判定擦边。
2. **开头 3 行/前 2 秒给核心结论**（书：AIDA·兴趣→渴望、公众号精简"结论前置"；规：13-1/13-3/13-4 均已内建；官：各平台偏好"信息增量与直接表达"）。→ 已生效，作为共同基线。
3. **信息增量 = 抗"模板化/低质"治理的唯一解**：四平台都在治理"批量同质、套路模板、无增量"内容（官：微信3.28套路化模板、头条流量作弊、小红书批量发布、抖音拼接无实质内容）。→ 我们 AI 批量生产必须**每篇带人工本地增量**（本地数字、政策细节、口语案例），并满足 04 的 AI 标识。**把"人工增量"从可选变成生产环节强制项（P0）**。
4. **教育垂类 = 专业背书**：抖音明文鼓励教育等专业领域账号认证核验、头条要求健康/财经等资质、微信对"假借官方/专家名义"从严（官）。→ **用平台专业认证/简介背书替代文案内的"专家语气"**（P1，运营侧）。
5. **站外导流全平台收紧**：小红书最严（联系方式/二维码/水印全禁），抖音禁第三方水印与恶意导流，微信治诱导关注/违规导流，头条治附联系方式转线下（官）。→ 现有"搜一下HSEE/文末非门槛导流"口径继续执行（规：04A §3、13-3 合规）。

### 4.5 "让平台多推我们"的动作

- 评论勤回、私信合规转化（0 站外引流词）；参与官方"笔记灵感"活动话题拿流量扶持（书§4.2）。
- 敏感点：D类/非深户等分区内容用"风控语言"，**不做 AC/D 群体对立叙事**（官：官方"反对制造对立"），与规04 §2 一致。

## 五、抖音

### 5.1 目标与考核
原生视频拉新（北极星：完播率；辅助：2s 跳出、主页访问、搜索占比）。已生效基线：13-4（黄金档 50-75 秒/220-300字/开头大字≤12字/钩子前 2 秒兑现）、16 §2（单点·减负·确定性 CTA）、记忆 douyin-safe-area（底 1/6 + 右 1/10）。

### 5.2 文案（口播）与标题
| 建议（草案） | 级别 | 依据 |
|---|---|---|
| 维持 13-4"开头大字=答案"结构；**对每条先问"这一条让观众记住哪 1 个点"**，记不住就拆条（16 单点化） | P0 | 规13-4/16 |
| 标题 10-15 字含情绪词但**不得夸大/与内容不符**（官抖音"夸张标题"）；"反常识/数据冲击"钩子必须真，禁"标题党炒作/引战式营销"（官自律公约第33条） | P0 | 官抖音 |

| 真人出镜/讲解导向（官"真实表达·避免虚假人设伪纪实"）：数字人可用但标注 AI；不做"卖惨/演戏炒作"式考生叙事（官自律公约第23条） | P0 | 官抖音 |
| 画面/文案中不出现**第三方水印/logo/站外账号信息**（官第34条恶意导流）；我们数据卡自带角标属自有品牌，无碍 | P0 | 官抖音 |

### 5.4 "让平台多推我们"的动作
- **申请平台专业认证**（官自律公约第36条：教育等专业账号应认证核验）→ 增权重与信任，也减少政策内容被判"无资质"风险（P1，运营侧）。
- 发布节奏固定、垂直；冷启动用"完播引导"而非"点赞刷量"（书小红书冷启动经验可迁移：先完播再互动，官方反作弊）。
- 抖音→头条默认同步（16 §6），不需重做。
