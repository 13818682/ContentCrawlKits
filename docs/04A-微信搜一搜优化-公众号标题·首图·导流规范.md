# 微信搜一搜优化 · 公众号标题/首图/导流规范（04 合规补充）

> 用途：正文标题、封面首图、文末导流在"被搜到 + 不踩红线"之间的统一口径。
> 来源三篇：
> 教程01《如何让公众号文章获取更多搜索流量》、教程02《为什么搜不到（10 个自检因素）》、教程03《昵称/描述/菜单提升帐号流量》。

## 一、官方结论速查（写稿前必看）

| 维度 | 官方要求 | 我们落地 |
|---|---|---|
| 标题 | 清晰直接、含主旨与关键信息；不标题党、不堆关键词/修饰词；别太长被截断 | → §2 标题模板 |
| 原创 | 同质内容下搜一搜优先展示"声明原创" | 每篇发布时勾选原创 |
| 正文 | 主题单一、有论据、可操作；分段+小标题；适度加粗核心句 | 标题小节＝用户会搜的词 |
| 图频文 | 必须配文字介绍（帮助索引） | 卡与文案 md 成对，保持 |
| 红线 | 裂图/水印/白边/模糊；前置广告；需登录/关注/跳转才见完整内容；批量统一导流 | → §3 导流规范 |
| 取巧 | 隐藏字、堆词、堆地域名、模板批量、小窗堆字 | 禁止，一律不采用 |
| 账号 | 昵称避开通用词；描述讲清功能；菜单用具体功能名；建议认证 | → §5 账号层待办 |

## 二、标题模板（发布时建议，非品牌叙事题）

**公式**：`深圳中考＋[用户会搜的主题词]＋[一句承诺/限定]`；整题 ≤ 约 30 字；不叠加多个关键词。

| 内容 | 建议发布标题 |
|---|---|
| P1-1 全景 | 深圳中考志愿填报怎么入门？先看懂录取规则再动手 |
| P1-2 630构成 | 深圳中考630分怎么算？语数英物化只占440？一文讲清 |
| ACD（拟独立篇） | 深圳中考ACD三类考生是什么？D类（非深户）能报哪些学校 |
| 志愿顺序/批次 | 深圳中考志愿顺序填错会怎样？"分数优先、按志愿"怎么录 |
| 时间线 | 深圳中考全年时间表：报名到录取，哪个月做什么 |
| 问答-滑档 | 深圳中考滑档去了排名40的高中怎么办？3个补救思路 |

> 说明：标题在公众号后台发布时最终定稿；本表与 md 正文标题并存，md 不改，发布复制用本表。
> 系列感（政策解码器）通过合集/话题标签体现，**不靠标题前缀占字**（官方鼓励清晰直接）。

## 三、文末导流规范（防"恶意引流/获取成本高"）

- ❌ 不写"打开小程序才看到完整数据/完整结果"（正文内信息要先给全）。
- ❌ 不在每篇结尾重复同一种强导流句式。
- ✅ 口径：核心数字已在正文给全并标注官方来源；小程序只作**增值检索**、非门槛。
- ✅ 已改示例（P1-1）：
  > 文中的核心数字都来自深圳市教育局官方发布，并逐条核对。想按某所学校继续查历年录取分数线，可用 HSEE 小程序自行检索。
- 已执行范围：P1-1（公众号精简/极简/终稿/头条长文/瘦身）、P1-2（公众号精简/头条长文/瘦身），共 9 个 md。初稿文件保留历史未动；P1-3 及后续新稿套用本句模板。

## 四、首图规则升级：信息前置（封面 v2.0）

> ⚠️ **适用范围：仅公众号首图**。头条/小红书封面维持各自原有风格，**不套用"信息前置/搜索向"设计**——本套优化目标就是微信搜一搜召回，跨平台场景不同。

在「一句话触发点」（记忆 `simplified-design-rule`）之上叠加：
- **主句以「深圳中考＋本篇主题关键词」开头**（志愿填报 / 630构成 / ACD / 批次 / 时间线 / 滑档…），情绪钩子降为第二行金句或并入承诺行。
- 封面不再只有情绪句（如"考得好≠填得好"需配主题），保证分享卡/列表里一眼知道"讲深圳中考哪件事"。
- 主句含"深圳中考"字样时，可省顶部地域标识；不含则保留顶部「深圳中考」金字标识（C4）。
- 手机可读：900 画布最小正文字 ≥ 20px；四边留安全边距防搜索结果/分享卡裁剪；无白边/水印；长图文字加大防压缩糊。

## 五、账号层待办（运营后台，本文案暂不执行）
- 简介：写清"深圳中考政策＋志愿填报原创解读"，不用通用词。
- 菜单：具体功能名（如"历年分数线""志愿规则""指标生"），不要"更多服务/办事大厅"类宽泛名；功能树覆盖主要栏目。
- 认证：主体/商标认证提升权威度排序（视运营进度）。
- 搜不到自检：昵称全称搜 → 等 1 天 → 检查"禁搜"设置 → 仍不行经"微信搜一搜助手"公众号申诉。
