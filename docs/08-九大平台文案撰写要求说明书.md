# 九大平台文案撰写要求说明书

## 文档概述

本文档面向HSEE内容创作平台，定义微信公众号、B站、小红书、抖音、微博、知乎、快手、百度贴吧、今日头条九大平台的文案撰写规范。文档包含各平台用户画像、文案要求、标题策略、语气风格和可直接使用的AI提示词模板。

### 适用场景

编辑准备好基础素材（选题角度+核心数据+案例素材）后，按本文档选择目标平台的提示词模板，发送给AI平台生成初稿，再进行人工润色发布。

## 第一章：AI内容创作平台推荐

### 1.1 推荐平台速览

| 平台 | 适用场景 | 费用 | 推荐指数 |
|------|---------|------|:---:|
| **豆包** (doubao.com) | 自媒体文案批量生成，中文能力强，多风格适配 | 免费额度充足 + API按量¥0.8/百万token | ⭐⭐⭐⭐⭐ |
| **DeepSeek** (chat.deepseek.com) | 深度长文、政策解读、逻辑推理型内容 | 免费 + API按量极低 | ⭐⭐⭐⭐⭐ |
| **Kimi** (kimi.moonshot.cn) | 超长文本处理（20万字上下文），适合公众号深度长文 | 免费额度 + API按量 | ⭐⭐⭐⭐ |
| **智谱清言** (chatglm.cn) | 结构化内容输出，数据表格型文案 | 免费额度 + API | ⭐⭐⭐⭐ |
| **通义千问** (tongyi.aliyun.com) | 多模态内容（图+文联动） | 免费额度 + API | ⭐⭐⭐ |

### 1.2 各场景推荐

| 场景 | 首选 | 备选 |
|------|------|------|
| 小红书笔记（短文+emoji） | 豆包 | DeepSeek |
| 抖音口播脚本 | 豆包 | Kimi |
| 公众号深度长文 | DeepSeek / Kimi | 豆包 |
| B站长视频文案 | Kimi（长上下文） | DeepSeek |
| 知乎专业回答 | DeepSeek | 智谱清言 |
| 微博热点短文案 | 豆包 | 通义千问 |
| 数据分析报告 | 智谱清言 | DeepSeek |
| 多平台批量变形 | 豆包（批量API） | — |

### 1.3 使用建议

- **验证阶段**：优先用免费网页版，日均20篇以内足够
- **自建阶段**：接入豆包API（按量计费，国产模型数据不出境）+ DeepSeek备用
- **不推荐**：ChatGPT/Claude直接用于中文自媒体内容——中文语气和平台风格适配不如国产模型

## 第二章：九大平台逐一说明

### 2.1 微信公众号

#### 用户画像

| 维度 | 特征 |
|------|------|
| 用户规模 | 月活13亿+，覆盖全年龄段 |
| 核心用户 | 30-50岁职场人士、家长群体、中产家庭 |
| 使用场景 | 深度阅读、信息获取、工作学习 |
| 内容消费习惯 | 主动订阅，忠诚度高，朋友圈/微信群二次传播 |
| 阅读时间 | 通勤、午休、晚间，单篇阅读时长3-8分钟 |

#### 文案撰写要求

| 要素 | 规范 |
|------|------|
| **字数** | 1200-2500字。低于800字缺乏深度感，超过3000字完读率骤降 |
| **结构** | 导语（痛点引入）→ 正文（2-4个小标题分段）→ Q&A或总结 → CTA引导 |
| **标题** | 15-25字，数字+痛点+解决方案。禁止标题党——公众号用户反感"震惊体" |
| **语气** | 正式中带温度。不能说教，也不能太随便。"专业但不高冷" |
| **排版** | 段落短（手机屏3-4行一段），重点加粗，配数据表格截图，段落间留白 |
| **配图** | 封面图2.35:1，正文每300-500字配一张图 |
| **转化设计** | 文末小程序卡片/阅读原文/二维码 |

#### 标题公式

```
模板1：数字+痛点+解决方案
  "深圳中考冲稳保怎么填？3步搞定，附16个志愿分配模板"
模板2：提问+权威答案
  "孩子一模考了550分能上什么高中？近3年数据告诉你"
模板3：场景+认知反差
  "90%的家长都不知道：指标生不是'降分录取'这么简单"
```

#### AI提示词模板

```
你是微信公众号深度长文作者。目标读者是深圳初三家长（35-45岁），
他们关心孩子升学，有一定教育程度但非教育专业人士。

【写作要求】
- 字数：1500-2000字
- 风格：专业但不学术，有温度但不煽情。像一个资深升学规划师在跟家长聊天
- 结构：导语引入痛点 → 展开3-4个要点（每个要点配小标题）→ 实用建议 → 文末总结
- 标题要求：15-25字，包含数字和痛点关键词
- 排版要求：段落短（每段不超过4行手机屏），重点内容用**加粗**标记
- 数据引用：所有数据必须标注来源
- 禁止：标题党、恐吓式营销、"保证""100%"等绝对化词汇

【本次选题和素材】
{粘贴基础素材}

请输出：
1. 3个备选标题
2. 完整正文（含小标题）
3. 文末引导语
```

### 2.2 B站

#### 用户画像

| 维度 | 特征 |
|------|------|
| 用户规模 | 月活3.4亿+ |
| 核心用户 | 15-30岁，Z世代为主。男性略多于女性（约55:45） |
| 使用场景 | 学习教程、深度内容、兴趣圈子、娱乐消遣 |
| 内容消费习惯 | 愿意看长内容，对质量要求高，弹幕互动活跃 |
| 视频时长偏好 | 教育类内容：8-15分钟最佳 |

#### 文案撰写要求

| 要素 | 规范 |
|------|------|
| **视频文案结构** | 开头30秒（吸引+预告）→ 正文分章节展开 → 结尾（总结+互动引导） |
| **口播风格** | 口语化但不随意。讲清楚逻辑，但不能像读稿。"像给朋友讲一个你很懂的话题" |
| **标题** | 10-20字，教程感+价值承诺。好的B站标题让用户觉得"看完我就能学会XX" |
| **弹幕预埋** | 在文案中标注"此处可预埋弹幕"，设计互动点 |
| **章节标记** | 视频说明区列出时间戳+章节标题 |

#### 标题公式

```
模板1：价值承诺型
  "从零搞懂深圳中考志愿填报：看完这个视频就够了"
模板2：对比/排名型
  "深圳四大名校全方位对比：深中vs实验vs深外vs高级"
模板3：问题解决型
  "深圳中考志愿填报最容易犯的5个错误，一次讲清楚"
```

#### AI提示词模板

```
你是B站知识区UP主。你的观众是想系统学习某件事的年轻人。

【写作要求】
- 视频时长：8-12分钟
- 口播风格：口语化，"你"字打头的对话感。像面对面教朋友
- 结构：
  ① 开头30秒：抛出一个观众关心的痛点+预告本期内容
  ② 正文分3-5个章节，每章2-3分钟
  ③ 结尾30秒：总结要点+引导点赞投币收藏
- 弹幕设计：在合适位置标注"此处可预埋弹幕：XXX"
- 标题要求：包含"教程/攻略/指南"感，10-20字
- 说明区：列出视频章节时间戳

【本次选题和素材】
{粘贴基础素材}

请输出：
1. 视频标题
2. 完整的口播文案（标注章节）
3. 弹幕预埋建议（3-5处）
4. 视频说明区文字（含章节时间戳）
```

### 2.3 小红书

#### 用户画像

| 维度 | 特征 |
|------|------|
| 用户规模 | 月活3.4亿+ |
| 核心用户 | 19-35岁女性（占比约70%），一二线城市 |
| 使用场景 | 搜索生活攻略、消费决策参考、碎片化阅读 |
| 内容消费习惯 | 搜索+推荐双驱动，注重真实感和实用性 |
| 阅读时间 | 碎片化，单篇浏览30-90秒 |

#### 文案撰写要求

| 要素 | 规范 |
|------|------|
| **字数** | 300-700字最佳。超过1000字完读率断崖下跌 |
| **结构** | 痛点钩子 → 3-4个要点（用emoji分区）→ 个人建议/总结 → 话题标签 |
| **标题** | 15-20字，数字+痛点+解决方案，可用emoji点缀 |
| **语气** | "闺蜜分享"感。真实、接地气、不说教。避免"小编""笔者"等官方自称 |
| **配图** | 3-9张图，首图最重要——必须带文字标题，决定点击率 |
| **话题标签** | 5-8个精准标签，#深圳中考 #深圳教育 等 |
| **互动引导** | 结尾用提问引导评论："你家孩子准备得怎么样了？评论区聊聊" |

#### 标题公式

```
模板1：数字+结果
  "孩子一模550分，靠这个方法进了公办普高"
模板2：避坑提醒
  "深圳中考填志愿前，这3个坑千万别踩！"
模板3：信息差
  "99%的深圳家长不知道：指标生可以这样用"
模板4：清单体
  "深圳中考家长必存！志愿填报10项自检清单"
```

### 2.6 知乎

#### 用户画像

| 维度 | 特征 |
|------|------|
| 用户规模 | 月活约8300万（2024年，同比↓21%） |
| 核心用户 | 18-40岁，男性略多。高学历、高收入群体集中 |
| 使用场景 | 深度阅读、专业讨论、搜索答案 |
| 内容消费习惯 | 搜索驱动（百度搜索结果常含知乎），长尾流量显著 |
| 内容特点 | 先给结论，再展开分析。注重逻辑严谨和来源标注 |

#### 文案撰写要求

| 要素 | 规范 |
|------|------|
| **字数** | 问答：500-2000字。专栏文章：1500-3000字 |
| **结构** | 结论先行 → 分点论证 → 数据支撑 → 来源标注 → 总结 |
| **语气** | 理性、客观、专业。可以用第一人称经验分享，但要逻辑自洽 |
| **价值点** | 知乎用户愿意读长文，但前提是"信息密度高"。水文会被点踩 |
| **搜索优化** | 回答高流量问题可获得持续搜索流量。选择关注者多、浏览高的问题回答 |
| **数据标注** | 每个引用的数据必须标注来源，知乎用户对此极为敏感 |

#### 标题公式

```
知乎标题 = 问题本身。选题即选"要回答什么问题"

高频问题类型：
模板1：政策解释型
  "2026年深圳中考指标生政策有哪些变化？"
模板2：方法指导型
  "深圳中考志愿填报怎样科学设置冲稳保梯度？"
模板3：经验分享型
  "作为过来人，对2027届深圳中考家长有什么建议？"
```

#### AI提示词模板

```
你是知乎教育领域答主，专业背景为深圳本地升学规划。

【写作要求】
- 字数：800-2000字（按问题深度灵活调整）
- 风格：理性、专业、有据可查
- 结构：
  ① 第一句给出核心结论（"先说结论：XXX"）
  ② 分2-4点展开论证，每点配数据或案例支撑
  ③ 数据来源必须标注
  ④ 结尾总结+欢迎讨论
```
