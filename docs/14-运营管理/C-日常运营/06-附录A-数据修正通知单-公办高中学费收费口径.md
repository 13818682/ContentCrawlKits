## 一、错了什么

`0GD.深圳资料/4.数据导入模板/学校介绍MD文档/普高/` 下的学校介绍模板，把 **1131 元/学期** 写成
「按深圳市公办普通高中**统一收费标准**执行」。

**这是错的。** 公办普高学费**不是统一价**，而是**按学校等级分四档**。

**为什么会被写成"统一"**：按模板抽样到的那两所学校（沙井中学、港中深附属明德）**恰好都是省一级**，1131 正好是它们该缴的数——于是"这一档"被当成了"全市统一"。

---

## 二、正确的口径（请以此为准）

**依据：深价联字〔2002〕37号**《深圳市物价局、市教育局、市财政局关于调整我市中小学收费标准全面实行"一费制"的通知》（2002-08-29 发布，自 2002 年秋季开学起执行）。

**公办普通高中学费（"一费制"口径下的学杂费），按学校等级分四档，单位 元/生·学期：**

| 学校等级 | 学杂费 |
|---|---:|
| 一般学校 | **905** |
| 区一级学校 | **996** |
| 市一级学校 | **1041** |
| **省一级学校** | **1131** |
| 国家一级学校 | —（该通知表中无对应标准） |

**两条容易漏的口径**：

1. **该费已含**杂费、课本教材费、练习本费；学校**不得另行收取**课本资料费、练习本费、证册费、实习实验费、军训费等（"一费制"原则）。
2. **住宿费另计，450 元/生·学期**（依据 **深价〔2001〕49号**）。**与学费不同，住宿费确实是全市统一的**——所以原模板里讲住宿费的那句"统一收费标准"**是对的，不用改**。

> 🔴 **请勿引入**：该通知里另有一档「**借读生书杂费**」（一般 2405 / 区一级 2646 / 市一级 2766 / 省一级 3006）。那是 **2002 年口径**，**现行是否仍收取未核**，**不要落库**。

### 4.4 🔴 另外两条**存疑**，请你侧判

2. **三所公办中职写了非免学费的具体标准**，本仓**未核**：

### 4.5 还有一句在 prompt 里（即迁移 110 恢复的那句）
