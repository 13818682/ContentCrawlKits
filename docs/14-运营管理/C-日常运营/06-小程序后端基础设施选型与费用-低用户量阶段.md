# 小程序后端基础设施选型与费用（低用户量阶段）

> **回答的问题**：小程序要跑起来，后台数据库和服务器到底要不要买？用户还很少，选哪家、什么配置、大概多少钱？
> ⚠️ **价格口径**：下表为 2026-09 各家官网促销/新用户价，**促销价随时变动、多为首年价，续费通常跳价**；采购当天以官网实时报价为准。

---

## 一、结论先给

| | 推荐方案 | 成本 |
|---|---|---|
| **首选** | **腾讯云轻量应用服务器 2核4G** + 同机自建数据库 + 对象存储 COS + 自有域名（做 ICP 备案） | **首年 ≈¥200–500；稳定期 ≈¥600–1200/年** |
| **省心备选** | **微信云托管 / 云开发**（后端容器化托管，免运维，可能免域名备案） | 有免费额度；基础套餐 **¥19.9/月 ≈ ¥239/年** |
| 不推荐 | 共享虚拟主机、海外/香港服务器 | 前者不支持自定义环境，后者**无法备案**（小程序 request 域名过不了） |

**一句话**：**要买，但很便宜**。低用户量阶段服务器+域名+对象存储三样加起来，**一年花不到 1000 元**，远低于 BP 里"云服务器是最大单项"的预留。

---

## 二、不管选哪条路，这 5 件事都要办

| # | 事项 | 费用 | 耗时 | 说明 |
|---|---|---|---|---|
| 1 | **域名** | ¥1–60（首年活动）/ ¥60–90（常规续费） | 当天 | 需实名认证，**域名持有者必须与个体户主体一致或可授权** |
| 2 | **ICP 备案（网站/域名）** | **¥0** | 通管局 **1–20 个工作日** | 只能给**境内服务器**备案；这是在关键路径上的最长项 |
| 3 | **公安联网备案** | **¥0** | 数个工作日 | ICP 备案通过后 **30 日内**办理 |
| 4 | **HTTPS 证书** | **¥0**（免费 DV 证书） | 当天 | 小程序只接受 https，http 一律不通 |
| 5 | **小程序后台配置 request 合法域名** | ¥0 | 即时 | 域名必须**已备案**才能填；否则所有后端接口调用失败 |

> ⚠️ **这是与小程序备案（MP 后台）完全不同的两件事**，别混：小程序备案管小程序本体，本条管你自建服务器上的域名。

> 💡 **路径 B 的省时优势**：微信云托管/云开发走 `wx.cloud.callContainer` 等微信内网通道，**可能不需要自备已备案域名**，能省掉第 2、3 项那 1–3 周。此口径请在办理时以官方文档/工单确认（见 §七待确认）。

---

## 三、三条路径对比

| 维度 | 路径 A：轻量应用服务器 | 路径 B：微信云托管 / 云开发 | 路径 C：云服务器 ECS / CVM |
|---|---|---|---|
| 形态 | 一台 VM，自己装 Python、数据库、定时任务 | 容器 / Serverless，托管在微信生态内 | 一台 VM，规格与稳定性更高 |
| 运维负担 | **中**（自己打补丁、备份、监控） | **几乎为零**（自动扩缩容） | 中高 |
| 域名备案 | **必须** | 可能免（待确认） | **必须** |
| 成本 | **最低** | 低（按量，低峰几乎不花钱） | 中（同配置贵 2–4 倍） |
| 适合场景 | 常规 Python 后端 + 同机数据库 + 定时任务 | 后端已容器化（Docker）、想彻底省运维 | 流量上来、需要高可用之后 |
| 迁移成本 | 低（就是一台机器） | 中（绑定微信生态，换云要改造） | 低 |

## 四、配置建议（按当前用户量）

| 项 | 建议 | 说明 |
|---|---|---|
| **CPU/内存** | **2核4G**（推荐）/ 2核2G（能跑但紧） | 关键判断：**AI 生成走外部 LLM API，本机不吃 CPU**；真正占内存的是数据库、Python 进程、以及**若在本机跑向量模型**（如 tao-8k embedding）→ 那种情况要 **≥4核8G** |
| **系统盘** | 40–60G ESSD | 够放代码 + 数据库 + 日志；PDF/图片**不要放本机** |
| **带宽** | 轻量套餐自带（3–5M 或"峰值 200M 不限流"） | 小程序 API 流量很小，够用 |
| **数据库** | **同机自建 MySQL 8 / PostgreSQL** | 用户量小时最省；云数据库基础版要 ¥30–100/月，等量上来再迁 |
| **对象存储** | COS / OSS（存方案 PDF、学校图片、水印文件） | 走存储比走服务器磁盘便宜、且便于加防盗链 |
| **备份** | **开每日自动快照** + 每周数据库导出异地保存 | 用户/订单数据是不可再生资产，这一步不能省（几元/月） |
| **地域** | **广州 / 上海**（境内部署） | 离微信服务节点近；**不要选香港/海外** |

## 六、推荐组合与理由

**首选组合**：腾讯云轻量应用服务器 2核4G（有 3 年套餐时优先买 3 年）+ 同机 MySQL + COS + 自有域名做 ICP 备案。

**为什么是它**：
1. 一台机器同时承载 API 服务、数据库、定时任务，**没有额外组件费用**；
2. 面板自带防火墙、快照、监控，运维门槛低；
3. 与微信生态同厂，备案与工单衔接顺畅；
4. 成本最低且完全可控。

**为什么初期不上云数据库（RDS）**：用户量小，同机自建可省 **¥360–1200/年**；等单点故障代价变高（如付费用户 > 500）再迁。

**什么时候改选路径 B（云托管）**：如果 `1.HSEE-Prj` 的后端**已经是 Docker 容器化**形态，且你更看重"零运维"而不是"完全可控"——云托管可以省掉补丁/备份/扩容的全部操心，且可能省掉域名备案那 1–3 周。**按实际部署形态定，两个方案不要混用。**

## 七、动作清单

- [ ] 定域名（.com/.cn），域名实名认证，主体与个体户一致
- [ ] 购买服务器（**境内**，广州/上海；优先选"续费同价"或直接买 3 年）
- [ ] 提交 **ICP 备案**（免费，1–20 个工作日）→ 通过后 30 日内办 **公安联网备案**
- [ ] 申请**免费 SSL 证书**并部署
- [ ] 小程序后台配置 **request 合法域名**（必须已备案 + https）
- [ ] 服务器初始化：Python 环境、数据库、**每日快照**、监控告警、日志轮转
- [ ] 建对象存储桶（存 PDF/图片）+ 配置防盗链
- [ ] 数据库**每周导出异地保存**（服务器挂掉时的最后一道保险）
- [ ] 把实际采购金额回填到 `B-策划与决策/01-商业测算与成本决策` 的第一年成本表

## 八、避坑

1. **别买海外/香港服务器**——不能备案，小程序 request 域名永远填不进去。
2. **别买共享虚拟主机**——不支持自定义 Python 环境与数据库。
3. **促销价多为"新用户首年"**——次年续费可能翻数倍；长期项目优先挑"续费同价"款或直接买 3 年。
4. **备案主体必须与小程序主体一致**，否则小程序侧过不了。
5. **数据库必须开自动备份**：用户与订单数据不可再生，丢一次等于项目归零。
6. **PDF/图片放对象存储，不放服务器磁盘**：既便宜又避免磁盘打满导致服务宕机。
7. **备案是长尾**：通管局 1–20 个工作日、退回重排——**今天就去买域名开备案**，不要等小程序开发完。

## 十、与第一年成本预算的关系

`B-策划与决策/01-商业测算与成本决策` 中"第一年运营成本 ¥2000–8000（云服务器为最大单项）"——按本方案实际可压到 **¥300–800/年**（首年活动价更低），**留出 ¥1200 以上的预算余量**。建议把差额留在 LLM API 调用与后续扩容上，而不是花在规格过剩的服务器上。
