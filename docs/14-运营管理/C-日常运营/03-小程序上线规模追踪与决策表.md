# 小程序上线决策追踪表

> **一句话**：**正式（可访问）上线 = 2026.10 中前（卡 P1-4 硬 CTA，不设规模门槛）；商业化付费灰度 = 2027.3 上旬（赛季锚，动不了）。规模（公众号 ≥1500 才大推）只当"投放大小的拨杆"，不当"开不开的开关"。** 本表每周日更新一次，按"观测指标 → 复算到达时点 → 命中触发器 → 调整决策"闭环跑。

## 〇、为什么不能让"规模"当开关
公众号是唯一能一步直达小程序的桥，而 2026-09-05 公众号仅 **22 粉**、周净增 **+7**——按现速算到 1500 需 211 周，**2027 赛季前到不了**。若把规模当上线 gate，必然错过志愿季。所以：**时间锚定"何时上线"，规模只定"上线后冲多猛"。**

## 一、两个不可动的时间锚（决策基准）

| 上线层级 | 时间锚 | 卡点 | 规模门槛 |

## 四、到达时点推算（三情景 · 到公众号 1500）

| 情景 | 公众号周净增 | 到 1500 周数 | 到达时点 | 含义 |
|---|---|---|---|---|
| A 维持现节奏 | +7 | ~211 周 | 错过 2027 赛季 | 必须抬增速 |
| B 引擎全开+回流优化 | +50 | ~30 周 | ≈2027.4 | 贴着志愿季·险 |
| C 加投放/爆款/矩阵/社群 | +80 | ~19 周 | ≈2027.1 中 | 从容 |

**每周复算公式**：`到达周数 = (目标1500 − 公众号累计) ÷ 周净增`；也可改算"到 2027.3/4 需要周净增 = (1500 − 累计) ÷ 剩余周数"。

## 六、决策触发器（命中即调整）

1. 🔴 **公众号周净增连续 4 周 < +30** → 判定连 B 情景都达不到 → 二选一：投入抬增速（投放/头条回流/搜一搜深耕），或**把 2027 定义成"学漏斗第一季"**（放弃大推，只灰度）。
2. 🟠 **2026.12 底公众号 <500** → 商业化 2027.3 仍开灰度但**不上投放**，把预算留给内容放大。
3. 🟢 **公众号 ≥1500 且周进入 ≥300 ×2-4 周** → 切大推档，全量引导付费。
4. ⏰ **2026.10.15 前小程序未过审发布** → P1-4 CTA 软化为「同名小程序搜一搜」，并评估行政链卡在哪。
5. 🟢 首测 B→C 注册转化 / C→D 付费转化（上线后）→ 与 11 号基线（≥5% / ≥3%）对比，不达则修承接页而非加量。
