# 使用说明（**发布前删除本页**）

**这份文件是干什么的**：小程序的《隐私政策》，在**登录页 / 我的页面 / 考生档案填写页**公示，并作为 **MP 后台《用户隐私保护指引》的底稿**。与《用户协议》第十条互为引用（协议说"详见《隐私政策》"，本政策说"详见《用户协议》"）。

**为什么必须有**：本服务处理的个人信息中含**考生信息**（姓名/称呼、就读初中、模考成绩等），**可能涉及未成年人**。按《个人信息保护法》：**不满十四周岁**未成年人的个人信息属敏感个人信息（第 28 条），处理须取得监护人同意并制定专门处理规则（第 31 条）；**已满十四周岁的按一般个人信息处理**（中考考生通常已满 14 周岁，故一般**不触发**第 31 条）。另有两项独立义务：**微信强制**要求在 MP 后台配置《用户隐私保护指引》（未配置会导致 `getPhoneNumber` 等接口直接调用失败），以及本服务构成"自动化决策"须做**事前影响评估（PIA）并保存记录三年**（第 55/56 条）。口径校正依据见 `05-附录D-B9需求变更建议-个人信息保护口径重构.md`。

3. **本政策与 MP 后台《用户隐私保护指引》必须同步**——同一批信息类型、同一批用途。两张表对不上是审核驳回与投诉的主因。

# 隐私政策

**生效日期**：【待填 · 小程序内发布日】

**处理者**：深圳市罗湖区旭日领航信息咨询工作室（统一社会信用代码：【待填 · 照执照抄录】）（以下简称"我们"）

**适用小程序**：HSEE

**导言**：我们深知个人信息对您的重要性。本政策说明我们在您使用 HSEE（以下简称"本小程序"）时**收集哪些个人信息、如何使用与保护、以及您可以如何行使权利**。请您在使用前完整阅读，**特别是加粗条款**。

## 第一条 适用范围与处理者

1.1 本政策适用于本小程序提供的**中考志愿填报咨询服务**及**积分充值**功能所涉及的个人信息处理活动。

1.2 **个人信息处理者**为上述"处理者"（本小程序的运营主体）。

1.3 本政策与《用户协议》配套适用；两者对个人信息的表述不一致时，**以本政策为准**。

## 第二条 我们收集哪些个人信息

我们遵循**最小必要**原则，仅收集为提供服务所必需的信息。**除标注"必需"外，其余均为您可自主选择是否提供**；您拒绝提供非必需信息，不影响您使用本小程序的基本功能。

## 第三条 我们如何使用个人信息

3.1 **用于提供服务**：依据您填写的考生信息，调用人工智能模型生成个性化的志愿参考方案与相关解读内容。

3.2 **用于交易与账务**：完成积分充值、消费扣减、退款审核与对账。

3.3 **用于安全与风控**：识别批量注册、恶意套取赠送积分、异常退款等行为，保护您与其他用户的合法权益。

3.4 **用于服务改进**：以**去标识化、聚合**的方式统计服务使用情况（如页面访问量、渠道转化），**该等统计结果不含可识别到您个人的信息**。

3.5 **用于必要的通知**：向您发送与交易、服务相关的必要信息（如退款进度、服务变更）。**我们不会向您发送商业性营销信息**；如未来提供该等推送，将另行取得您的同意。

3.6 **我们不会将您的个人信息用于本政策未载明的其他用途**。如需超出本政策范围使用，将另行告知并取得您的同意。

3.7 **自动化决策的说明与您的权利 ★**：本服务的核心功能——依据您填写的考生信息**自动推算并生成志愿参考方案**——属于《个人信息保护法》第七十三条所称的**自动化决策**。就此我们承诺：

（一）已就该等处理**事前进行个人信息保护影响评估**，并对处理情况进行记录，**保存不少于三年**（第五十五、五十六条）；

（二）保证决策的**透明度和结果公平、公正**，不因任何与志愿填报无关的因素对您作出差别对待；

（三）如该决策对您的权益有重大影响，您**有权要求我们予以说明**，并**有权拒绝我们仅通过自动化决策的方式作出决定**——您可通过第十一条渠道提出，我们将提供**人工复核**路径。

## 第四条 未成年人个人信息 ★

4.1 本服务面向中考考生，所处理的考生信息**可能涉及未成年人**。**不满十四周岁**未成年人的个人信息属于**敏感个人信息**，我们采取严格于一般个人信息的保护措施（含单独告知与监护人同意）；**已满十四周岁**的，按**一般个人信息**处理，同样采取加密、访问控制等保护措施。

4.2 **填写者授权与监护人同意**：
（一）您填写与提交考生信息前，**应确认已取得该考生及其监护人的授权**（本款同时适用于**家长本人填写**与**机构人员代考生录入**两种情形）。
（二）**不满十四周岁**考生的个人信息，依《个人信息保护法》第三十一条须取得其父母或其他监护人的同意；我们会在考生信息填写页作出**单独告知**并留存确认记录。
（三）本服务**不要求填写考生年龄**。若您所填考生不满十四周岁，请务必在取得监护人同意后使用，并通过第十一条渠道联系我们，以适用**专门的处理规则**。

4.3 **单独告知**：单独告知的**触发条件是"处理敏感个人信息"**（第二十九条），即**不满十四周岁**考生的个人信息。我们不会因您同意本政策而当然取得对该等信息的处理授权——该授权须通过**单独的告知与确认环节**作出。

4.4 **监护人的权利**：监护人可随时要求**查阅、更正、删除**该未成年人的个人信息，或**撤回同意**。撤回同意后，我们将停止处理相应信息；但已完成的、基于此前同意的处理不受影响。

4.5 **处理的必要性与自动化决策**：我们处理考生信息的目的**仅限于生成志愿参考方案这一核心服务**。本服务使用**自动化决策**（第七十三条）生成志愿参考内容，我们保证决策的**透明度与结果公平、公正**；您**有权要求我们予以说明**，并**有权拒绝仅通过自动化决策的方式作出决定**（第二十四条）。相关影响评估情况见第三条 3.7。
