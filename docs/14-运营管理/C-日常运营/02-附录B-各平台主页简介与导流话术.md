## 三、导流话术红线（对齐 04 合规清单 §E）

1. **不承诺结果**：不写"保证录取/100%进/稳上"。
2. **不诱导关注**：不用"关注领资料/转发抽奖"诱导（微信/平台双红线）。
   > 判据：**"关注不迷路"合规**（中性表述）；**"关注领资料/转发抽奖"违规**（利益交换）。
3. **不索取隐私**：评论区/私信不要求用户留分数/手机号，引导"小程序可查/私信"。
4. **弱营销**：一句轻量引导（"小程序『HSEE择校助手』可查"），不堆广告词。
5. **正文不贴码/链接**：微信生态外一律走"简介写全名 → 用户搜索"。
