# 深圳中考志愿填报 — 内容运营落地方案

> 本方案回答一个问题：**如何从零开始，把内容流量做起来，并在合规前提下把流量变现为付费订阅。** 核心结论先行——付费订阅是"虚拟支付"，个人主体无法开通微信支付，因此运营必须分两步走：**先以个人身份做内容引流，验证闭环后再注册企业主体做变现。**

---

## 一、项目现状与目标

### 1.1 现状盘点（2026年8月）

| 维度 | 现状 |
|------|------|
| 时点 | 2026 中考已结束（7月底录取完成），正式切入 2027 届运营周期 |
| 内容资产 | S1 基本态势 7/7 ✅、P1 政策解码器 8/8 ✅（含平台变形）；P2–P5 选题规划就绪待创作 |
| 数据资产 | 180 所学校介绍 MD（`5.CrawlTool/data/`）、政策/招生/录取数据（`3.政策文件资料/`） |
| 产品侧 | 小程序 + BFF + admin + LLM 引擎代码在 `1.HSEE-Prj/`，具备变现设计 |
| 主体 | 当前个人身份运营，尚未注册公司 |

### 1.2 运营目标

通过 9 个内容平台发布内容引流 → 沉淀私域（公众号 + 小程序）→ 分档订阅变现（套餐 A ¥100 / 套餐 B ¥500）→ 生成志愿方案。

### 1.3 核心矛盾（决定整套方案的主轴）

> ⚠️ **付费订阅 = 虚拟支付。微信个人主体小程序不能开通微信支付、虚拟支付、付费订阅。** 必须在企业（或个体工商户）主体下才能合规变现。详见第二章。

## 二、运营主体与注册认证方案（重点）

### 2.1 关键约束：个人主体 vs 企业主体的硬边界

| 能力 | 个人主体 | 企业主体（含个体工商户） |
|------|:---:|:---:|
| 小程序注册 | ✅ 免费（身份证） | ✅（营业执照） |
| 普通微信支付 | ❌ | ✅ |
| **虚拟支付 / 付费订阅 / 会员** | ❌ | ✅（需单独开通虚拟支付专用商户号） |
| 公众号订阅号 | ✅ 免费，每天 1 条群发 | ✅ |
| 公众号服务号 | ❌（仅企业/组织） | ✅ 认证后支持微信支付 |
| 认证费 | 无 | 约 ¥300/年（小程序、服务号各一份） |
| 获取手机号 / 直播 / 卡券 | 受限 | ✅ |

**三个关键规则：**

1. **虚拟支付与普通微信支付是两套独立体系**：卖会员/订阅必须**单独开通"虚拟支付专用商户号"**，仅支持**对公账户**结算，费率安卓/鸿蒙/Windows 约 1%、iOS 约 12%（苹果税；腾讯 2026 年技术服务费暂免）。2026 年 4 月 1 日起全终端虚拟交易必须走虚拟支付。
2. **个人小程序不能直接升级为企业主体**：需重新注册，用户数据有损失风险 → **小程序宜等企业主体就绪后再注册**，避免迁移成本。
3. 个体工商户 2026 年起也可开通虚拟支付（审核更严），是"轻量变现主体"的首选。

### 2.2 分阶段主体策略

| 阶段 | 主体 | 能做什么 | 不能做什么 |
|------|------|---------|-----------|
| **第一阶段（引流期，个人身份）** | 个人 | 个人公众号订阅号 + 9 平台个人账号 + 内容发布 + 私域沉淀 | 小程序付费订阅、任何平台内收款 |
| **第二阶段（变现期，企业主体）** | 个体工商户 / 公司 | 企业小程序 + 微信支付 + 虚拟支付 + 付费订阅 | — |

> **推荐路径**：第二阶段优先注册**个体工商户**（无注册资本、线上可办、3–5 工作日出证），跑通付费闭环后再升级为公司（升级机制与风险详见 §2.5）。**切勿"借壳挂靠"他人资质收款**——资金走他人账户不受控，且微信严禁借壳，一经发现直接封号。

### 2.3 微信生态注册认证手续（清单）

**① 微信公众号**
- **订阅号**（第一阶段，个人）：邮箱 + 身份证 + 绑定银行卡的微信扫码验证 → 免费，每天 1 条群发。个人订阅号不可认证、无微信支付。
- **服务号**（第二阶段，企业）：邮箱 + 营业执照 + 法人身份 + 对公账户 → 微信认证 ¥300/年，每月 4 条群发，认证后支持微信支付（费率约 0.6%–1%）。
- ⚠️ 2018 年 3 月后新注册公众号默认**无留言功能**，开通需"公众号迁移"（迁移审核费 + 购买老账号，成本较高）——如留言功能非必需可暂不处理。

**公众号命名与主体规则（个人号阶段关键）**

- **命名红线**：个人号名称含「地名 + 行业词」（如"深圳中考"）会触发**资质要求**（需办学许可/教育部门备案证明），个人主体无法提供 → 被拒；个人号也不可用"官方/公司/集团/企业"等字眼、不可冒充机构、不可用广告法禁用词（最/第一/保录取）。
- **解法（品牌词替代地名）**：复用已定字号「鹏程」——推荐名称 **「鹏程志愿填报」/「鹏程升学规划」/「鹏城升学指南」**（"鹏城"=深圳别称，非行政区划名，保留地域联想又不触发资质）。
- **搜索靠简介**：名称审核严、简介审核宽松；简介写"专注深圳中考志愿填报、升学规划、择校咨询"，微信搜索会匹配名称 + 简介，家长搜"深圳中考"仍有机会命中。
- **名称可改**：一年可改 2 次，但审核标准不变，个人号**改不出**"深圳中考"这类资质名。
- **⚠️ 个人号不能变更主体**：个人订阅号无"主体变更/账号迁移"能力（迁移仅支持组织号）；将来要"认证 + 带深圳中考 + 挂小程序支付"的公众号，必须**重新注册企业公众号**，而非把个人号升级/改名。

**两段式公众号策略**：现在个人号「鹏程志愿填报」引流发内容 → 个体户/企业就绪后**重开企业公众号**「深圳中考志愿填报」（有资质）做主号 + 支付入口；两号并存，个人号继续当矩阵号。

**② 微信小程序**
- 个人主体：免费，仅信息展示/工具，无支付能力（本方案**不在个人阶段注册小程序**）。
- 企业主体：营业执照 + 微信认证 ¥300/年 + 对公账户。

**③ 微信支付 + 虚拟支付商户号**
- 微信支付商户号：需企业/个体工商户资质。
- 虚拟支付专用商户号：在上述基础上**额外开通**，仅对公账户结算。

**④ 个体工商户办理手续（推荐轻量路径）**
1. 名称核准（如"深圳市 XX 升学信息咨询服务部"）
2. 提交：经营者身份证 + 经营场所证明（可用住所承诺制）
3. 3–5 个工作日出营业执照
4. 刻章 + 税务登记（小规模纳税人，季度 30 万以内免征增值税）
5. 银行开对公账户（微信支付/虚拟支付结算必需）

**⑤ 公司注册（第二步升级）**：名称核准 → 营业执照 → 刻章 → 银行开户 → 税务/社保登记。可用于后续融资、招聘、更规范的税务主体。

### 2.4 九大内容平台账号注册手续

| 平台 | 注册主体 | 实名要求 | 引流到 HSEE 的方式 |
|------|---------|---------|------------------|
| 微信公众号 | 个人 | 身份证 | 文末小程序卡片 / 二维码（企业后） |
| 小红书 | 个人 | 身份证实名 | 主页简介引导 / 评论区 |
| 抖音 | 个人 | 身份证实名 | 口播"点主页" / 评论区置顶 |
| 今日头条 | 个人 | 身份证实名 | 图文长文复用公众号 |
| B站 | 个人 | 身份证实名 | 评论区链接 / 简介 |
| 知乎 | 个人 | 身份证实名 | 回答内标注"HSEE" |
| 微博 | 个人 | 身份证实名 | 头条文章 + 链接 |
| 快手 | 个人 | 身份证实名 | 口播引导 |
| 百度贴吧 | 个人 | 身份证实名 | **贴吧吞外链** → 用"搜一下 HSEE"引导 |

通用手续：手机号 + 身份证实名认证，个人阶段全部可注册，零费用。注意各平台挂载小程序/外链普遍有粉丝量或资质门槛，第一阶段以"沉淀粉丝 + 建立信任"为主。

### 2.5 个体工商户 → 公司：小程序主体变更的风险分析与处理建议

**结论先行**：个体工商户注册的小程序**可以**通过微信官方"主体变更"流程升级到公司主体，**AppID、OpenID、用户数据均不丢失**，业务不中断。风险不在"能否变更"，而在三个连带环节——**支付商户号、类目资质、变更时机**。

**关键区别：主体变更 ≠ 主体迁移（务必分清）**

| 项目 | 主体变更（要走的） | 主体迁移（要避免的） |
|------|------|------|
| 性质 | 原账号上直接换运营主体 | 注销原小程序、启用新小程序 |
| AppID | 不变 | 全新 |
| OpenID | 不变 | 变 |
| 用户数据 | 不丢失 | 需迁移 |
| 服务 | 基本无感知 | 中断 |

**三个真实风险点**

1. **支付商户号**：个体工商户的微信支付/虚拟支付商户号不能直接转给公司。变更后需解绑原商户号，**用公司主体重新开通并绑定商户号**——支付能力短暂中断、结算主体变更、对账需切换。
2. **服务类目资质**：教育咨询类目需用公司主体资质重新提交审核。
3. **备案**：需注销原备案、由新主体重新备案（期间不影响使用与 openid）。

**变更前置条件（决定是否顺畅）**

- 原主体（个体户）营业执照**保持正常存续、切勿注销**——一旦注销，流程必须走公证，复杂且费用更高。
- 小程序无违规/处罚记录；变更前解绑非目标主体的商户号；变更完成 30 天内不能再变更。
- **跨城市主体变更同样支持**：A 城市个体户 → B 城市公司无地域限制（微信仅要求目标主体为大陆境内企业/个体户/组织）。但注意工商层面是"注销 A 个体户 + 在 B 新设公司"两个动作（"个转企"只适用于同一登记机关），且 B 城市需有注册地址。

**流程与成本**

- 路径：小程序后台 → 设置 → 基本设置 → 主体信息 → 主体变更。
- 验证方式：双方主体正常存续且法人可扫脸 → **法人扫码，无需公证**；原主体已注销/法人不能扫脸/工商数据不一致 → 必须公证。
- 成本：腾讯审核费 ¥300（固定）+ 公证费（如需，线上约 100–480 元 / 线下约 300–800 元）。
- 时间：常规 1–3 个工作日。

**处理建议（三条路径）**

| 路径 | 做法 | 适用 |
|------|------|------|
| A 直接公司 | 跳过个体户，小程序从一开始就用公司主体 | 资金充足、已确定长期运营 → 彻底规避迁移 |
| B 个体户先行 + 后期主体变更（推荐） | 个体户验证闭环 → 跑通后"主体变更"升级公司 | 低成本验证，接受后期变更工作量 |
| C 个体户长期运营 | 小程序始终个体户主体，公司仅作管理/持股 | 不融资、个体户即可承载规模 |

**若走路径 B 的执行要点**

1. 变更前**个体户保持存续、不注销**（否则要公证）。
2. 必须选"**主体变更**"而非"主体迁移"（保住 AppID/OpenID/用户数据）。
3. 变更后立即用公司主体重新绑定商户号，**安排在 9–12 月淡季执行**，避开 6–7 月填报高峰，减少支付中断影响。
4. 提前准备公司主体的教育咨询类目资质。

### 2.6 路径 A vs 路径 B：一笔账（2026 年深圳估算）

> 假设：验证期 6 个月；成功场景按运营 2 年（24 个月）计。金额为深圳市场价估算，以当地实际为准。

**一次性与年度成本单价**

| 成本项 | 个体户 | 公司（小规模纳税人） |
|------|------|------|
| 注册 / 刻章 / 开户 | ¥0–100（线上，多数免费） | ¥0–1500（自己办免费，代办 ¥500–1500） |
| 记账报税 | ¥0–2000/年（核定征收可自记） | ¥2400–4000/年（代理记账） |
| 注册地址 | 自家地址 ¥0 | ¥0–1000/年（集群注册免费或低费） |
| 银行对公账户 | 开户 ¥0–500、年费 ¥0–500 | 同左 |
| 微信认证 | 小程序 ¥300/年 + 服务号 ¥300/年 | 同左 |
| 社保（法人） | 自愿 | 通常需交，约 ¥1500–2500/月/人 |

**两年总成本对比（成功场景，不含社保）**

| 项目 | 路径 A 直接公司 | 路径 B 个体户 → 变更 |
|------|------|------|
| 主体注册 | ¥0–1500 | ¥0–100 |
| 记账报税（24 个月） | ¥4800–8000 | 个体户 6 月 ¥0–500 + 公司 18 月 ¥3600–6000 |
| 微信认证（2 年） | ¥1200 | ¥1200 |
| 主体变更（一次性） | — | ¥300–980 |
| 银行账户（2 年） | ¥0–1000 | ¥0–1000 |
| **合计** | **¥6000–11700** | **¥5100–8780** |

- 路径 B 省约 **¥900–2900**。
- **含社保差距更大**：路径 A 从第 1 个月起给法人交社保，路径 B 前 6 个月个体户阶段可不交，多省约 6 个月社保（≈¥9000–15000）。

**验证失败场景（6 个月放弃）**

- 路径 A：注册 + 6 个月代账 + 认证 ≈ ¥1500–4500。
- 路径 B：个体户注册 + 6 个月零/低代账 + 认证 ≈ ¥600–1600。
- 路径 B 少沉没约 **¥900–2900**。

**结论**

路径 B（个体户先行）在**成功和失败两种场景下都更省钱**，代价仅是后期一次性 ¥300–980 的变更 + 商户号重绑的操作成本。**除非**满足以下之一，才建议直接走路径 A：① 已确定要融资 / 签大客户，公司主体信任度更高；② 有免费注册地址 + 极低记账成本；③ 不愿承担变更期间短暂支付中断的风险。

## 三、内容生产与分发体系（复用既有资产）

### 3.1 五大内容支柱

P1 政策解码器 / P2 降分通道 / P3 数据择校 / P4 志愿填报作战室 / P5 录取后行动指南。

### 3.2 三阶段运营节奏

| 时间段 | 阶段 | 家长心理 | 内容任务 |
|--------|------|---------|---------|
| 3–5 月 | 前期·政策科普 | 模糊焦虑 | 建立认知，系统输出政策基础 |
| 6–7 月 | 中期·填报实操 | 决策焦虑峰值 | 提供确定性：方法 + 数据 + 案例 |
| 7–8 月 | 后期·录取复盘 | 分享意愿最高 | 收割传播，引导 UGC 蓄水 |

### 3.3 "一鱼多吃"分发公式

1 篇公众号深度长文 → 9 平台共 10–13 条内容：

```
公众号长文（1500字，主阵地）
 ├─→ 小红书拆 3 篇（各 500 字）
 ├─→ 抖音拆 2 条（各 60 秒）
 ├─→ 今日头条 1 篇图文（复用长文）
 ├─→ B站合成 1 个教程（10 分钟）
 ├─→ 微博拆 2 条（各 150 字）
 ├─→ 知乎回答 1 个高流量问题
 ├─→ 快手拆 1 条（40 秒）
 └─→ 贴吧发 1 个分享帖
```

### 3.4 平台优先级（HSEE 评级）

- **主阵地（⭐⭐⭐⭐⭐）**：微信公众号、小红书、抖音
- **次阵地（⭐⭐⭐）**：B站、知乎、今日头条
- **补充（⭐⭐）**：微博、快手、百度贴吧

### 3.5 高价值选题（转化/流量核心）

| 选题 | 窗口 | 评分 | 价值 |
|------|------|:---:|------|
| B4-2 冲稳保梯度策略 | 7月 | 9.5 | 全年转化力最强 |
| P3-1 一分一段表解读 | 7月初 | 9.2 | 全年流量峰值 |

## 四、引流转化漏斗

```
免费内容（9平台）→ 关注公众号（私域沉淀）→ 小程序注册（留资）
  → 免费额度体验 → 分档订阅（¥100 / ¥500）→ 生成志愿方案
```

- 第一、二阶段漏斗末端（付费订阅）依赖企业主体就绪；主体未就绪前，末端停在小程序注册 + 公众号沉淀。
- 指标生、一分一段表等"独家数据"选题是**核心转化点**——用"查你所在初中分到哪些高中的指标生名额"引导家长去 HSEE 查询。

### 4.1 流量获取策略（并入自 2A §9.3）

1. **免费自然流量**：SEO 长尾（"深圳中考 D 类分数线""深圳指标生政策"等搜索词）+ 小红书/知乎干货，低成本覆盖信息焦虑型家长。
2. **付费精准投放**：仅对「中端一对一」等高毛利产品，在信息流/朋友圈投放**定向非深户家长（D 类）**，控制 CAC（获客成本）≤ 客单价的 1/3。
3. **裂变获客**：老带新激励（目标转介绍占付费用户 30%+），用「免费模拟填报工具」换联系方式，形成私域池。

### 4.2 流量漏斗管理（拉新→激活→转化→留存→裂变）

| 阶段 | 动作 | 关键指标 | 细分侧重 |
|------|------|------|------|
| **拉新** | 公域内容 + 免费工具引流 | 曝光→点击率 | 焦虑求助型为主 |
| **激活** | 免费模拟填报、政策查询 | 注册→使用率 | 全部 |
| **转化** | 中端方案付费 + 高端升级 | 免费→付费转化率（≥3%） | 求助型走量、DIY 型高客单 |
| **留存** | 案例库、社群、录取跟进 | NPS（≥50） | 中端+高端 |
| **裂变** | 老带新激励、方案截图分享 | 转介绍率（≥30%） | 全部 |
