# 原 02 · 注册材料清单与号码隐私风险处理

# 注册材料清单与号码隐私风险处理

## 一、结论速览

1. **是的**：信息发布平台和小程序注册都需要手机号（多数还需邮箱 + 身份证实名）。
2. **同一个手机号跨平台注册有风险**：骚扰电话/短信、隐私跨平台关联、平台风控、账号安全集中。
3. **互联网存在"接码/临时号码"服务，但强烈不推荐用于正式运营账号**——账号无归属权、主流平台风控封杀。
4. **推荐做法**：办一张**独立实名手机卡（副卡）**作"运营专用号"，与个人号隔离，而非用接码平台。

## 二、注册材料总清单

### 2.1 个人阶段（引流期）

| 项目 | 手机号 | 邮箱 | 身份证 | 其他 |
|------|:---:|:---:|:---:|------|
| 微信公众号（订阅号） | ✅ | ✅（一个邮箱只注册一个号） | ✅ | 绑定银行卡的微信扫码验证 |
| 小红书 | ✅ | 可选 | ✅ | — |
| 抖音 / 今日头条 | ✅ | 可选 | ✅ | — |
| B站 | ✅ | 可选 | ✅（部分功能） | — |
| 知乎 | ✅ | 可选 | ✅ | — |
| 微博 | ✅ | 可选 | ✅ | — |
| 快手 | ✅ | 可选 | ✅ | — |
| 百度贴吧 | ✅ | 可选 | ✅（部分） | — |

### 2.2 个体工商户阶段（变现期）

| 项目 | 所需材料 |
|------|---------|
| 个体工商户注册 | 经营者身份证、经营场所证明（或住所承诺）、名称 |
| 微信小程序（个体户主体） | 营业执照、法人身份证、对公账户、邮箱、管理员手机号、微信认证 ¥300/年 |
| 微信公众号（服务号，如需） | 同上 + 认证 ¥300/年 |
| 微信支付商户号 | 营业执照、法人身份证、对公账户、经营类目资质 |
| 虚拟支付商户号 | 上述基础上额外申请，仅对公账户结算 |

> **商户号与对公账户要点**（付费订阅场景）：
> - **付费订阅 = 虚拟商品**，必须开通**虚拟支付商户号**（虚拟支付专用/二级商户号），不能走普通微信支付商户号——两套体系独立、分开结算对账。
> - 虚拟支付**仅支持对公账户结算**（提现只能到对公账户，T+3 到账），所以**必须开银行对公基本户**。
> - 对公基本户原则上在**个体工商户注册地（A 城市）开户**；注册地与经营地都在 A 城市即正常"本地开户"。仅当注册地与经营地跨省/市/县时才涉及异地开户（可办，但需注册地人行出具"未开立基本户证明"）。
> - 一个个体户只能开**一个基本户**；线上经营的个体户开户，银行可能核验经营场所，建议备好场所证明或选"简易开户"银行。

### 2.3 公司阶段（可选升级）

| 项目 | 所需材料 |
|------|---------|
| 公司注册 | 名称核准、股东/法人身份证、注册地址、章程 |
| 小程序主体变更（个体户→公司） | 双方营业执照、法人身份证、《主体变更申请函》、（可能）公证书 |

## 三、手机号使用风险分析

### 3.1 骚扰电话 / 短信
- 手机号一旦进入注册/营销/工商公示名单，会被营销公司抓取，收到代账、推广、贷款等推销电话。
- **工商公示是重灾区**：个体工商户/公司注册后，登记的联系电话会被企业信息平台（企查查、天眼查等）公开，成为骚扰电话主要来源。

### 3.2 隐私关联（跨平台画像）
- 手机号 + 实名信息在多平台注册后，第三方数据服务商可通过手机号做 ID 打通，形成"一人多号"的用户画像。
- 平台间数据不直接共享，但通过手机号这一唯一标识，你的身份在不同平台被关联。

### 3.3 平台风控
- 同一手机号 + 同一身份证注册过多平台账号，部分平台会触发风控。
- 若未来做矩阵（一平台多号），一个手机号通常只能绑定一个账号，多号需"一机一号一卡"。

### 3.4 账号安全集中风险
- 一个号码失窃/换号，绑定的所有账号都可能被找回、被攻击。
- 核心资产账号（公众号管理员、小程序管理员、支付）应用最稳定的号码。

## 四、接码平台 / 虚拟号服务说明与风险

| 类型 | 是什么 | 风险 | 是否推荐 |
|------|--------|------|:---:|
| 接码平台（临时号码） | 共享临时手机号收验证码 | 账号无归属权、号码共享易被他人登录/找回、主流平台风控封杀、违反平台规则 | ❌ 强烈不推荐 |
| 虚拟运营商号段（170/171/165/167 等） | 正规实名卡，但号段特殊 | 部分平台对虚拟运营商号段注册有限制 | ⚠️ 谨慎 |
| 独立实名副卡/新卡 | 三大运营商实名卡 | 无（正常使用） | ✅ 推荐 |

> 结论：接码平台不适合要长期运营、要变现的核心账号。核心账号必须用自己实名的稳定号码。

## 五、处理建议

1. **办一张独立"运营专用"手机卡**（三大运营商副卡，月租几元至十几元），与个人生活号完全隔离。注册、工商登记、对外留号都用它。
2. **核心资产账号用最稳定的号码 + 独立邮箱**：公众号管理员、小程序管理员、微信支付商户号用运营专用号；邮箱用独立邮箱（不用个人主力邮箱）。
3. **对外不公开运营手机号**：内容里、主页里不留手机号，用平台私信/公众号自动回复/企业微信客服对外。
4. **工商登记用运营专用号**，并接受"登记电话会被企查查等平台公示"的现实；开启运营商骚扰拦截（移动"高频骚扰电话拦截"、电信"天翼防骚扰"等）。
5. **不要用接码平台注册核心账号**；若临时测试用接码，仅限一次性测试账号，绝不用于要沉淀用户/变现的账号。
6. **规划矩阵账号时**：一机一号一卡，避免多账号共用一号被平台判定关联违规。
7. **定期自查**：用号码查询工具检查运营号是否被标记为推销/骚扰，及时申诉。

## 七、实操细化：运营专用号办理 + 工商登记防骚扰

### 7.1 运营专用号怎么选（副卡 vs 新卡，三大运营商）

| 方式 | 做法 | 月费 | 适合 |
|------|------|------|------|
| **副卡** | 挂在个人主卡名下，独立号码，共享主卡套餐 | 功能费约 ¥10/月 | 已有主卡、想省事的首选 |
| **独立低月租新卡** | 单独办一张保号套餐卡 | ¥5–19/月 | 想彻底独立、不与主卡任何绑定 |

- 三大运营商（移动/电信/联通）**都提供副卡**，办理免费或收一次性工本费，副卡月功能费约 ¥10/月。
- 副卡与主卡是**不同手机号**，但同一身份证实名——对"隔离骚扰"已足够（骚扰打到副卡号，不影响主卡生活号）。
- 注意实名限额：同一身份证在同一运营商最多办 5 张卡（工信部规定），规划矩阵账号时留意额度。

### 7.2 套餐怎么选

运营专用号的唯一需求 = **能收验证码 + 能接电话 + 来电显示 + 骚扰拦截**，不需要流量和大量通话。因此：

- 选**最低月租的"保号套餐"**（市场主流约 ¥5–19/月，如电信无忧卡 5 元、移动 8 元自由选等经典保号套餐）。
- 开通**来电显示**（部分保号套餐需单独开通，否则陌生来电无显示）。
- 开通**运营商官方骚扰拦截**：
  - 移动：高频骚扰电话拦截（官方公众号/App 可开）
  - 电信：天翼防骚扰（官方公众号/小程序可开）
  - 联通：在「中国联通 App」内开启骚扰拦截/安全防护
- ⚠️ 套餐名称与价格频繁调整，办理时以运营商当前实际为准；核心是"月租最低 + 能收验证码 + 来电显示 + 拦截"。

### 7.3 个体户/公司登记时，最大限度减少手机号公示骚扰

**骚扰来源**：登记电话会进入"国家企业信用信息公示系统"，并被企查查、天眼查等平台自动抓取公开，成为代账/推广/贷款电话的主要来源。无法完全避免，但可这样隔离：

1. **用运营专用号登记**（不用个人生活号）——骚扰只落到专用号。
2. **区分三个登记字段**：经营者联系电话、联络员电话、邮箱，**全部填运营专用号/专用邮箱**。
3. **注册后主动申请平台"号码保护"**：企查查、天眼查等有号码隐藏/申诉入口，可在公司主页申请隐藏电话（以各平台实际功能为准）。
4. **年报（每年 1–6 月）继续用专用号**，保持隔离。
5. **开启专用号骚扰拦截**（见 7.2），推销电话不接/标记，系统会自动学习拦截。
6. **顺手保护住址隐私**：个体户"经营场所"如用家庭住址会被公示；可考虑「集群注册/托管地址」（几百元/年）避免公示家庭住址。
7. **预期管理**：公示是法定要求，防不住"被收录"，只能防"骚扰影响个人生活"——专用号 + 拦截 = 影响趋近于零。

# 原 07 · 注册地选择：广州 vs 深圳 + 升级路径

# 注册地选择：广州 vs 深圳 + 升级路径风险对比

## 一、广州 vs 深圳 个体工商户注册对比

| 维度 | 广州 | 深圳 |
|------|------|------|
| 行政费用 | 0 元 | 0 元 |
| 刻章 | 200–500 元（部分区免费） | 免费（新办赠章） |
| 办理效率 | AI 帮办，最快当天拿照（智能审批 1 工作日） | "一表一窗一天免费办结"，最快 3 小时 |
| 办理渠道 | 穗好办 / 粤商通 / 一网通 | 一窗通 / 掌上办 / 自助机 24h |
| 经营场所 | 住宅可用（住改商，咨询/电商类）或挂靠 1000–4000/年 | 住所托管登记（集群注册） |
| 代理记账 | 80–500 元/月 | 相当 |

**结论**：注册本身两地都不难、近乎免费，无实质差距。

## 二、核心差异：以后"升级公司"这一步

| 环节 | 方案一：广州个体户 → 深圳公司 | 方案二：个体户+公司都在深圳 |
|------|------|------|
| 工商升级 | 跨城，"个转企"用不了 → 注销广州个体户 + 深圳新设公司 | 深圳"个转企"直接变更：保留统一社会信用代码/成立日期/字号，最快 3 小时，奖励 ≥1 万元 |
| 微信小程序主体变更 | 跨城市可以，数据保留 | 同城更顺 |
| 对公账户 | 广州开 → 深圳重开 | 都在深圳 |
| 税务 | 跨城衔接（广州注销 + 深圳新办） | 同城衔接 |

> 深圳"个转企"是决定性优势：2024 年 12 月上线直接变更登记系统，保留统一社会信用代码（旧模式"先注销再设立"保不住），最快 3 小时，每户奖励 ≥1 万元。

## 三、微信小程序：支付与系统运行影响分析

### 3.1 系统运行 —— 不受影响

主体变更期间小程序正常运营，AppID、OpenID、用户数据全保留，用户无感知。

### 3.2 用户支付（付费订阅）—— 两方案相同的中断

个体户 → 公司，商户号主体变更，**虚拟支付商户号必须用公司主体重新开通**（审核 5–7 工作日 + 重新配置回调），付费订阅会有约 1–2 周中断。

- 这个中断是"个体户→公司"本身带来的，**与是否跨城市无关**——方案一、方案二在此点上风险一致。
- 方案一额外增加的是财税侧麻烦（工商注销+新设、对公账户跨城、税务跨城），不在微信支付侧。

### 3.3 中断应对

安排在 9–12 月淡季执行主体变更，避开 6–7 月填报高峰；变更前个体户保持存续不注销。

## 四、结论与建议

**推荐方案二（个体户和公司都在深圳）**：
1. 深圳"个转企"保留统一社会信用代码 + 3 小时办结 + 奖励 1 万；
2. 账户、税务、商户号衔接都在同城；
3. 与"深圳先行"战略一致（主要经营地在深圳）。

**例外**（才考虑方案一）：人/经营场所在广州，或广州有明确税收优惠。

# 原 08 · 深圳注册落地执行方案：经营场所与执行清单

# 深圳注册落地执行方案

## 一、关键决策速查（已登记事项汇总）

| 问题 | 已定结论 |
|------|---------|
| 变现主体 | 个体户先行 → 后期"个转企"升级公司（深圳同城，保留统一社会信用代码） |
| 付费订阅走哪种商户号 | **虚拟支付商户号**（虚拟商品不能走普通微信支付商户号） |
| 虚拟支付需要对公账户吗 | 需要，**仅支持对公账户结算**，须开银行基本户 |
| 对公账户本地开户 | 原则上在**注册地（深圳）开户**，注册地经营地都在深圳即正常本地开户 |
| 个体户能否跨城市升级 | 微信主体变更可跨城市（数据保留），但工商是"注销+新设"；**推荐同城深圳"个转企"** |
| 主体变更影响 | 系统运行不受影响；付费订阅约 1–2 周中断（两方案相同，因商户号需重开） |
| 注册地选择 | **深圳**（注册免费、免费刻章、个转企 3 小时 + 奖励 ≥1 万） |

## 二、深圳个体户注册方案

### 2.1 业务性质判断

中考志愿填报咨询 = 线上信息服务/咨询类，**无实体门店、无需上门核查、无需许可证**，符合深圳"电子商务、咨询、策划"类住所托管的适用范围。

### 2.2 经营场所经济处理方案（重点）

| 方案 | 年费用 | 适用 | 推荐度 |
|------|:---:|------|:---:|
| **集群注册 / 住所托管** | ¥1000–2000 | 官方《商事主体住所托管办法》支持，电商/咨询/策划类 | ✅ 推荐 |
| 前海免费挂靠 | ¥0 | 需符合前海产业目录，可享 15% 所得税优惠 | ✅ 若能挂靠 |
| 商务秘书地址托管 | ¥500–2000 | 最省心，信件代收 + 电话转接 | ⚠️ 备选 |
| 住宅地址（住改商） | 0 但有风险 | 需业主同意证明，审核严、开户/补贴通过率低 | ❌ 不推荐做核心主体 |
