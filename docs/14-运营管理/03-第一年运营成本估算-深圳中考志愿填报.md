# 深圳中考志愿填报 — 第一年运营成本估算（个体户主体）

## 一、估算口径与结论

**主体路径**：个体工商户起步 → 个体户注册小程序 + 公众号 + 微信支付/虚拟支付 → 个体户在其余 8 大内容平台注册账号引流。

**结论**：第一年必要运营成本约 **¥2000–8000**（不含程序设计与维护，该项按 0 计）。

| 成本层级 | 第一年合计 |
|---------|:---:|
| 最低必要配置（验证闭环跑通即可） | ≈ ¥2000 |
| 舒适配置（体验好、有冗余） | ≈ ¥8000 |

> 三个特征：① **云服务器是最大单项**（¥1200–3000/年）；② 微信生态认证是固定年费（¥600/年）；③ 个体户主体在"注册/记账"上几乎零成本，省下的正是公司主体那笔代理记账 + 社保。

## 四、说明与注意事项

1. **最大单项是云服务器**：程序设计与维护虽为 ¥0，但服务器、域名、存储是跑通小程序闭环的硬成本，不可省。早期流量小，2核4G 轻量服务器（活动价 ¥1200/年左右）足够，后续按用户量扩容。
2. **LLM API 与短信是变动成本**：随付费用户量线性增长，第一年验证期几乎可忽略；进入变现后需单独纳入单位经济模型（每单订阅抽成多少）。
3. **个体户主体省下的钱**：相比公司主体，第一年免掉代理记账（¥2400–4000）与法人社保（¥15000+），这正是"个体户先行"策略的成本优势（详见 `01` §2.6）。
4. **价格时效**：云服务器、域名等价格随厂商活动浮动较大，以上为区间估算，办理时以各平台当前实际报价为准。
5. **可缓项**：公众号认证（¥300）、企业号认证（各 ¥600/年）、代理记账（¥2400/年）均非第一年必需，可等流量验证后再上。
