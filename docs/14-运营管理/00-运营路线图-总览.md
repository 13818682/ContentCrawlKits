# 运营路线图（总览）

> 本目录「docs/14-运营管理」（原独立项目 `2.内容管理及运营`，2026-08-30 并入本仓）是深圳中考志愿填报项目的**正式运营工作区**。本文件是全部运营侧文档的总入口，一条链看懂"从零到变现再到多城"的完整路径。

## 一、一句话定位

**内容引流（9 平台）→ 小程序订阅变现（套餐 A ¥100 / 套餐 B ¥500）→ 深圳先行跑通闭环 → 东莞 → 广州。**

## 二、已定决策速查

| # | 决策项 | 结论 |
|---|--------|------|
| 1 | 变现主体 | **个体户先行 → 个转企升级公司**（深圳同城，保留统一社会信用代码） |
| 2 | 注册地 | **深圳 · 龙华/宝安**（不用前海/核心区） |
| 3 | 多城市 | 深圳先行（2027 届）→ 东莞 → 广州（2028 届），技术已在 `1.HSEE-Prj` 实施 |

## 三、完整执行路线图（8 步闭环）

```
① 定主体 ──→ ② 定注册地 ──→ ③ 注册个体户 ──→ ④ 开通支付
（个体户）   （深圳龙华/宝安）（托管地址+税务+对公户）（小程序+虚拟支付商户号）
                                                     │
⑧ 多城复制 ←─ ⑦ 个转企升级 ←─ ⑥ 变现验证 ←────────── ⑤ 内容引流
（东莞→广州）（保留信用代码）  （订阅¥100/500，15-50付费用户回本）（9平台，5支柱+一鱼多吃）
```
