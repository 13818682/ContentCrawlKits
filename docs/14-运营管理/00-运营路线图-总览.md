# 运营路线图（总览）

> 本目录「docs/14-运营管理」（原独立项目 `2.内容管理及运营`，2026-08-30 并入本仓）是深圳中考志愿填报项目的**正式运营工作区**。本文件是全部运营侧文档的总入口，一条链看懂"从零到变现再到多城"的完整路径。

## 一、一句话定位

**内容引流（9 平台）→ 小程序订阅变现（套餐 A ¥100 / 套餐 B ¥500）→ 深圳先行跑通闭环 → 东莞 → 广州。**

## 二、已定决策速查

| # | 决策项 | 结论 |
|---|--------|------|
| 1 | 变现主体 | **个体户先行 → 个转企升级公司**（深圳同城，保留统一社会信用代码） |
| 2 | 注册地 | **深圳 · 龙华/宝安**（不用前海/核心区） |
| 3 | 多城市 | 深圳先行（2027 届）→ 东莞 → 广州（2028 届），技术已在 `1.HSEE-Prj` 实施 |
| 4 | 付费商户号 | **虚拟支付商户号**（非普通商户号）+ 对公账户（注册地本地开户） |
| 5 | 内容平台 | 9 个：公众号/B站/小红书/抖音/今日头条/微博/知乎/快手/贴吧 |
| 6 | 内容支柱 | P1–P5 五支柱 + S1；三阶段（3–5 月科普 / 6–7 月填报 / 7–8 月复盘） |
| 7 | 程序设计 | **¥0**（复用 `1.HSEE-Prj` 已有代码） |
| 8 | 经营场所 | 集群注册/住所托管（约 ¥1000–2000/年） |
| 9 | 税务 | 前期无需代账，自己零申报；咨询类多为查账征收 |
| 10 | 主体变更时机 | 9–12 月淡季，避开 6–7 月填报高峰 |

## 三、完整执行路线图（8 步闭环）

```
① 定主体 ──→ ② 定注册地 ──→ ③ 注册个体户 ──→ ④ 开通支付
（个体户）   （深圳龙华/宝安）（托管地址+税务+对公户）（小程序+虚拟支付商户号）
                                                     │
⑧ 多城复制 ←─ ⑦ 个转企升级 ←─ ⑥ 变现验证 ←────────── ⑤ 内容引流
（东莞→广州）（保留信用代码）  （订阅¥100/500，15-50付费用户回本）（9平台，5支柱+一鱼多吃）
```

## 四、带时间点的里程碑

| 时间 | 里程碑 | 关键动作 |
|------|--------|---------|
| 2026.08 | 注册准备 | 定字号/经营范围 + 办龙华/宝安托管地址 |
| 2026.09 | 个体户注册 | 线上拿照 → 税务报到 → 开对公基本户 → 办运营专用卡 |
| 2026.10–12 | 小程序+支付+内容 | 小程序认证 + 虚拟支付商户号 + 9 平台内容铺量 |
| 2027.01–02 | 蓄水 | 引流蓄水，测主力平台 |
| 2027.03–05 | 变现准备 | 政策科普 + 付费订阅上线 |
| 2027.06–07 | **填报决战** | 冲刺盈亏平衡（≥50 付费用户）★ 首个闭环 |
| 2027.07–08 | 复盘+升级 | 判定闭环 → 个转企升级公司（奖励 ≥1 万） |
| 2027.07 起 | 东莞复制 | 东莞数据准备 → 账号 → 内容（2028 届） |
| 2028.06–07 | 三城闭环 | 东莞/广州各自达成闭环，全年模式定型 |
