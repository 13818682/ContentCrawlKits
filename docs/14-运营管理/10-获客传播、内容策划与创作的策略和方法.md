## 第一章：用户全旅程分析

### 1.1 模型概述："一轴四线"架构

中考志愿填报领域的用户旅程具有特殊性：**信任构建、价值体验、付费升级、分享传播**并非"到了某个时刻才发生"，而是从用户第一次接触内容就开始启动、贯穿多个时间阶段、彼此交织、互相支撑的并行过程。简单的线性阶段模型无法准确描述这种复杂性。

因此，本PRD采用**"一轴四线"**结构来描述用户旅程：

- **一轴（主时间线）**：用户必然经历的时间序列，**单向推进——知晓期→注册期→使用期→完结期**
- **四线（贯穿维度）**：四个从知晓期启动、贯穿全程、到完结期收束的并行线程——**信任构建、价值体验、付费升级、分享传播**

|--|--------|--------|-------------|-------------|-------------|--------|
| **线1 信任构建** | "这号好像懂行" | "数据有官方来源" | "方法论有道理"+"案例真实" | "策略看起来能行" | "就看结果了" | "结果兑现了信任" |
| **线2 价值体验** | 单篇文章有用 | 免费工具好用 | 个性化报告+数据更新 | 专家审核+社群答疑 | 录取预测缓解焦虑 | "值了！" |
| **线3 付费升级** | 免费内容消费 | ¥0注册 | ¥99体验版 或 ¥199轻享版 | ¥999进阶版 或 ¥2,999尊享版 | 暂停(等待验证) | 终止/续费/推荐 |
| **线4 分享传播** | 被动接收(别人转来) | 私下提及("关注了个号") | 私密分享(只发配偶) | 高度保密(竞争顾虑) | 配偶间焦虑交流 | **黄金窗口**(写经验帖) |

**v2.0 补充：多路径模型 —— 从"广度入口"维度扩展一轴四线**

一轴四线模型从**时间深度**维度展开用户旅程，描述了用户从知晓到完结的完整演进。但该模型隐含假设用户沿线性路径推进——"看到内容→关注→注册→试用→付费"。

2026年7月引入的[非线性多路径模型](HSEE-SZ-业务流程图谱-v1.0.md)（v2.0）从**广度入口**维度补充了这一框架：用户不必走完完整线性流程，而是通过五种不同路径进入产品，每种路径的起点、节奏、信任基础不同。

两个模型的关系是**互补而非替代**：
- **一轴四线**回答"用户在时间维度上如何演进"——适用于已进入产品的用户，指导内容策略沿时间线布局
- **多路径模型**回答"用户从哪里来、以什么状态进来"——适用于获客策略，指导不同入口的内容形态和转化设计

**对内容策略的关键启示**：

1. **Path B（外部流量信任用户，~30%）—— 内容不仅要"教育"，还要"验证"**
   - 从抖音/小红书/头条进入的用户已有初步信任（被内容打动才扫码），不需要从头科普
   - 他们需要的是**快速确认信号**："这个平台靠谱"——数据来源标注（"数据来源：szeb.sz.gov.cn"）、好评展示、权威认证标识
   - 内容策略：首页/落地页优先展示信任证据（Layer 1-3），而非从头介绍中考基础知识
   - 这类用户注册后**不强制弹出科普引导**，直接进入核心功能

2. **Path C（朋友介绍直达，~15%）—— 外部平台分发的内容应包含清晰CTA**
   - 朋友推荐+邀请码进入的用户信任基础最强，可能跳过内容浏览直接订阅
   - 外部平台（抖音/小红书/头条）分发的内容末尾不应仅是品牌曝光（"关注我们了解更多"），而应包含清晰行动号召：**"扫码直接获取你的志愿方案"**
   - 邀请码机制让Path C用户注册后直达套餐页，而非五维内容矩阵

3. **全时全域入口设计**：内容分发时需为不同入口来源的用户设计差异化的落地体验（参见[业务流程图谱v2.0](HSEE-SZ-业务流程图谱-v1.0.md) 底部导航栏五Tab + 悬浮按钮 + 页面内嵌CTA设计）

### 1.2 一轴：主时间线（用户必然经历的四阶段）

#### 1.2.1 知晓期（9月→次年1月）

用户从"不知道"到"知道了"。这是所有四线的起点。

| 维度 | 描述 |
|------|------|
| **用户状态** | 模糊焦虑——"听说中考很难"、"志愿填报好像很重要"，但不知道具体该做什么 |
| **核心关注点** | 深圳中考基本态势、录取率、有哪些学校、大概需要多少分 |
| **信息获取渠道** | 微信公众号文章、今日头条推荐流、抖音短视频、朋友转发、学校家长群 |
| **产品设计要点** | 生产"认知启蒙"类免费内容，铺设搜索关键词，建立第一印象 |
| **本阶段四线动态** | ①信任："这号好像懂行"（初步印象）；②价值："这篇文章有用"（单篇体验）；③付费：未启动；④分享：被动接收（别人转发给我） |
| **关键指标** | 内容曝光量、公众号关注数、头条文章阅读量 |

#### 1.2.2 注册期（11月→次年2月）

用户从"知道了"到"进来看看"。时间上与知晓期有重叠——部分用户被内容打动后立即注册，部分用户观望数月才行动。

| 维度 | 描述 |
|------|------|
| **用户状态** | 开始重视但仍拖延——"先注册看看"、"免费的先用着" |
| **核心关注点** | 免费能拿到什么？操作是否简单？信息是否靠谱？ |
| **信息获取渠道** | 小程序注册、免费测评工具、可下载的PDF指南 |
| **产品设计要点** | 提供"即时满足"的免费体验——如一次免费的成绩-学校匹配测算、一份可下载的《深圳中考志愿填报速查手册》 |
| **本阶段四线动态** | ①信任："数据有官方来源，试试看"；②价值：免费工具初次体验；③付费：¥0注册，接触套餐结构；④分享："我关注了这个号"（私下提及） |
| **关键指标** | 注册转化率、首次体验完成率、留存率（7日） |

#### 1.2.3 使用期（1月→7月）—— 核心战场

用户从"进来看看"到"持续使用"。这是**全旅程最长的阶段（约6个月）**，也是四线最活跃的时期。内部按决策节奏分为三个子阶段：

**准备子阶段（1月→4月）："慢慢研究"**

| 维度 | 描述 |
|------|------|
| **用户状态** | 一模成绩出来后，开始认真研究，但不急迫——"还有时间" |
| **核心关注点** | 数据是否官方？方法是否科学？有没有成功案例？我的分数能上什么学校？ |
| **典型行为** | 深度阅读公众号长文、在小红书搜索学校和攻略、使用免费测评工具反复测算、在家长群打听 |
| **产品设计要点** | 展示"信任证据链"五层（见线1详述）；分数段-学校匹配工具；学校深度测评系列内容 |
| **本阶段四线动态** | ①信任：关键积累期——"数据靠谱→方法论有道理→案例真实"；②价值：从免费内容逐步深入付费功能；③付费：首次付费决策（¥99体验版或¥199轻享版）；④分享：高度私密——只发给配偶和最亲密朋友 |

**决策子阶段（4月→5月底）："必须决定了"**

| 维度 | 描述 |
|------|------|
| **用户状态** | 决策焦虑峰值——"马上就要填了，冲稳保怎么排？"、"这个方案真的最优吗？" |
| **核心关注点** | 一对一专家审核、最终方案确认、风险排查、同类家长的选择参考 |
| **典型行为** | 升级套餐获取专家服务、反复修改志愿方案、与客服深度沟通、寻求同类案例验证 |
| **产品设计要点** | 灵活升级路径（补差价即可升档）；专家一对一审核服务；志愿方案自检checklist；限时紧迫感（"距离志愿填报截止还有X天"） |
| **本阶段四线动态** | ①信任：验证时刻——"策略有效吗？"；②价值：峰值体验（专家审核=最高价值感知点）；③付费：升级高峰（¥199→¥999或直接¥999/¥2,999）；④分享：几乎不分享——高度保密，担心竞争对手 |

**等待子阶段（6月→7月）："只能等了"**

| 维度 | 描述 |
|------|------|
| **用户状态** | 等待焦虑——"会不会滑档？"、"第一志愿能上吗？" |
| **核心关注点** | 录取概率预测、同分段其他考生动态、补录/调剂信息 |
| **典型行为** | 反复查看录取进度、关注分数线预测、与其他家长交流焦虑 |
| **产品设计要点** | 录取结果预测工具；分数线公布后的"志愿方案复盘"自动生成；未录取用户的补录指导 |
| **本阶段四线动态** | ①信任：待验证——"就看结果了"；②价值：焦虑缓解型内容（预测工具、进度推送）；③付费：基本停止，等待结果验证；④分享：适度分享焦虑（仅限于最亲密圈子） |

#### 1.2.4 完结期（7月→9月）

用户从"用完了"到"离开或回头"。四线在此收束。

| 维度 | 描述 |
|------|------|
| **用户状态** | 尘埃落定——如满意则愿意分享，如不满意则可能沉默或抱怨 |
| **核心关注点** | 面子（孩子考上好学校）、帮助他人（给低年级家长建议）、自我总结 |
| **典型行为** | 分享录取结果、写经验帖、退出/保留社群、推荐给低年级家长 |
| **产品设计要点** | "晒录取喜报"活动（分享=积分）；"学长学姐说"经验征集（UGC黄金窗口）；跨届传承计划（引导已录取家长为下一届提供咨询）；不满用户的安抚与反馈收集 |
| **本阶段四线动态** | ①信任：终局验证——"结果兑现了信任" or "信任断裂"；②价值：最终评判——"值了" or "不值"；③付费：终止（除非跨届推荐转化）；④分享：意愿达峰值（满意时）or 归零（不满意时） |
| **关键指标** | 分享率、邀请注册数、评论区UGC数量、NPS净推荐值 |

### 1.3 四线：贯穿全程的并行维度

这四条线不是阶段，而是**从知晓期就启动、在整个使用期交织演进、到完结期才收束**的并行线程。每条线都有自己的"积累-验证-收束"节奏。

#### 1.3.1 线1：信任构建线（Trust Building Thread）

信任不是一个"寻找锚点"的时刻，而是一条**持续积累（也可能中途断裂）**的曲线。

```
知晓期          注册期           使用期（准备）     使用期（决策）   使用期（等待）   完结期
──────────────────────────────────────────────────────────────────────────────
"这号好像    "数据有官方     "方法论有道理"   "策略看起来"    "就看结果了"   "结果兑现
 懂行"  →    来源，试试"  →  "案例真实"    →  能行"      →              →  了信任"
                                   "客服专业"                                    or
                                                                          "信任断裂"
```

**信任构建的五层证据链**（每层对应不同阶段的信任深化）：

| 层级 | 证据类型 | 作用阶段 | 示例 |
|------|---------|---------|------|
| Layer 1 | 数据可信 | 知晓期→注册期 | 标注官方数据来源URL，每篇内容注明数据年份和出处 |
| Layer 2 | 方法论可信 | 使用期（准备） | 公开决策模型的逻辑（博弈论+贝叶斯+前景理论），让用户理解"为什么这样推荐" |
| Layer 3 | 案例可信 | 使用期（准备→决策） | 展示脱敏的真实用户案例和结果，包含具体的分数、学校、录取结果 |
| Layer 4 | 专家可信 | 使用期（决策） | 一对一咨询中展示专业度；直播答疑中实时展现知识深度 |
| Layer 5 | 社会可信 | 使用期→完结期 | 用户数量、好评、媒体报道、评论区真实反馈 |

**信任断裂风险点**：
- 数据出错（如某学校分数线标注错误）→ 信任瞬间崩塌
- 承诺未兑现（如预测录取结果与实际不符）→ 完结期信任断裂
- AI批量生成的低质量内容被用户识别 → 专业形象受损

#### 1.3.2 线2：价值体验线（Value Experience Thread）

用户对"这东西值不值"的感知是**持续累积**的，不是某一次体验决定的。

```
知晓期          注册期           使用期（准备）     使用期（决策）   使用期（等待）   完结期
──────────────────────────────────────────────────────────────────────────────
"这文章    "免费工具     "个性化报告   "专家审核    "录取预测"   "录取了，
 有用"  →  挺好用"  →   "数据更新"  →  "社群答疑" →           →  值了！"
                           "社群交流"    "一对一咨询"               or "不值"
```

**价值感知的阶梯递进**（每层体验为下一层铺垫）：

| 体验层级 | 对应套餐 | 核心价值感知 | 对下一层的拉动 |
|---------|---------|-------------|--------------|
| 免费内容 | ¥0 | "这号懂行，内容有用" | → 关注/注册 |
| 免费工具 | ¥0 | "这个工具能帮我定位" | → 注册/体验版 |
| 基础付费功能 | ¥99体验版 | "付费内容比免费更深入" | → 轻享版 |
| 深度付费功能 | ¥199轻享版 | "个性化分析很精准" | → 进阶版 |
| 专家服务 | ¥999进阶版 | "有人帮我把关，放心多了" | → 尊享版 |
| 全程陪伴 | ¥2,999尊享版 | "从填志愿到录取都有保障" | → 传播推荐 |

**关键原则**：每层价值体验都是下一层付费升级的**前置条件**。如果用户觉得¥99不值，绝不会升级到¥199。因此，每个付费档位的价值交付必须"超预期"。

#### 1.3.3 线3：付费升级线（Payment & Upgrade Thread）

付费不是一次性的"订阅时刻"，而是一个**渐进升级**的过程。用户可能在任何时间点进入付费体系，也可能在任何时间点升级。

```
知晓期          注册期           使用期（准备）            使用期（决策）        完结期
──────────────────────────────────────────────────────────────────────────────────
(内容消费)      ¥0注册       ¥99体验版 或  ¥199轻享版       ¥999进阶版           --
                              直接¥199轻享版             ¥2,999尊享版
                                                     (决策焦虑驱动跳级)
```

**升级驱动因素**：

| 驱动因素 | 典型升级路径 | 触发时机 |
|---------|-------------|---------|
| **价值驱动**（"免费不够用了"） | ¥0→¥99 | 使用期准备阶段，发现免费工具不能覆盖需求 |
| **焦虑驱动**（"快填志愿了，我需要更专业的帮助"） | ¥99→¥199 或 ¥99→¥999（跳级） | 使用期决策阶段 |
| **信任驱动**（"用了这么久，确实靠谱"） | ¥199→¥999 | 使用期决策阶段 |
| **安全驱动**（"万一滑档怎么办"） | →¥2,999 | 使用期决策阶段（焦虑峰值） |
| **社交驱动**（"朋友买了说好"） | 任意→任意 | 任何阶段，来自他人口碑推荐 |

**五级套餐定价体系**：

| 套餐 | 价格 | 核心权益 | 目标用户 |
|------|------|---------|---------|
| 免费注册 | ¥0 | 基础内容浏览、一次性分数-学校匹配测算 | 所有进入用户 |
| 体验版 | ¥99 | 个性化志愿方案（1次生成）、速查手册下载、基础数据查询 | 想试试付费价值的用户 |
| 轻享版 | ¥199 | 多次志愿方案修改、模考成绩动态更新、会员社群、学校深度数据 | 认真准备志愿的用户 |
| 进阶版 | ¥999 | 一对一专家审核志愿方案、VIP微信群、录取概率动态评估、志愿提交前最终审核 | 决策期需要专家把关的用户 |
| 尊享版 | ¥2,999 | 全程一对一咨询、录取后跟踪服务、补录/调剂优先指导、跨届传承计划资格 | 追求最大确定性的用户 |

```

**各阶段分享行为特征**：

| 阶段 | 分享意愿 | 分享对象 | 分享内容 | 传播价值 |
|------|---------|---------|---------|---------|
| 知晓期 | 被动 | 被别人分享给我 | 单篇文章/短视频 | 获客入口（别人转来的流量） |

| 完结期（不满意） | 极低 | 私下抱怨 | 负面评价 | 负面传播风险 |

**评论区：比转发更重要的"被动传播"阵地**（详见1.4节家长传播心理分析）

### 1.4 家长传播心理深度分析

#### 核心判断：家长在中考志愿填报领域的分享行为遵循"高度选择性分享"模式

**一、家长会主动分享链接吗？**

**会，但有严格的条件限制。** 分享行为由以下动机驱动：

1. **利他动机（最强烈）**：分享给"正在经历同样焦虑"的家长——特别是亲戚家的同龄孩子、亲密朋友的孩子。分享时的心理台词是"这个东西有用，你也看看"。
2. **社交货币动机**：分享体现自己"做了功课"、"信息灵通"——这在家长群中是一种无声的社交资本积累。
3. **自我总结动机**：录取结束后分享经验，本质上是给自己的陪考旅程画上句号。

**二、主动分享的利弊分析**

| 利 | 弊 |
|----|-----|
| 帮到亲友，获得感谢和社交认可 | 暴露孩子成绩水平（隐私风险） |
| 展示自己"做足功课"的信息优势 | 被亲友认为"过度焦虑"或"鸡娃" |
| 通过分享获得更多信息交换 | 竞争对手（同校同分段）也可能看到 |
| 获得平台积分/优惠 | 如果孩子最终录取结果不理想，分享变成"打脸" |

**三、家长的保护心理与分享边界**

这是一个**被严重低估的关键洞察**：

> 家长在中考阶段存在强烈的"信息保密"倾向。他们**最愿意分享的对象是亲人和极亲密朋友**（特别是已经有孩子经历过中考的"过来人"），**最不愿意分享的对象是同校同年级的其他家长**（潜在竞争者）。

**分享圈层模型：**

```
第一圈（高意愿）：配偶、孩子的爷爷奶奶/外公外婆、亲兄弟姐妹
第二圈（中意愿）：已经经历过中考的朋友、孩子已经上高中的朋友、低年级家长
第三圈（低意愿）：同班/同校同年级家长（竞争对手）、普通朋友
第四圈（极低意愿）：公开朋友圈（除非结果已定且满意）
```

**四、时间维度上的分享规律**

> **核心发现：考试结束后（录取结果确定后），分享意愿显著上升。**

- **考前/填志愿前**：高度保密，不愿透露孩子的目标学校和志愿方案
- **填完志愿后至录取前**：适度分享，但仍有保留（怕万一滑档被笑话）
- **录取结果公布后（满意）**：分享意愿达到峰值，愿意写"经验帖"帮助后来者
- **录取结果公布后（不满意）**：几乎不分享，甚至回避相关话题
- **孩子上高一后**：对中考话题的关注度断崖下降，分享意愿归零

**五、评论区反馈的替代性传播价值**

> **评论区是比"转发链接"更安全、更低心理门槛的传播方式。**

- 家长在匿名或半匿名的评论区的表达意愿远高于主动转发链接
- 评论区的真实反馈（"我家孩子也是这样的"、"这个分析很准"）对后来者的说服力**不亚于主动分享**
- 评论区的负面反馈也有价值——真实的不完美反而增加了可信度

**六、对产品设计的启示**

1. **不依赖公开分享（朋友圈转发）作为主要传播渠道**——中考的特殊性决定了这**不是一个"晒娃"场景**
2. **设计"安全的一对一分享"功能**——如"转发给指定好友"而非"转发到朋友圈"
3. **重视评论区运营**——评论区是"被动传播"的核心阵地
4. **录取后的"经验帖征集"是UGC黄金窗口**——此时家长分享意愿最高
5. **建立"跨届传承"机制**——引导已录取的高一家长为下一届家长提供经验

### 1.5 一轴四线模型对产品设计的综合启示

基于以上分析，产品设计需要同时服务"一轴"的时间节奏和"四线"的持续演进：

**对主时间线的设计原则**：

1. **知晓期的内容必须"捞人"**——用强钩子标题+反常识开头+数据冲击，在海量信息流中截获注意力
2. **注册期的体验必须"即时满足"**——用户注册后60秒内必须获得可感知的价值（一次测算、一份手册）
3. **使用期的价值必须"层层递进"**——免费→¥99→¥199→¥999→¥2,999，每一层都让用户觉得"值，下一层更值"
4. **完结期必须"善始善终"**——满意的用户是下一年的获客入口，不满的用户至少不要变成负面传播源

**对四条线的设计原则**：

1. **信任构建线（全程）**：每一篇内容、每一次互动都在投票——增强或削弱信任。数据出错是红线，AI批量低质内容会慢性消耗信任
2. **价值体验线（全程）**：不要等用户付费后才给价值。免费阶段就给"超出预期的免费内容"，付费阶段的每一档都要"超预期交付"
3. **付费升级线（全程）**：升级路径必须"无摩擦"——补差价即可升级，不要设置"必须先退订再重新订阅"等障碍。焦虑驱动的跳级（¥99直接→¥999）是好事，要支持
4. **分享传播线（全程）**：不依赖公开分享（朋友圈转发），重点设计"安全的一对一分享"和评论区运营。完结期的"经验帖征集"是UGC黄金窗口，错过不再来

**关键设计决策**：

| 决策 | 常见误区 | 一轴四线修正 |
|------|-----------|-----------|
| 信任建设时机 | 有一个"寻找信任锚点"的阶段 | 信任从第一眼就开始，每个触点都在建设或消耗 |
| 付费节奏 | 先订阅→再升级，两步 | 五级渐进，用户可在任意时刻跳级 |
| 分享驱动 | 录取后集中做传播 | 每阶段分享形式不同，评论区是持续传播阵地 |
| 价值交付 | 付费后才给核心价值 | 免费阶段就超预期，付费阶段逐层加深 |
| 焦虑处理 | 提供信息缓解焦虑 | 焦虑是升级驱动力（焦虑驱动跳级），但需提供"确定性"来平衡 |

## 第二章：全生命周期内容策略

### 2.1 三阶段内容矩阵总览

```
前期（唤醒认知）          中期（建立信任）          后期（促成决策+传播）
9月 → 次年2月             2月 → 5月                  5月 → 9月

目标：让用户"知道我"      目标：让用户"信我"        目标：让用户"买我/传我"
```

### 2.2 阶段一：前期 — 唤醒认知（9月→次年2月）

**用户画像**：初三家长，刚意识到中考的存在，对志愿填报几乎零认知，焦虑但不知从何入手。

**内容目标**：成为用户"中考志愿填报"领域的第一印象来源。

#### 2.2.1 选题策略

**选题公式**：`深圳中考 + [时间/数量/排名/对比/避坑] + 家长想知道但不知道的事`

**五大选题方向**：

| 方向 | 示例选题 | 目标平台 | 可信度来源 |
|------|---------|----------|-----------|
| **全景认知** | 《2026深圳中考：142所高中，80,303个公办学位，你家孩子排第几？》 | 公众号、头条 | 官方招生计划数据 |
| **数据冲击** | 《深圳中考录取率真实数据：公办普高率约54%，剩下46%去哪了？》 | 头条、抖音 | 历年录取数据汇总 |
| **规则扫盲** | 《深圳中考志愿填报16个志愿怎么填？一篇文章讲清楚冲稳保底》 | 公众号、小红书 | 官方报考指南 |
| **时间线** | 《2026深圳中考大事记：从现在到录取，每个月该做什么》 | 公众号、小红书 | 官方日程安排 |
| **破除谣言** | 《深圳中考5大谣言：指标生不是关系户、走读不等于差生》 | 头条、抖音 | 官方政策文件 |

#### 2.2.2 标题方法论

基于"饼干哥哥"文章的流量权重公式：**选题占50%，标题占20%**。

**四类高转化标题**：

1. **数据冲击型**：`深圳中考：101所公办高中排名出炉，第一名分数线XXX`
2. **反常识型**：`为什么中考550分在深圳可能上不了公办高中？`
3. **嘴替共鸣型**：`"孩子模考480分，我能睡着觉吗"——一个深圳初三家长的真实焦虑`
4. **悬念引导型**：`深圳中考志愿填报最容易踩的5个坑，第3个90%的家长都不知道`

**标题自检清单**：
- □ 是否超过15字？（超过则需压缩）
- □ 是否包含具体数字？（数字 = 可信度）
- □ 是否避免"你知道吗"、"今天分享"等AI套话？（前3秒决定生死）

#### 2.2.3 开头写作方法

**AI最弱的环节，需要人工把关。** 四种高转化开头：

| 类型 | 模板 | 适用于 |
|------|------|--------|
| **嘴替共鸣** | "你是不是也在想……？" | 公众号长文 |
| **反常识** | "深圳中考有一个冷知识：……" | 头条、抖音 |
| **个人故事** | "去年这个时候，我收到一位家长的私信……" | 公众号、小红书 |
| **数据冲击** | "2026年深圳中考报名人数预计突破13万。" | 全平台 |

#### 2.2.4 关键平台策略（前期）

| 平台 | 内容形式 | 发布频率 | 核心KPI | 可信度标注 |
|------|---------|---------|---------|-----------|
| **今日头条** | 800-1500字图文 + 数据图表 | 每周3-5篇 | 推荐量、阅读量 | ★★★★（算法推荐精准） |
| **微信公众号** | 2000-4000字深度长文 | 每周1-2篇 | 关注转化率 | ★★★★★（私域沉淀核心） |
| **抖音** | 15-60秒短视频 | 每周3-5条 | 完播率、互动率 | ★★★（娱乐心态用户） |
| **小红书** | 图文笔记（干货清单型） | 每周2-3篇 | 搜索排名、收藏数 | ★★★★（搜索长尾价值高） |
| **视频号** | 3-5分钟深度讲解 | 每周1-2条 | 转发率、社交裂变 | ★★★★（社交信任背书） |

**平台选择依据**：基于"抖音、视频号、小红书：不同平台的短视频获客逻辑对比"一文的结论——
- 抖音 = "被动刷" → 适合前期唤醒，强钩子+快节奏
- 视频号 = "社交看" → 适合中期信任，朋友点赞 = 信任背书
- 小红书 = "主动搜" → 适合全周期，搜索长尾流量持续3-6个月

### 2.3 阶段二：中期 — 建立信任（2月→5月）

**用户画像**：一模成绩出来后，家长开始认真研究志愿填报，急切需要可操作的具体指导。

**内容目标**：从"这个号有点东西"升级为"这个号值得信赖"。

#### 2.3.1 信任建立的五层证据链

```
Layer 1: 数据可信 → 标注所有数据的官方来源URL
Layer 2: 方法论可信 → 公开决策模型的逻辑（博弈论+贝叶斯+前景理论）
Layer 3: 案例可信 → 展示脱敏的真实用户案例和结果
Layer 4: 专家可信 → 展示团队的教育/数据科学背景
Layer 5: 社会可信 → 展示用户数量、好评、媒体报道
```

#### 2.3.2 中期内容产品线

| 内容产品 | 形式 | 目的 | 对应信任层 |
|---------|------|------|-----------|
| **速查手册** | 可下载PDF | 让用户"拿到手上"的价值感 | Layer 1, 2 |
| **学校深度测评** | 公众号长文系列 | 展示研究深度和专业度 | Layer 1, 2, 3 |
| **决策模型科普** | 系列文章+图解 | 建立方法论壁垒（别人没有） | Layer 2 |
| **家长案例（脱敏）** | 人物故事型文章 | 情感共鸣+社会证明 | Layer 3, 5 |
| **政策解读直播** | 视频号直播+回放 | 实时互动建立个人信任 | Layer 4 |
| **免费测评工具** | 小程序内功能 | 让用户"亲自体验"价值 | Layer 2, 3 |

#### 2.3.3 小红书搜索流量的精准截获

基于"小红书流量不是玄学"一文的8个底层机制，中期内容必须**从"我想表达什么"转向"用户正在搜什么"**。

**深圳中考家长在小红书的TOP搜索意图**：

| 搜索意图 | 典型搜索词 | 对应内容策略 |
|---------|-----------|-------------|

**小红书内容自检表（基于林卿的8条标准）**：

- □ 这篇内容服务的是哪一类人？（越具体越好："龙岗区AC类考生，模考500分左右"）
- □ 封面、标题、正文、图片是否都指向同一个核心问题？
- □ 冷启动期内容方向是否稳定？（不要今天发政策解读，明天发情绪鸡汤）
- □ 搜索场景里，这篇内容是不是一个真正的答案？
- □ 是否围绕核心人群建立了语义资产（持续输出同一领域的内容集群）？

### 2.5 分人群内容定位：家长付费心理四象限

> 上述三阶段是"时间轴"，还需叠加"分人群轴"——不同家长类型的付费意愿与内容需求截然不同。本节从家长心理维度给出分人群内容定位，作为三阶段内容的"横切维度"。

#### 核心判断：付费意愿 = 学业关注度 ×（1 − 信息获取能力）

家长是否付费，本质上由两个心理变量决定：

| 心理轴 | 定义 |
|------|------|
| **对考生学业的关注度** | 家长对子女升学的重视与投入程度 |
| **家长获取知识点的意识与能力** | 能否读懂政策、检索信息、独立判断 |

> **"越想管 + 越搞不定" = 付费意愿最强；"越想管 + 自认为搞得定" = 意愿被能力压制；"不太想管" = 意愿低。**

#### 四象限家长类型 × 内容策略

| 家长类型 | 学业水平 | 典型心理 | 付费意愿 | 内容策略（语言风格 + 钩子） |
|------|:---:|------|:---:|------|
| **① 自信DIY型** | A+/A | "我已研究透，能自己填" | 中（被能力压制） | 用"独家数据"反杀：指标生校内排名/末位同分比较等查不到的数据；"你收藏的37篇攻略，有12篇数据是错的" |
| **② 焦虑求助型 ⭐** | B+/B | "很重视但看不懂规则" | **极高** | 用"风控语言"给避坑指南/冲稳保模板/滑档预警；"16个志愿格，填错1个=孩子用3年买单" |
| **③ 临界求生型 ⭐** | C+ | "差一分就滑档" | **极高** | 用"兜底恐惧"给保底方案/补录攻略/民办性价比；"差一分滑档，临界生每一步都值3年" |
| **④ 佛系放任型** | C | "民办也行" | 低 | 用"从众裂变"给民办对比/中职解析；低价工具+社交裂变，不做深读 |

#### 关键结论（内容资源分配）

1. **②焦虑求助型 + ③临界求生型 合计约9.18万人、占60%**，是"数量最多 + 付费意愿最强"的黄金客群——内容主打"**避坑指南 + 保底方案 + 滑档预警**"这类**风控语言**，而非"名校冲刺"的**机会语言**。

2. **①自信DIY型（A+/A）付费能力最高（¥5,000-12,000）**，但需用"独家数据 + 权威结论"反杀其自信，是高端产品的撬动点。

3. **④佛系放任型（C）**靠社交裂变 + 低价工具（¥199-800）覆盖，不宜深度投入。

> 本节与三阶段矩阵（2.1-2.4）正交：每个阶段的内容，都应按上述四象限进一步"分人群定制"，形成"3阶段 × 4人群"的完整内容矩阵。

### 3.3 维度二：信息搜集

#### 3.3.1 信息来源与可信度分级

| 可信度 | 来源类型 | 具体来源 | 使用原则 |
|--------|---------|---------|---------|
| **S级（官方一手）** | 官方政策文件 | szeb.sz.gov.cn官方通知、2026报考指导手册 | 直接引用，标注出处 |
| **A级（官方二手）** | 官方数据衍生 | 历年录取分数线汇总、招生计划表 | 交叉验证后引用 |
| **B级（专业分析）** | 行业专家/机构 | 教育媒体解读、培训机构分析 | 多方对比，标注"仅供参考" |
| **C级（用户反馈）** | 真实用户声音 | 评论区、家长群讨论、小红书真实笔记 | 匿名化处理，注明样本局限 |
| **D级（竞品参考）** | 同类产品内容 | 中考志愿网、本地宝等内容 | 仅作选题参考，不直接引用 |

#### 3.3.2 信息搜集SOP（基于曾俊"ClaudeCode素材处理"方法适配）

```
Step 1: 设置信息监测点
├── 官方渠道：szeb.sz.gov.cn RSS监控
├── 数据渠道：各校招生简章、录取分数线公告
├── 竞品渠道：同类公众号/小红书账号内容更新
└── 用户渠道：客服记录、评论区高频问题

Step 2: 抓取与清洗
├── 网页内容：直接抓取正文 → 保留标题/来源/发布时间/URL
├── PDF/文件：提取文本 → 结构化整理
└── 用户反馈：脱敏 → 归类 → 标签化

Step 3: 去重与排序
├── 同一信息多个来源 → 保留可信度最高的来源
├── 矛盾信息 → 标记冲突，优先采信官方来源
└── 过时信息 → 标记"已过时"并归档

Step 4: 结构化入库
├── 存入知识库：按主题/时间/可信度分类
├── 关联标签：关联到具体的选题和内容产品
└── 定期清理：过时数据每季度清理一次
```

#### 3.3.3 冲突校验规则

当多个来源的信息矛盾时：

1. **政策类**：以szeb.sz.gov.cn官方文件为准
2. **数据类**：以原始Excel数据文件为准（知识库中的合并版Excel）
3. **解读类**：取多家解读的"最大公约数"，标注分歧点和可信度
4. **经验类**：注明"个体经验，不代表普遍情况"

### 3.4 维度三：内容构思

#### 3.4.1 内容三问（每篇内容创作前必须回答）

基于"林卿"内容输出方法论：

1. **写给谁？** → 越具体越好。不是"初三家长"，而是"龙岗区AC类考生家长，孩子模考480-520分，第一次接触志愿填报"
2. **解决什么问题？** → 用户看完后能做什么？（不是"了解中考"，而是"能用这张对照表找到孩子分数对应的5所目标学校"）
3. **为什么是我？** → 我的独特价值是什么？（官方数据 + 博弈论模型 + 真实案例，竞品没有的组合）

#### 3.4.2 内容构思框架

```
文章/笔记构思模板：
├── 核心观点（一句话说清楚）
├── 目标读者画像（谁会在什么场景下读到）
├── 用户看完后的行动（转发？收藏？评论？付费？）
├── 信任锚点（哪些数据/案例/资质能证明我说的）
├── 差异化角度（同样的话题，我的不同切入点是什么）
└── 转化路径（这篇文章在整个用户旅程中的位置）
```

### 3.5 维度四：撰写方法

#### 3.5.1 好内容六条标准（适配中考领域）

基于"饼干哥哥"的六条标准，适配到中考志愿填报内容：

| 标准 | 原始定义 | 中考领域适配 |
|------|---------|-------------|
| **逻辑递进** | 每300-500字有新观点 | 从问题→原因→数据→方法→案例，一气呵成 |
| **开头反常识** | 制造认知冲突 | "深圳中考竞争最激烈的不是四大名校，而是……" |
| **持续阅读钩子** | 让读者觉得"下面还有东西" | 用具体案例和数据制造"然后呢？"的悬念 |
| **素人感/人设感** | 像一个真人在说话 | 用"我研究了三年深圳中考数据发现……"开场 |
| **强烈个人观点** | 敢表态 | "我不建议500分以下的考生冲四大，原因有三" |
| **结尾升华** | 洞察/金句/反问 | "志愿填报的本质，是用信息差换分数差" |

#### 3.5.2 AI辅助写作工作流（四步法）

基于"饼干哥哥"的2.0工作流：

```
Step 1: 素材准备（人工）
├── 收集相关数据（Excel提取）
├── 确定核心观点和角度
├── 找2-3篇风格参考（自己的历史高阅读文章）
└── 整理关键案例（脱敏后的真实案例）

Step 2: AI初稿（AI + 约束提示词）
├── 喂入素材和风格参考
├── 使用结构化提示词（见下文）
├── 生成2-3个版本
└── 选择最佳版本进入下一步

Step 3: 人工加工（关键环节）
├── 读出声检查——哪里走神了就是哪里要改
├── 删空话、加个人经历、改结尾
├── 开头、结尾、关键判断句——这三处必须人工把关
└── 确保数据准确性和来源标注

Step 4: AI精修（只删不加）
├── 让AI做减法：删冗余、调节奏、统一风格
├── 明确指令："只删不加"
└── 通过去AI味检查清单（见3.6.2）
```

#### 3.5.3 结构化提示词模板

```
角色：你是深圳中考志愿填报领域的资深内容顾问。
任务：撰写一篇关于[主题]的[文章/笔记/短视频脚本]。
目标读者：[精确画像]
核心观点：[一句话]
约束条件：
- 字数：[XXX字]
- 风格：第一人称，像一个研究了5年深圳中考数据的人
- 数据来源：必须引用[具体数据文件]
- 禁止：套话（"值得注意的是""总的来说"）、AI式总结结尾
- 开头：[指定类型：反常识/数据冲击/嘴替共鸣/个人故事]
- 结尾：[指定类型：首尾呼应/个人判断/反直觉数据收尾]
- 阅读钩子：每300字一个
- 信任元素：至少包含1个数据引用+1个案例+1个个人判断
```

### 3.6 维度五：内容制作

#### 3.6.1 多格式内容生产矩阵

一篇核心长文（公众号）→ 拆解为多种格式分发到不同平台：

```
核心长文（3000字，公众号）
├── 头条版：压缩至1000字 + 3张数据图 + 强标题
├── 小红书笔记版：核心要点清单（图文，5-8张卡片）
├── 抖音脚本版：前3秒钩子 + 30秒核心信息 + CTA
├── 视频号版：5分钟深度讲解 + 公众号导流
├── 家长群转发版：1张长图（核心结论+二维码）
└── 播客/音频版：10分钟深度解读（可选）
```

#### 3.6.2 去AI味检查清单

基于"饼干哥哥"的8项检查清单适配：

```
发布前逐项自检：
□ 有没有"值得注意的是""总的来说""此外"等AI套话？ → 删
□ 每段是否都整齐"开头-展开-总结"？ → 打破结构
□ 连续数字列表超过2个？ → 改成叙述
□ 结尾是泛泛总结或展望？ → 换成具体判断
□ 缺少"我"的视角？ → 加真实故事或亲身经历
□ 所有观点都平衡中立？ → 大胆表态，敢说"我建议/不建议"
□ 读出声，哪里走神了？ → 那里要改
□ 删掉最后一段，文章更好？ → 直接删
```

#### 3.6.3 制作规范

| 规范项 | 标准 |
|--------|------|
| 数据引用 | 必须标注来源和年份，例如"（数据来源：szeb.sz.gov.cn，2026年招生计划）" |
| 学校名称 | 使用官方全称，首次出现时加括号标注简称 |
| 分数标注 | 标注AC类/D类区分，标注是否为折算后分数（2026年总分630） |
| 免责声明 | 每篇含数据分析的文章末尾：**"本文分析基于历史数据和公开政策，仅供参考，不构成志愿填报的最终建议。请以官方发布的最新政策和数据为准。"** |
| 合规红线 | 不承诺"保证录取"、不贩卖焦虑（"不上XX学校就完了"）、不泄露未公开的个人信息 |

#### 3.7.2 跨平台分发SOP

```

## 附录A：信息处理方法论

### A.1 去重规则

1. 同一事实多来源覆盖 → 保留可信度最高的来源（S级 > A级 > B级）
2. 同一选题多篇文章覆盖 → 提取"最大公约数"观点 + 标注差异化视角
3. 重复数据 → 保留最新版本（如2026年数据替代2025年数据）

### A.2 排序规则

1. **按时效性**：政策解读类 > 数据报告类 > 方法论文
2. **按可操作性**：有SOP/清单/模板的 > 纯理论/概念的
3. **按与HSEE的相关性**：中考/教育 > 通用内容营销 > 其他行业

### A.3 冲突校验规则

| 冲突类型 | 处理方式 |
|---------|---------|
| 数据冲突 | 以官方原始数据（Excel）为准，标注版本差异 |
| 观点冲突 | 保留多方观点，标注"行业存在不同看法" |
| 方法论冲突 | 标注适用条件和局限性，不强制统一 |

### A.4 可信度标注

本文档中引用的所有外部信息均标注可信度：

- ★★★★★ 官方一手来源（政府文件、原始数据）
- ★★★★ 经过验证的专业分析（有数据支撑、可复现）
- ★★★ 个人实战经验（有案例但样本有限）
- ★★ 行业通用方法论（未针对中考领域验证）
- ★ 推测/假设（需要进一步验证）

#### 文章10：ClaudeCode的172个应用场景（1）：内容创作（曾俊/Aaron）
- **可信度**：★★★★（780+会话实战验证，方法论系统完整）
- **核心要点**：
  - **前置准备五步法**：分人群素材调研+写作框架 → 拆解自己的写作风格（生成"风格说明书"）→ 拆解竞品博主爆款套路 → 选题生成与标题批量打磨（15-20个角度）→ 爆款方法论提炼+写作风格建模
  - **批量生产体系**：分人群批量写长文（同一套素材+框架复用）、主题系列长文（素材包反复调用）、专家访谈解读型长文（外部权威+本地化案例）、白皮书工程化写作（拆章节+统一风格+质检）、角色化AI Skills推荐系列（固定模板批量覆盖）
  - **多平台分发**：采访视频→原创分析短文（70%分析判断+30%事实概括）、同题不同稿批量改写、Markdown长文→小红书文案（换标题+增代入感+删技术细节+加收藏点）、AI爆款改写（多标题评估+结构重构）
  - **后期加工**：Markdown批量转图文卡片（HTML→3:4卡片→PNG导出）、文章价值观校验（对照CLAUDE.md+知识库做发布前质检）、视频逐镜头解析→复刻prompt
  - **五大关键原则**：①调研和写作要分离（素材做一次，反复用）②风格要显性化（"写得像我"→可复用规则）③批量生产必须带质检（字数/格式/禁用表达/事实来源/价值观校验）④一份素材多次产出（访谈→长文→小红书→卡片→系列）⑤Claude Code更适合做内容工程
- **对HSEE的启示**：为深圳中考不同家长人群（AC类/D类、不同分数段、不同区域）建立分人群素材包；建立HSEE的"写作风格说明书"；每篇政策解读长文→自动生成头条版、小红书版、抖音脚版本、家长群长图版；发布前必须通过价值观校验（数据来源标注、是否承诺"保证录取"、是否贩卖焦虑）
