# 视频制作与分发 SOP

## 文档概述

本文档是 `10-发布素材自动化方案` 的**第 3 步（视频 + 分发）落地 SOP**。前两步（数据图、封面）已脚本化，本步骤的"可自动化"部分是**口播脚本生成**，视频制作和分发依赖外部 SaaS 工具（剪映 / 腾讯智影 / 蚁小二），本文档给出标准操作流程。

**完整流水线**：

```
初稿 MD
  ├─① 文案变形（LLM，见 08 文档提示词模板）
  ├─② 数据图（scripts/generate_p5_4.py 等，已脚本化）
  ├─③ 封面（scripts/hsee_charts/cover.py，已脚本化）
  └─④ 口播脚本（本文档，LLM 按 08 文档口播模板变形）
        ↓
  剪映/腾讯智影 制作视频  →  蚁小二 一键分发  →  数据回传
```

---

## 一、口播脚本生成（可自动化）

### 1.1 三个视频平台的脚本模板

口播脚本是"初稿 MD → 视频脚本"的 LLM 变形，模板在 `08-九大平台文案撰写要求说明书` 的抖音/B站/快手章节。此处提炼核心参数：

| 平台 | 时长 | 字数 | 结构 | 语气 |
|------|:---:|:---:|------|------|
| 抖音 | 60-90 秒 | 200-300 字 | 0-3秒Hook → 3个信息点 → CTA | 快节奏、情绪词 |
| 快手 | 40-60 秒 | 180-250 字 | "家人们"开场 → 2-3要点 → 提醒 | 真诚接地气 |
| B站 | 8-12 分钟 | 1500-2500 字 | 开头30秒 → 3-5章 → 结尾30秒 | 教程感、口语化 |

### 1.2 生成方式

- **验证期（手动）**：把初稿 MD 的"核心结论"喂给豆包/DeepSeek，套用 08 文档对应平台的口播提示词模板。
- **自建期（脚本化）**：接入豆包 API，批量调用——输入初稿 MD + 平台参数，输出口播脚本。示例产物见 `scripts/output/p5-4-视频口播脚本.md`。

### 1.3 示例（P5-4 已产出）

`scripts/output/p5-4-视频口播脚本.md` 含抖音/快手/B站三个平台脚本，可直接复制到剪映/智影。

## 二、视频制作（剪映 AI 图文成片 + 腾讯智影数字人）

### 2.1 两条制作路线

| 路线 | 工具 | 成本 | 适用 | 产出 |
|------|------|:---:|------|------|
| **图文成片** | 剪映专业版 | ¥30/月 | 数据图 + 口播 → 快速成片 | 短视频（图文+配音+字幕） |
| **数字人口播** | 腾讯智影免费版 | ¥0 | 长文提炼 → 数字人出镜 | 真人感口播视频 |

### 2.2 剪映 AI 图文成片（约 10 分钟/条）

| 步骤 | 操作 |
|:---:|------|
| 1 | 打开剪映 → 图文成片 → 粘贴口播脚本 |
| 2 | AI 自动匹配素材（可手动替换为 HSEE 数据图/封面） |
| 3 | 选配音音色（成熟女声，适配家长受众） |
| 4 | 检查自动字幕（重点核对数据、校名、数字） |
| 5 | 导出：抖音/快手 9:16，B站 16:9 |

### 2.3 腾讯智影数字人（几乎全自动）

| 步骤 | 操作 |
|:---:|------|
| 1 | 把公众号长文提炼为 3 分钟口播脚本（或直接用 B站脚本） |
| 2 | 智影 → 数字人播报 → 粘贴脚本 |
| 3 | 选数字人形象 + 配音（固定成熟女声） |
| 4 | 自动字幕 + 背景（可加 HSEE 品牌底） |
| 5 | 导出视频 |

> ⚠️ 剪映/智影 API 不一定稳定——**先手动验证效果，稳定后再做 API 对接**（这是设计文档既定的原则）。

## 三、分发（蚁小二）

### 3.1 蚁小二能力

| 能力 | 说明 |
|------|------|
| 多平台统一管理 | 绑定抖音/小红书/视频号/公众号/头条/B站等账号 |
| 定时发布 | 按各平台流量高峰自动排期 |
| 标题/标签适配 | 自动适配各平台标题、标签、封面规范 |
| 数据回传 | 汇总各平台曝光/阅读/互动数据 |

### 3.2 发布流程

| 步骤 | 操作 |
|:---:|------|
| 1 | 素材包就绪：9 平台文案 + 数据图 + 封面 + 视频（对应平台） |
| 2 | 蚁小二 → 新建发布任务 → 选择平台 |
| 3 | 上传对应素材（图文平台传图+文，视频平台传视频） |
| 4 | 预设发布时间（各平台流量高峰，见 08 文档附录） |
| 5 | 人工终审（合规 + 数据）→ 确认发布 |
| 6 | 发布后数据回传 → 蚁小二汇总面板查看 |

### 3.3 各平台发布时间（蚁小二预设）

| 平台 | 最佳发布时间 |
|------|------|
| 公众号 | 周二/五 12:00 |
| 抖音 | 19:00-21:00 |
| 快手 | 18:00-20:00 |
| 小红书 | 12:30 / 20:00 |
| 今日头条 | 7:00-9:00 / 20:00-22:00 |
| B站 | 12:00 / 19:00 |

## 四、成本与时间

| 环节 | 工具 | 月成本 | 单条耗时 |
|------|------|:---:|:---:|
| 口播脚本 | 豆包/DeepSeek | 按量极低 | 1-2 分钟（AI） |
| 图文成片 | 剪映专业版 | ¥30 | ~10 分钟 |
| 数字人口播 | 腾讯智影 | ¥0 | ~5 分钟 |
| 分发 | 蚁小二专业版 | ¥129 | ~3 分钟/平台 |

**合计月成本约 ¥160**（剪映 ¥30 + 蚁小二 ¥129），与 10 号方案的成本估算一致。

---

## 五、验收标准

- [ ] 一篇初稿 MD 能产出 3 平台口播脚本（抖音/快手/B站），数据准确、符合各平台语气
- [ ] 剪映图文成片/智影数字人能直接吃入口播脚本 + 数据图，产出视频
- [ ] 视频字幕中的校名、数字、分数线经人工核对无误
- [ ] 蚁小二能按预设时间一键分发到目标平台，数据正常回传
- [ ] 每个素材包发布前经人工终审（04 合规清单）
