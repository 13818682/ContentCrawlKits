# 视频制作与分发 SOP

## 文档概述

本文档是 `10-发布素材自动化方案` 的**第 3 步（视频 + 分发）落地 SOP**。前两步（数据图、封面）已脚本化，本步骤的"可自动化"部分是**口播脚本生成**，视频制作和分发依赖外部 SaaS 工具（剪映 / 腾讯智影 / 蚁小二），本文档给出标准操作流程。

**完整流水线**：

```
初稿 MD
  ├─① 文案变形（LLM，见 08 文档提示词模板）
  ├─② 数据图（scripts/generate_p5_4.py 等，已脚本化）
  ├─③ 封面（scripts/hsee_charts/cover.py，已脚本化）
  └─④ 口播脚本（本文档，LLM 按 08 文档口播模板变形）
        ↓
  剪映/腾讯智影 制作视频  →  蚁小二 一键分发  →  数据回传
```

---

## 一、口播脚本生成（可自动化）

### 1.1 视频平台的脚本模板

口播脚本是"初稿 MD → 视频脚本"的 LLM 变形，模板在 `08-九大平台文案撰写要求说明书` 的抖音/B站/快手章节，小红书视频笔记见 `13-3` 模板。此处提炼核心参数（跨平台复用边界见 **第六节**）：

| 平台 | 时长 | 字数 | 结构 | 语气 |
|------|:---:|:---:|------|------|
| 抖音 | 60-90 秒 | 200-300 字 | 0-3秒Hook → 3个信息点 → CTA | 快节奏、情绪词 |
| 快手 | 40-60 秒 | 180-250 字 | "家人们"开场 → 2-3要点 → 提醒 | 真诚接地气 |
| B站 | 8-12 分钟 | 1500-2500 字 | 开头30秒 → 3-5章 → 结尾30秒 | 教程感、口语化 |
| 小红书（视频笔记） | 1-3 分钟 | 400-800 字 | 开头给结论+引导收藏 → 三件事信息全 → 收藏/关注CTA | 平缓、信息完整、收藏向 |

### 1.2 生成方式

- **验证期（手动）**：把初稿 MD 的"核心结论"喂给豆包/DeepSeek，套用 08 文档对应平台的口播提示词模板。
- **自建期（脚本化）**：接入豆包 API，批量调用——输入初稿 MD + 平台参数，输出口播脚本。示例产物见 `scripts/output/p5-4-视频口播脚本.md`。

### 1.3 示例（P5-4 已产出）

`scripts/output/p5-4-视频口播脚本.md` 含抖音/快手/B站三个平台脚本，可直接复制到剪映/智影。

## 二、视频制作（剪映 AI 图文成片 + 腾讯智影数字人）

### 2.1 两条制作路线

| 路线 | 工具 | 成本 | 适用 | 产出 |
|------|------|:---:|------|------|
| **图文成片** | 剪映专业版 | ¥30/月 | 数据图 + 口播 → 快速成片 | 短视频（图文+配音+字幕） |
| **数字人口播** | 腾讯智影免费版 | ¥0 | 长文提炼 → 数字人出镜 | 真人感口播视频 |

### 2.2 剪映 AI 图文成片（约 10 分钟/条）

| 步骤 | 操作 |
|:---:|------|
| 1 | 打开剪映 → 图文成片 → 粘贴口播脚本 |
| 2 | AI 自动匹配素材（可手动替换为 HSEE 数据图/封面） |
| 3 | 选配音音色（成熟女声，适配家长受众） |
| 4 | 检查自动字幕（重点核对数据、校名、数字） |
| 5 | 导出：抖音/快手 9:16，B站 16:9 |

### 2.3 腾讯智影数字人（几乎全自动）

| 步骤 | 操作 |
|:---:|------|
| 1 | 把公众号长文提炼为 3 分钟口播脚本（或直接用 B站脚本） |
| 2 | 智影 → 数字人播报 → 粘贴脚本 |
| 3 | 选数字人形象 + 配音（固定成熟女声） |
| 4 | 自动字幕 + 背景（可加 HSEE 品牌底） |
| 5 | 导出视频 |

> ⚠️ 剪映/智影 API 不一定稳定——**先手动验证效果，稳定后再做 API 对接**（这是设计文档既定的原则）。

## 三、分发（蚁小二）

### 3.1 蚁小二能力

| 能力 | 说明 |
|------|------|
| 多平台统一管理 | 绑定抖音/小红书/视频号/公众号/头条/B站等账号 |
| 定时发布 | 按各平台流量高峰自动排期 |
| 标题/标签适配 | 自动适配各平台标题、标签、封面规范 |
| 数据回传 | 汇总各平台曝光/阅读/互动数据 |

### 3.2 发布流程

| 步骤 | 操作 |
|:---:|------|
| 1 | 素材包就绪：9 平台文案 + 数据图 + 封面 + 视频（对应平台） |
| 2 | 蚁小二 → 新建发布任务 → 选择平台 |
| 3 | 上传对应素材（图文平台传图+文，视频平台传视频） |
| 4 | 预设发布时间（各平台流量高峰，见 08 文档附录） |
| 5 | 人工终审（合规 + 数据）→ 确认发布 |
| 6 | 发布后数据回传 → 蚁小二汇总面板查看 |

## 五、验收标准

- [ ] 一篇初稿 MD 能产出 3 平台口播脚本（抖音/快手/B站），数据准确、符合各平台语气
- [ ] 剪映图文成片/智影数字人能直接吃入口播脚本 + 数据图，产出视频
- [ ] 视频字幕中的校名、数字、分数线经人工核对无误
- [ ] 蚁小二能按预设时间一键分发到目标平台，数据正常回传
- [ ] 每个素材包发布前经人工终审（04 合规清单）

## 六、跨平台视频复用边界（小红书 vs 抖音 · 一稿双成片）

> **完整原则文档**：`docs/03-内容创作-深圳中考志愿填报/问答专区/001+非深户可在深圳参加中考读高中吗/00-抖音小红书视频制作原则与复用边界.md`（含分平台制作细则）。本节为项目级摘要，所有跨平台视频统一遵循。

**一句话：同源素材，不同成片。小红书视频笔记是"资料"，抖音视频是"钩子"。禁止原样直投。**

| 维度 | 抖音 | 小红书视频笔记 |
|------|------|------|
| 观众心智 | 完播型（前2秒定生死） | 收藏型（为保存信息看完） |
| 时长 / 字数 | ≤60秒 / 220-300字 | 1-3分钟 / 400-800字 |
| 开头 | 前2秒甩数字/结论钩子 | 点题给结论 + 引导收藏 |
| 信息密度 | 一条一记忆点，只留1个锚点数字 | 信息全保留，收藏价值核心 |
| 字幕 | 大字关键词，辅助完播 | 全量字幕，便于回看 |
| 封面 | 竖版 9:16 钩子 | 3:4 封面即信息预告 |
| 核心指标 | 完播率 / 2s跳出率 / 主页访问 | 收藏率 / 获粉 |

**复用边界**：
- ✅ **可共用**：选题、核心数据、素材源（主稿/数据卡图）、配音音色；**视频内分镜图（9:16）抖音→小红书直接复用**（小红书视频同 9:16 全屏播放，无需裁切）
- ⚠️ **按平台处理**：**小红书封面（首图）必须单独出 3:4**（feed 缩略是 3:4，点击率第一决定因素，勿传 9:16）；分镜图文字层按平台重排（底图共用、文字不同）
- ❌ **必须分开**：口播脚本、字幕方式、时长节奏、封面、CTA

**红线规则**：
- 小红书视频**原样直投**抖音 = 重复"公众号图文搬抖音"的错误（完播率被砍推荐）。
- 两者是"减"与"全"的关系：抖音版信息**砍到单点**，小红书版信息**全保留**——不是改措辞。
- 资源有限时跨投**最少做三件事**：换开头（前2秒甩结论）+ 砍信息（留1个锚点数字）+ 改字幕（大字关键词）。

**跨平台补充规则（2026-08-31 定稿，完整版见 QA-001 `00-…复用边界.md`）**：
- **抖音→头条视频**：默认直接同步（字节系原生打通、受众重叠、零成本吃放量）；仅**高长尾/需完整讲解型**主题（政策/数据复盘/志愿实操/费用对比）值得单独做 2-3 分钟头条资讯版吃中视频池。
- **抖音图文/文章 vs 头条**：文字素材可复用（原创同源）；结构必须重构（头条文章→抖音图文轮播卡，一卡一点）；头条 1200×900 横版图不能直传，需改竖版；**战术上不建议重点投入抖音图文**（周数据图文低播放，主场是原生视频）。
- **小红书三载体**：`01.视频/`（分镜复用抖音9:16、封面单独3:4）、`02.图文/`（独立脚本+首图+正文图N一卡一点）、`03.长文/`（文字复用头条长文+1-2张竖版数据图）。
- **图片命名编号**：图文笔记 `正文图{序号}`、长文笔记 `长文{序号}` 按脚本顺序编号；PNG、脚本 md 的 `cover/images`、生成脚本 `save()` **三处同步维护**。
