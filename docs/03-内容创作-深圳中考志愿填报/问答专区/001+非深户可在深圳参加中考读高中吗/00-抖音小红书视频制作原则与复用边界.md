# 跨平台内容与视频复用边界（抖音 · 小红书 · 今日头条）

> 一句话定位：**同源素材，不同成片。** 小红书="资料"（收藏型）、抖音="钩子"（完播型）、头条="放量"（顺风车）。素材源共享，成片按平台各产一版，禁止原样直投。

## 一、两平台视频原则对比

| 维度 | 抖音 | 小红书视频笔记 |
|---|---|---|
| 观众心智 | 完播型（前2秒定生死） | 收藏型（为了保存信息看完） |
| 最佳时长 | 15-60秒，冷启动期更短 | 1-3分钟，容忍度高 |
| 口播字数 | 220-300字黄金档 | 不限（收藏向可到600-800字） |
| 开头 | 前2秒甩数字/结论钩子 | 点题给结论即可，可稍缓 |
| 信息密度 | 一条视频一个记忆点 | 信息全保留（收藏价值核心） |
| 节奏 | 快、段落感强、分段大字卡 | 平缓、分段清晰、贴纸卡切换 |
| 字幕 | 大字关键词，辅助完播 | 全量保留，便于回看 |
| 封面 | 竖版 1080x1920，钩子先行 | 3:4 1080x1440，封面即信息预告 |
| 核心指标 | 完播率 / 2s跳出率 / 主页访问 | 收藏率 / 获粉 / 完播（参考） |
| 失败后果 | 完播低→被砍推荐（本周6%垫底） | 完播低也能靠收藏沉淀 |

## 二、抖音制作原则（QA-001 见 `04B.抖音/...V2.md`）

1. **钩子前置**：前2秒兑现标题结论，禁止铺垫。
2. **单点化**：一条视频只讲一个记忆点；多件事 → 拆系列，或每件事只留 1 个锚点数字。
3. **数据减负**：口播只留最能冲击的锚点数字，其余沉评论区置顶。
4. **视觉节奏**：分段配【大字标题卡】切换画面，靠视觉拉回走神观众、撑完播。
5. **确定性CTA**：预告下一条具体内容 + "关注我"，给关注理由；可加转发钩子触发圈层传播。
6. **考核**：完播率 / 2s跳出率 / 主页访问量 / 搜索占比；粉丝净增降级为参考（抖音关注转化率天然低）。

## 三、小红书制作原则（QA-001 见 `03.小红书/...视频笔记.md`）

1. **信息全保留**：收藏是核心价值，数字、条件、路径一个都不能少——小红书观众收藏是为了"以后查"。
2. **封面即信息**：3:4 首图大字写清结论+关键数字，点击率靠封面预告。
3. **开头给结论 + 引导收藏**："先说结论……记得先收藏，慢慢核对"。
4. **字幕完整**：全量字幕便于回看，不用像抖音那样为完播砍字幕。
5. **分段贴纸卡**：三件事各配一张大字卡，保持分段清晰。
6. **考核**：收藏率 / 获粉转化（我们小红书首周净增42粉，是获客主阵地）。

## 四、复用边界（明确什么能共用、什么必须分开）

| 能否共用 | 内容 | 说明 |
|---|---|---|
| ✅ 可共用 | 选题、核心数据、素材源（原始稿/数据卡图） | 同源，来自问答专区001主稿 |
| ✅ 可共用 | 配音音色（成熟女声）、品牌底、分镜图素材 | 技术资产，比例/字幕可调整 |
| ❌ 必须分开 | **口播脚本** | 抖音=钩子前置·单点化·减负；小红书=信息全·收藏向，两版不同 |
| ❌ 必须分开 | **字幕方式** | 抖音=大字关键词；小红书=全量字幕 |
| ❌ 必须分开 | **时长与节奏** | 抖音≤60秒快节奏；小红书1-3分钟平缓 |
| ❌ 必须分开 | **封面** | 抖音=竖版9:16钩子；小红书=3:4信息预告 |
| ❌ 必须分开 | **CTA** | 抖音=确定性预告+关注+转发；小红书=收藏+关注+评论区互动 |

**红线规则**：
- 小红书视频**原样直投**抖音 = 重复"公众号图文搬抖音"的错误（完播率被砍）。
- 抖音版**信息砍到单点**，小红书版**信息全保留**——两者是"减"与"全"的关系，不是"改措辞"的关系。
- 若资源有限，最少做三件事再跨投：**换开头（前2秒甩结论）+ 砍信息（留1个锚点）+ 改字幕（大字关键词）**。

## 五、一稿双成片流程（每个主题的标准动作）

```
问答专区001 主稿（资格/竞争/出路，数据已核）
   ├─ ① 抖音脚本（04B.抖音）   钩子前置 · 单点化 · 220-300字 · ≤60秒
   ├─ ② 小红书视频笔记（03.小红书） 信息全保留 · 收藏向 · 可600-800字 · 1-3分钟
   └─ ③ 各自封面 + 分镜/贴纸卡（复用数据卡图，按平台比例改）
两个成片，一套素材源，一稿双产出。
```

**产出物清单（每主题 · 2026-08-31 定稿）**：
- `03.小红书/`（三载体，各自独立子目录）
  - `01.视频/`  视频笔记脚本 + 首图（3:4）；内部分镜复用 `04.抖音` 9:16 图，**封面单独设计**
  - `02.图文/`  图文脚本 + 首图 + 正文图1-N（一卡一个信息点）
  - `03.长文/`  长文脚本（**文字复用头条长文**）+ 长文1-N 数据图（1-2张轻量辅助）
- `04.抖音/` 或 `04B.抖音/` 口播脚本 + 分镜图（9:16）
- 头条长文/图文在主稿目录，为跨平台复用源

## 六、抖音 → 今日头条视频同步策略（2026-08-31 定稿）

- 抖音一键同步头条是**字节系原生打通**，受众重叠度高（头条用户偏大龄、家长比例更高），**边际成本≈0**。
- **默认动作**：抖音视频直接同步头条，先零成本吃放量。
- **按主题二选一**：
  - **钩子型/时效型**（如"四大名校AC/D持平"）→ 同步即可，不值得单独做。
  - **高长尾/需完整讲解型**（政策解读、数据复盘、志愿实操、费用对比）→ 值得单独做 2-3 分钟"头条资讯解说版"，信息更全，吃头条中视频+搜索池。
- 注意：60秒抖音版吃头条"短视频"池；2-3分钟资讯版才能进"中视频"池。

## 七、抖音图文/文章 vs 头条内容复用边界（2026-08-31 定稿）

| 层面 | 判断 |
|---|---|
| 文字内容（数据/要点） | ✅ **可复用**（同源原创） |
| 文章结构 | ❌ **必须重构**：头条=文章逻辑（标题+分节段落）；抖音图文=轮播卡逻辑（一屏一个信息点），需拆成 N 张卡 |
| 图片 | ❌ **不能直接套用**：头条封面 1200×900（4:3横）→ 抖音图文 3:4/1:1 竖版，需重排版；数据卡底图可裁切复用、文字层按卡重排 |
| 战术价值 | ⚠️ **不建议重点投入**：抖音图文权重低（周数据图文/长图文全部低播放），抖音主场是原生视频；头条长文留头条、抖音专注视频 |

## 八、小红书三载体目录结构与要求（2026-08-31 定稿）

| 子目录 | 脚本来源 | 配图要求 | 关键规则 |
|---|---|---|---|
| `01.视频/` | 独立口播脚本（收藏向） | 首图 3:4 单独设计 | 内部分镜**复用抖音 9:16 图**（小红书视频同 9:16 全屏）；文字层按平台重排 |
| `02.图文/` | 独立卡片化脚本 | 首图 3:4 + 正文图 3-9 张 | 每张图**一个信息点**、独立可读；图承结论、文承关键词 |
| `03.长文/` | **复用头条长文** | 长文N 数据图 1-2 张 | 原创跨平台复用无合规问题；配图为轻量辅助，非全套卡 |

## 九、小红书图文 vs 长文区别与素材要求（2026-08-31 定稿）

| 维度 | 图文笔记 | 长文笔记（纯文字） |
|---|---|---|
| 流量入口 | 封面/图 决定点击（信息流强） | 标题+正文 决定搜索命中（搜索强） |
| 阅读方式 | 看图滑动，一图一个点 | 通读文字，分段扫读 |
| 信息承载 | 图上（数据卡/表格/图解） | 文字里（段落/列表/加粗） |
| 适合内容 | 数据、清单、图解政策、对比表 | 政策深度解读、逐条讲条件、破误区、经验帖 |
| 收藏动机 | "这张图值得存" | "这篇讲得清" |
| 制作成本 | 高（每张图都要出） | 低（纯文字） |

**图文素材要求**：首图 3:4 大字标题+关键数字；正文图 3-9 张、一卡一点、每张独立可读；图与文互补（图承结论、文承关键词）；标题≤20字。
**长文素材要求**：无需配图（可加 1-2 张竖版数据图辅助）；标题钩子 + 首段3行内亮观点 + 小标题分节 + 可扫读；关键词布局吃搜索。

## 十、图片命名编号规范（2026-08-31 定稿）

- **图文笔记**：文件名 `…小红书-正文图{序号}-{内容}-1080x1440.png`，序号按脚本顺序（正文图1、正文图2…）；**首图不加序号**（上传排第一）。
- **长文笔记**：`…小红书-长文{序号}-{内容}-1080x1440.png`，序号按脚本顺序（长文1、长文2…）。
- **视频笔记**：首图单独命名 `…-小红书-首图-1080x1440.png`；分镜图沿用抖音命名。
- **同步维护三处**：① PNG 文件名 ② 脚本 md 的 `cover:`/`images:` 字段 ③ 生成脚本 `save()` 路径——三处保持一致，避免改一处漏两处。
