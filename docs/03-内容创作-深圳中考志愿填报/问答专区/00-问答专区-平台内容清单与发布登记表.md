## 二、发布时段建议（对齐 S1 清单表口径）

| 平台 | 建议时段 | 理由 |
|---|---|---|
| 公众号（完整版/精简版） | **周三/周四 20:30-21:30** | 家长晚间读完即转发收藏 |
| 公众号（极简版） | 完整版次日 20:00 或 **周六 20:00** | 极简=收藏型，做二次触达 |
| 今日头条长文 | **12:00-13:00** 或 **18:30-20:00** | 头条午休/通勤阅读高峰 |
| 微头条 | 长文发布**前1-2小时**（12:30 或 19:00） | 微头条占位引流到长文 |
| 小红书 | **20:00-21:30** | 妈妈群体晚间刷手机高峰 |
| 抖音 | **19:00-21:00** | 家长晚间流量高峰 |
| 知乎（想法） | **12:30-13:00** 或 **20:30-21:30** | 想法轻内容，碎片时间刷到 |
| 知乎（回答） | **20:30-22:00** 或周末白天 | 知乎用户晚间深度阅读/搜索 |

**单篇内部发布顺序**：引流先行 → 长文承接。即 知乎想法 / 抖音口播 / 微头条 先发占位引流 → 当日或次日 公众号 / 今日头条长文 / 知乎回答 承接完整内容。
