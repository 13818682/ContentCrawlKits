## 三、⚠️ 使用纪律

1. **PDF 原件不入 git**：8份合同均为**扫描型图文版**（0字体、全JPEG图像，14—16页/份，合计39.1MB）。按仓库既有规则（`.gitignore` 中 `2.参考资料/*（扫描型图文版）*.pdf`——扫描件可由文本版再得，不入库），已在 `.gitignore` 增加对应排除规则。本地保留可查，但不随仓库同步。
2. **媒体材料一律标注**：「据媒体汇总／报道」，不得写作「据教育局公布」。
3. **「47.24亿元」未找到官方出处**：仅见于用户提供的今日头条文章，本目录未收录该文（反爬拦截）。引用须标注为媒体口径，或改用可核实的单体投资数。
4. **数字时效**：本目录所有数据截至 **2026-09-10**。2027年招生计划预计2027年5—6月发布，届时需回填。
