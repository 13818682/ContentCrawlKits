# 深圳将新建4所公办高中

（深圳本地宝，2026-03-06）

【导语】3月5日上午，深圳市教育局官网连续发布两则招标公告，分别是《关于公开遴选深圳市第三十九、第四十高级中学项目社会稳定风险评估报告编制服务单位的招标公告》以及《关于公开遴选深圳市第四十五、四十六高级中学项目建议书编制服务单位的招标公告》，计划新建4所公办高中。

招标公告介绍，这四所高中都是深圳市"十五五"期间项目。市教育局的招标方案指出，**深圳市第三十九、第四十高级中学是深圳市"十五五"时期第一批新改扩建公办高中项目。**

## 深圳市第三十九高级中学

项目为深圳市"十五五"时期第一批新改扩建公办高中项目之一。

- **选址**：深圳市南山区月亮湾大道与棉山路交汇处西南角
- **办学规模**：48班 **2400学位** 的寄宿制高级中学
- **新建总建筑面积**：67808 平方米
- **项目建议书批复总投资匡算**：**53,862.00 万元**（约5.39亿元）
- **用地信息**：用地面积 35465 平方米，用地性质为教育设施用地，已完成土地整备收地并征转为国有土地
- **项目定位**：48班（50生/班）、2400人的**半寄宿制公办高中（含50%走读生）**
- **面积**：总建筑面积 70818 平方米（生均29.5㎡）
- **工期**：总投资匡算约 58,298.40 万元，**计划总工期36个月**

## 深圳市第四十高级中学

项目为深圳市"十五五"时期第一批新改扩建公办高中项目之一。

- **选址**：深圳市坪山区石井街道石井社区深中创新学校南侧，绿荫南路与金田路交汇处西南角
- **办学规模**：36班 **1800学位** 的寄宿制高级中学
- **新建总建筑面积**：55446 平方米
- **项目总投资匡算**：**43,701.00 万元**（约4.37亿元）
- **用地信息**：面积 32617 平方米，用地性质为教育设施用地，已全部征（转）为国有土地
- **项目定位**：36班（50生/班）、1800人的**半寄宿制公办高中（含30%走读生）**
- **面积**：总建筑面积 57721 平方米（生均32.07㎡）
- **工期**：总投资匡算约 46,830.14 万元，**计划总工期36个月**

## 其他两所学校资讯

**深圳市第四十五高级中学（宝安BA05-3地块）、第四十六高级中学（光明GM04-3地块）**作为"十五五"重点公办高中项目，拟以"市投市建"模式立项。其中：

- 第四十五高级中学：新建建筑面积 **14.21万平方米**，新增学位 **4800个**，投资匡算 **11.34亿元**。
- 第四十六高级中学：新建建筑面积 **5.33万平方米**，新增学位 **1800个**，投资匡算 **4.31亿元**。

两项目总投资匡算 **15.65亿元**，建成后将补充区域公办高中学位、优化教育资源布局。
