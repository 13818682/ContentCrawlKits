# P2-降分通道 — 系列创作规划方案

## 一、系列定位

### 1.1 P2 与 P1 的关系

```
P1-政策解码器（规则理解）          P2-降分通道（战术执行）
─────────────────────────          ─────────────────────────
"指标生是什么"              →      "指标生志愿填哪所最划算？"
"自主招生怎么录"            →      "自招报名材料怎么准备？"
"走读调剂是什么"            →      "哪些学校的走读分差最值得勾？"
"投档规则怎么运转"          →      "指标生+第一批怎么配成双保险？"

看完P1="我知道规则了"        看完P2="我知道怎么用规则了"
```

### 1.2 核心洞察

深圳中考有三条被家长低估的"降分通道"，掌握任意一条都能让孩子用更低的分数进更好的学校：

| 通道 | 降分空间 | 竞争范围 | 认知门槛 | 家长知晓度 |
|------|:---:|------|:---:|:---:|
| **指标生** | 5-20分 | 校内竞争 | 中 | 高（但策略层理解浅） |
| **自主招生** | 不定（综合分PK） | 全市（报名者） | 高 | 中 |
| **走读调剂** | 5-35分 | 全市（勾选者） | 低 | 低（2026年新增） |

> P2的使命：不只是告诉你"存在降分通道"，而是给你**具体到每所初中、每所学校、每个分数段的可执行策略**。

### 1.3 目标读者

| 读者类型 | P1结束后状态 | P2要解决的问题 |
|---------|------------|--------------|
| **中等生家长**（核心） | 知道指标生可以降分，但不知道怎么填 | "540分，指标生冲深中还是稳科高？" |
| **D类家长**（重点） | 知道D类竞争更激烈，需要弯道超车 | "D类的三条通道怎么组合使用？" |
| **高分段家长** | 知道自招存在，但不知道要不要报 | "孩子数理A+，自招报深中一类值不值？" |
| **低分段家长** | 知道走读调剂可以降分，但怕通勤 | "哪些学校的走读分差大且离家近？" |

### 1.4 品牌调性

延续 HSEE 人格——**"懂政策的数据控学长"**，P2 系列特别强调：

- ✅ 每个策略配 HSEE 独家数据（指标生分配表、走读分差排行）
- ✅ 决策框架化——不给"建议"，给"决策表"让家长自己判断
- ✅ 每个策略跟一个真实案例（匿名化）
- ✅ 核心转化点：引导家长去 HSEE 查自己初中的指标生名额
- ❌ 不越界到 P4（志愿填报作战室）——P2 只讲通道策略，不讲志愿排序

## 三、逐篇详细规划

### P2-1：指标生志愿怎么填——冲高vs保稳的决策框架

**定位**：P2系列旗舰篇。P1-5讲了"指标生是什么"，这篇讲"指标生填哪所"。

**核心角度**：不给"标准答案"，给"决策框架"——每个家长的情况不同（分数段/初中/目标），没法用一个建议覆盖所有人。但可以用一个决策矩阵让家长自己得出答案。

**差异化策略**：竞品讲指标生策略要么"一律建议冲高"（过于激进），要么"求稳为主"（过于保守）。HSEE的差异化——**分初中类型给策略**。你在名校初中（竞争激烈）vs 普通初中（校内竞争弱），指标生策略截然不同。

**内容大纲**：
1. Hook："指标生只有1个志愿——填对了降20分进名校，填错了等于白填"
2. 决策三要素：①你所在初中的竞争激烈程度 ②你的预估分数段 ③目标高中的控制线
3. 决策矩阵：

| 初中类型 | 你的校内排名 | 建议策略 | 示例 |
|------|:---:|------|------|
| 名校初中（四大率高） | 前10% | 可冲更高 | 深中初中部→指标生冲深中 |
| 名校初中 | 中等 | 求稳为主 | 校内竞争激烈，控制线边缘风险大 |
| 普通初中 | 前20% | 大胆冲高 | 校内竞争弱，降分空间大 |
| 普通初中 | 中等 | 冲稳平衡 | 冲一所跳一跳够得到的 |

4. "冲高"和"保稳"各自的利弊分析（表格对比）
5. 一个成功案例 + 一个失败案例（匿名化）
6. CTA：HSEE小程序→输入初中→查看指标生分配表→计算你的最优策略

**数据需求**：HSEE `quota_allocations` 表、各初中指标生名额、各校指标生控制线

**变形平台**：小红书「指标生决策矩阵」一图流

### P2-2：指标生+第一批联动——双重保险的正确排法

**定位**：P2-1的姊妹篇。P2-1解决"指标生填哪所"，P2-2解决"指标生和第一批怎么配"。

**核心角度**：指标生和第一批是两个独立批次——填对了是"双重保险"，填错了是"互相浪费"。这篇文章用模拟案例展示正确排法和错误排法的差异。

**差异化策略**：大多数竞品把指标生和第一批分开讲——分开讲家长永远学不会联动。HSEE把它们放在一起，用同一个考生的完整志愿方案来演示。

**内容大纲**：
1. Hook："指标生录了→第一批作废。所以不能填'录了也不想去'的学校"
2. 正确联动法则三条：
   - 法则1：指标生和第一批第1志愿填同一所学校（双保险）
   - 法则2：指标生填"冲"的学校，第一批第1志愿填"稳"的学校（梯度保险）
   - 法则3：指标生不能填"保底"——万一录了，第一批更好的选择全作废
3. 三个模拟案例（不同分数段×不同策略）
4. 常见联动错误：指标生填了保底校 / 指标生和第一批第1志愿差距太大 / 忘记填第一批的同一所学校
5. CTA：HSEE小程序模拟→分别试"冲高"和"保稳"两种指标生策略，看录取概率变化

**数据需求**：投档规则、指标生控制线数据

**变形平台**：小红书「双保险排法」示意图

---

### P2-3：自主招生申请实战——从报名到录取的每一步

**定位**：P1-6讲了"自招是什么、谁适合报"，这篇讲"决定报了以后每一步怎么走"。

**核心角度**：自招最难的不是考试——是信息不对称。大多数家长不知道报名材料怎么写、学校考核考什么、时间节点怎么卡。这篇文章是一份"自招申请操作手册"。

**差异化策略**：竞品对自招的内容停留在"一类vs二类"的概念层面，几乎没有实操指南。HSEE填补这个空白。

**内容大纲**：
1. Hook："自招不是报了就能考——报名材料不过关，连考试资格都没有"
2. 自招全流程时间表：5月简章发布→6月报名→中考后考核→成绩公布后录取
3. 报名材料清单（一类）：
   - 初中阶段的成绩单（尤其是数理科目）
   - 竞赛/科创获奖证书（如有）
   - 自荐信/个人陈述（怎么写？突出什么？）
4. 报名材料清单（二类）：
   - 艺术/体育获奖证书或等级证明
   - 专业能力证明（比赛成绩/演出视频/训练记录）
5. 学校考核准备：
   - 一类：笔试通常考什么？（数理思维+综合素养）怎么准备？
   - 二类：专业考核标准是什么？考前需要做什么准备？
6. 报名策略：报哪所学校？（和指标生一样的决策逻辑——冲刺用）
7. CTA：HSEE小程序查看2026各校自招简章+录取分数

**数据需求**：2026年各校自招简章、自招录取数据

**变形平台**：小红书「自招报名材料清单」图文

---

### P2-4：走读调剂选校策略——分差排行与通勤决策

**定位**：P1-4讲了"走读调剂是什么、决策表怎么用"，这篇讲"具体哪些学校值得勾选"。

**核心角度**：走读调剂的分差因校而异——从几分到三十几分。这篇文章用2026年真实数据做一个"走读分差排行榜"，帮家长精准识别高价值目标。

**差异化策略**：没有任何竞品做过"走读分差排行榜"——因为需要逐校提取走读线和住宿线做差值计算。HSEE有完整的2026录取标准Excel数据，这是独家内容。

**内容大纲**：
1. Hook："走读调剂能降5到35分——但不是每所学校都值得勾。先看分差，再看通勤。"
2. 2026年走读分差排行榜（按分差从大到小排列，Top 20）：

| 排名 | 学校 | 住宿线 | 走读线 | 分差 | 区域 |
|:---:|------|:---:|:---:|:---:|------|
| 1 | 深实验崇文高中 | 506 | 471 | **35分** | 龙岗 |
| ... | ... | ... | ... | ... | ... |

3. 决策双维度：分差大 + 离家近 = 最优目标
4. 各区域走读友好学校推荐（按家长的居住区域分类）
5. 通勤成本计算器思路：单程时间×3年×200天——每天多1小时=三年多600小时
6. CTA：HSEE小程序→筛选走读分差大的学校→输入家庭地址查看通勤时间

**数据需求**：2026年录取标准Excel（住宿/走读分列）、各校地址

**变形平台**：小红书「走读分差Top 20」数据卡片

### P2-5：降分通道组合拳——不同分数段的最优通道组合

**定位**：P2系列收尾篇。前面4篇分别讲了各通道的独立策略，这篇把它们串成"组合拳"。

**核心角度**：每个分数段的家长，面对的降分通道优先级不同。高分段重点看自招+指标生冲高，中分段重点看指标生+走读调剂，低分段重点看走读调剂+民办保底+3+4中本贯通。

**差异化策略**：分场景决策模型——输入孩子的分数段+类别+初中类型，输出推荐的通道组合。这是HSEE独家内容，竞品没有能力做跨通道的综合策略。

**内容大纲**：
1. Hook："你家孩子不是只有一条降分通道——三条通道怎么组合，取决于你站在哪里。"
2. 分场景决策模型：

| 分数段 | AC/D类 | 推荐通道组合 | 优先级排序 |
|------|:---:|------|------|
| 550+ | AC类 | 自招一类 + 指标生冲高 | 自招→指标生→第一批正取 |
| 550+ | D类 | 指标生冲高 + 自招一类 | 指标生→自招→第一批正取 |
| 500-550 | AC类 | 指标生求稳 + 走读调剂 | 指标生→走读→第一批正取 |
| 500-550 | D类 | 指标生冲高 + 走读调剂 + 民办保底 | 指标生→走读→第一批→民办 |
| 450-500 | AC/D类 | 走读调剂 + 民办 + 3+4中本贯通 | 走读→民办→中本贯通 |
| <450 | AC/D类 | 民办 + 3+4/3+2中高贯通 + 中职 | 民办→中本贯通→中职 |

3. 每种组合的"正确打开方式"（简版，引导到对应P2-1~P2-4的详细文章）
4. 一个完整的家长决策路线图
5. CTA：HSEE小程序→输入分数段+类别+初中→获取个性化通道组合建议

**数据需求**：所有前4篇的核心数据 + AC/D分差表

**变形平台**：抖音「你属于哪一种？3秒对号入座」互动视频
