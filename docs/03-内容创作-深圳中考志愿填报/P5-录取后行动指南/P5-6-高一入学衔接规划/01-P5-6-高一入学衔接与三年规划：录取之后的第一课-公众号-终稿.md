# 高一入学衔接与三年规划：录取之后的第一课

拿到录取通知书的那一刻，很多家庭松了一口气——"终于结束了"。

但真相是：**中考不是终点，是高中三年的起点。** 录取那天不是"结束"，而是"开始"。

而且，高中三年和初中三年完全不同——**高中每一年的重点都不一样，踩错节奏，代价很大。**

这篇帮你建立"高中三年节奏感"，从高一的适应与选科，到高二的分科，到高三的冲刺。同时也给被中职录取的家庭一个清晰的规划方向。

---

## 一、先记住高中三年的"节奏"

初中三年是"匀速跑"，高中三年是"变速跑"——每一段的重点完全不同：

| 年级 | 核心任务 | 关键节点 |
|------|------|------|
| **高一** | 适应 + **选科** | 高一下学期末确定选科（新高考 3+1+2） |
| **高二** | 分科 + 学业水平合格考 | 合格考、学科竞赛、节奏定型 |
| **高三** | 高考冲刺 + 志愿填报 | 一模/二模/三模、高考、填志愿 |

> **最容易被忽略的是高一**——很多人以为"高一刚进校，先适应适应"，结果高一结束要选科了才发现：**选科选的不是"喜欢"，是"大学专业的方向"。** 高一没想清楚，高二高三要花大力气补。

---

## 二、高一：适应 + 选科（全年最重要的决定）

### 2.1 适应：从初中到高中的三跨越

| 跨越 | 初中 → 高中的变化 | 怎么应对 |
|------|------|------|
| **难度** | 知识点更深、更快 | 别用"初中考前突击"的老方法 |
| **节奏** | 课程多、进度快 | 提前预习，别等到听不懂 |
| **心理** | 竞争对象变了 | 重新定位，别用中考排名绑架自己 |

### 2.2 选科：广东新高考 3+1+2

这是高一最重要的一件事——**选科，直接决定了你高考能报哪些大学专业。**

广东新高考实行 **"3+1+2"模式**：

| 部分 | 科目 | 分值 | 说明 |
|------|------|:---:|------|
| "3"（必考） | 语文、数学、外语 | 各150分 | 所有考生都考 |
| "1"（首选） | **物理** or **历史**（二选一） | 100分 | 决定大方向（理工 vs 人文） |
| "2"（再选） | 化学/生物/政治/地理（四选二） | 各100分 | 等级赋分 |

**满分 750 分，共 12 种选科组合。**

### 2.3 选科怎么选？三个原则

| 原则 | 说明 |
|------|------|
| **先看专业** | 想读什么大学专业，倒推需要选哪几科（如学医大多要物化） |
| **再看优势** | 在"能报目标专业"的前提下，选自己最擅长的组合 |
| **别看跟风** | 别因为"大家都选物化"就盲目跟，物理/历史各有所长 |

> ⚠️ **一个关键提醒**：选科的窗口，通常在高一下学期末（或高二初），**高一结束前必须定下来**。不要拖到高二——分科后想改，成本极高。

## 三、高二：分科 + 合格考，节奏定型

### 3.1 分科之后：进入"深水区"

高二是高中三年里知识量最大的一年。分科之后，各科难度开始拉开。

| 重点 | 说明 |
|------|------|
| 主科 + 选科 | 集中精力打牢核心科目 |
| 节奏定型 | 养成稳定的学习节奏，别被"高二分化"甩开 |
| 竞赛/特长 | 有竞赛或特长规划的家庭，高二要发力 |

### 3.2 学业水平合格考

| 项目 | 说明 |
|------|------|
| 是什么 | 全省统一的合格性考试（非选考科目的"达标考"） |
| 影响 | 不合格可能影响高中毕业证和部分录取 |
| 心态 | 难度不高，但别不当回事 |

## 四、高三：冲刺 + 高考志愿，一鼓作气

### 4.1 三个关键节点

| 节点 | 时间 | 作用 |
|------|------|------|
| 一模 | 高三上期末 | 第一次全真摸底，定位排名 |
| 二模/三模 | 高三下 | 查漏补缺、志愿参考 |
| 高考 | 6月 | 决定性的考试 |

### 4.2 高三志愿：和中考志愿完全不同的逻辑

| 对比 | 中考志愿 | 高考志愿 |
|------|------|------|
| 志愿数量 | 16 个（普高+中职） | 数十个（院校+专业组） |
| 填报逻辑 | 按学校+批次 | 按"院校专业组" |
| 依据 | 排名+等级 | 排名+位次+选科匹配 |

## 五、不同录取去向，三年规划完全不同

上面讲的是普高生的节奏。如果你被中职/技工录取，规划是另一条路：

| 去向 | 三年规划重点 |
|------|------|
| **公办普高/民办普高** | 高一选科 → 高二分科 → 高三高考 |
| **中职 3+4** | 中职 3 年专注专业 + 转段考核，直通本科（见 P3-5） |
| **中职 3+2** | 中职 3 年 → 转段 → 大专 2 年，可专升本 |
| **中职直接就业/高职高考** | 中职期间练技能，走高职高考或就业 |

> **中职不是"没有规划"，而是"另一套规划"。** 3+4/3+2 的转段考核在中职三年里就有，**中职生同样要重视每一次考试**（转段不达标，升学路就断了）。中职的详细升学路径，回看 P3-5 系列。
