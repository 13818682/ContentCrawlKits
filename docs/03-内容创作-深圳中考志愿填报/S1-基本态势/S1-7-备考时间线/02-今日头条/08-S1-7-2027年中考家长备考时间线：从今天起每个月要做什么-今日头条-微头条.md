# 2027深圳中考还有9个月，家长现在就该开始

中考不是2027年5月才开始——从初三开学就进入倒计时。9个月怎么安排？5个阶段：

1️⃣ 现在-9月 · 建立认知框架：搞懂三组数字（16-18万考生/8万公办学位/52%录取率），弄清AC/D类区别，了解指标生。体育过程性评价14分从初三开始累积。

2️⃣ 10-12月 · 信息收集期：研究指标生政策（你所在初中有哪些高中名额）、关注目标学校分数线。11月期中考第一次定位。

3️⃣ 1-3月 · 定位校准期：一模（各区1-3月）第一次有参考价值的定位；关注2027政策发布；3月下旬中考报名（D类注意社保/居住证）。

4️⃣ 4-5月 · 决策冲刺期（最关键）：二模定位、确认招生计划与指标生名额、草拟冲稳保志愿方案、决定是否走读。5月下旬志愿填报，只有10天窗口。

5️⃣ 6-8月 · 考试录取复盘：中考→出分→录取→高一衔接。
