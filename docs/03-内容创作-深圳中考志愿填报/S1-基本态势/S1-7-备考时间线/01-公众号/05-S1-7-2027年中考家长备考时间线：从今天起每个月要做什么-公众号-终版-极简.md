# 2027届备考时间线（极简版）

你以为中考倒计时从明年5月开始？错了——从今年9月开学第一天就开始。但好消息是：你现在开始，还有9个月，刚刚好。不贩卖焦虑，只给节奏。1分钟看完，就知道这9个月每个月该做什么。

---

## 一、9个月，5个阶段

| 时间 | 关键动作 | 关键节点 |
|------|---------|------|
| 8-9月（现在） | 建立认知框架 | 体育过程性评价（14分开始累积） |
| 10-12月 | 研究指标生+目标学校 | 11月期中定位 |
| 1-3月 | 一模定位+政策跟踪 | 3月下旬中考报名 |
| 4-5月 | **志愿草拟+最终方案** | 志愿填报（10天） |
| 6-8月 | 中考+录取 | 录取公布+高一衔接 |

**这意味着什么？** 关键决策集中在4-5月，但前8个月都是信息储备——谁准备得早，谁填志愿不慌。

---

## 二、现在就要开始的3件事

**① 体育过程性评价**：前两年分数已入账，初三这一年的14分从现在开始累积——早练早拿分。

**② 理化实验操作**：计入总分（630分制），不是"走过场"。

**③ 收集学校信息**：30分钟搞懂三组数字（16-18万考生 / 约8万公办学位 / 约52%录取率），弄清AC/D类，开始浏览目标学校。

**这意味着什么？** 中考不只是孩子的事——家长的"信息准备"从今天就开始，也在拉开差距。

---

## 三、家长 vs 孩子：谁该做什么

**孩子**：跟上新课 → 期中期末 → 一模 → 二模+体育中考 → 冲刺 → 中考。

**家长**：建认知框架 → 研究指标生 → 一模定位 → 草拟志愿 → **10天窗口内定稿** → 录取跟进。

**这意味着什么？** 孩子拼的是分数，家长拼的是决策——两份"试卷"都别交白卷。

---

## 四、对号入座

**初三家长**：现在从"三组数字+指标生"开始，别等下学期。

**D类家长**：提前备好社保、居住证等报名材料，3月下旬报名别卡壳。

**初一初二家长**：收藏这篇，明年9月准时用——越早看，越不慌。
