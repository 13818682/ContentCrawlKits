# 2027中考备考时间线：每月做什么

从今天到2027年6月中考，约300天。关键节点就这几个，收藏照着做。🗓️

**① 现在（2026.8）** ✍️
确认体育过程性评价历史分，规划初三训练（耐力/技能/球类各选一项）。开始搭认知框架，别等明年5月才动手。

**② 2027年1-3月** 📝
一模，定位基准。各区一模时间不同，通常在初三下学期初。用一模成绩对目标学校，才靠谱。

**③ 2027年4-5月** 📋
招生计划、指标生名额陆续公布；**5月下旬志愿填报，只有约10天**。先填志愿、后考试，这段时间最需要提前准备。

**④ 2027年6-7月** 🎯
中考 → 录取。前面准备充分，这段就是验证。
