# 收藏！志愿填报前要核对的清单

深圳中考"先填志愿、后考试"，5月下旬填报只有约10天。这份清单现在就开始核对，别到时候手忙脚乱。✅

**① 指标生** 🎯
只能填1所。现在就去查：你所在初中的指标生名额分配 + 目标高中近两年的使用情况。降分空间：四大1-5分，中等学校5-15分。

**② 走读 / 住宿** 🚶
评估通勤距离。走读最高降35分，但被录取后无法改回住宿——这个取舍要提前想清楚。

**③ 候选方案** 🛤️
民办普高哪些"低进高出"？中职3+4/3+2怎么报名？分数在公办线边缘的孩子，候选方案从现在就要备。

**④ 定位基准** 📐
一模成绩出来后再定冲稳保。现在先搭框架，到时候往里填数据。

数据来自深圳市教育局公开信息，逐条人工核对。收藏这份清单，填志愿前逐项过一遍。你家孩子现在准备到哪一步了？评论区聊聊。💬
