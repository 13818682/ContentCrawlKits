# 深圳中考考生8年翻倍，2027年16-18万人抢学位

2018年7.21万 → 2027年预计16-18万，深圳中考考生8年翻了一倍多。很多家长一听就慌，但看3个真相：

1️⃣ 为什么涨？三个引擎：人口净流入（7年净增500万人）+出生人口高峰（2023年跳涨1.4万）+初中升中考转化率稳定95%以上。2024年初中入学人数，几乎直接决定2027年中考人数。

2️⃣ 学位在追着跑："十四五"新建49所公办高中、新增11.8万学位，"十五五"再增10万。公办学位从5.9万涨到8万（+35%），录取率从2020年的44%回稳到52%。

3️⃣ 何时见顶？2027-2030。出生人口已过峰、人口流入减速、学位恰好覆盖峰值窗口——你现在经历的，可能是最难的时候，但不是终点。
