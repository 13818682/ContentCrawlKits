# 深圳中考8年翻倍，和多少人抢学位

深圳中考考生8年翻了一倍：**7.21万 → 16-18万**。你家孩子，正处在这场增长里。📈

**① 增长有多快** 🚀
2018年7.21万 → 2026年15.30万，几乎翻倍。按年均+0.9万推估，2027年预计16-18万。

**② 但学位在追着跑** 🏗️
公办学位从5.9万涨到约8万（101所），"十四五"新增11.8万学位，"十五五"（2026-2030）再增10万。

**③ 录取率稳在52%** ⚖️
人多，学位也加码。公办录取率多年稳在52%——别被"翻倍"两个字吓住。

压力在高位，但方向在好转。数据来自深圳市教育局公开信息，逐条人工核对。收藏这篇，给自己定个心。📌
