# 升初三前，先记住这3个数字

中考信息千千万，越看越慌。别急，先记住3个数字，再看任何信息都有坐标系。🧭

**① 16-18万** 👨‍👩‍👧
2027年深圳中考预计考生人数。2026年是15.30万，按年均增长0.9万推估。

**② 约8万** 🏫
公办普高招生人数，101所学校。这是"公办学位"的大盘子。

**③ 约52%** 📊
公办普高录取率。加上民办，全市普高（含民办）录取率超73%。

记住这3个数，再看志愿怎么填、指标生怎么用、分数线涨跌，都能知道它在坐标系上的位置，不慌。✅

数据来自深圳市教育局公开信息，逐条人工核对。收藏这篇，升初三前翻出来看一眼。📌
