## 三、发布时段建议

### 各平台最佳时段（面向深圳家长）

| 平台 | 建议时段 | 理由 |
|---|---|---|
| 公众号（完整版） | **周三/周四 20:30-21:30** | 家长晚间读完即转发收藏；避开周一忙、周五松 |
| 公众号（极简版） | 完整版次日 20:00 或 **周六 20:00** | 极简=收藏型，做二次触达 |
| 今日头条长文 | **12:00-13:00** 或 **18:30-20:00** | 头条午休/通勤阅读高峰 |
| 微头条 | 长文发布**前1-2小时**（12:30 或 19:00） | 微头条占位引流到长文 |
| 小红书 | **最佳 20:00-21:30** | 妈妈群体晚间刷手机高峰；周六 10:00-11:30 亦可 |
| 抖音 | **19:00-21:00** | 家长晚间流量高峰（13-4 模板口径） |
| 知乎（想法） | **12:30-13:00** 或 **20:30-21:30** | 想法轻内容，碎片时间刷到 |
| 知乎（回答） | **20:30-22:00** 或周末白天 | 知乎用户晚间深度阅读/搜索 |

### S1 系列发布节奏（建议，对齐小红书三批逻辑）

| 批次 | 内容 | 目的 | 建议时间窗口 |
|---|---|---|---|
| **第一批 · 认知打底** | S1-1 → S1-7 → S1-3 | 建立关注理由 + 收藏型 + 全景框架 | 2026年8月下旬-9月 |
| **第二批 · 数据立信** | S1-2 → S1-4 | 数据复盘 + 8年翻倍，建立专业信任 | 2026年9-10月 |
