# 2027深圳中考家长必读：一张图看懂竞争格局

2027年，深圳约有16到18万孩子和你家孩子一起参加中考。

这是什么概念？——比8年前，多了一倍。

2018年，深圳中考考生7.21万人。那一年，公办普高录取率约53%，家长们已经开始喊"太难了"。他们不会想到，8年后的今天，"难"字的定义已经被刷新了好几轮。

但今天这篇文章，不是来制造焦虑的。恰恰相反——**当你把数字摆在面前，焦虑反而会变小。** 因为你会发现：竞争确实存在，但学位也在同步增加；一半人上公办是事实，但七成以上能上普高也是事实；非深户的路更窄，但并非没有路。

我们先从三组关键数字开始。

## 一、三组数字，建立你的中考认知坐标系

如果你是第一次认真了解深圳中考，请记住这三组数字。它们是你后续所有判断的基准线。

**第一组：考生规模——16到18万。**

2026年深圳中考考生15.30万人（数据来源：2026年体育中考报名人数）。2027年这个数字预计继续增长，线性推估值在16到18万之间。准确数字要等2027年体育中考报名结束后才能确认，但大方向是明确的——还在涨。峰值预计在2027到2030年区间到来，之后将随着出生人口变化逐步回落。

**第二组：公办学位——约8万。**

2026年深圳101所公办普高共招生约8万人，较上年增加约6,000个名额（数据来源：深圳市教育局2026年高中阶段学校招生计划）。7所新公办普高首次招生：曙光中学、启元中学、深大附中盐田校区、深理工附中、深圳市第二高级中学宝安高中部（简称：二高宝安高中部）、创新高级中学、益新中学。学位在涨，只是涨得没有考生快。

**第三组：录取率——约52%。**

公办普高录取率多年来稳定在52%上下。2022年约53%，2024年约52%，2025年约52%，2026年预计约52%。这个数字的潜台词是：大约一半的孩子能上公办普高。但这不是故事的全部——我们后面会说到。

记住这三组数字：**16-18万考生，8万公办学位，52%录取率。** 心里有了这个坐标系，再看任何中考信息，你都有个大概评估。

## 二、翻倍的8年：考生在涨，学位也在涨

我们来看一条时间线。

2018年，深圳中考考生7.21万人。那一年，公办普高录取率约53%。

2020年，考生8.92万人，公办普高招生约4.1万人（数据来源：深圳市教育局2020年高中阶段学校招生计划）——考生涨了1.7万，学位却还没开始大规模扩充。那一年公办普高录取率降至约44%，是近年最低点。如果你在2020年参加中考，确实很难。

但2020年之后，变化发生了。

深圳启动了大规模高中建设计划。2020到2025年（"十四五"期间），完成49所新改扩建公办高中，新增11.8万个学位。

效果是显著的：

- 2022年：考生11.2万，公办招生5.9万，录取率回升至约53%
- 2024年：考生13.52万，公办招生6.9万，录取率约52%
- 2026年：考生15.30万，公办招生约8万，录取率约52%

**考生从7.21万涨到15.30万，翻了一倍多。但公办学位也从5.9万涨到了约8万，增长了35%。** 录取率没崩，稳在52%左右——这不是偶然，是学位建设在追着考生增长跑。

再看未来。"十五五"规划明确：2026到2030年，再新增10万个公办高中学位。

所以，当你听到"考生越来越多"时，请同时记住下半句："学位也在越来越多"。竞争存在，但不至于绝望。

## 三、一张全景图：所有出路，一次看清

"一半孩子上不了公办"——这句话对，但也不完全对。

对的地方在于：公办普高录取率确实约52%。不对的地方在于：它让人误以为另一半孩子"没书读"。

实际上，2026年深圳高中阶段总学位146,752个，覆盖全部15.30万考生。

我们把这个全景展开来看：

**第一层：公办普高——约8万人，101所，约52%**

这是大多数家长的首选目标。7所新校加入后，选择面进一步扩大。但要注意，公办普高的8万招生指标里，AC类招生61797人，D类（非深户）招生18506人，D类考生在公办普高这条路上的竞争更激烈——其公办招生指标占比约23%。

**第二层：民办普高——33,195人，49所**

学费从每年3万到15万不等（具体以各校招生简章为准），差异巨大。部分优质民办校在艺术教育和国际课程方向有自己的特色。对于经济条件允许的家庭，这是一个值得认真了解的选项。

**第三层：中职及技工——33,254人，30所**

这是最被低估的出路。2026年有两个重要变化：一是"3+4"中本贯通试点落地——深圳一职对口深技大、二职对口深职大，300个名额，中职3年后直接升本科，毕业拿全日制本科文凭。二是"3+2"中高贯通有近5,000个名额。中职不再是终点，而是一条"曲线读大学"的路径。

**三层加起来：约8万 + 33,195 + 33,254 = 146,752人，基本覆盖全部考生。**

所以，正确的表述应该是：

- 约52%的孩子上公办普高
- 超过73%的孩子能上普高（含民办）
- 几乎所有孩子都有高中阶段学校可读

"一半人没高中读"——这是一个需要被纠正的误解。

## 四、给不同家长的三句话

看到这里，你可能会根据自己的情况，产生不同的感受。我们来逐一回应。

**如果你是非深户（D类）家长——**

你是对的，D类的路确实更窄。公办普高的8万招生指标里，AC类招了61797人，D类只招了18506人——D类指标占比仅约23%，而D类考生占了考生总数的约54%。不过，有两点值得注意：第一，指标生已经实现D类全覆盖——名额分配到校，这是一条实实在在的降分通道；第二，民办普高和中职路径对AC类和D类是一视同仁的。路窄，但不是死胡同。

**如果你是孩子成绩在400分左右的家长——**

你可能是最焦虑的一群人。但请特别注意"3+4"中本贯通——300个名额虽然不多，但这是一条全新的路径，2026年第一年试点，很多家长还不知道。中职3年加本科4年，拿的是全日制本科文凭。另外，民办普高中也有一些"低进高出"的学校值得关注。别只盯着公办一条路。

**如果你是初二家长，觉得"还早"——**

2027年考生预计16到18万，竞争不会比2026年轻松。但你的优势是时间——你可以现在就搞清楚基本规则，可以关注2026年的录取数据（这些数据对未来填报极有参考价值），可以开始关注孩子的体育过程性评价（14分，从初一就开始累积）。早准备一年，焦虑少一半。
