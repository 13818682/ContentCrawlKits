# 2027深圳中考16-18万考生，竞争到底有多激烈？

2027年深圳中考，预计16到18万孩子一起抢约8万个公办普高学位——录取率约52%，比8年前翻了一倍多的考生规模。

先别慌，看3个真相：

1️⃣ 学位在追着考生跑：8年间考生从7.21万涨到15.30万，公办学位同步从5.9万涨到约8万，"十四五"新增49所、11.8万个学位，录取率多年稳在52%。

2️⃣ 出路不止公办：公办52%之外，全市普高（含民办）录取率超73%，还有中职"3+4"中本贯通——深圳一职对口深技大、二职对口深职大，300个名额，中职3年直升本科，拿全日制本科文凭。

3️⃣ 总学位14.7万个，覆盖全部考生："一半人没书读"是被误解的，几乎所有孩子都有高中阶段学校可读。
