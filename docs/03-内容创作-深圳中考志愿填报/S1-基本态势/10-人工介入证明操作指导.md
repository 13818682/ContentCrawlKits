# 人工介入证明操作指导

## 文档目的

本文档规定了每篇AI辅助内容必须留存的**人工介入证据**的具体格式、操作方法和判定标准。这些证据在文章被平台误判为AI生成时，作为申诉的核心材料。

## 核心原则

**证据要有"不可自动化"特征。** 平台审核员/算法判断"是不是人写的"时，最看重的是：AI做不到的事情，人做了。

以下三类改动具有最强的证明力：

| 证据类型 | 证明力 | 为什么AI做不到 |
|------|:---:|------|
| 数据纠错 | ⭐⭐⭐⭐⭐ | AI不会"发现数据错误并主动查证修正"——S1-1的2020年公办招生数从5.9万修正为4.1万就是典型 |
| 结构调整 | ⭐⭐⭐⭐ | AI不会"觉得段落顺序不对，重新组织逻辑" |
| 本地化细节 | ⭐⭐⭐⭐ | AI不会加入"去年有位龙岗妈妈"这类只有运营者知道的真实案例 |

## 一、证据1：数据核验清单（强制，每篇必填）

### 1.1 格式模板

沿用已建立的核验清单格式（参考 S1-1/05、S1-6/04、S1-7/03），必须包含以下要素：

```markdown
---
version: "1.0"
date: "2026-08-09"
type: "数据核验清单"
article: "S1-X"
reviewer: "[真实姓名或工号]"     ← 必须有
review_time: "[YYYY-MM-DD HH:MM]" ← 必须有
status: "已核验"
---

# S1-X 数据核验对照表

## 一、数据逐条核验

| # | 稿中数据 | 权威来源 | 来源位置 | 核验结果 | 备注 |
|:---:|------|------|------|:---:|------|
| 1 | 15.30万 | 教育局2026招生计划 | memory/2026-enrollment-data | ✅ | |
| 2 | 约4.1万 | firecrawl查实 | 观研报告网 | ✅ | 已修正，原稿误写为5.9万 |

## 二、发现并修正的错误

| # | 错误描述 | 原文 | 修正后 | 发现方式 |
|:---:|------|------|------|------|
| 1 | 2020年公办招生数 | 约5.9万 | 约4.1万 | firecrawl查证 |

## 三、核验签名

核验人：[真实姓名]           ← 必须有
核验完成时间：[时间戳]        ← 必须有
数据准确率：XX/XX = XX%
```

### 1.2 判定标准

以下情况，核验清单具有申诉证据效力：

| 标准 | 要求 |
|------|------|
| ✅ 有效 | 每项数据标注了来源文件+章节位置，核验人签名，发现并修正了至少1处数据错误或标注了至少1项⚠️风险点 |
| ❌ 无效 | 仅打勾未标注来源、无核验人签名、全部"✅"无任何标注（显得像模板填充） |

**关键**：一份**发现并修正了实际错误**的核验清单（如S1-1修正了2020年公办招生数从5.9万→4.1万），比十份"全部✅"的清单更有证明力。因为AI不会主动发现并修正自己的错误。

### 1.3 存档位置

保存在对应文章目录下，文件名格式：`{序号}-{文章编号}-{文章标题}-数据核验清单.md`

### 2.2 什么算一次"有效改动"

以下类型的改动才算有效改动，具有申诉证明力：

| 改动类型 | 有效 | 示例 |
|------|:---:|------|
| **数据修正** | ✅ | "5.9万"→"4.1万"（查证后修正） |
| **结构调整** | ✅ | 把"给三类家长的话"从文末移到文中第四节 |
| **新增案例** | ✅ | 加入"去年有位龙岗妈妈……"的真实场景 |
| **语气调整** | ✅ | 删除3处AI味的"值得注意的是""综上所述" |
| **标题优化** | ✅ | "深圳中考竞争格局"→"一张图看懂竞争格局" |
| 改一个标点/空格 | ❌ | 不算——太细微 |
| 全文替换某个词 | ❌ | 不算——显得像脚本操作 |
| 仅改格式不加内容 | ❌ | 不算——无实质贡献 |

**最低要求**：每篇至少3处有效改动，其中至少1处为数据修正或结构调整。

### 2.3 改前/改后对比的格式要点

- **必须原样粘贴**改前和改后的完整段落，不要只摘录改动的那几个字
- 改动说明要体现**人工判断逻辑**：为什么改、基于什么考虑
- 如果涉及数据修正，标注查证方式和来源

## 三、申诉材料包的组装

当文章被平台限流或误判为AI生成时，提交以下材料包：

```
申诉材料包/
├── 1. 数据核验清单.pdf          ← 证据1：人工数据核查
├── 2. 人工润色记录.pdf           ← 证据2：人工编辑投入
├── 3. AI初稿与终稿对比.pdf       ← 可选：完整diff（如有工具生成）
├── 4. 参考素材来源列表.pdf       ← 数据来源的权威性证明
└── 5. 申诉说明信.txt             ← 简要说明+联系信息
```

### 3.1 申诉说明信模板

```
尊敬的[平台名称]内容审核团队：

本人是"深圳中考志愿规划（HSEE）"的运营者。账号[ID]下的文章《[标题]》
（发布时间：[日期]）近期被系统标记为"疑似AI生成"，推荐量受到限制。

现提交以下证据，证明该文章由本人及团队通过人工编辑创作完成：

1. 数据核验清单：文章中的[X]项数据逐一标注了官方来源，核验人[姓名]，
   发现并修正了[Y]处原始错误（附修正记录）。
2. 人工润色记录：初稿到终稿共进行了[Z]处实质性修改，包括[X]处结构调整、
   [Y]处数据修正、[Z]处原创内容新增，文本修改率[XX]%。
3. 所有数据来源于深圳市教育局官方公开信息，每项均标注了精确来源。

本账号使用AI工具作为写作辅助（类似Word的语法检查功能），
但核心内容创作、数据核查、编辑决策均由人工完成。

请贵平台复核。如需进一步提供创作过程的其他证据，请告知。

[署名]
[日期]
[联系方式]
```

### 3.2 关键注意事项

- **不要否认使用AI**——平台能检测到AI痕迹。承认"AI辅助工具"但强调"人工主导创作"
- **不要夸大**——说"完全没有使用AI"反而可能因为平台检测到痕迹而被判定为撒谎
- **话术要点**：AI工具辅助 + 人工数据核查 + 人工编辑审核 = 人工创作

## 四、执行检查清单

每篇文章发布前确认：

### 数据核验清单
- [ ] 所有数据点逐条标注来源文件和章节位置
- [ ] 核验人签名 + 时间戳
- [ ] 至少标注1项⚠️风险点或1处修正
- [ ] 核验清单保存到文章目录下

### 人工润色记录
- [ ] 至少3处改前/改后对比
- [ ] 至少1处为数据修正或结构调整
- [ ] 每处改动附人工判断逻辑说明
- [ ] 编辑签名 + 时间戳
- [ ] 人工润色记录保存到文章目录下

### 存档完整性
- [ ] 两文件均在发布前完成（时间戳早于发布时间）
- [ ] 文件名包含文章标题，便于追溯
- [ ] 保留至少12个月

---

> **一句话总结**：不是"填了表就行"——要**记录真实的人工介入动作**。AI发现不了的数据错误被你发现并修正了，这就是最有力的证据。
