# 52%录取率=一半没书读？别被带节奏

"深圳一半孩子上不了公办普高"——这句话吓退了多少家长。真相其实是…🤔

**① 公办52%只是第一层** 📊
公办普高录取率约52%不假，但全市普高（含民办）录取率**超73%**。加上民办，七成以上孩子能上普高。

**② 中职不是"没出路"** 🎓
3+4中本贯通：中职读3年 → 全日制本科读4年，拿的本科文凭和高考考上的一样。深圳试点一职对口深技大、二职对口深职大。3+2中高贯通还有近5,000个名额。

**③ 方向在好转** 📈
学位建设追着考生跑，录取率多年稳定。孩子不是在被淘汰，而是在被选择。

别再被"一半人没书读"带节奏了。数据来自深圳市教育局公开信息，逐条人工核对。收藏这篇，转给焦虑的家长朋友。💬
