# 中职3+4中本贯通，被忽略的升学路

400分段的孩子，别只盯公办普高。有一条很多人还不知道的路：**中职3+4中本贯通**。🛤️

**① 什么是3+4** 📚
中职读3年 → 本科读4年 → 全日制本科文凭。和高考考上的本科一样，含金量不低。

**② 深圳试点** 🏫
深圳中职对口本科：一职对口深技大、二职对口深职大。2026年首批约300个名额，知道的人还不多。

**③ 适合谁** 🎯
分数在公办线边缘、目标本科的孩子。低进高出，弯道超车——这是很多家长忽略的第三条路。

**还有3+2中高贯通**：中职3年 → 高职2年，近5,000个名额，路径更宽。

数据来自深圳市教育局公开信息，逐条人工核对。你家孩子分数段在哪？评论区聊聊，帮你参谋这条路线适不适合。💬
