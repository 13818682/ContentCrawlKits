# 深圳中考6条出路，一篇讲全

2026深圳高中阶段总共**146,752个学位、180所学校**，覆盖全部考生。出路远比你想象的多。🗺️

**① 公办普高** 🏫
约8万·101所，约52%。大多家长首选，AC类61,797人、D类18,506人（占比约23%）。

**② 民办普高** 💰
33,195人·49所。AC类和D类**同分录取**——对D类家长是重要补充选项。

**③ 中职及技工** 🛠️
33,254人·30所。公办中职15,924、民办中职17,330。

**④ 3+4中本贯通** 🎓
中职3年 → 本科4年 → 全日制本科文凭。一职对口深技大、二职对口深职大。

**⑤ 3+2中高贯通** 🎒
中职3年 → 高职2年，近5,000个名额。

**⑥ 走读 / 指标生** 🚶
降分通道：走读最高降35分；指标生校内竞争，降分空间因学校层次而不同。

收藏这篇，填志愿时一定用得上。数据来自深圳市教育局公开信息，逐条人工核对。你家娃现在什么分段？评论区聊聊。💬
