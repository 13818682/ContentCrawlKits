# P1-政策解码器 — 系列创作规划方案

## 一、系列定位

### 1.1 为什么需要 P1

S1-基本态势回答了"竞争有多激烈"——家长读完知道了16-18万考生、52%录取率、8年翻倍。
但家长紧接着会问：**"那规则是什么？我怎么玩？"**

这就是 P1-政策解码器的使命：**把深圳市教育局的官方政策文件，翻译成家长听得懂、记得住、用得上的"游戏规则说明书"。**

### 1.2 与 S1-基本态势的关系

```
S1-基本态势（宏观认知）         P1-政策解码器（规则理解）
─────────────────────────      ─────────────────────────
"竞争有多激烈"          →      "规则是什么"
"多少人、多少学位"      →      "怎么考、怎么录"
制造紧迫感               →      提供理解力
看完"知道要准备"         →      看完"知道怎么准备"
```

### 1.3 与下游系列的分工

| 系列 | 定位 | 与P1的边界 |
|------|------|-----------|
| **P1-政策解码器** | 规则是什么 | ← 当前系列 |
| P2-降分通道 | 怎么利用规则降分 | P1讲"指标生是什么"，P2讲"指标生志愿怎么填才能最大化降分" |
| P3-数据择校地图 | 选哪所学校 | P1讲"分数线怎么看"，P3讲"101所学校各自的分数线、校风、特色" |
| P4-志愿填报作战室 | 志愿怎么排 | P1讲"批次规则和投档逻辑"，P4讲"冲稳保梯度具体怎么排16个志愿" |
| P5-录取后行动指南 | 录取之后怎么办 | P1讲"录取批次与补录规则"，P5讲"出分后滑档补救、复读决策、高一衔接" |

### 1.4 目标读者

| 读者类型 | 特征 | P1要解决的问题 |
|---------|------|--------------|
| **零基础家长**（核心） | 孩子刚升初三，从未接触过中考政策 | "中考到底考什么？怎么录？"——从零建立规则认知 |
| **D类焦虑家长**（重点） | 非深户，担心户籍吃亏 | "D类到底比AC类差在哪？有什么机会可以弥补？" |
| **信息混乱家长** | 看过零散信息但相互矛盾 | "官方规则到底是什么？网上说的哪些对哪些错？" |

延续 HSEE 人格——**"懂政策的数据控学长"**，P1 系列特别强调：

### P1-1：深圳中考游戏规则——30分钟从入门到看懂

**定位**：P1系列旗舰篇。零基础家长的政策"第一站"。

**核心角度**：用"游戏规则说明书"的比喻，把整个深圳中考体系翻译成家长能理解的框架。

**差异化策略**：竞品的"政策解读"通常从第一条政策开始逐条讲，家长读完更晕。我们反其道——先给全景地图，再逐一深入。

**内容大纲**：
1. Hook："深圳中考不是一场考试，而是一个系统。搞懂规则的人，比只埋头读书的人多50%的机会。"
2. 全景流程图：报名→体育中考→英语听说→文化课考试→成绩公布→志愿填报→分批录取
3. 四句话概括游戏规则：
   - 总分630，考8科（语数英物化历道体）
   - 考生分三类（ACD），户籍决定赛道宽度
   - 录取分五批，前一批录了后面全作废
   - 16个志愿，"分数优先、依照志愿顺序"
4. 本系列预告："这8篇文章，帮你搞懂每一条规则的'为什么'和'怎么用'"

### P1-2：630分怎么来的——考试科目、计分规则与2026年三大变化

**定位**：解决家长搜索最多的一个问题——"中考考什么？"

**核心角度**：不罗列科目表，而是告诉家长"每1分的来源和权重"——哪些科目是"一分一操场"，哪些科目是"锦上添花"。

**差异化策略**：竞品只列科目和分值表。我们增加：
- 每科的"性价比"分析（投入时间vs提分空间）
- 2026年三大变化对备考策略的实际影响
- 同分PK规则——生地会考为什么比你想象的更重要

**内容大纲**：
1. Hook："总分630，但不是每1分都同样重要。"
2. 630分完整拆解表：语120/数100/英100/物化140/史70/道50/体50
3. 2026年三大变化深度解读：
   - 变化1：理化实验操作从12分→20分——"动手能力"权重翻倍
   - 变化2：道德与法治改为开卷——"抄书就能得分"是误解
   - 变化3：体育过程性评价14分——初一就开始累积
4. 同分PK规则："分数相同，谁先录取？"——生地合分→语数英合分
5. 单科等级制（A+/A/B+/B/C+/C）：为什么等级也重要（省一级学校要求C+）
6. CTA：HSEE小程序查看各校历年录取分数线

**数据需求**：2026年各科分值表、等级比例（5%/20%/25%/25%/20%/5%）

**变形平台**：小红书"630分拆解图"——一张图看完所有科目和分值

### P1-3：AC类还是D类——考生类别决定了你站在哪条赛道

**定位**：直面家长身份焦虑的第一篇。D类家长读完"路更窄但不是死胡同"，AC类家长读完"有优势但不能掉以轻心"。

**核心角度**：不回避D类的劣势，但重点放在"知道了差距，该怎么做"——把焦虑转化为行动。

**差异化策略**：竞品要么回避D类话题（怕引发争议），要么贩卖焦虑（"非深户太难了"）。我们走第三条路——客观数据+具体出路：
- AC类和D类的录取分数差距，分层次呈现（四大基本持平，中下层差距拉大）
- D类5个报名条件逐条解读+材料准备清单
- D类的三个"弯道超车"机会（指标生全覆盖、民办同分、3+4中本贯通）

**内容大纲**：
1. Hook："ACD三个字母，决定了你的孩子站在哪条起跑线上。"
2. 什么是A/C/D类：用一张表讲清楚

4. D类家长必读：5个报名条件+材料清单
5. D类不是死胡同：指标生全覆盖+民办同分录取+3+4中本贯通
6. AC类家长也别掉以轻心：52%录取率的压力在每个人身上
7. CTA：HSEE小程序按类别筛选目标学校

### P1-4：先录谁、怎么录——招生批次与投档规则全解

**定位**：整个P1系列中"最硬核"的一篇。投档规则不理解，后面所有策略都是空中楼阁。

**核心角度**：用"排队上车的比喻"讲透"分数优先、依照志愿顺序"——这是家长最容易误解的规则。

**差异化策略**：竞品要么用官方语言照抄规则，要么举过于简化的例子。我们：
- 用3个详细的模拟案例（不同分数段、不同志愿排列）展示投档全过程
- 用"错误填法vs正确填法"对比表
- 重点讲清楚最容易犯的4个错误（后面批次填了更想去的学校、不理解的"不退档"规则等）

**内容大纲**：
1. Hook："投档规则是深圳中考最核心的游戏规则。搞错了，分再高也可能滑档。"
2. 五个批次的录取顺序（一张图说清楚）
3. "分数优先、依照志愿顺序"——用排队比喻+3个案例讲透
4. 同分PK规则：生地合分→语数英合分，实际案例演示
5. 四个最容易犯的投档理解错误：
   - 错误1："我把保底学校放在第一志愿最保险"——为什么这是浪费
   - 错误2："前面批次没录上，后面还有机会"——对，但前提是你填了
   - 错误3："被录取了不想去可以不去"——不退档、不转录！
   - 错误4："16个志愿太多了随便填"——每个位置都有策略意义
6. CTA：HSEE小程序模拟志愿填报

### P1-5：名额分配——50%指标到校，校内竞争怎么玩

**定位**：指标生是家长关注度最高的单一政策。这篇讲清楚"是什么"和"基本玩法"。

**核心角度**：指标生=校内竞争（不是全市竞争），核心优势=降分空间。但降多少因校而异——要用数据说话。

**差异化策略**：竞品讲指标生要么太浅（"可以降分"一句话带过），要么太深（直接跳进填报技巧）。我们精准卡位"规则理解"层：
- 控制线怎么算（前三年平均-20分）
- 你在学校的竞争对手是谁（同校同届填同一所高中的同学）
- 未使用指标生名额自动转正取——这意味着什么

**与P2-1的边界**：P1-5讲规则，P2-1讲"指标生志愿怎么填能最大化降分效果"。

**内容大纲**：
1. Hook："50%的公办高中学位，不是全市抢，而是在你的初中里抢。"
2. 指标生是什么：一页纸讲清楚
3. 三个关键条件：3年连续学籍+控制线+校内竞争
4. 控制线计算方式：前三年录取线平均值-20分
5. 一个指标生录取的完整案例（从名额分配到录取）
6. "指标生名额用不完怎么办？"——自动转正取
7. 2027届家长现在该做什么：查你所在初中的指标生分配表
8. CTA：HSEE小程序查每所初中的指标生名额

### P1-6：自主招生——一类和二类有什么区别，谁适合报名

**定位**：自主招生是"小众但高价值"的通道。知道的人少、用的人更少——恰恰是信息差最大的领域。

**核心角度**：不鼓吹所有人都去报自招，而是帮家长判断"我家孩子适不适合"。

**差异化策略**：竞品对自招的覆盖是"中等偏少"（竞品调研确认）——这是P1系列中竞争最不激烈的选题。我们的优势：
- 一类（学术/科创）和二类（艺体/体育）的差异一目了然
- 自招的"隐形门槛"——中考成绩仍然占60%，不是"才艺好就能上"
- 2026年自招的实际录取案例

**内容大纲**：
1. Hook："自主招生不是'偏才通道'——中考成绩仍然占60%。但它可以让你用更低的分数进更好的学校。"
2. 一类vs二类：一张表对比（招生对象、考核方式、分数构成、时间节点）
3. 自招的隐形门槛：中考成绩占60%，综合能力考核占40%
4. "我家孩子适合报自招吗？"——决策树
5. 自招时间线：报名（6月中旬）→考核（中考后）→录取（第一批之前）
6. 致命的注意事项：一类和二类不能同时报、只能报1所学校、录取后不退档
7. CTA：HSEE小程序查看自招学校的历年录取数据

### P1-7：报名到录取——关键时间节点一个都不能错过

**定位**：家长可打印的"中考年历"。时间节点错过一个，全年准备可能白费。

**核心角度**：不仅列时间节点，更要告诉家长"每个节点你应该做什么准备"——把被动等通知变成主动规划。

**差异化策略**：教育局的时间表只写"什么时候做什么"，我们写"什么时候做什么+为什么重要+提前多久准备"。

**内容大纲**：
1. Hook："中考不是6月才开始——从3月报名到8月录取，每一个月都有你不能错过的事。"
2. 全年时间线（3月→8月）：
   - 3月：中考报名（D类家长注意5项材料）
   - 4月：体育中考
   - 5月：理化实验操作考试+英语听说考试
   - 5月23日-6月1日：**志愿填报（全年最重要的10天）**
   - 6月中旬：自主招生报名
   - 6月26-28日：文化课考试
   - 7月16日：成绩公布
   - 7月下旬-8月：分批录取
3. 三个"一旦错过就不再来"的节点（志愿填报、自招报名、补录窗口）
4. 志愿填报的"保存≠确认"——每年都有人因此白填
5. CTA：关注HSEE公众号，每个节点前一周推送提醒

**数据需求**：2026年精确时间节点（以2026年公告为准，2027年标注"待当年公告"）

### P1-8：中考术语速查手册——A-Z搞懂所有"黑话"

**定位**：伴随整个P1系列的常青工具内容。家长在任何阶段遇到不懂的术语，这篇都能查到。

**核心角度**：不是冷冰冰的词典，而是"家长版翻译"——每个术语后面跟一句"说人话"。

**差异化策略**：竞品的术语解释通常只给定义。我们给三个层次：
1. 官方定义（标注出处）
2. 人话翻译（家长听得懂的版本）
3. 为什么重要（不搞懂会有什么后果）

**内容大纲**：
按使用频率排列约30-40个核心术语：
- 基础类：ACD类、正取生、指标生、自招生
- 分数类：原始分、单科等级、一分一段表、录取分数线
- 批次类：提前批、第一批、第二批、补录
- 策略类：冲稳保、梯度、走读调剂、签约
- 路径类：3+4中本贯通、3+2中高贯通、综合高中
- 操作类：保存vs确认、短信验证码、打印回执

**变形平台**：小红书拆成5-8篇"每天学3个中考术语"系列卡片

**参考来源**：`2.方案设计/2.中考基本概念与术语速查手册`
