# 深圳中考术语黑话翻译器🔤 每天3个，7天搞懂所有！

收藏这篇，遇到不懂的词随时回来翻👇

---

## DAY1️⃣ 基础类

**ACD类** = 户籍决定了赛道宽度
A/C=深户，D=非深户。D类考生占54%但公办指标仅占23%

**应届/往届** = 往届生不能走指标生和自招

**省一级学校** = 深圳大多数公办普高都是。要求所有科目C+以上

---

## DAY2️⃣ 分数类

**原始分** = 你考了多少就是多少

**单科等级** = A+前5%/A前20%/B+前25%…等级比分数更能反映全市排位

**录取分数线** = 不是学校"设"的线，是最后一名录取考生的分数

---

## DAY3️⃣ 分数类

**指标生控制线** = 前三年均分-20分。低于这条线指标生跟你无关

**一分一段表** = 全市排名定位器。不知道排名=盲填志愿

---

## DAY4️⃣ 批次类

**五个批次** = 自招→指标生→第一批→第二批→第三批。前面录了后面全作废

**不退档不转录** = 录了就定了，没有"我再看看"的机会

---

## DAY5️⃣ 通道类

**正取生** = 第一批按分录取，最常规的路

**指标生** = 50%到校，校内竞争

**自招一类/二类** = 中考占60%+校考占40%

---

## DAY6️⃣ 路径类

**3+4中本贯通** = 中职3年+本科4年→全日制本科文凭（300名额）

**3+2中高贯通** = 中职3年+大专2年（近5000名额）

**民办普高** = 学费贵但AC/D同分录取

---

## DAY7️⃣ 操作类

**保存≠确认** = 每年都有人填完志愿没确认→白填！

**短信验证码** = 最多3次确认机会。手机号别换！

**走读调剂** = 增加录取概率但可能每天通勤3小时
