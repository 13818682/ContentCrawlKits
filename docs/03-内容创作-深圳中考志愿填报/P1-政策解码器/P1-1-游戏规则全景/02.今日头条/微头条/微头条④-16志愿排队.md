# 微头条 · 16个志愿怎么录？排队录取

统一招生第一批16个志愿，按**"分数优先、依照志愿顺序"**投档：

- 全市按分数从高到低**排队**，轮到谁处理谁
- 处理到你，按志愿顺序（1→2→3…）**依次检索**
- **第一个有名额的学校即录取**

用比喻一下就懂了——**排队录取**：分数高的排前面，你手里有张纸条写志愿顺序，打饭阿姨按纸条找，哪个窗口还有饭就安排你到哪。

**不能说"1号没饭了想去5号"——系统只能按顺序来。**

所以：最想去的放前面，按喜欢程度从高到低排。同分先比生地合卷，再比语数英。
