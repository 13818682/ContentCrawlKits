# P1-2 · 试点工作区（新思路·规则18）

## 为什么另建本目录
P1-2 原平台目录（01.公众号/02.今日头条/03.抖音/04.小红书）是按**旧思路**（13-x 直接模板）产出的。规则18 在 D1-D5 与 V1-V4 确认后，先在本目录按**新思路**设计与预演文案，人工审后发布、试点验证，验证回流后再回写 13-x。**本目录不覆盖、不改动任何原目录文件**。

## 工作流（后续每篇照此）
```
① 取素材（现有 P1-2/公众号主线-精简 或 对应 md）
 → ② 本地增量（D5：补本地数字口径核对 / 口语化转述 / 本地场景；见 01）
 → ③ 分平台变形（标题A/B、封面差异化、口播锚点…按本目录各文件 + 13-x 原模板兜底）
 → ④ 人工审（04/04A 合规 + A/B 判断表 + 数据来源按 18 附录规范）
 → ⑤ 发布 → ⑥ 数据回 15-运营数据 周报 → ⑦ 结论回流 18 §6.2 → ⑧ ≥2批支持后回写 13-x（另任务）
```

## 合规与边界
- 所有数字以深圳市教育局/招考办公开文件为准，标注按 18「附录·来源标注规范」；本目录文案中的"待人工核验"点一律在发布前核清。
- 公众号：发布时会点原创（D1），来源逐条注明公开文件。
- 小红书：无站外导流（只"搜一下HSEE"）；封面走 V1 封面PK 候选。
- 抖音：不夸大、不卖惨、开头 2s 兑现答案、不含第三方水印（D4 认证由运营侧申请，本目录只记录）。
