# 科目性价比 · 小红书图文（Step1 发布稿）

## 笔记标题（正文栏）
同样的复习时间，花在哪科涨分最快？

## 正文（约430字）
别让孩子把晚上的复习时间全耗在历史题海里——先给主科，涨分更实在。

📚 **语数英物化＝440分**：深圳中考630分里，这几科是大头，公办还是民办，主要看它们。每天的可支配时间，先排给主科。

⚗️ **理化实验2026涨到20分**：操作分靠刷题刷不出来，得跟着学校真动手练——这门课花的时间，性价比很高。

🧮 **历史70＋道法50＋体育50＝170分**：稳住即可，别让副科题海吃掉孩子主科的时间。

**中等生家庭最该做的一件事**：把每晚时间先给主科和大题，实验跟着学校节奏动手练；副科跟住进度就行，不用加量。

**尖子生家庭提醒**：主科已稳的话，别在这门实验的"送分"上丢分——一次操作失误可能就没了。

一句话记住：**主科决定上限，实验是最稳的加分，副科稳住别拖后腿。**
