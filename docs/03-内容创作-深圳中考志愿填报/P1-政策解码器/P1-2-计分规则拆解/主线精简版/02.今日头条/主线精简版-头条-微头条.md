# 主线精简 · 头条微头条（数字式）

深圳中考 630 分，记住 4 个关键词就够了：**440、20、170、同分 PK**。

· 440＝语文120+数学100+英语100(含听口)+物化笔试120，主科，决定位置；
· 20＝理化实验(2026为20分)，操作分要动手练；

· 同分 PK＝总分相同先比生地，生地已考完，分数要心里有数。
