# 深圳中考630分一篇讲透：构成、三大变化、等级、隐形战场

先说结论：深圳中考 630 分＝**440 笔试主科（含英语听口）＋ 20 理化实验 ＋ 170 历史道法体育**。把握住 4 个关键词——440、20、170、同分 PK——630 的规则就基本清楚了。

## 一、630 怎么构成

语文120＋数学100＋英语100(含听说25)＋物理化学笔试120＝440；理化实验20；历史70＋道法50＋体育50＝170。加总正好630。**主科决定位置，实验稳定加分，史道体稳住别拖后腿。**

## 二、2026 三大变化

- 理化实验涨到 20 分：操作分刷题拿不到，跟学校实验课真练。
- 道德与法治改开卷：会翻书≠会得分，考理解和框架。
- 体育改"三年累积"：过程14＋现场36，初三定三项早练。

## 三、两类容易被忽略的分

**单科等级**：每科按全市固定比例给等级，A+永远是前5%；报省一级学校，任一科不能掉到 C。

**隐形战场**：生物地理不计总分，但同分 PK 先比它（真实案例：两个552分，生地96录、82落选，14分差一个学位）；信息科技、艺术"合格"是报省一级的入场券。

## 四、精力怎么分（初三版）

总纲一句话：**主科优先、实验跟练、副科稳住、两个门槛心里有数。**

| 优先级 | 科目 | 初三动作 |
|:---:|---|---|
| 🔴 | 语文·数学·英语 | 黄金时间先给它们 |
| 🔴 | 物化实验 | 抓住每次实验课 |
| 🟡 | 体育 | 现在定三项，每周≥3次 |
| 🟡 | 道法 | 搭框架＋快速索引 |
| 🟢 | 历史 | 跟节奏，考前集中背 |
| ⚪ | 生地 | 已考完，确认分数 |

## 五、系列怎么读

读本篇建立框架；想深挖就按清单走：构成(S1)→实验→道法开卷→体育→单科等级→隐形战场，各有独立篇。下一条主线讲 AC 类还是 D 类（户籍怎么影响录取）。
