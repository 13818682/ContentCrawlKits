# 微头条 · 不计入630分的科目，却可能决定录取

有两类科目**不进总分，却可能决定孩子的录取**：

**① 生地（合卷100分）**：不计总分，但**同分PK时先比生地**。真实案例：两名考生总分都是552，生地96的被录取、生地82的落选——14分差一个学位。

**② 信息科技 & 艺术**：报省一级学校必须"合格"，别让合格考最后翻车。

生地初二考完，分低别慌：同分PK第二层还比语数英，可以对冲；信技艺术是入场券，务必确认合格。
