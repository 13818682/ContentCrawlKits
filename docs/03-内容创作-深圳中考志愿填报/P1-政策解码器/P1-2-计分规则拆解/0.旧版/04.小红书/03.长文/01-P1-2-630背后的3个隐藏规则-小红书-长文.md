# 小红书长文笔记 · 630背后的3个隐藏规则

## 笔记标题
知道孩子630分，和会用这630分，是两回事｜升初三家长收藏

## 正文文案

深圳中考满分630分，这个话题全网说烂了。但大多数家长知道的，只是"总分630"五个字。

**知道总分，和知道怎么用这630分做决策，是两回事。**

孩子明年中考，你最先该想的不是"能考多少分"，而是三个问题：同样的时间花在哪涨分最快？同分的孩子凭什么一个录一个落选？哪些科目不进总分却决定录取？

这三个问题，就是630分背后真正的3个隐藏规则。

---

### 规则一：每1分的性价比不一样——精力花在刀刃上

**同样一小时复习，砸在不同科目，涨分完全不同。**

- **语数英物化笔试 = 440分，占总分约70%**（语120/数100/英100/物70/化50）。主战场，决定公办民办，必须全力投入。
- **理化实验2026年涨到20分**。从12涨到20，新增8分性价比最高——**动手分刷题拿不到，认真练几乎白送**。
- **历史+道法+体育 = 170分**（70/50/50）。稳定发挥即可，别让副科挤占主科时间。

> 中等生别在历史题海里苦熬，把时间投到数学大题和物化实验上，涨分更快、更确定。

---

### 规则二：单科等级比分数更准——A+永远是全市前5%

分数有个问题：会骗人。试卷难，分数低；试卷简单，分数高。拿今年分数比去年录取线，本身就是错的。

深圳中考的解法是：每科除了分数，还按全市固定比例给**等级**：

- **A+ = 前5%**，单科顶尖
- **A = 前5%-25%**，录取线稳定盘
- **B+ = 前25%-50%**、**B = 前50%-75%**，中等竞争区
- **C+ = 前75%-95%**——**省一级学校报考门槛就卡在这**

**省一级硬门槛：全科 C+ 及以上、体育 C 即可。任何一科掉到C，直接失去报考资格。**

很多家长忽略这个坑：孩子总分够，初二有个会考科目掉到C，省一级连报都报不了，等发现已来不及补。

> 分数会浮动，等级稳定。看孩子是A还是C+，才知道他的真实位置、哪科在拖后腿。

---

### 规则三：不计入总分的"隐形战场"——生地、信技、艺术

这三科**根本不进630分**，却可能在录取最后一刻决定命运。

**① 生物与地理（合卷100分）**
生地初二会考完，不计总分，只作"同分排序"用——但关键时刻比总分还重要：

**总分相同，深圳中考按序比三样：先生地合卷，再语数英总分，再语数英单科。生地排同分PK第一顺位。**

真实案例，2026年某区属高中最后1个名额，两人都552分：
- 考生A 生地96 → 录取
- 考生B 生地82 → 落选

**14分的生地差距，就是一个高中学位。** 生地已考完分不理想别慌，同分第二层语数英可以冲。

**② 信息科技与艺术**
报省一级学校这两科须"合格"，通常学校自行组织，绝大多数能过——**正因为都能过，才容易被忽略，别让合格考翻车**。

> 生地是底牌，信技艺术是入场券。

---

### 把规则落到现在：三件事

1. **看性价比调精力**——主战场优先，实验8分认真练；
2. **看等级定位孩子**——哪科在C边缘，哪科现在补；
3. **确认两个隐形门槛**——生地分数记清楚，信技艺术确认合格。
