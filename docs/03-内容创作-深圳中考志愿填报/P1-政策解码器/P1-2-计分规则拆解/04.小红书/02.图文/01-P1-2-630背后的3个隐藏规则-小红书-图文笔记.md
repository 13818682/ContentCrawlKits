# 小红书图文笔记 · 630背后的3个隐藏规则

## 笔记标题
630分，藏着3个决定录取的规则｜升初三家长建议收藏

## 正文文案

知道孩子考630分，和知道怎么用这630分做决策，是两回事。

**分数之外，有3个规则悄悄决定录取：**

**① 性价比——同样的时间，花在哪最划算**
语数英物化440分主战场全力投入；理化实验2026涨到20分，8分增量=性价比之王；历史道法体育170分，稳定即可，别挤占主科。

**② 等级制——看等级，别只看分数**
A+永远前5%，试卷难易不影响。省一级学校要全科C+及以上、体育C即可——掉到C，报名资格都没有。

**③ 隐形战场——生地、信技、艺术**
生地合卷100分不计总分，但同分PK先比生地；信息科技艺术报省一级须合格。案例：两个552分，生地96录、82落选，14分差一个学位。

**3条都搞懂，孩子备考精力花对地方、门槛不踩空。**
