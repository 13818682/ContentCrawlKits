# S4 · 头条微头条（数字式）

深圳中考体育 50 分，早不是"初三跑一次"那么简单了——一半靠**三年攒**，一半靠**一次考**。

记住三点：
· **14 分是过程分**：体质测试每年 3 分（及格即得）＋体育课参与每年 1 分＋初二下一次通识考 2 分——几乎只考"人有没有到齐"；
· **36 分是现场考**：三大类（耐力 / 速度力量灵敏 / 球类）各选 1 项，4 月中下旬考；
· **别备错**：引体向上、仰卧起坐、立定跳远已经移出现场考试、并进体质测试了。

现在（初三上）就做：先查前两年过程分有没有漏，再定好三类项目、耐力类每周至少练 3 次。
