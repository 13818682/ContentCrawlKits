## 口播正文
很多非深户家长问：孩子要比深户多考多少分，才进得了同一所高中？

先说答案：**不是定数，看你在哪一层。**

第一层，四大名校——0分。2026深中AC类592、D类也是592，一分不差。**冲四大，户籍不卡你。**

越往下，差距越拉开。

区属中坚，AC530到554这段，D类普遍要高2到9分。

最狠的在边缘：AC线500到530这段公办，D类要高15到23分。深实崇文AC506，D类529，差了23分。

还有一句要提醒：这两年很火的集团新校区和综合高中班，**别以为新校好考——2026它们的分差反而最大，能到20到30分**。

一句话记牢：**四大0分，越往"勉强上公办"那段差越多。**

孩子目标在哪层？去查那所学校真实的分差，比听别人说管用。

关注我，下条讲：深户跨区报考的C类，别被忽略了。
