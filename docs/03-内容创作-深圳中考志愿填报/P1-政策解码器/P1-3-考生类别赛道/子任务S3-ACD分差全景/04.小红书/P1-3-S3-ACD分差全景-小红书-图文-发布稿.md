# P1-3 · S3 小红书图文（分差五层）

## 笔记标题（正文栏）
D类要多考多少分？分五层看

## 正文（约480字）
非深户（D类）孩子要比深户多考多少分，才进得了同一所公办？**答案不是定数，看孩子分数在哪一层。**这篇按 2026 住宿线实测分五层，📌建议收藏，择校随时翻。

🧱 **① 四大头部（587+）：差 0 分**
深中 AC 592 / D 也是 592，同分进。**冲四大，户籍不卡你。**

🏫 **② 区属中坚（530-554）：差 2-9 分**
例：七高 530→535，福海 535→544。

⚠️ **③ 公办边缘（500-529）：差 15-23 分**
22 所里 16 所 D 高 10 分以上。深实崇文 506→529，差 23 分。**D 类的坑主要在这段。**

🚨 **④ 集团新校/综合高中班（500以下）：差 20-31 分**
曙光 497→526（+29）、创新综高 487→518（+31）。**别信"新校区好考"，2026 它们分差最大。**

📊 规律一句话：**四大0分，越往"勉强上公办"那段，D类越多考。**

✅ 行动：先定目标层 → 查目标校真实 D 线（对照当年官方录取标准）→ 按层定冲/稳/保。
