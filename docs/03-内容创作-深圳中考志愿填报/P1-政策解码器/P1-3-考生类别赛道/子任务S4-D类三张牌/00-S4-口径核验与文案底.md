# S4 口径核验：D类不是死胡同——三张牌（指标生 / 民办 / 3+4）

> **一句话结论**：D 类的路不止"死磕公办"一条。难在"约54%考生（约8.3万）抢约23%公办名额、公办边缘段 D 还要多考 15-23 分"（S3）。但**三张牌的本质 = 把"全市 D 类混战"换成"更小的池子 / 拉平的线 / 不挤的赛道"**：①指标生（名额到校·D类单列·拼同校D类）→ 池子变小；②民办高中（ACD 同一条线·49所/33,195学位）→ 分数线拉平；③3+4 中本贯通（6校8专业300人·ACD 同线·全日制本科直通）→ 换赛道。

### 4. 指标生（D 类通道，机制层）
- 公办普高设**指标生名额分配到初中校（名额到校）**，其中给 **D 类单列**；报同一校指标生的 D 类孩子，**在本校 D 类同学间竞争**，非全市 D 类混战。
- 头部公办给 D 类的名额里**指标生占大头**（2026 计划可见 D 类名额=指标生+普通两栏，指标生明显多于普通）。
- 各校名额/降分规则/使用细节 → **P1-5（后续单篇）**，S4 只到机制结论，不引各校名额数字。

## 三、三句大实话（每张牌必须配代价，防"卖希望"违规/失真）

1. **指标生不是降分神器**：要孩子在本校 D 类里排名靠前才硬；名额到校不等于人人有份。
2. **民办的"线低"换的是"学费高"**：3 万–15 万/年，且办学口碑差异大，是兜底不是首选。
3. **3+4 读的是 3 年职校**：拿的是应用型本科（多为职业本科），与"考普通本科/985"是两条路，别神话"本科"二字。
