# D 类非深户只能死磕公办？答案：不是，有三张牌

先说痛点：2026 D 类考生约 8.3 万（约 54%），公办给 D 的名额只有约 1.85 万，边缘段还要多考 15-23 分。听着难，但路不止一条：

- **① 指标生**：名额到校、D 类单列——拼的是**同校 D 类位次**，不是全市混战
- **② 民办**：2026 深圳 49 所、33,195 学位，录取**一条 ACD 线，不分户籍**——够不到公办 D 线也有普高兜底（但要扛学费）
- **③ 3+4 中本贯通**：职校 3 年 + 本科 4 年拿全日制本科，2026 深圳首批 **300 名额**，D 类可报、同线录取——知道的人还不多

一句话：**D 类不是死胡同，是选择要比别人多想一层。**
