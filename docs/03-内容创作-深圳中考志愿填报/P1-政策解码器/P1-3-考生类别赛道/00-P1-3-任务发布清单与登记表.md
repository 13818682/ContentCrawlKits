> **用途**：P1-3《考生类别赛道》的"平台发布登记清单"——主线完整版 + 子任务 S1–S6，各载体发布时人工填写实际发布情况。
> **图例**：✅已产（发布稿/配图已生成，待人工审后发）；空白/待 ＝ 未产/未发布；🔒 ＝ 暂缓（知乎）；— ＝ 不适用；◇ ＝ 替代形态（主线在抖音/小红书用预告视频/长图卡，不用文字长文）。
> **文件分布**：`P1-政策解码器/P1-3-考生类别赛道/{主线完整版 | 子任务S1-…/…}`，各子任务下 `01.公众号 / 02.今日头条 / 03.抖音 / 04.小红书`。
> **平台分工（Q1·2026-09-06 修订）**：大长篇只在**公众号＋今日头条**出文字完整版（头条含微头条 teaser）；**抖音/小红书不产文字总览/文字长文**——主线在抖音=1条身份定位预告视频（互动向，非内容总览）、在小红书=1套全景长图卡进合集（收藏锚点）；深度发布单元＝各子任务逐条产 抖音口播/小红书图文。见 00-结构规划 §五。
