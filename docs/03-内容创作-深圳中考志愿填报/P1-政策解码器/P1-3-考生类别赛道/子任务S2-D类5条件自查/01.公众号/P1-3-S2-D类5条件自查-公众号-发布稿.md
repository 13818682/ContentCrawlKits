# 非深户D类报考：5个条件现在先自查这3项

如果你家孩子是非深户（D类），想在深圳参加中考、报考公办高中——**5个报名条件缺一不可，而且材料要提前准备**。别等到报名前才翻箱倒柜，每年都有人因为材料不齐在报名时手忙脚乱。

这篇给你一张**自查清单**，先看最要紧的 3 项现在就要确认的事。

## 一、D类报考的 5 个条件（官方口径，缺一不可）

| # | 条件 | 需要什么 | 常见问题 |
|:---:|------|------|------|
| 1 | **合法稳定职业** | 父母一方在深就业证明 | 灵活就业可用社保记录作辅助 |
| 2 | **合法稳定住所** | 租房需租赁凭证/自有房产证明 | 凭证报名前办好 |
| 3 | **持有深圳有效居住证** | 父母一方有效居住证 | 别过期，及时续签 |
| 4 | **社保（养老+医疗两险）** | 两险都缴 | **只需一个险种累计满3年**；补缴不计，截至当年8月31日 |
| 5 | **3年完整初中学籍** | 在深完成3年完整初中 | 转学手续要齐全 |

> 条件不全也能参加中考，但**只限民办普高补录或中职注册入学**，不能参加公办普高划线录取——这条很多人不知道，先记下。

## 二、现在（9月）就该先自查的 3 项

**第 1 项：社保满没满 3 年？（最常翻车）**
D 类要求的社保，是**养老+医疗都缴、但只需其中一个险种累计满 3 年**。别等报名才发现：①断缴了（补缴不计，需连续/累计达标）；②其中一个险种刚缴不久、不够 3 年。**现在就拉一下社保记录数一数。**

**第 2 项：居住证过期没？**
有效居住证是必要条件。**居住证需要按时续签**，过期了补办要时间。现在打开看一眼有效期，别到 3 月报名才发现过期。

**第 3 项：租赁凭证/住所证明办没办？**
租房家庭需要**租赁凭证**（不是普通租房合同），且要在报名前办妥。如果还没办，现在就去街道办/社区了解流程——这个也要时间。

## 三、剩下 2 项怎么自查

**职业与学籍**通常问题不大：父母一方在深有正经工作（劳动合同/营业执照）即有职业；孩子在深读了 3 年初中即有学籍。这两项一般正常就满足，重点盯上面那 3 项。

---

**一句话行动**：现在去查三样——**社保满没满3年、居住证过期没、租赁凭证办没办**。这三样是要"提前办、花时间"的，越早查越从容。
