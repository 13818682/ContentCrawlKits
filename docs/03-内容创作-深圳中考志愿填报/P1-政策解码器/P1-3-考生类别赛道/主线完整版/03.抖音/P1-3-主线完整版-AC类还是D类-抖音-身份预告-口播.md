**A类**，深户、学籍同区，最宽；**C类**，深户但学籍跨区，报名要二选一，别忽略；**D类**，非深户——占了考生一半还多，却只竞争约23%的公办指标。

但D类别慌：四大名校AC和D分数线已经持平，分数到了，户籍不卡你。

真正的分差在中下层——越往下的学校，D类要考的分往往越高。所以关键是：**先搞清楚自己是哪一类，再谈分数。**
