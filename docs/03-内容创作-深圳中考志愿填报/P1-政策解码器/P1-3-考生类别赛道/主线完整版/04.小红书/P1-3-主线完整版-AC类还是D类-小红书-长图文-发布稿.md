AC类还是D类？一张图看清深圳中考考生赛道

## 正文（约480字，收藏向索引）
深圳中考把孩子分 **A、C、D 三类**——先分清是哪一类，才知道路有多宽、分差在哪。📌这篇是全景，先收藏，逐张看图。

📂 **三类一句话**
· A 深户+学籍同区 → 最宽，公办都能报
· C 深户+学籍跨区 → 报名要二选一
· D 非深户 → 占一半多，公办指标约23%

📋 **D类重点 3 张图**
· 5个报名条件（社保满3年/居住证/3年学籍…）
· AC vs D 分差：四大0分，越往下越大
· 三张牌：指标生全覆盖/民办同分/3+4贯通

⚖️ **AC类也别大意**：52%公办率同样适用，指标生是校内的竞争。

✅ **一句话**：先确认自己是哪一类 → 查赛道分差 → 研究指标生 → 按类别筛校。详细解读见系列长文（深圳中考各平台同步发）。
