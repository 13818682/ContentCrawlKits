# 2026深圳中考：走读调剂该不该勾？被走读录取不能转住宿；保存≠确认，别白填

P1-4 收官篇，两个**操作层最易出事**的点：

## 一、走读调剂（2026 新增）
第一批普高志愿里，最多可对 **4 所学校**勾"接受走读调剂"。勾=多一次录取机会，但可能是走读。
- 勾了、住宿未满 → 录住宿生 ✅
- 勾了、住宿满/走读有余 → **录走读生，不能转住宿** ⚠️
- 没勾、住宿满 → 该志愿落空，进下一志愿

**决策**：≤30 分钟可勾；30-45 谨慎；>45 分钟或需换乘不勾；身体必须住宿绝不勾。**走读是"锦上添花"，不是"雪中送炭"——别为一点概率搭三年通勤。**

## 二、保存 ≠ 确认
流程：填写→保存→**确认（短信验证码）**→打印回执。2026 最多 3 次确认、第 3 次后不能改；截止 **6月1日 18:00**，没确认=志愿作废。**每年都有人只保存没确认，白填。**

## 三、收口
P1-4 主线+S1~S4 已把五批次、志愿顺序、同分、梯度、走读、保存确认讲全。下一步最该做的是亲手试一次：用 HSEE"模拟志愿填报"排一次，看系统怎么录；查目标校历年 AC/D 线。下一篇 P1-5 讲名额分配（50% 指标到校）为什么是降分通道。
