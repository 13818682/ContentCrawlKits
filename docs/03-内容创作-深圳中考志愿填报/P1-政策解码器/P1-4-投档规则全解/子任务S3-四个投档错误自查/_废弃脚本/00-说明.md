# 为什么这个脚本被弃用

`_build_p14_s3_all.py` 的 `BASE` 直接指向**子任务根目录**，没有平台子目录：

```python
BASE = ".../P1-4-投档规则全解/子任务S3-四个投档错误自查"
p = f"{BASE}/P1-4-S3-四错自查-抖音-镜头{n:02d}-1080x1920.png"
```

**后果**：跑它会往 S3 根目录倒 15 张废图，而 `01.公众号/ 02.今日头条/ 03.抖音/ 04.小红书/` 里的真图**一张都不会更新**；而且它每张都打印 `OK`（`check()` 打开的是仍然存在的旧文件），看上去像成功了。

这与 S2 目录里已废弃的 `_build_p14_s2_all.py` 是同一个缺陷。

# S3 的正确生成器（都在 P1-4 根目录）

| 脚本 | 产出 |
|---|---|
| `_build_p14_dyxhs_rich.py S3` | 抖音 6 分镜 + 小红书封面/正文图1-4 |
| `_fix_tt_covers.py` | 头条 3 图封面（跑全量，S1-S4+主线） |
| `_fix_gzh_covers.py` | 公众号封面（跑全量） |
| `_p14_dyxhs_family.py` | 版式模板库（被上面第一个 import） |

# 教训（已写入记忆）

子任务目录内**不应**保留自己的生成脚本；生成器统一放 P1-4 根目录，输出路径必须带平台子目录。
