# 报名到录取：关键时间节点一个都不能错过

前面6篇讲了深圳中考的所有"游戏规则"。这一篇是"游戏时间表"——每一关在什么时候、多久之内必须完成。

中考不是6月那2.5天的考试。从3月报名到8月录取，整整6个月。错过其中任何一个节点，前面所有的准备都可能白费。

**建议把这篇收藏或打印，贴在冰箱上。**

---

## 月度时间表

### 3月：中考报名

| 事项 | 说明 |
|------|------|
| **做什么** | 登录深圳招考网，填写报名信息，上传照片，选择体育考试项目 |
| **D类特别注意** | 5项材料必须备齐（详见P1-3）——社保、居住证、租赁凭证、学籍证明、计划生育 |
| **重要性** | ⚠️ **没有报名就没有考试资格**——没有补报机会 |
| **提前多久准备** | 现在就开始核查材料，不要等到3月 |

### 4月：体育中考

| 事项 | 说明 |
|------|------|
| **做什么** | 现场考试（36分）——耐力跑/游泳+技能类+球类，三项各选1 |
| **重要性** | 36分直接计入中考总分——考前突击无效，必须长期训练 |
| **提前多久准备** | 初三上学期确定选哪三项，每周至少3次针对性训练 |

### 5月：实验操作 + 英语听说 + 志愿填报

这是全年最密集的月份。

| 事项 | 时间 | 分值 | 重要性 |
|------|------|:---:|:---:|
| 理化实验操作考试 | 5月中下旬 | 20分 | 现场动手做实验，操作规范是关键 |
| 英语听说考试 | 5月中旬 | 25分 | 人机对话，考前多模拟 |
| ⚠️ **志愿填报** | **5月23日-6月1日**（参考2026） | — | 🔴 **全年最重要的10天！** |

> **志愿填报为什么重要？** 这10天里你要决定：16个第一批志愿怎么排、指标生填哪所、勾不勾走读调剂——确认后不可更改。前面P1-1到P1-6所有的准备，都是为了这10天的决策。

### 6月：自主招生报名 + 文化课考试

| 事项 | 时间 | 说明 |
|------|------|------|
| 自招报名 | 6月10-14日（参考2026） | 一类二类选其一，只能报1所 |
| **文化课考试** | **6月26-28日** | 2.5天，7科——孩子的主战场 |
| 自招考核 | 中考后1-2天 | 报了的才参加 |

### 7月：成绩公布

| 事项 | 时间 | 说明 |
|------|------|------|
| **成绩公布** | **7月16日**（参考2026） | 含总分+各科等级（A+~C） |
| 成绩复查申请 | 成绩公布后2天内 | 觉得分数有异常可以申请复核 |

### 7月下旬-8月：分批录取

| 批次顺序 | 说明 |
|------|------|
| 自招批录取 | 最先录取——录了后面全作废 |
| 名额分配批录取 | 指标生录取结果 |
| 第一批录取 | 16个志愿的主战场——**大多数孩子的录取结果在这一批确定** |
| 第二批录取 | 本市中职技校 |
| 第三批录取 | 外省市中职 |
| 补录/注册入学 | 最后的兜底机会——补录通常没有公办普高 |

## 三个"一旦错过就不能回头"的节点

| 节点 | 错过后果 | 如何防止 |
|------|------|------|
| 🔴 **中考报名（3月）** | 无法参加中考 | 现在就核查材料（尤其D类），设置3月1日手机提醒 |
| 🔴 **志愿填报（5月下旬）** | 无法被任何学校录取 | 设置5月20日手机提醒——不是23日！提前3天开始准备 |
| 🔴 **志愿确认（6月1日18:00前）** | 志愿填写无效——保存≠确认！ | 确认后检查短信验证码是否收到，打印回执签字 |

> **每年都有家长**：填完了志愿、点了"保存"、以为搞定了。结果6月1日18:00一过才发现没有点"确认"——孩子一年的努力，因为一个按钮白费。**填完志愿必须确认收到了短信验证码。**
