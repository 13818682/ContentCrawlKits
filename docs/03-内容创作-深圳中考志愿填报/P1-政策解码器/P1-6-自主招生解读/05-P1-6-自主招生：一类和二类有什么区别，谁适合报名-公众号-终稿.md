# 自主招生：一类和二类有什么区别，谁适合报名

如果说指标生是"大家都知道、大家都在抢"的降分通道，那自主招生就是"知道的人少、竞争反而小"的那条路。

但很多家长有一个误解——"自主招生 = 特长生专属"。不是的。科创类、创新类自招对理科好的普通学生同样开放。而且中考成绩仍占60%——不是"拿了自招资格就不用中考了"。

这篇文章帮你判断：**我家孩子适不适合报自招？**

---

## 一类 vs 二类：一张表讲清楚

深圳中考自主招生分两类，核心区别在于招生对象和考核方式：

| 对比维度 | 一类（学术/科创） | 二类（艺体/体育） |
|------|------|------|
| **招生对象** | 学科特长突出、创新潜质强的学生（数理/科创/人文） | 艺术（音乐/美术/舞蹈）或体育特长生 |
| **考核方式** | 学校组织的综合能力考核（笔试/面试/机考） | 学校组织的专业考核（现场表演/体能测试） |
| **分数构成** | 中考成绩60% + 学校考核40% | 中考成绩60% + 学校考核40% |
| **报名时间** | 6月中旬（中考后） | 6月中旬（中考后） |
| **考核时间** | 中考后、成绩公布前 | 中考后、成绩公布前 |
| **录取批次** | 自主招生批（五批次中的第1批） | 同左 |
| **典型学校** | 深中、实验、深外、高级等头部学校的数理/创新班 | 各校的体育/艺术特色项目 |

> **关键区别一句话**：一类看"脑子"（学术潜力），二类看"才艺"（专业水平）。如果孩子数理特别好但没有艺术体育特长——一类可以冲。如果孩子有艺术体育特长但文化课稍弱——二类可以保。

---

## 60%+40%：自招不是"偏才通道"，更不是"降分捷径"

这是家长对自招最大的误解。

| 成绩构成 | 占比 | 说明 |
|:---:|:---:|------|
| 中考成绩 | **60%** | 中考考多少分，按比例折算 |
| 学校综合考核 | **40%** | 学校组织的专业测试（笔试/面试/实操） |
| 总分 | 100% | 按综合分从高到低录取 |

> **用具体数字说**：假设深中自招招50人。一个校考满分但中考500分的学生，综合分大概率不如校考70分但中考570分的学生——因为中考占60%，500分在中考这一端就把综合分拉低了。**想走自招，中考同样不能放松。**

自招录取还有一个"残酷"的现实——它在五批次中排第一：

| 录取结果 | 后果 |
|------|------|
| 自招录取了 | 名额分配批、第一批、第二批、第三批——**全部作废** |
| 自招没录 | 正常进入名额分配批→第一批→…没有任何影响 |

再加上三条"死规定"：

| 规则 | 说明 |
|------|------|
| **一类二类不能同时报** | 只能选一个类别 |
| **只能报1所学校** | 选了深中就不能报实验 |
| **录取后不退档不转录** | 和所有批次一样——没有后悔药 |

> **这意味着什么？** 自招的正确用法是"冲刺更好学校"——冲不上没关系，第一批还有正取。**不要拿自招报一所和正取差不多甚至更差的学校**——万一自招录了，正取的好学校就去不了了。

## 决策树：我家孩子适合报自招吗？

| 孩子情况 | 适合报自招吗？ | 建议 |
|------|:---:|------|
| 数理成绩突出（数学/物理稳定A+），有竞赛或科创经历 | ✅ 非常适合 | 冲一类自招，目标四大/八大的创新班 |
| 数理成绩好（A/B+），无竞赛经历但对理科有兴趣 | ✅ 可以尝试 | 一类自招的考核偏思维而非知识储备，平时理科思维好的孩子有优势 |
| 有明确的艺术/体育特长（拿过奖/校队水平） | ✅ 非常适合 | 二类自招——专业水平是硬通货 |
| 成绩均衡但无突出科目，无艺术体育特长 | ⚠️ 谨慎 | 自招不是必经之路——第一批正取性价比更高 |
| 成绩较弱（预估500分以下），想通过自招"捡漏" | ❌ 不建议 | 中考占60%，500分拉低综合分，捡漏概率极低 |

> **二类自招特别提醒**：二类自招的学校考核是专业能力测试，不是"兴趣爱好展示"。比如报声乐——你要能现场视唱；报篮球——你要能打全场。如果只是"学过几年"但无比赛成绩或专业训练背景，二类自招的通过率很低。**"有特长"≠"能过自招"。**

## 自招时间线：这几个节点不能错过

| 时间 | 事项 | 注意 |
|------|------|------|
| 2027年5月 | 各校发布自招简章 | 关注目标学校官网——一类和二类的招生计划、考核方式都在简章里 |
| 2027年6月中旬 | 自招报名 | 只能选1所学校、1个类别，报了就不能改 |
| 中考后1-2天 | 学校综合考核 | 一类通常考数理思维/综合素养，二类考专业能力 |
| 中考成绩公布后 | 综合分排名+录取 | 自招批最先录取——录了后面全作废 |
