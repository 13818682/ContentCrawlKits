# 深圳公办高中梯队全盘点：四大/八大/二十大/新校

P1讲了规则，P2讲了降分战术。现在进入最关键的问题——**101所公办普高，我家孩子选哪所？**

这篇是择校总纲。不评价学校"好不好"——用2026年录取分数线把101所学校分成5个梯队。你在哪个分数段，就看哪个梯队。

> 分数线格式：**AC住宿 / D住宿**。走读分差和AC/D分差的完整数据见 P2-4（走读分差排行）和 P3-2（AC/D分差排行榜）。
