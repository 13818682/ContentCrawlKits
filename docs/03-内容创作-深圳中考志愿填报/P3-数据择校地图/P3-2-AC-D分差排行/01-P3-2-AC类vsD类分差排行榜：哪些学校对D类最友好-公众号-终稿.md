# AC类vs D类分差排行榜：哪些学校对D类最友好

P1-3 讲了ACD三类的区别——D类占考生54%但公办指标仅占23%。

这篇给D类家长一个独一无二的工具：**全深圳公办普高，按"对D类友好度"从高到低排列。**

---

## AC/D分差是什么？

AC/D分差 = **D类住宿线 - AC类住宿线**。分差越小，D类和AC类进入这所学校的门槛越接近。

| 分差 | 友好度 | 含义 |
|:---:|:---:|------|
| **≤0分** | ⭐⭐⭐⭐⭐ | D类与AC类同分甚至更低——罕见但存在 |
| **1-3分** | ⭐⭐⭐⭐⭐ | 几乎同一起跑线——大胆报 |
| **4-8分** | ⭐⭐⭐⭐ | D类需要多考几分，差距可控 |
| **9-15分** | ⭐⭐⭐ | 有明显差距——指标生策略变得关键 |
| **16-25分** | ⭐⭐ | 差距大——D类预估分需相应提高 |
| **>25分** | ⭐ | 差距很大——需充分准备或另选目标 |

## D类择校速查

| D类预估分 | 推荐目标 | 策略 |
|:---:|------|------|
| 585+ | 四大——分差全为0 | 大胆冲，户籍不卡你 |
| 560-585 | 八大中分差≤3分的学校 | 指标生双保险+走读调剂 |
| 530-560 | 30强中分差<10分的学校 | 指标生+走读调剂（重点！）+民办备选 |
| 490-530 | 50强/百强 | 走读调剂主力+民办+3+4中本贯通 |
| 460-490 | 百强/新校/综合高中 | 多通道并行——不把鸡蛋放一个篮子里 |
