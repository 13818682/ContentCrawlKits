# D类考生专属填报策略：16个志愿的非深户排列法

P4-2 给了四个分数段的冲稳保公式——但那是AC类的逻辑。

**D类家长，你的16个志愿排列逻辑和AC类完全不同。** 不是因为你不懂规则——是因为D类的可选学校只有AC类的1/3，而且AC/D分差从-4到+31不等。

全网找不到第二篇D类专属的志愿排列策略。这就是为你写的。

---

## 一、D类 vs AC类：三个核心差异

### 差异1：可选学校更少

2026年深圳95所公办普高中：

| 分差类型 | 学校数 | D类可选？ |
|------|:---:|:---:|
| 零/负分差（D≤AC） | 30所 | ✅ 完全可选——和AC类一样公平 |
| 小分差（1-5分） | 28所 | ✅ 可选——多考几分就行 |
| 中分差（6-15分） | 19所 | ⚠️ 谨慎——D类要多考6-15分 |
| 大分差（16分以上） | 18所 | 🔴 不建议——D类门槛远高于AC类 |

**D类实际友好的学校约58所**（零/负分差+小分差），只有AC类的60%。而且这58所在各分数段的分布不均衡——低分段友好校更少。

### 差异2：分数线波动更大

D类招生名额少（大多数学校D类仅100-250人），导致大小年效应更明显。一所学校D类名额只有50-100人——多几个高分考生报，分数线就涨。这意味著：

- **不能只看一年分数线**——要看三年趋势
- **保和底的余量要更大**——不能像AC类那样"保-20分就够了"

### 差异3：指标生红利相对较小

D类指标生名额远少于AC类（约1:7到1:10的比例）。而且D类指标生控制线也是按该校D类正取线计算——不是AC类的控制线。所以D类的"降20分"空间在绝对值上可能不如AC类。

> **但**：正因为D类名额少、竞争激烈，**指标生对D类的意义甚至更大**——它是少数能绕过AC/D分差壁垒的通道。

## 二、D类第一步：先把"无效学校"筛掉

在套用任何梯度公式之前，D类家长需要先做一步AC类不需要做的事——**把D类分差太大的学校从候选清单中剔除。**

### 筛选原则

| D类预估分 | 筛选标准 | 剩余可选学校（约） |
|:---:|------|:---:|
| 580+ | 关注零/负分差学校即可 | ~20所 |
| 550-580 | 零/负分差 + 小分差（≤5分） | ~40所 |
| 500-550 | 零/负分差 + 小分差 + 少量中分差 | ~50所 |
| 500以下 | 所有分差都可考虑（此时"有学上">分差大小） | ~70所 |

**筛选逻辑**：预估分560的D类考生，不要看D类线575以上的学校（差距>15分=冲不到），也不要看AC/D分差>20的学校（即使AC线够低，D线也比你预估分高太多）。

|:---:|------|------|------|------|
| 585+ | 深中/深实验/深外/深高级[587-592] | 红岭/宝中/育才/深大附中[582-584] | 科高/翠园/南科大附中[576-579] | 龙华高级/人大附深[573-574] |

## 三、D类专属梯度公式

### 🔵 D类A段（预估585分以上）：头部D类的"窄门"

**核心特征**：D类头部可选学校约20所——四大+八大+部分区属龙头。但四大D类名额合计仅512人（深中182+深实验55+深外97+深高级178），竞争极度激烈。

**分配公式**：冲2 / 稳5~6 / 保3~4 / 底1~2

| 梯度 | 数量 | 策略要点 |
|------|:---:|------|
| 冲 | 2个 | 深中/深实验/深外/深高级中选2所 |
| 稳 | 5-6个 | 红岭[584]+宝中[581]+育才[583]+深大附中[582]+科高[579]+翠园[578] |
| 保 | 3-4个 | 龙华高级[572]+南科大附中[576]+人大附深[574] |
| 底 | 1-2个 | 新安中学[570]+深高东[565] |

**D类A段特别注意**：深实验D类仅55人——580+的D类考生报深实验要谨慎，名额太少。

---

### 🟢 D类B+段（预估550-580分）：D类的主力区间

**核心特征**：这是D类考生最大的群体。可选学校约40所，选择面尚可——但需要在"冲一所分差小的好学校"和"稳一所分差大但D类容量大的学校"之间权衡。

**分配公式**：冲2 / 稳4~5 / 保4~5 / 底2

**D类B+段特别注意**：
- **"负分差"学校优先放在稳梯度**——深高东[565/-2分]、盐田高级[559/-2分]、华侨城高级[558/-3分]、深外弘知[542/-3分]、三高[540/-4分]。这些学校D类比AC类还低——D类反而有优势。
- **跨区全寄宿学校可以是"稳"的主力**——深高东（坪山）、盐田高级（盐田）、深外弘知（光明）都是全寄宿，地理位置不影响，D类友好度高。

---

### 🟡 D类B段（预估500-550分）：边缘考生的D类困局

**核心特征**：这个区间的D类可选学校开始急剧减少。500分以下的公办普高中，D类分差普遍>15分——意味着D类500分等效于AC类485分的择校空间。

**分配公式**：冲1~2 / 稳3~4 / 保4~5 / 底3~4

**D类B段特别注意**：
- **"底"数量要多于AC类**——因为D类在低分段的学校选择更少，底不够深很容易滑档
- **民办高中在这个分数段对D类的价值比AC类更大**——P3-4有完整的民办筛选指南
- **中职3+4中本贯通放在第13-16志愿**——不是"退路"，是"拿全日制本科的另一条路"

---

### 🟠 D类C段（预估500分以下）：有学上是第一优先级

**分配公式**：冲1 / 稳2 / 保3~4 / 底5~6

这个分数段的D类考生：**民办+中职双轨并行**。第一批填满普高（含民办）+中职试点，第二批18个中职专业志愿全填满。

C段的详细策略见 P3-5（中职技工学校）和 P3-4（民办高中筛选指南）。

## 四、D类指标生：填哪所？

D类指标生的核心问题是——**名额太少（大多数学校D类指标生只有10-30个），但控制线比AC类更低（因为D类正取线可能更高或更低）。**

| D类预估分 | 指标生策略 |
|:---:|------|
| 580+ | 填四大中的一所——指标生控制线约560-570，你远超，校内竞争基本稳赢 |
| 550-580 | 填一所"冲"的学校——降20分后刚好在"稳"区间。**注意选D类指标生名额多的学校**（深高东、盐田高级、深二外、南头中学） |
| 500-550 | 填一所D类友好校（负分差/零分差）——利用指标生降分+低分差双重红利 |
| <500 | 填一所民办或中职——确保"有学上"比"上好学"更重要 |

> D类指标生名额在《报考指导手册》中有完整列表。HSEE小程序→学校档案→每校的"名额分配"标签可以看到D类名额分配详情。

## 五、D类 vs AC类：梯度策略差异总结

| 维度 | AC类 | D类 |
|------|------|------|
| 可选学校 | 95所公办全可选 | 实际友好约58所 |
| 冲的数量 | 2-3个 | 1-2个（可冲更少） |
| 保/底的数量 | 相对少 | **更多**——分数波动大 |
| 指标生价值 | 红利大 | 名额少但价值更大 |
| 民办的角色 | 备选 | **刚需**（低分段） |
| 中职的角色 | 少数情况 | 重要备选路径 |
| 走读调剂 | 按通勤判断 | 更谨慎——D类通勤通常更不便（租住不确定） |

## 六、D类家长的"最后一道检查"

填完16个志愿后，D类家长需要多做一道检查：

| 检查项 | 通过标准 |
|------|------|
| ✅ 每所学校的"D类住宿线"都确认过 | 不是AC线，不是"估计差不多" |
| ✅ 每个梯度都至少有一所D类友好校（分差≤5） | 确保有"公平"的选择 |
| ✅ 底梯度至少有一所D类招生>200人的学校 | 容量大的学校大小年波动小 |
| ✅ 中职试点4个志愿没有空着（如果预估分<530） | 第一批就要留好中职的备选 |
| ✅ 没有把所有希望寄托在一两所学校 | D类曲线救国——多条路更安全 |

---

D类家长的志愿填报，比AC类多了一层"分差筛选"的复杂度——但反过来，正因为知道的人少，**用好分差数据的D类家长反而有信息差优势。**
