# 公众号内容生产提示词模板（精简版 · 极简版 · 长图 · 插图）

## 文档概述

公众号内容生产四件套，覆盖同一篇终稿的四种形态，各司其职：

| 产物 | 用途 | 阅读时长 | 首发跑通 |
|---|---|---|---|
| **精简版** | 全文压缩、结论前置，**数据全保留** | 3-4 分钟 | S1-1/2/3/4 |
| **极简版** | 只留核心数据+观点+对号入座，带三件套 | 1-2 分钟 | S1-3 首发，S1-1/2/4 |
| **长图** | 单张连续渐变公众号图，极简版配套 | 视觉扫读 | S1-3 首发 |
| **插图** | 封面+章节条+数据卡，精简版配套 | 文中配图 | S1-4 共11张 |

核心受众逻辑：最大量受众 = 焦虑求助型 + 临界求生型（约 60%），偏好**短、数字密集、结论前置**；缺"承前启后 + 兴趣钩子 + 系列钩子"会导致读完即走、不留存、不追合集——这是 2026-08-21 用户明确要求补齐的三件套。

---

## 〇、生产链路总览

```
终稿.md
 ├─ ① 精简版  → ② 极简版  → ③ 长图（极简版配套）
 └─ ─ ─ ─ ─ ─→ ④ 插图（精简版配套：封面+章节条+数据卡）
```

- **①② 与 ④ 可同批**：先出精简版，据此定封面标题/数据卡；插图按精简版正文结构拆分。
- **③ 长图**与极简版同源：极简版定稿后生成，视觉风格与插图同系列同款配色。
- 每个产物生成前先提方案给用户审批；**原终稿绝不动**，全部为同编号新文件。

article: 正确编号（终稿若有旧编号错误需纠正）

- 生成后必须跑"越界 + 重叠 + 渐变单调"三检，合格样本：
  - `OVERFLOW: PASS`、`OVERLAP: PASS`、`GRADIENT MONOTONE: PASS`
