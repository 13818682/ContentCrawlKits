# 小洁查志愿 · 系列策划书

| 项 | 值 |
|---|---|
| **系列全称** | **小洁查志愿：深莞广佛四城中考志愿填报手记** |
| 定名 | 2026-10-02（经营者） |
| 主名 / 副题 | 主名 `小洁查志愿`（每篇顶部固定标识）；副题只在系列介绍与首次出现时用 |
| 结构 | 主名短、能口口相传；副题承载覆盖面（深莞广佛四城）与形式（手记） |
| ⚠️ 注意 | ① 副题里"志愿"出现两次——**有意保留**，因"中考志愿填报"是完整标准词<br>② "深莞广佛"+"四城"双重锁定城市名单，**加第五城时两处都要改**<br>③ **它是内容名，不是产品名**——以后命名付费服务时须避开 |

> **为什么要有这个系列**：四城产品线正在同步推进（深圳/东莞原型就绪、广州调试中、佛山约一周后开工、10 月底四城齐备），
> 而家长对"凭什么是你"的信任门槛极高。**把正在发生的过程公开留痕**，是成本最低、也最难被抄走的信任建设方式。
> 本系列不是增长手段——是**信任资产与转化入口**。

## 二、受众

**四城初三学生家长**（深圳 / 东莞 / 广州 / 佛山），并兼顾**初二家长**（提前一年关注，决策窗口更长）。

**"为什么是这四座城市"——系列必须自答，不能留给读者猜。**
标准答案（经营者 2026-10-02 定）：**"我们服务过的家长朋友，主要来自这四座城市。"**
→ 既解释了范围（不是我划的版图，读者本来就是他们），又顺带立住资历。**第 2 篇负责说这句。**

- 他们**不关心产品怎么做**，只关心两件事：**这个工具准不准**、**做它的人靠不靠得住**。
- 所以每篇都必须落回"**对家长意味着什么**"——这条是硬闸口，写不出这一段的选题直接砍掉。
- 跨城阅读的天然理由：四城家长会互相比较（尤其东莞/佛山家长关心广州、深圳的做法）。

### 2.1 家长心态依据（调研，2026-10-02 补）

**来源**：`1.HSEE-Prj/docs/1.市场与用户研究/` 之 `2A 用户画像` · `2 需求分析报告` · `3 广东省用户洞察`。

**① 他们怕的不是"考不上"，是"因为我的判断失误，孩子三年都不开心"。**
更深一层是"作为父母失职"的恐惧（移民家庭尤重）。→ 文案可以点到这一层，**但绝不能拿来施压**（红线 2 禁制造焦虑）。

**② 🔴 焦虑只驱动"搜索"，驱动付费的是"解脱"。**
本系列最重要的一条：**共鸣能带来阅读，带不来行动。** ⑤ 参与位与整季的承诺必须落到"**有人把这件事扛起来**"的解脱感——不是"我懂你很难"。

**③ 家长原话（第 ① 段"被说中"直接用，不要改写）**
- "每天晚上 7 点到 8 点，在下班回家的路上，我都会塞着耳机听中考升学的直播，听了至少十多二十场。"
- "查了两周攻略，越看越不敢填。"
- "深夜 11 点还在家长群问'XX 和 YY 到底哪个好'。"
- "看了两周越看越乱。如果有人能一次性帮我都理清楚，花几千块我愿意。"
- "老师讲解速度快，很多概念听不懂。"

**第 1 篇开场白直接用上面的场景**，不要自己另编。

**④ 决策者是谁**：**母亲为主（约 70%）**，父亲参与最终确认；窗口集中在填报月（深圳约 10 天）。→ 场景与语气按"**下班路上 / 深夜 / 家长群**"来写。

**⑤ ⚠️ 一处必须诚实对待的缺口**
经营者提出的"**我也想参与到这个里面**"——**三份调研里没有这条需求**。文件里只有**相邻行为**：有家长自发写小程序统计同年级志愿意见（报告自评"显然不可持续"）、深夜在群里提问、把"方案截图发到群里被夸专业"当爽点。
**可以用，但只能作为我们的判断与引申，不能对外声称是调研结论。** 若第 ⑤ 参与位不奏效，此条是第一嫌疑人。

**⑥ 与内容主线的分工**：调研建议的获客主线是**风控语言**（避坑 / 保底 / 滑档预警），**不是**名校冲刺的机会语言。
本系列属**信任层**，不承担获客干货职能——但**不得漂移成"机会语言"**（例如把"冲名校"写成卖点）。

**⑦ 调研与红线的交叉印证**：广东报告给的获客红线是"**禁预测分数线、禁保证录取、禁制造焦虑**"，与本系列 §六 红线 2 一致。

## 三、人设（核心资产）

**人设是这条系列的第一资产**——读者记住的是人，不是栏目名。

### 3.1 设计原则

**代入感不来自"我很懂"，来自"我曾在同一个位置困惑过"。**

| 要 | 不要 |
|---|---|
| 教育行业从业者，**做了 N 年**（N 必须是真实值） | ❌ 自称"专家""老师""资深规划师"（合规红线，已入 04 合规清单） |
| 站在家长一侧，反信息不对称 | ❌ 站在机构一侧说话 |
| 承认自己踩过坑、查错过 | ❌ 摆权威、只说结论 |
| 一个稳定的自称（真名或笔名，待定） | ❌ 一会儿"我"一会儿"本公司" |

### 3.2 人设骨架（待填实）

| 字段 | 值 | 状态 |
|---|---|---|
| 对外自称 | **"小洁"（笔名）** | ✅ 2026-10-02 已定 |
| 身份描述 | **教育机构工作者，近 10 年从业经验** | ✅ 2026-10-02 已定 |
| 起点故事 | **自己和朋友的孩子中考时都遇到过困扰，身边的家长朋友也有类似苦恼；这个念头一直在脑海里盘旋——中考信息量太大，没有足够的知识背景和经验，很难较好地处理** | ✅ 2026-10-02 已定 |
| 立场声明 | 站在家长这一侧 | ✅ 已定 |
| 语气习惯 | 先困惑、再查证、后结论 | ✅ 已定 |
| 禁用语 | "专家/老师/权威/保证/一定" | ✅ 已入红线 |

**起点故事的使用要点**：它是整个系列的**情绪锚点**，第 3 篇必须用它当主线——但要用**第一人称的"我当时也不知道"**，不是"我作为从业者的洞察"。
从业身份是背景板，"我也曾手足无措"才是钩子。

**署名用法**：**正文一律第一人称"我"**；"小洁"只在**每篇文末署名**与**第 1 篇开头自我介绍一次**出现。
❌ 不要写"小洁觉得……"这种第三人称自称——会把读者推远。

**🔴 笔名补偿（2026-10-02 定：对外自称 `小洁`，为笔名）**
笔名意味着"近 10 年从业经验"**没有可核实的姓名锚点**。补偿办法：

- **用具体细节代替身份**——文末固定一段作者简介，写**做过的具体事**，而不是只写一句年限。
- 🔴 **禁止为了补可信度而编造资历**——撞 §三 真实性硬约束，代价是整个系列的信任资产归零。

**简介落点（经营者 2026-10-02 定调）**：写**过程之苦**（耗时、费力、煎熬），**不写结果之险**。

> ✅ 方向："小洁，做教育快十年。这些年为了把一件事说明白，光查资料就要花掉大量时间和精力，耗时费力，备受煎熬。"

**🚫 表述禁令（2026-10-02 新增）**：**不用"差点填错 / 险些出错 / 差一点就……"这类自我贬低式说法。**
两条理由：① 它暗示做事靠运气，**当场拆掉专业人设**；② 它把"填错"渲染成恐怖事件，**撞红线 2（禁制造焦虑）**。

> 🔴 **真实性硬约束**：身份与经历**必须是真实发生的**（本仓有过教训——`05-附录C` 因两句不实写法被迫升版重写，2026-09-28）。
> 经营者 2026-10-02 已据实给出"教育机构工作者，近 10 年从业经验"，**该项已满足**；**对外自称（真名/笔名）仍空**，定稿前必须填实。

## 四、内容结构（四层 · 其中「方法论」是承重墙）

| 层 | 内容 | 作用 | 原料来源 |
|---|---|---|---|
| **A 主线 · 诞生记** | 四城推进的真实过程：疑难 → 查证 → 结论 → 对家长的意义 | 信任、连载势能 | 产品仓 `1.HSEE-Prj` 进度（**须逐篇核实**） |
| **B 起源 · 为什么做** | 家长困扰、竞争压力、朋友提议、我们如何规划 | 代入感、开场 | 经营者口述 + 家长调研 |
| **C 通用层 · 干货** | 冲稳保梯度、指标生、志愿填报的坑（不锁城市） | 有用、可被搜到 | 本仓 P1~P4 已有资产（**复用，不新增调研**） |
| **D 方法论 · 我是怎么查的** | 找官方数据 → PDF 处理 → 整理 → 发现矛盾 → 回源核对 | **专业与可信的承重墙** | 真实工作记录 |

**第一季以 B 开场 → A 承接 → D 贯穿 → C 收尾**（见 `01-第一季选题与排期表.md`）。

### 4.1 为什么 D 层是承重墙

调研给出了家长最深的恐惧之一——**怕被背叛**："付费后拿到旧数据、套模板方案，愤怒点是'**你辜负了把孩子的未来托付给你的信任**'"。

而"**展示我怎么查数据**"是对这个恐惧最直接的回答。D 层不是附属内容，是**信任的证据链**。

### 4.2 固定栏目「我是怎么查的」（2026-10-04 修订：**位置固定，栏名自拟**）

**每篇第 ② 段固定位置、固定功能**——写"我实际做了什么动作、做了什么判断"，把"专业"重复强化到读者记住。

**⚠️ 2026-10-04 修订（经营者改第 07 篇时定）**：**不再强制统一定名「我是怎么查的」**，栏名可按本篇内容自拟。

**理由**：定名统一固然有识别度，但八篇都叫同一个名字，读到后面会**像模板**；且不同篇目的 ② 段本来做的事就不一样（有的在查文件、有的在排除法找答案）。

**已用栏名（2026-10-04 盘查）**：

| 篇 | ② 段栏名 |
|:--:|---|
| 01 | 这位妈妈是怎么查的 |
| 02 | （② 段并入"家长最常卡住的五处"主体，未单列） |
| 03 | 这些年，我们攒下了一套自己的资料 |
| 04 | 先做前期规划，再动手准备资料 |
| 05 | （② 段未单列，直接以"第一件事，是总分就不一样"进入证据） |
| 06 | 我是怎么查的 |
| 07 | 我为什么说"不早" |
| 08 | （收官篇②为"这八篇，其实只讲了四件事"，属回顾，不适用本栏目） |

**栏名可以变，写法和功能不许变**——下面这张表仍是硬约束：

| 要 | 不要 |
|---|---|
| 写**动作与判断**："官方发布的是 PDF，表格跨页断了，拼起来后第三行数字对不上" | 写工具与代码："我用 Python 解析了 PDF" |
| 写**来源与出处**："这份文件第 7 页" | 写内部表名 / 视图 / 字段 |
| 写**发现矛盾 → 追问 → 确认**的完整回合 | 只给结论不给过程 |
| 写"**我们把不确定的地方标出来了**" | 写"我们的数据绝对准确"（**无法兑现的承诺**） |

**唯一判据**：读者读完应觉得"**这个人不会糊弄我**"，而不是"这个人技术真强"。**技术炫技 = 跑偏。**

### 4.3 主角城市制（经营者 2026-10-02 定 · 适用全季）

**问题**：**系列是跨城的，读者是单城的。** 读者点进来是"我是深圳家长"，不是"我是四城家长"——
一篇里四分之三的内容，对任何一位读者都是"别人的事"。

**经营者判断（2026-10-02）**：
- 横向对比对家长的**决策**没有使用价值——各城独立制定、独立录取，**"广州复杂"对"深圳报考"零影响**；
- 它只会**稀释单城读者的注意力**。

**决策：乙方案——每篇设一个"主角城市"，主角讲厚，其余三城各一句带过。**

| | |
|---|---|
| 主角轮换 | 跟**数据成熟度**走：**深圳 → 东莞 → 广州 → 佛山** |
| 其余三城 | **最多一句**，且只用于佐证"同一个词在不同城市指不同东西"，**不得展开其规则** |
| 每篇必给 | 非主角城市读者**一个锚**（"你们那座，我会一座一座写过来"） |
| 后续 | 再为各城出专题（经营者 2026-10-02） |

**保留跨城对比的唯一理由**：它是"**证明规则乱**"的论据——只讲一座城市，家长会以为"是我不懂"；
摆出同一个词在别的城市指别的意思，家长才能确信"**这行本身就乱**"。**论据可以留，知识不必给。**

## 五、每篇骨架（防止写成流水账）

经营者 2026-10-02 定下的**三层共鸣目标**，直接映射成骨架：

| 共鸣层 | 对应段 | 要让读者产生的感觉 |
|:--:|:--:|---|
| **我也有这样的困扰** | ① 共鸣开场 | 被说中了 |
| **我希望有人能解决** | ③④ 做法与结论 | 有人在认真处理这件事 |
| **我也可以说上话** | ⑤ 收尾的最后一句 | 他听我的，但他说了算 |

```
【前情行】标题下、正文上——全季同一段，只换篇次（见 §5.2）

① 共鸣开场——一个具体家长场景，**开场不推销产品**（2026-10-05 改；原为"不出现产品"）
② 我是怎么查的——固定栏目：官方源 → 处理 → 核对，写动作不写工具（见 §4.2）
③ 发现了什么——含踩坑（信任爆点在这里）
④ 对家长意味着什么——必须落回家长；**产品锚点**落在此处（见 §5.3）
⑤ 收尾——**以我为主**（细则见 §5.1）：由"我"给出判断／计划／方法；**形状随篇**（未决事项型／推进预告型／方法交付型），**不求人、不交专业判断**
```

**④ 是硬闸口**：写不出"对家长意味着什么"，选题即砍。
**① 是第二闸口**：开场若不能让人"被说中"，后面全白写——共鸣素材取自 **§2.1 家长心态依据**，不靠自己揣测。

### 5.1 ⑤ 段铁律：以我为主，形态随篇（经营者 2026-10-03 定 · 同日修订）

**病**：第 01–04 篇初稿**全以"想请你帮个忙／想先听听你的想法"收尾**——套路化，且**把主导权让给了读者**，与"近 10 年从业者"的人设相悖。

**药**：收尾必须**以我为主**——由"我"给出判断、计划或方法，而不是把选择权交出去。

**硬约束（全季通吃，不许破）**

| # | 约束 |

### 5.4 人设分界（经营者 2026-10-05 定）

**病**：第 05 篇曾被点"**你是一个专家，为什么有这么多没想清楚**"。
**根因**：那篇的"没想清楚"落在**业务侧**（跨年份数据怎么标）——那是专家该有答案的地方。

**药——一条分界线**：

| ❌ 业务上不许含糊 | ✅ 只有这一块可以"还没定" |
|---|---|
| 政策、数据、规则、资料、换算、判断 | **面向家长的诉求取舍**——要什么、先给什么、怎么表达 |

> **人设内核是专家**（经营者 2026-10-05 明确的**不可变项**）；**对外仍不出现"专家"二字**——那是形式，与内核不冲突。

**同一原则的对外版：与"共建"的分界**
经营者要求灵活运用"**与用户互动共建**"（营销学对应 co-creation）。其**硬前提是读者真的能影响结果**，否则是 participation theater——被识破一次，反噬比不做更重。

| 交出去 ✅ | 不交 ❌ |
|---|---|
| **内容选题**——下一篇写哪座城、写哪个卡点 | **专业判断**——这个分能报哪、先做哪座城市 |
| **素材供给**——你孩子的情况、你卡在哪 | **结论与排序**——录取怎么排、功能做不做 |

**一句话：读者提供输入，我保留决定权。**

⚠️ **且"共建"必须是真的**——不许让读者以为是自己定下了一件**早已定好**的事。
**已发生的反例（禁止重演）**：产品名 `HSEE择校助手` 于 **2026-09-21 改定、09-23 随 ICP 备案生效**。**不可写成"征集了读者意见之后才确定"**；**可写**的是真实的取舍过程（想过哪些方向、各自卡在哪、为什么落这一个）。

**已落地的三处改造（全季实例，2026-10-05）**

| 篇 | 原写法（**业务侧**未决） | 现写法（**判断**） |
|:--:|---|---|
| **第 05 篇** | "清楚一点，还是省事一点，这条线划在哪儿，我还没想清楚" | "深圳那边是往上加，好歹算得出来。东莞这个算不出来——**一年的线归一年，分开标**" |

| **第 04 篇** | "怎么保证推荐结果既科学，又透明？……那和'拍脑袋'有什么区别？" | "**把历史数据列出来，让家长自己看得见**。孩子的成绩会有波动，所以**给正式推荐的同时，再列几所学校作参考**——不是只扔一个结论，是把依据和备选一起摆出来" |

> 后两条的**答案由经营者给出**（2026-10-05），不是本仓自拟——业务口径一律不自己编。

**仍允许保留的"还没定"（经核，全部是诉求取舍，不是业务判断）**：第 01 篇「查到什么程度算够」「家长看不看得懂」；第 02 篇「自己要看得懂，还是直接给答案」；第 03 篇「信任能不能搬进一套流程」；第 04 篇「官方数据怎么变成家长能看懂的判断」「不同情况的家长怎么都能用得上」。
