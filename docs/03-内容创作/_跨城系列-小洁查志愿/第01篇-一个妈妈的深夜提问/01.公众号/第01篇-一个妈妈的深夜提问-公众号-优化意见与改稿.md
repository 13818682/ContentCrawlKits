## 一、修改意见

### 1. 总体判断

原稿底子很好：深夜家长群的场景开头符合故事纪实“关键动作开头”标准；“同一所学校四个分数线”是全文最有说服力的细节；核心判断“家长不该先变成内行，该有人先替他们查清楚”成立且有传播力；文末保留了事实边界（来源声明）。

核心结构问题：**妈妈的故事线写到中途断掉，「我」没有立起来，产品预告转折突兀，结尾没收束**——缺的是把「妈妈的故事 → 我的判断 → 我为什么能做这件事 → 产品预告」串成一条信任链。

### 2. P0 · 必改（不改文章立不住）

**P0-1 「我」没有立起来，信任链断裂**
- 问题：全文只有一句“我是小洁，做教育快十年了”。而核心主张恰恰是“家长不用先变内行，有人替他们查清楚”，读者不知道这个“有人”凭什么可信。
- 建议：把原稿结尾简介里“光查资料就要花掉大量时间和精力。耗时，费力，也煎熬”这段亲身经历搬进正文（放入“家长要的，不是先变成内行”一节），写“我”自己踩过的坑——同一份数据多说法、翻原文、对口径、标年份。信任靠具体经历，不靠头衔。
  > ⚠️【2026-10-06 对照《00-创作规范》修订】原建议“把‘耗时，费力，也煎熬’搬进正文”与规范 §2 硬规矩 1「专业者不得自贬」冲突（耗时只能挂家长）。正文已改为“我快、家长慢”的对比写法，并在经历处标注【新增内容 · 请核实与事实相符】。

**P0-2 产品预告转折突兀**
- 问题：从“该有人先替他们把这件事查清楚”直接跳到“有一件事我已经定下来了：今年第四季度，设计一个…小程序”，理念到决策之间缺一环。
- 建议：补上“这个念头从哪来（就来自那位妈妈）、我拿什么来做（十年积累 + 她摊开的那堆资料）、我先想清楚了什么（数据保真、方案可读）”，让产品预告成为论证的自然落点；原“下一步”一节的功能设想合并进本节。

**P0-3 妈妈的线断了，结尾没收**
- 问题：开头是妈妈，第三节之后她再没出现过；结尾变成“产品预告 + 互动征集”，与故事型开头不匹配。
- 建议：结尾场景回扣——“那位妈妈的提问，我还欠她一个正式的回答”，顺势引出“深莞广佛四城答案从来不是一个”，再落到下一篇预告与互动引导。
  > ⚠️【2026-10-06 对照《00-创作规范》修订】① 结尾互动句已按 §3.3「邀约降到最后一句＋相邻收尾不重复」调整：第 01 篇以 B 型预告收尾（预告为末句），互动征集删除（系列互动由第 02/06 篇承接）；② 下一篇预告已修正为指向第 02 篇（原“四城差在哪”与第 02 篇内容不符）。

### 3. P1 · 强烈建议改

**P1-4 数据呈现方式**
- “529/515/506/471”一行一句，手机上阅读太碎；建议做成“同一所学校、四个分数”的对比表格（改稿已落地）。
- “150 所普高 + 30 所中职”从信息陈列转成处境：“150 所学校摆在面前，光筛出'哪些值得看'这一步，就足够一个外行走丢。”

**P1-5 术语门槛**
- “名额分配”“末位同分比较”“第一批次”首次出现时无一句人话解释；建议首次出现加括注（改稿已落地），让家长“感知难度但不会被吓退”。

**P1-6 标题人物缺位**
- 现标题痛点成立但缺人物与冲突，备选方向（正文沿用原标题，供经营者终审选）：
  1. 人物+悬念：深夜十一点，群里那个提问的妈妈，两周后还是没答案
  2. 冲突+数据：同一所学校，四个录取分数线：中考志愿到底该信谁
  3. 处境+变化：查了两周志愿攻略，她攒下几十页表格，却越来越不敢填
  4. 判断式：没有经验的家长，不该先花两周学会查中考志愿

**P1-7 系列感没埋**
- 系列叫“深莞广佛四城”，第 1 篇只有深圳；改稿结尾补“四城答案从来不是一个——每一城的批次、名额分配、录取口径都不一样”，立住系列格局，并把“接下来我会一段一段往下写”提为显眼追更钩子。

### 4. P2 · 打磨项

- **小标题**：“查到了，也不敢信”和“家长要的，不是先变成内行”保留；第一个“这位妈妈是怎么查的”改为“两周时间，她攒下了什么”（有信息量）。
- **重复与衔接**：“查了两周攻略，越看心里越没底”在标题、正文引用处各保留一次即可；删除“初三家长会卡在哪，我见得多”（并入“作为从业者”一句）；“对于家长…压力就非常大了”改写为“可换作一个普通家长…完全是另一回事”（压力具体化：白天上班、晚上听直播、深夜查资料）。
- **配图方案**：
  - 头图：深夜书桌场景示意（台灯、手机、摊开的攻略；屏幕内容模糊不可读，不呈现聊天记录界面）；
  - 文中图表 1：四个分数线对比表（改稿已表格化，发布时建议转卡片式图文）；
  - 文中图表 2：“四份文件”示意图（录取线表 / 招生计划表 / 名额分配表 / 考生手册）；
  - 文中图表 3（可选）：“150 所学校”数量感配图。
- **事实边界与发布前清理**：
  - “XX 中学和 YY 中学”拟名与后文真名案例混用，文末统一加“部分校名与家长昵称已做匿名处理”（改稿已加）；
  - “至少十多二十场”数字含糊，改为“前前后后听了十几场”；
  - 发布前删除原稿文件头部 YAML 内部信息（version / status / doc_id / 来源“经营者手改稿”等）；
  - “晚上十一点多”“一百多号人”“只有两个人回”等细节，请经营者与事实核对后再定稿（拟名可以，虚构不行）；
  - 改稿 P0-1 新增的“我查资料踩坑”经历描述，是基于原稿简介的合理展开，请经营者确认与事实相符；正文已按 §6.2 标注【新增内容 · 请核实与事实相符】。

### 5. 修改顺序建议

1. 先按 P0 把「我立起来 → 转折补一环 → 结尾回扣妈妈」连在一起改（它们是一条链）；
2. 再处理数据呈现（表格化）与标题选型；
3. 最后打磨语言、配图与元信息清理。
