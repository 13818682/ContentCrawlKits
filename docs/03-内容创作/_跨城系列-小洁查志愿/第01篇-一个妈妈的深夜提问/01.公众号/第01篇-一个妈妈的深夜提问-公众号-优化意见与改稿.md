## 一、修改意见

### 1. 总体判断

原稿底子很好：深夜家长群的场景开头符合故事纪实"关键动作开头"标准；"同一所学校四个分数线"是全文最有说服力的细节；核心判断"家长不该先变成内行，该有人先替他们查清楚"成立且有传播力；文末保留了事实边界（来源声明）。

核心结构问题：**妈妈的故事线写到中途断掉，「我」没有立起来，产品预告转折突兀，结尾没收束**——缺的是把「妈妈的故事 → 我的判断 → 我为什么能做这件事 → 产品预告」串成一条信任链。

### 2. P0 · 必改（不改文章立不住）

**P0-1 「我」没有立起来，信任链断裂**
- 问题：全文只有一句"我是小洁，做教育快十年了"。而核心主张恰恰是"家长不用先变内行，有人替他们查清楚"，读者不知道这个"有人"凭什么可信。
- 建议：把原稿结尾简介里"光查资料就要花掉大量时间和精力。耗时，费力，也煎熬"这段亲身经历搬进正文（放入"家长要的，不是先变成内行"一节），写"我"自己踩过的坑——同一份数据多说法、翻原文、对口径、标年份。信任靠具体经历，不靠头衔。

**P0-2 产品预告转折突兀**
- 问题：从"该有人先替他们把这件事查清楚"直接跳到"有一件事我已经定下来了：今年第四季度，设计一个…小程序"，理念到决策之间缺一环。
- 建议：补上"这个念头从哪来（就来自那位妈妈）、我拿什么来做（十年积累 + 她摊开的那堆资料）、我先想清楚了什么（数据保真、方案可读）"，让产品预告成为论证的自然落点；原"下一步"一节的功能设想合并进本节。

**P0-3 妈妈的线断了，结尾没收**
- 问题：开头是妈妈，第三节之后她再没出现过；结尾变成"产品预告 + 互动征集"，与故事型开头不匹配。
- 建议：结尾场景回扣——"那位妈妈的提问，我还欠她一个正式的回答"，顺势引出"深莞广佛四城答案从来不是一个"，再落到下一篇预告与互动引导。

### 3. P1 · 强烈建议改

**P1-4 数据呈现方式**
- "529/515/506/471"一行一句，手机上阅读太碎；建议做成"同一所学校、四个分数"的对比表格（改稿已落地）。
- "150 所普高 + 30 所中职"从信息陈列转成处境："150 所学校摆在面前，光筛出'哪些值得看'这一步，就足够一个外行走丢。"

**P1-5 术语门槛**
- "名额分配""末位同分比较""第一批次"首次出现时无一句人话解释；建议首次出现加括注（改稿已落地），让家长"感知难度但不会被吓退"。

**P1-6 标题人物缺位**
- 现标题痛点成立但缺人物与冲突，备选方向（正文沿用原标题，供经营者终审选）：
  1. 人物+悬念：深夜十一点，群里那个提问的妈妈，两周后还是没答案
  2. 冲突+数据：同一所学校，四个录取分数线：中考志愿到底该信谁
  3. 处境+变化：查了两周志愿攻略，她攒下几十页表格，却越来越不敢填
  4. 判断式：没有经验的家长，不该先花两周学会查中考志愿

**P1-7 系列感没埋**
- 系列叫"深莞广佛四城"，第 1 篇只有深圳；改稿结尾补"四城答案从来不是一个——每一城的批次、名额分配、录取口径都不一样"，立住系列格局，并把"接下来我会一段一段往下写"提为显眼追更钩子。

### 4. P2 · 打磨项

- **小标题**："查到了，也不敢信"和"家长要的，不是先变成内行"保留；第一个"这位妈妈是怎么查的"改为"两周时间，她攒下了什么"（有信息量）。
- **重复与衔接**："查了两周攻略，越看心里越没底"在标题、正文引用处各保留一次即可；删除"初三家长会卡在哪，我见得多"（并入"作为从业者"一句）；"对于家长…压力就非常大了"改写为"可换作一个普通家长…完全是另一回事"（压力具体化：白天上班、晚上听直播、深夜查资料）。
- **配图方案**：
  - 头图：深夜手机屏幕上的家长群消息界面（可 AI 生成或实拍示意）；
  - 文中图表 1：四个分数线对比表（改稿已表格化，发布时建议转卡片式图文）；
  - 文中图表 2："四份文件"示意图（录取线表 / 招生计划表 / 名额分配表 / 考生手册）；
  - 文中图表 3（可选）："150 所学校"数量感配图。
- **事实边界与发布前清理**：
  - "XX 中学和 YY 中学"拟名与后文真名案例混用，文末统一加"部分校名与家长昵称已做匿名处理"（改稿已加）；
  - "至少十多二十场"数字含糊，改为"前前后后听了十几场"；
  - 发布前删除原稿文件头部 YAML 内部信息（version / status / doc_id / 来源"经营者手改稿"等）；
  - "晚上十一点多""一百多号人""只有两个人回"等细节，请经营者与事实核对后再定稿（拟名可以，虚构不行）；
  - 改稿 P0-1 新增的"我查资料踩坑"经历描述，是基于原稿简介的合理展开，请经营者确认与事实相符。

# 中考志愿怎么报？查了两周攻略，越看心里越没底

*深莞广佛四城中考志愿一查就明白 · "HSEE择校助手"小程序诞生记 · 第 1 篇*

【配图建议：头图——深夜手机屏幕上的家长群消息界面】

---

晚上十一点多，家长群里弹出一条消息。

"请教一下，XX 中学和 YY 中学，中考志愿到底选哪个好？"

群里一百多号人。等了十几分钟，只有两个人回：一个说"我家也在纠结"，另一个发了个叹气的表情。

没有人答得上来。

我是小洁，做教育快十年了。这样的场面，我不是第一次见到。但前几天，一位妈妈找我聊，她说的一句话，我一直记着——

**"查了两周中考志愿攻略，越看心里越没底。"**

可听她讲完那两周，我更确定了一件事：攻略她已经攒了一堆，**缺的是一个能直接给结果、还能追溯来源的方案**。

## 两周时间，她攒下了什么

她把手机翻给我看：每天晚上七点到八点，下班回家的路上，她塞着耳机听中考升学的直播，前前后后听了十几场；深夜十一点，还在家长群里问"XX 和 YY 到底哪个好"。

手机里攒着几十页攻略，表格一张接一张，来回翻看费时费力。她说，光"录取规则"就分好几层：刚看完第一批次（深圳录取分批次进行，第一批是普通高中）的规则，翻两页又出现"名额分配"（高中把一部分学位直接分给初中学校，各校分到的名额不一样），再翻几页还有"末位同分比较"（同分时按规则依次比较单科成绩，决定谁先录取）。这些概念都很陌生，录取流程和规则细节也搞不清；网上搜出来的数字，有的没标出处，有的标了出处却对不上原文。

查了两周，越查心越乱。

我说，你把孩子的基础资料给我，我帮你分析一遍吧。作为从业者，这些政策我查过、算过、跟过录取结果，心里有数。

可换作一个普通家长，要自己弄清这些规则、还要查阅数据，完全是另一回事。就拿深圳来说，2026 年招生的普通高中就有 150 所，另有中职技工学校 30 所；志愿还分好几个批次，往前还要看前几年的数据。**150 所学校摆在面前，光筛出"哪些值得看"这一步，就足够一个外行走丢。**

## 查到了，也不敢信

有些数据**查到了也不敢信**。

同一所学校、同一年，能查出来好几个不一样的数字。你多查几个来源，反而更糊涂。

举个例子：深圳实验学校崇文高中 2026 年录取分数线，有人说是 529，有人说只要 506 就够了。

到底哪个数据是准的？真实情况是——分数线按"住宿/走读、AC 类/D 类"分成了四条，每一句都有人传错：

| 考生类型 | 录取分数线 |
| --- | --- |
| 住宿 · D 类 | 529 分 |
| 走读 · D 类 | 515 分 |
| 住宿 · AC 类 | 506 分 |
| 走读 · AC 类 | 471 分 |

【配图建议：此表发布时转为"同一所学校、四个分数"的卡片式图文】

而这些数还不在一处。去年的录取线在一份表里；每所学校招多少人，在另一份表里；名额分配分到多少，又是一份；到底怎么报、该注意什么，还在考生手册里。

【配图建议：四份文件示意图——录取线表 / 招生计划表 / 名额分配表 / 考生手册】

**要准确分析和判断，要查阅四份文件。**

这位妈妈说："看了两周越看越乱。要是有人能一次帮我都理清楚，那是真帮了大忙。"

我听完，心里很明白她的焦虑。

## 家长要的，不是先变成内行

官方文件写得全、写得准，可它不是为"一个没有经验的家长"写的。

**中考志愿填报这件事本身就复杂。**如果我不是在这个行业做了近十年，也会和家长一样心里没底。

事实上，这些年为了把一件事说明白，我自己也没少花时间：同一份数据，教育局官网是一种说法，自媒体是一种说法，学校招办又是另一种说法。只能一份份翻原文、对口径，标上年份才敢用。**耗时，费力，也煎熬。**我尚且如此，一个白天上班、晚上才有空查资料的家长，怎么可能两周内变成内行？

所以我想，家长不该先花两周去学规则、学术语、学数据口径。

**该有人先替他们把这件事查清楚，再原原本本地交到他们手里。**

## 为什么是我来做这件事

这个念头，就是那位妈妈给我的。

她来找我的那天晚上，把几十页攻略和四份文件的截图摊在我面前。那一刻我想的是：这些资料我都查过、都整理过，把它们理成一份"直接能给结果、还能追溯来源"的方案，正是我做了十年的事。

**有一件事我已经定下来了：今年第四季度，设计一个方便、专业的中考志愿填报小程序，先请一批家长进来试用。**

怎么保证数据准确？我的想法是：**只认最新的官方正式文件，不听道听途说。**不同的说法，以更新的那份为准，每一份都标上年份。

怎么让家长看得懂？给出的方案要清晰、直接，一眼看明白。

## 那位妈妈的提问，我还欠她一个回答

接下来我会一段一段往下写：它怎么来的、我打算怎么做、中间会遇到什么。

那位妈妈的提问，我还欠她一个正式的回答。因为深莞广佛四城，答案从来不是一个——每一城的批次、名额分配、录取口径都不一样，一篇写不完，所以有了这个系列。

如果你也是四城的家长，或者正在为志愿填报头疼，欢迎把你的情况说给我听。下一篇，我先写写这四城到底差在哪。
