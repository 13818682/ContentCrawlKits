# 第 01 篇 · 公众号配图规格与要求（外发制作）

> **给制作方的一句话**：本篇是**故事文，没有数据**。所以本仓惯用的"数据卡"版式**不适用**，
> 请按下面的**文字驱动版式**做——**主标题与主句就是视觉主体**，不要硬凑数字。

---

## 一、通用规格（三张图共用）

| 项 | 要求 | 说明 |
|---|---|---|
| **主色** | **深蓝系**，**禁止更换色相** | 全系列统一；强调色用金色（数据/关键词），浅蓝作辅助 |
| **套图一致性** | 同篇各图共用**同一档深浅 + 同一套光影 + 同一光线角度** | 三张图摆在一起要是"一套" |
| **字体** | 无衬线；标题加粗 | 主标题 ≥26px；正文类文字基准 13–16px |
| **卡片内文字** | 距边框四边 **≥15px**（理想 20–40px），左右对称 | 文字压边 = 废图 |
| **卡片间距** | 相邻卡片 **≥28px** | 贴在一起 = 废图 |
| **🔴 底部留白** | 页面最底部元素距下边缘 **≥20px** | 铁律；曾因胶囊贴边被否 |
| **水印/落款** | 不加水印、不加二维码 | 二维码由公众号正文承载 |
| **文件格式** | PNG，不压缩到有明显锯齿 | — |

**命名规范**（严格照此，便于归档比对）：

```
第01篇-一个妈妈的深夜提问-公众号-封面.png
第01篇-一个妈妈的深夜提问-公众号-插图01-她这两周重复发生的三件事.png
```

## 二、配图清单与逐图脚本

### 图 1 · 封面　`900 × 383`

**版式**：极简大字版——**主标题就是视觉主角**，不做数据卡。

**自上而下的元素顺序**（版式会挤，但顶部那两行是系列的脸，不能省）：

```
小洁查志愿              ← 栏目名（小字置顶）
深莞广佛 四城中考        ← 城市标识
查了两周攻略，越看越不敢填  ← 主标题（视觉主体，大字加粗）
一个妈妈的深夜提问        ← 钩子
小洁                    ← 署名
```

| 元素 | 内容 | 规格 |
|---|---|---|
| **栏目名** | **小洁查志愿** | **小字置顶**；系列识别用（2026-10-02 定名后新增）。**只写主名，不带副题** |
| 城市标识 | **深莞广佛 四城中考** | 小字，紧随栏目名之下；**跨城系列标识，不可写成"深圳"** |
| **主标题（视觉主体）** | **查了两周攻略，越看越不敢填** | 大字加粗，占画面主导 |
| 一句钩子 | 一个妈妈的深夜提问 | 中文中等字号，副位 |
| 署名 | 小洁 | 小字，右下或底部 |
| 底部留白 | — | **≥20px** |

> **注意**：主标题是**家长的原话**，要用引号感（可加引号），不要改成"如何科学填报志愿"这类标题党。

### 图 2 · 正文插图　`900 × 400`

**图题**：**她这两周，重复发生的三件事**

**版式**：三格并列卡（格 260×220，卡距 ≥20px，整组居中）

| 格 | 格子文字（上：序号/标签　下：内容） |
|:--:|---|
| 1 | **晚七点到八点**<br>下班回家的路上，塞着耳机听中考直播，听了十多二十场 |
| 2 | **深夜十一点**<br>还在家长群里问"XX 和 YY 到底哪个好"，没人答得上来 |
| 3 | **同一所学校**<br>收藏的两份攻略，数字却对不上 |

> **这三格必须来自正文，不许新增情节。** 事实源：`00-写作简报.md` §二 素材来源表。

### 长图　`900 × 自然高`

**本篇建议不出。**

理由：长图的功能是**盘数据**，本篇没有数据可盘，硬做会变成装饰性排版。
→ **长图留到第 5 篇**（四城数据到位时）。若制作方坚持要，请先与本方确认，不要自行发挥。

> 依据：`02-规范/13-1` §"极简版规则修正（2026-09-02）"——极简方向只产出**极简大字版封面 + 长图**；
> 本篇按上方"极简大字版封面"执行，长图暂缺。

## 三、四道闸口（出图后逐条自检，不通过返工）

| # | 闸口 | 检查方式 |
|:--:|---|---|
| 1 | **文字不出框** | 每块文字的四边与容器边框间距 ≥15px，肉眼可见不贴边 |
| 2 | **底部留白** | 量最底元素下边缘到下边界 ≥20px |
| 3 | **同套一致性** | 图 1 与图 2 的蓝档深浅、光影、光线角度一致 |
| 4 | **文案逐字核对** | 图上每个字与本文档"逐图脚本"**逐字一致**（错别字、漏字一律返工） |

## 四、合规注意（交给制作方一并遵守）

| 禁止 | 原因 |
|---|---|
| ❌ 写"专家 / 老师 / 名师 / 规划师" | 教育内容红线，系列禁用 |
| ❌ 写分数线、录取率等**具体数字** | 本篇未引用数据；图上出现数字会被当作承诺 |
| ❌ 写"保证""一定""包上" | 承诺红线 |
| ❌ 用"填错就完了""差一点就……"这类恐吓句 | 焦虑红线；系列明令禁用 |
| ❌ 伪造家长群聊截图 | 铁律，不得伪造 |
| ❌ 出现内部代号、内部表名、我方小程序名 | 内部信息不外露 |

**图上允许出现的数字只有一处**：插图中的"十多二十场"——这是**家长自己说的**，属原话，可用。
