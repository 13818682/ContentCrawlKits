## 一、骨架落实

| 骨架 | 落点 |
|---|---|
| ① 共鸣开场 | 「朋友问完那句话之后，我没有马上去做一个工具」——先停下，因为最容易犯的错是**做出一个"看起来很全"的东西**。所以最先做的不是"做"，是想清楚**给谁用** |
| ② **我是怎么查的** | 把四座城市的官方文件一份一份下下来、归好（招生文件／招生计划／历年录取标准，各归各的年份）。**收着才看清：这件事的份量比想的重** |
| ③ 发现了什么 | 「**"给家长做一个工具"等于什么都没说**」——三层差别：**深户／非深户能报的范围不同**（同城同分，不是同一个池子）；**分数段不同纠结不同**（冲不冲／稳不稳／有没有学上）；**初二与初三要的不一样**（**一个要地图，一个要路标**） |
| ④ 决定 | 「四座城市，四套规则，只能一座一座来」——**"什么都做"这条路被自己划掉**；没拿任何现成模板；每多看一城就多一整套要重头核的东西（**不是复制粘贴能解决的**） |
| ⑤ 参与位（**本季最重要的收集位**） | **你最希望它先帮你解决哪一件事？** ＋ 结尾「**先做哪一件，由你们决定**」＋ 给非主角城市读者留锚 |
