## 一、骨架落实

| 骨架 | 落点 |
|---|---|
| ① 共鸣开场 | 用一个**具体规则**开场：同一个问题，问四个城市的人，得到四个不一样的答案。结尾轻点范围声明（经营者 2026-10-02 定）：「**找我聊的家长，主要来自四座城市——深圳、东莞、广州、佛山。**」 |
| ② **我是怎么查的** | 把四座城市各自的官方文件摊开对照。**写动作不写工具**：同一件事在四份文件里叫什么、归在哪个批次、谁能报。⚠️ **素材待核实** |
| ③ 发现了什么 | 落点：**"四套规则"不是同一份东西的四份复制，是四套独立的东西。** 旁证：学校大课讲一遍已是极限——「**老师讲解速度快，很多概念听不懂**」（调研原话） |
| ④ 对家长意味着什么 | **本篇核心动作：树敌**（原文见 `01` §五 第 2 篇）。对手**显性化、外部化**：不是别人家的孩子，也不是你自己，是规则太绕、没人替家长把关 |
| ⑤ 参与位 | 你所在的城市，最难懂的是哪一条规则？／如果只能先讲清一条，你最想是哪条？ |
