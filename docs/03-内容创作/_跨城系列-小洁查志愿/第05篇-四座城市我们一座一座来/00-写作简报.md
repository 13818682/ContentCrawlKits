## 一、骨架落实

| 骨架 | 落点 |
|---|---|
| ① 共鸣开场 | 东莞家长的实问：「深圳的攻略我看得差不多了，**东莞是不是照着套就行**？」→ 答"不行"，且**不是细节差别，是从第一件事起就不是同一套** |
| ② **我是怎么查的** | 把四市官方文件一份一份下下来、**各归各的城市，各归各的年份**；收上来后做的第一件事是**把每座城市的"中考总分"对齐**——对齐的结果就是本篇的证据 |
| ③ 发现了什么 | 三层证据（全部回源官方文件，见 §二）：**① 四城总分不是一个数**；**② "批次"这张表不一样**；**③ 同一件事四个说法** |
| ④ 对家长意味着什么 | ① **你所在的城市现在到哪一步**（四行状态词）；② 看到一份攻略，**先确认它讲的是哪座城、哪一年** |
| ⑤ 参与位 | **跨年份的数据到底该怎么标**——深圳可以粗 +20，东莞 800→680 是降分且改科目，**没有任何系数能换算**。我的倾向：宁可一年一年分开标，也不给看似精确的换算值；**代价是家长读起来更累**。这条线划在哪儿，还没想清楚 |
