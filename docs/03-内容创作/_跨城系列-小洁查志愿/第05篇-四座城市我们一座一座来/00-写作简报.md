## 一、骨架落实

| 骨架 | 落点 |
|---|---|
| ① 共鸣开场 | 东莞家长看到我们为深圳做的工作（招生文件、历年录取标准已整理），来问：**「能不能也帮东莞家长做一份？」**＋「**这两个城市是不是差不多？**」→ 答"不一样"，且**不是细节差别，是从第一件事起就不是同一套** |
| 🆕 **前情行** | 标题下一行（全季统一装置）。中途进来的读者一眼接上"这个系列在做什么"，并**第一次看到产品名** |
| ② **我是怎么查的** | 把四市官方文件一份一份下下来、**各归各的城市，各归各的年份**；收上来后第一件事是**把每座城市的"中考总分"对齐** |
| ③ 发现了什么 | **三层证据**（全部回源官方文件，见 §二）：**① 四城总分不是一个数**；**② "批次"这张表不一样**；**③ 志愿能填几个、录取怎么排，也不一样** |
| 🆕 **产品锚点**（③ 节末） | **早年录取线不能直接比**——深圳 610→630 换了尺度，同一个 550 分不是一个位置；**家长自己查最容易栽的正是这一步**（经营者所给开发困难 1，翻译为家长处境） |
| ④ 对家长意味着什么 | ① **「你们那座城市，做到哪儿了」**——状态词用**资料侧**（"资料已经重新梳理完毕"），并**首次亮出产品名 `HSEE择校助手`**（含取名由来：起名规则卡死 → 退到英文缩写 → **与家长在规则里选学校同构**）。**亮名字，不亮进度**；② 同一分数、同一志愿顺序，在深圳是"喜好顺序"、在东莞带"分数代价"——**别看别城的攻略照着填** |
| 🆕 **人设分界首次落地**（④ 节前） | 原 v1.0 的"**清楚一点，还是省事一点，这条线划在哪儿，我还没想清楚**"（业务侧未决，曾被点"专家为什么这么多没想清楚"）→ 改为**专业判断**：「深圳那边是往上加，好歹算得出来。东莞这个算不出来——**一年的线归一年，分开标。**」 |
| ⑤ 段（**B 推进预告型**） | 工作量不小 → **好在多年积累、资料现成、方法跑熟** → 🆕 **埋内测线一句**（"等四座城市都齐了，我想先请一批家长进来试用"）→ **我会接着写：东莞之后，广州和佛山各自会遇到什么** |
