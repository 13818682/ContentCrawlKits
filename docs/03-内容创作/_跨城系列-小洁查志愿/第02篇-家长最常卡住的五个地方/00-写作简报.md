## 一、骨架落实

| 骨架 | 落点 |
|---|---|
| ① 共鸣开场 | **讲方案讲到一半，停下来问"有没有跟不上的"——几乎每次都有人点头。** 家长的理由都一样：「**不是不想搞明白，是真的没有那个时间和精力**」。落到处境：一天能腾出的功课时间，就是下班路上那四五十分钟和睡前半个钟头；**而志愿表填的时候，孩子的成绩还没出来** |
| ② **家长最常卡住的五处**（本篇主体） | ① **专有术语**：名额分配、ACD 类、控制线、自主招生、统招第一批；**且同一件事两个名字**（指标生／名额分配）<br>② **录取顺序**：自主招生批 → 名额分配批 → 统招第一批 → 统招第二批 → 统招第三批；**前一批录取了，后面的批次就不再看了**<br>③ **数据散乱**：分数线分住宿/走读、A/C/D 类；总分 610 → 630，旧线还能不能对照；各校招生数、名额分配数、民办学费——**散在好几份文件好几张表里**<br>④ **学校介绍散乱**：水平、管理、距离、住宿、往年分数，没有一份现成完整的，要拼好几个来源<br>⑤ **自媒体数据打架**：同一所学校同一年搜出好几个不一样的数字 |
| ③ 发现了什么 | 落点：**难的不是"看不懂"，是东西太多、太散。** 政策单拎一条都能听懂；难的是要在同一段时间里同时接住术语、顺序、好几年数据、几十所学校、一堆互相打架的说法——**而那段时间是挤出来的** |
| ④ 对家长意味着什么 | **本篇核心动作：定义"共同的困难和挑战"。**「这不是哪一位家长不够上心，是每一个第一次填志愿的家庭，都要一起过的关。」——**不用"对手"** |
| ⑤ 参与位 | 上面五处，哪一处最让你头疼？＋ **必给非主角城市读者一个锚**：「你们那座，我会一座一座写过来」 |
