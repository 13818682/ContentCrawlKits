## 一、骨架落实

| 骨架 | 落点 |
|---|---|
| ① 共鸣开场 | 家长递手机：同一所学校搜出三个版本的分数线，问"**到底哪个是真的？**"→ 答"**三个可能都是真的，因为它们说的不是同一件事**" |
| ② **我是怎么查的** | 看到分数先不问"对不对"，先问"**你是什么**"；三步：**出自哪一年 / 是哪条线 / 是谁说的** |
| ③ 发现了什么 | 三层：**① 一个分数至少有三种**（住宿／走读、ACD 类、正取线／名额分配控制线）；**② 年份更难**（深圳 2026 起 610→630，跨年不可比）；**③ 我们自己出过两处错**（见 §二） |
| ④ 对家长意味着什么 | **看到任何分数线，问三个问题**：哪一年的／哪条线／谁说的。并给出本篇结论：**大部分"互相打架"的分数线，其实没打架——它们只是被并排放在了一起** |
| ⑤ 参与位 | **"如果你也见过互相矛盾的中考数据，可以发给我。我来帮你核它是哪一年、哪条线、谁说的。"**（`01` §五 指定） |

## 二、⭐ 本篇的承重墙：两处**真实**的自我订正（已脱敏）
