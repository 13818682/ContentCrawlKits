## 一、骨架落实

| 骨架 | 落点 |
|---|---|
| ① 共鸣开场 | 初二家长实问：「**我们家明年才中考，是不是现在看这些还早？**」→ 答「**早。但也不早。**」——分两层：**该"研究怎么填志愿"确实早了一年；该"知道有几条路、孩子在什么位置"已经不早了** |
| ② **我是怎么查的** | 把**四市招生文件按时间排**过一遍（招生工作意见／填报志愿通知／录取工作通知），**只看它管哪一段时间**；发现**几乎所有文件时间线都压在初三下学期**；**原本以为初二有对应的东西，翻了几座城市都没找到** → 确认"初二没有官方指引"这一事实本身 |
| ③ 发现了什么 | **三件事**：**① 知道有几条路**（普高／中职／技工／中本贯通／自主招生，互不完全挡住）；**② 搞清楚分类**（深圳 A/C/D 类＋名额分配，先定"我家属于哪一类"）；**③ 记位次不记分数**（总分 610→630 会变，位次坐标更稳） |
| ④ 对家长意味着什么 | **提前一年的成本最低**：初三下所有事挤在一起，家长没时间看文件；而这三件事**几乎不占时间**——到填志愿月，你是**从一张已有的地图开始**，不是从零 |
| ⑤ 段（**A 未决事项型**） | 真问题：**"提前一年"最怕弄成"多紧张一年"**。我的判断：三件事**都是家长在自己本子上做的功课**，不该压到孩子身上；**该提前的是家长的准备，不是孩子的压力**。未决：**什么时候该让孩子知道、什么时候先不说**——说早了怕背包袱，说晚了怕他从别处听来不完整的说法 |
