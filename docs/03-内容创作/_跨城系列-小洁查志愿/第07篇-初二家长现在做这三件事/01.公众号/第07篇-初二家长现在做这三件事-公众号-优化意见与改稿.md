## 一、修改意见

### 1. 总体判断

本篇是全系列的“拉新型”文章（面向初二家长，扩大漏斗），定位精准：“早。但也不早。”回答有记忆点；“官方文件只在事情发生的那几个月告诉你怎么办”是洞察；三件事（知道几条路 / 搞清楚分类 / 记位次）具体可执行；“这不是给孩子贴标签，是给自己一个坐标”是金句；“今年该提前的，是家长的准备，不是孩子的压力”处理得体。主要问题在标题偏长、产品指代、“位次”概念首现无解释、一处表述边界。

> ⚠️【2026-10-06 对照《00-创作规范》修订】结尾原“接下来我会一块一块往下写：地图怎么画、分类怎么分、位次怎么看”预告无法兑现（第 08 篇为收官、系列无后续篇目），已改为 A 型收尾（三件事给出分步倾向）＋邀约最后，同时与第 06 篇（C 型邀约收尾）错开形状。

### 2. P0 · 必改

**P0-1 产品指代不统一**
- 问题：“我们正在做的那个东西，接的就是这个。”——“那个东西”在系列各篇叫法不一（第 02 篇“在做的那件事”、第 03 篇“这套东西”、第 05 篇“它叫 HSEE择校助手”），跳着读的读者对不上号。
- 建议：本篇首次提及即写全称“我们正在做的 HSEE 择校助手”。建议系列统一定为：每篇首次提及写全称，后续用“那个东西”承接。

### 3. P1 · 强烈建议改

**P1-2 标题偏长、口语化**
- “中考志愿：初二家长现在做这三件事，比初三再慌强”——“比初三再慌强”口语感强，且 20 字偏长。
- 备选：①“中考志愿：初二这一年，做这三件事就够了”；②“中考志愿：初二家长现在做这三件事，初三就不慌”。

**P1-3 “位次”概念首现无解释**
- 第三件“开始记'位次'”——“位次”对初二家长可能是生词。
- 建议加一句括注：“位次（孩子这次考试在年级里大致排第几、或在哪一档）”。改稿已落地。

**P1-4 一处表述边界过满**
- “我原本以为，初二该有一份对应的东西。翻了几座城市，都没找到。”——“都没找到”稍显绝对。
- 建议改为“翻了几座城市，都没有专门给初二家长的文件”（加“专门的”边界），更稳。

### 4. P2 · 打磨项

- 三件事的配图：四城路径图（普高 / 中职 / 技工院校 / 中本贯通 3+4 / 自主招生）、位次记录示意（每次大考记一笔）、“地图 → 分类 → 坐标”三件套卡片。
- 括号句“（这一年要做的事，四座城市是一样的……四座城市真正的差别，要等初三才咬人。）”——“咬人”生动，保留。
- 互动“你想先看哪一块，可以说给我听”——好，保留。
- 发布前删除文件头部 YAML 内部信息。
- 发布前复核：四城中考路径（普高/中职/技工/中本贯通/自主招生）表述与官方口径一致。

### 5. 修改顺序建议

先改 P0（产品指代统一）→ P1（标题、位次括注、边界句）→ 打磨配图与元信息。
