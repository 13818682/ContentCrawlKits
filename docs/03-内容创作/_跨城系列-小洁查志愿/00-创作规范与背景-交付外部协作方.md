# 《小洁查志愿》创作规范与背景 · 外部协作用

> **怎么用这份文件**：先读**第一、二节**（背景与硬规矩），再按需查后面的细则。
> **⚠️ 凡本文件与通用公众号写作方法论冲突，一律以本文件为准。** 通用方法论会给出"正确但违规"的建议——本文件第二节那八条，就是被踩过的坑。

---

## 一、系列背景

### 1.1 这是什么

| 项 | 内容 |
|---|---|
| **系列全称** | 小洁查志愿：深莞广佛四城中考志愿填报手记 |
| **体裁** | 连载 · **做一个产品的过程记录**（不是知识科普，也不是招生广告） |
| **第一季** | 8 篇，2026-10-08 → 2026-11-01，**每周四 + 每周日 20:30** |
| **渠道** | 微信公众号（第一季只发公众号） |
| **覆盖城市** | 深圳、东莞、广州、佛山（简称"深莞广佛"） |

### 1.2 写给谁

**深莞广佛四城的中考家长**——尤其是**第一次填志愿、没有经验**的家长。
他们不是在找"更多攻略"（攻略已经攒了一堆），是在找**"有人替我把这件事查清楚"**。

### 1.3 目标（不是涨粉）

**引流 ＋ 信任 ＋ 互动。**
判断一篇写得好不好，**不看阅读量**，看两件事：**留言互动数** 和 **小程序跳转**。

### 1.4 作者设定

笔名 **小洁**。业务设定：**教育行业近十年从业者**，整理过四城招生资料，有丰富的专业知识和经验。

> ⚠️ **该设定仅供写作时把握口吻，绝不许出现在文字里。**
> 对外**不得出现**"专家""老师""名师""规划师"等词（见 §5 红线）。

### 1.5 产品背景（写作时要用的）

正在做一个微信小程序，对外名 **HSEE择校助手**：把四座城市的中考志愿信息整理成"一查就明白"的工具。

> 名字来历（第 05 篇会写）："中考""升学""志愿"这些词政府部门在使用或已被注册，最后用了缩写 HSEE（High School Enrollment Exam）。

## 二、硬规矩（八条，不可破）

**这是本文件最要紧的一节。** 每条都是真实踩过的坑。

| # | 规矩 | 反例（**都真实发生过**） |
|:--:|---|---|
| 1 | **专业者不得自贬** | ❌「我卡了」「我查了半天没弄懂」「我花掉了一整个下午」。**要写"慢"，只能写家长慢。** |
| 2 | **产品只亮名字，不亮进度** | ❌「已经做出来了」「可以用了」。✅「正在做」「会做出来」 |
| 3 | **数据只说确定值，标官方来源** | ❌ 估算、推算、"大约""可能"。**不标来源的数字不许写。** |
| 4 | **不承诺、不制造焦虑、不称专家** | ❌「保证录取」「一定」；❌「填错就完了」「差一点就……」 |
| 5 | **⑤ 段不许停在"我还在想"** | ❌「这条线划在哪儿，我还在想」。✅ 可以摆问题，但**必须给出"我的想法是……"** |
| 6 | **相邻两篇的收尾形状不许重复** | ❌ 连着三篇都是"我没想清楚"或"我会接着写" |
| 7 | **跨篇去重**：同一组数据／同一个人物，**换角度也算重复** | ❌ 第 01 篇和第 06 篇都用"同一所学校好几个分数线"这个点 |
| 8 | **超出原文的补写，必须逐条标注"请核实"** | ❌ 不打招呼就补"真实笔记该有的例外、待核痕迹"——**那是拿真实性换手感** |

## 三、文章结构

### 3.1 五段骨架（每篇都有）

```
① 共鸣开场——一个具体家长场景，开场不推销产品
② 我是怎么查的——官方源 → 处理 → 核对，写动作不写工具
③ 发现了什么——含踩坑（信任爆点在这里）
④ 对家长意味着什么——必须落回家长
⑤ 收尾——以"我"为主（细则见 §3.3）
```

**④ 是硬闸口**：写不出"对家长意味着什么"，这个选题就该砍。
**① 是第二闸口**：开场若不能让人"被说中"，后面全白写。

### 3.2 前情行（固定一行，**逐字不动**）

标题下、正文上，**全季同一段，只有篇次变**：

```
*深莞广佛四城中考志愿一查就明白 · “HSEE择校助手”小程序诞生记 · 第 N 篇*
```

**为什么要它**：读者极少从第 01 篇开始读，极可能先读到中间某篇；这一行是唯一告诉他"这个系列在做什么"的地方。

- ✅ 一行，不换行不断句，斜体
- ❌ 不许改成粗体标题＋竖线＋冒号＋列表
- ❌ 不许每篇重写

### 3.3 ⑤ 段铁律

**硬约束（全季通吃）**

| # | 约束 |
|:--:|---|
| 1 | ❌ **不求人**——不出现「想请你帮个忙」「想先听听你的想法」 |
| 2 | ❌ **不交专业判断**——不出现"先做哪个由你们决定"这类业务判断的外包。<br>⚠️ **内容选题可以交给读者**（下一篇写哪座城），**判断与排序不行** |
| 3 | ✅ **以我为主收束**——由"我"给判断／给计划／给方法 |
| 4 | ✅ **邀约降到最后一句**——留言互动要保，但不能靠"求" |

**三种形状，按篇选，相邻不重复**

| 形状 | 适用 | 长什么样 |
|---|---|---|
| **A 未决事项型** | 方法篇、策划篇 | 摆出真问题 ＋ **给出我的倾向** |
| **B 推进预告型** | 进展篇、决心篇 | 正面收束 ＋ 接着写什么 |
| **C 方法交付型** | 干货篇 | 给一个**能带走的东西** ＋ 一句邀约 |

> ⚠️ **A 型不是通行证。** A 型是**"我判断得清楚，只是有一处还没定"**，不是**"我什么都不确定"**。
> 而按 2026-10-06 的最新方向，**即便是 A 型，也要写成"我的想法是……"，不能停在"我还在想"**。

### 3.4 开场与收尾的两个检查

- **开场**：让读者"被说中"——素材取自真实家长心态，不靠自己揣测
- **收尾**：如果开篇出现了一个具体的人或场景，**结尾要回扣**（故事线不能断在中途）

## 四、语言与体例

### 4.1 字数

**上限 ≤ 2,200 非空白字符。**

**口径**（很重要，别用错尺子）：

- **不计**：标题行、独立分隔线（`---`／`------`）、文末署名行、来源行
- **计入**：前情行
- ⚠️ **别拿"中文字符"当尺子**——与"非空白字符"差约 20%

### 4.2 体例（全系列统一）

| 项 | 规定 |
|---|---|
| 数字与汉字之间 | **加空格**：`2026 年`、`610 分`、`150 所`、`第 5 篇` |
| 引号 | **一律弯引号** `“ ”`，不用直角引号 `"` |
| 文末署名行 | **逐字固定**，不许改（**当前有一个待经营者拍板的新版本，未拍板前一律照各篇现有文字**） |
| 文末来源行 | 普通正文（不加斜体），格式：`本文涉及的……参考×××官方发布的……；具体口径请以官方最新发布为准。` |
| Markdown | **公众号后台支持 Markdown 直导，表格可正常显示**——需要"扫一眼就懂"的对比**优先用表格** |

### 4.3 语言

- 说人话，**主语先落到具体的人或事**，不要先给抽象标签
- **抽象名词**（"分析""判断""赋能""颗粒度"）能换具体动作就换
- 数据从**陈列**转成**处境**：
  > ❌「深圳有 150 所普高、30 所中职」
  > ✅「**150 所学校摆在面前，光筛出"哪些值得看"这一步，就足够一个外行走丢**」

## 五、内容红线

### 5.1 五条红线

| # | 红线 |
|:--:|---|
| 1 | ❌ 不出现**内部代号、内部表名、定价** |
| 2 | ❌ **不承诺、不制造焦虑、不称"专家"** |
| 3 | ⚠️ 可公开**公开源与处理方法**；**不公开内部加工资产与扩张时间表** |
| 4 | ✅ **数据一律标官方来源** |
| 5 | ⚠️ **产品事实须经营者的口径**——不得自行加码 |

### 5.2 三条文风禁令

**禁令一 · 专业者自贬**（见 §2 第 1 条）
> 耗时只能挂在家长身上。**专业者可以快，慢的是家长。**

**禁令二 · 「AI 风」六病灶**——**这些手法本身没问题，真人也用；病在密度：每段都来一遍，像节拍器。**

| # | 病灶 | 实例 |
|:--:|---|---|
| 1 | **自造小标题 ＋ 冒号** | 「四座城市，现在各自到哪一步：」 |
| 2 | **段段一个金句收尾** | 每小节末尾都加粗砸一句判断 |
| 3 | **"不是 A，是 B"** | 「不是因为它最好听，是因为……」<br>⚠️ **必须真的有 B**；光有"不是"不算 |
| 4 | **对仗排比** | 「想要的够不着，够得着的又觉得可惜」 |
| 5 | **破折号接解释** | 破折号后面那半句，多半可以删 |
| 6 | **主持人腔** | 「先说一句……」「先说能填几个，再说怎么录」 |

**禁令三 · 对抗性框架**
> ❌「对手」「敌人」（"我们共同的对手是……"）→ ✅「**共同的困难和挑战**」
> 对抗性框架不准确，且"树敌"写法逼近焦虑红线。

## 六、数据与事实（最容易出事的一节）

### 6.1 三条铁律

1. **不估算、不推算**——只写官方已公布的值
2. **每个数据标官方来源**——说不出出处的数，不写
3. **例子必须可核**——给"同一所学校好几个分数"这类例子时，**用真实存在的学校与真实的官方数字**，不许为了戏剧性编一个

### 6.2 补写必须标注

**这是最硬的一条。**

超出原文的补写**可以是合理展开**，但**必须逐条单独标出来**，并注明"**请核实与事实相符**"。

> **反例**：无标注地补"真实笔记该有的例外、待核痕迹"。
> **那是拿真实性换手感。查不到毛边就不补——宁可整齐。**

### 6.3 事实边界

- 拟名（"XX 中学""YY 中学"）与真名混用时，**文末须加"部分校名与家长昵称已做匿名处理"**
- 含糊的数字（"十多二十场"）→ **要么给确数，要么去掉**

## 八、配图规范

> 完整规格见 `00-系列配图规格与生成脚本.md`；此处只列**必须遵守的**。

### 8.1 视觉系统

主色**深蓝系**（底 `#0F2A4A`），强调色**金色** `#D4A843`，辅助浅蓝 `#8FB4D6`。
极简、克制、大留白；**禁花哨装饰、禁渐变滥用**；同一档深浅、同一套光影、同一光线角度。

### 8.2 画幅

| 角色 | 尺寸 |
|---|---|
| 封面（头图） | 900 × 383（2.35:1） |
| 正文插图／图表卡 | 900 × 400（2.25:1） |

### 8.3 封面统一版式（八篇共用骨架，顶部两行不能省）

```
小洁查志愿              ← 栏目名（小字置顶）
深莞广佛 四城中考        ← 城市标识（不可写"深圳"）
主标题                   ← 大字加粗，视觉主体
钩子                     ← 中文中等字号，副位（金色）
小洁                     ← 署名（小字）
```

### 8.4 配图红线

| 禁止 | 原因 |
|---|---|
| ❌「专家／老师／名师／规划师」 | 教育内容红线 |
| ❌「保证／一定／包上」 | 承诺红线 |
| ❌「填错就完了」类恐吓句 | 焦虑红线 |
| ❌ **伪造家长群聊截图、聊天记录** | 铁律 |
| ❌ 出现内部代号、内部表名、**产品名（配图不出现 HSEE择校助手）** | 内部信息不外露 |
| ⚠️ **录取分数线具体数字** | **图上出现录取线易被当作承诺**——只允许官方已公布的总分口径（如 610→630、800、810、740），且仅在数据篇图表出现 |

**AI 生图通用要求**：无衬线、克制留白、深蓝系、金色点缀、哑光；**不出现人物正脸特写**；**屏幕／文件内容一律模糊不可读**。

### 8.5 命名

```
第XX篇-<篇名>-公众号-封面.png
第XX篇-<篇名>-公众号-插图NN-<画面名>.png
第XX篇-<篇名>-公众号-图表NN-<内容名>.png
```

## 九、交付要求

### 9.1 审稿意见必须分级

| 级 | 含义 |
|:--:|---|
| **P0** | **不改文章立不住**——信任链断、事实错、违规 |
| **P1** | **强烈建议改**——类型不匹配、故事不回扣、只有数据陈列、没有钩子 |
| **P2** | **打磨**——措辞、小节信息量、元信息清理 |

**不分级的清单等于没审。**

### 9.2 不要整篇替换

**逐条筛。** 结构诊断值钱，**文字层整篇替换会碰上面那些红线**。

### 9.3 交付物

1. **审稿意见**（分级，含"为什么"）
2. **改后全文**（按规范，含前情行、署名行、来源行）
3. **修改处清单**（改了什么、依据哪一条）
4. **补写标注**（§6.2）
5. **配图**（按 §8）

### 9.4 交付前自检

- [ ] 前情行逐字正确，只换了篇次？
- [ ] 署名行、来源行**逐字未动**？
- [ ] 字数 ≤ 2,200（非空白字符，含前情行）？
- [ ] 没有专业者自贬？没有"我还在想"？
- [ ] 数据都标了来源？没有估算值？
- [ ] 补写处**全部**标注了"请核实"？
- [ ] 没有"专家／老师／名师"？没有承诺句、焦虑句？
- [ ] 配图没有伪造聊天截图？没有出现录取分数线具体数字？
