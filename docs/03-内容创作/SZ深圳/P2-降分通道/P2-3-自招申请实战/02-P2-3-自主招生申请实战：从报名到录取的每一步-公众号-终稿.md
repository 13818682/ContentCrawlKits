# 自主招生申请实战：从报名到录取的每一步

P1-6 讲了自招的游戏规则——一类看脑子、二类看才艺、中考占60%。如果你还不确定孩子适不适合报自招，先回 P1-6 用决策树判断。

这篇假设你已经决定"要报"。接下来是操作层——每一步具体怎么做。

---

## 自招全流程时间表

| 时间 | 事项 | 你该做什么 |
|------|------|------|
| **5月** | 各校发布自招简章 | 关注目标学校官网——招生人数、考核方式、报名条件都在简章里 |
| **6月10-14日** | 自招报名 | 只能选1所学校、1个类别，线上提交报名材料 |
| **中考后1-2天** | 学校综合考核 | 笔试/面试/专业测试——报了才参加 |
| **中考成绩公布后** | 综合分排名+录取 | 自招批最先录取——录了后面全作废 |

## 报名材料清单

### 一类自招（学术/科创）

| 材料 | 重要程度 | 准备建议 |
|------|:---:|------|
| 初中成绩单（尤其是数理科目） | 🔴 必需 | 找学校教务处打印盖章——数学、物理的成绩越好看越好 |
| 竞赛/科创获奖证书 | 🟡 加分项 | 区级以上数理化竞赛、信息学奥赛、科技创新大赛——有就附上，没有不硬凑 |
| 自荐信/个人陈述 | 🔴 必需 | **500-800字**，突出三个点：①为什么选这所学校 ②你在数理/科创方面的兴趣和成果 ③你未来的学习规划 |
| 教师推荐信 | 🟢 锦上添花 | 数学/物理/班主任——1封即可，不是必需但有加分 |

**自荐信怎么写？** 不要写成"我很优秀"的流水账。用一个具体的例子开头——"初二那年我参加学校的数学建模社团，第一次用函数拟合预测了食堂排队时间……"——比"我热爱数学，成绩优异"强一百倍。

### 二类自招（艺术/体育）

| 材料 | 重要程度 | 准备建议 |
|------|:---:|------|
| 获奖证书/等级证明 | 🔴 必需 | 市级以上比赛获奖或专业等级证书——这是硬通货 |
| 专业能力证明 | 🔴 必需 | 比赛成绩册/演出视频/训练记录/教练推荐信 |
| 自荐信 | 🟡 加分项 | 500字左右——突出专业训练经历和获奖情况 |
| 初中成绩单 | 🟢 参考 | 文化课成绩——自招中考占60%，成绩太差也会拉低综合分 |

> **二类特别提醒**：专业考核不是"兴趣爱好展示"。声乐=现场视唱，篮球=打全场。如果只是"学过几年"没有比赛成绩或专业训练背景——通过率很低。这是硬门槛，不是态度问题。

## 学校考核准备

### 一类考核——通常考什么？

| 考核形式 | 常见内容 | 怎么准备 |
|------|------|------|
| 笔试 | 数理思维题、逻辑推理、综合素养 | 不需要额外补课——平时理科思维好的孩子有天然优势。可以找往年该校自招真题（如有）感受题型 |
| 面试/小组讨论 | 时事热点分析、开放性问题、团队协作 | 考察的是思维深度和表达能力——不是知识储备。平时多和孩子讨论新闻，鼓励表达观点 |

**核心原则**：一类自招考的是"潜力"不是"知识"——学校想看到的是你会不会思考，不是你背了多少东西。临时抱佛脚的突击效果有限。

### 二类考核——标准是什么？

二类考核因专业不同差异极大——具体以各校简章为准。但有一个通用原则：**专业水平是硬通货。** 现场发挥决定一切，没有"印象分"。

---

## 报名策略：报哪所学校？

和指标生一样的逻辑——**自招用来冲刺，不用来保底。**

| 你的情况 | 建议 |
|------|------|
| 文化课预估分接近目标学校正取线 | ✅ 自招冲同一所——双保险（自招+正取） |
| 文化课预估分离目标学校差10-20分 | ✅ 自招冲这所——自招的降分空间让你有机会够到 |
| 文化课预估分离目标学校差>30分 | ❌ 中考占60%——差距太大，综合分拉不回来 |
| 二类：专业水平突出，文化课稍弱 | ✅ 自招是你的最佳通道——专业分拉高综合分 |

---

## 一个关键提醒：自招报名的"不可逆"操作

| 操作 | 后果 |
|------|------|
| 报了名但没去考核 | 不影响——自动进入后续批次 |
| 考核了但没录取 | 不影响——正常进指标生/第一批 |
| **录取了** | 🚨 指标生+第一批+第二批+第三批全作废——必须去！ |

> 所以回到P1-6的核心原则：**自招只用来冲更想去的学校，不报"录了也不一定想去"的学校。**
