# 非深户想让孩子以深户身份考深圳中考，最迟几年级办户口？

深圳中考的录取线背后，藏着一个多数家长没算过的差距：**非深户（D类）考生占约54%，公办普高给D类的招生名额却只有约23%**；更现实的是，越往下的普通校、新校，**D类录取线往往比AC类（深户）高13到31分**。

一句话结论先给你：**想让孩子以深户身份（AC类）参考，硬前提是初三下学期3月报名前拿到深圳户口。** 拿户口有快有慢——一方深户走子女随迁最快，父母走人才核准数月能办，而纯积分入户要"稳定住所＋社保"各满5年再抢年度名额，是提前5年以上的长线。**孩子越小越来得及，已上初中的家庭若走不了快路，把D类牌打满同样是赢。**

## 为什么这笔账值得算：AC和D类，差的是赛道

把两组数字摆在一起看：

| | AC 类 | D 类 |
|---|---|---|
| 身份 | 深户（含享受政策照顾类） | 非深户 |
| 考生占比 | 约 46% | 约 54% |
| 公办普高招生份额 | 约 77% | 约 23% |

人数多出一截，公办指标却少一大截。分数规律（已核口径）：

- **分越顶尖，AC/D 越接近**——四大名校基本持平，深户优势不明显；
- **越往中下游走，拉得越开**——普通校、新校 D 线常比 AC 线高 13–31 分；
- **而多数考生恰恰落在中下游。**

所以结论反直觉：**"要不要深户"，对多数家庭比对冲刺四大的家庭更重要。** 而决定权不只看条件，更看年级——孩子每大一岁，可选项就少一层。

## 户口最迟要什么时候办好：一句话＋例子对号

**深户必须在中考那一年的3月报名前，落到孩子头上**（户口如有变动，须在志愿填报截止前办完核验；具体日期以当年招考办通知为准）。

- 孩子**明年（2027年）中考**、现在读初三 → 最迟 **2027年3月** 前办好；
- 孩子现在**读初二**（2028年中考）→ 最迟 **2028年3月** 前办好；
- 孩子现在**读小学** → 按那届中考年份，往前数到该年的3月即可。

AC 不看"什么时候开始办"，只看**报名那一刻户口在不在**——这条卡点，决定了下面所有时间安排。

## 三条路，快慢差在哪

| 路线 | 门槛 | 速度 | 适合谁 |
|---|---|---|---|
| **未成年子女随迁** | 父母一方已是深户（或已入户） | 最快 | 先自查：家里有没有一方深户 |
| **人才核准入户** | 父母学历/技能符合条件、当年有名额 | 较快（数月量级） | 符合条件，想让孩子近期转AC |
| **纯积分入户** | 稳定住所（自有或租赁）＋社保各满5年；按分排名抢年度名额 | 5年以上长线 | 孩子还小，愿长期布局 |

三个容易踩坑的点（依据深圳市公安局《深圳市积分入户办法》）：

1. **"房"和"户"别混**。深圳早已取消"购房即落户"，买房不会直接送户口。房产的真实角色是**加分项＋落户落脚点**——纯积分入户的准入资格是"合法稳定住所连续满5年"，**自有住房或满5年租赁都算**；但自有住房每满1月积1分、租赁只积0.2分，而积分按年度名额从高到低排名，能不能排进去基本靠住房分拉开。
2. **社保别断**。社保每个险种每满1月积0.3分，中断剔除、补缴不计，申请时还须在缴。
3. **随迁才是落点**。父母入户成功当天，**未成年子女可同步随迁**——孩子户口一到手，下一场中考立刻按 AC 算。

## 按孩子年级，对号入座

| 孩子现在 | 现实判断 | 该做的 |
|---|---|---|
| 幼儿园~小学低年级 | 走纯积分**来得及** | 社保别断、住所年限（租或买）开始攒；目标上初中前入户，初中三年以深户学籍走AC |
| 小学高年级 | 纯积分5年起步**开始吃紧** | 先评估父母能否走人才核准快通道；走不了尽早转D类策略 |
| 初一、初二 | "临考转深户"基本无望（除非一方很快核准入户且当年成功） | 重心放回D类5项资格材料别断、指标生与志愿策略打满 |
| 已初三 | 户口**翻篇**，别再为它花时间 | 只盯5项资格核验、志愿梯度、别信"临时能办深户"话术 |

给每个家庭的提醒：**别为户口冲动买房**——先看自己走的是"纯积分长线路"还是"人才核准快线路"，缺的是分还是资格；房产只是加分项，不是通关门票。

## 给D类家长的两句话

**第一，深户是优势，不是唯一出路。** D类把5项资格保住（居住证、社保满3年、3年完整学籍），指标生、民办普高、中职"3+4/3+2"三条腿同样有出口。

**第二，别跨级焦虑。** 幼儿园的家长现在办最从容；初二初三的家长，把D类牌打好比研究户口有用一百倍。户口这事，要么从早办，要么早点放下——最怕到初三才想起来。
