# 深圳再添4所公办高中！

（凤凰网深圳，2026-03-10 15:58）

近日，深圳市教育局官网发布《关于公开遴选深圳市第四十五、四十六高级中学项目建议书编制服务单位的招标公告》。

据招标方案介绍，为应对高中阶段学位增长需求，两所学校作为**"十五五"重点公办高中项目，拟以"市投市建"模式立项**。其中——

- **第四十五高级中学（宝安BA05-3地块）**：新建建筑面积 **14.21万平方米**，新增学位 **4800个**，投资匡算 **11.34亿元**；
- **第四十六高级中学（光明GM04-3地块）**：新建建筑面积 **5.33万平方米**，新增学位 **1800个**，投资匡算 **4.31亿元**。

两项目总投资匡算 **15.65亿元**，建成后将补充区域公办高中学位、优化教育资源布局。

除了宝安、光明两所新建高中之外，**南山**和**坪山**也规划了两所高级中学。**另有**两所高级中学，已完成可行性研究报告编制服务采购。

今年1月，深圳市教育局还发布了另外两所高级中学项目的可行性研究报告编制服务采购结果公告。其中：

- **深圳市第三十九高级中学项目**，选址位于**南山区月亮湾大道与棉山路交汇处西南角**，规划为48班寄宿制高中，建成后可提供 **2400个学位**。项目新建总建筑面积67808平方米，**总投资匡算约5.39亿元**。

- **深圳市第四十高级中学项目**，则选址于**坪山区石井街道**，地处深中创新学校南侧、绿荫南路与金田路交汇处西南角，规划为**36班寄宿制高中**，可提供学位 **1800个**。项目新建总建筑面积55446平方米，**总投资匡算约4.37亿元**。
