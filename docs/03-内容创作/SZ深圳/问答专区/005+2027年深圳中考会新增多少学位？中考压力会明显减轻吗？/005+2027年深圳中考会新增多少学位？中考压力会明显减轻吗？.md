# 2027年深圳中考会新增多少学位？压力真的会减轻吗？

## 一条被传疯的消息，和它的两个误读

9月8日，一批政府采购合同公示刷屏了家长群：

> 深圳市教育局一批可行性研究报告编制服务合同对外公示——深圳市第四十二至四十八高级中学，以及深圳大学附属中学高中部扩建，一共8所公办高中，合计总投资47.24亿元，正式驶入项目前期快车道。

"8所新高中""47个亿""2027年""新增学位"——这几个词凑在一起，足够让任何一个初三家长心头一热。

**但这条消息，被读错了两层。而这两层，恰恰决定了你该用什么心态陪孩子读完初三。**

---

## 一、先把结论放这

| 你的问题 | 现在的答案 |
|---|---|
| 2027年新增多少学位？ | **官方未发布**。按惯例，当年招生计划在**次年5—6月**随中考招生文件下发 |
| 是扩招还是新建？ | **两条腿都在走**：老校改扩建（已有学校+1200座这种）+ 新建高中（39—48高序列） |
| 这8所新校能赶上2027年吗？ | **赶不上。** 这批项目才刚进入**可研编制**阶段，服务期到2027年9月 |
| 中考压力会大幅减轻吗？ | **大概率不会"大幅"减轻。** 学位在扩容，考生也在增长，公办普高录取率近年稳在**52%上下** |
| 家长现在该做什么？ | 守住校内排名、盯紧名额分配、把志愿梯度想清楚——**别等一个数字** |

---

## 二、两个误读，一次说清

### 误读一：把 75.5 万元的"论证费"，读成了 47.24 亿的"建设费"

我去深圳政府采购网调出了原始公示。9月8日当天，教育局一次性公示了 **A、B、C 三个包**：

| 包 | 包含项目 | 中标单位 | 合同金额 |
|---|---|---|---:|
| A包 | 第四十二、四十三、第四十四高级中学 | 深圳市建筑设计研究总院有限公司 | **628,000 元** |
| B包 | 第四十五、第四十七高级中学 | 鹏信工程项目管理顾问有限公司 | **602,000 元** |
| C包 | 第四十六、第四十八高级中学 + 深大附中高中部扩建 | 深圳市建星项目管理顾问有限公司 | **755,302 元** |
| | **8 个项目** | 3 家 | **1,985,302 元（约 198.5 万元）** |

三包合同的履约期限完全一致：**2026年9月4日 至 2027年9月3日**。

**这是"可行性研究报告编制服务"的合同，合计约 198.5 万元。它不是施工合同，不是 47.24 亿元。**

打个比方：这相当于**请人来做"这房子该不该盖、怎么盖"的论证**，而不是请施工队。合同签了，等于项目拿到了"去论证"的资格，距离"开工"还隔着好几道手续。

> 关于"47.24亿元"这个数字：我按已公布的单个项目反推——45高 11.34亿 + 46高 4.31亿 = 15.65亿，其余6个项目摊到约 31.59亿、均值5.27亿/个，与39高5.39亿、40高4.37亿、41高6.36亿的量级是吻合的。**数量级合理，但我没有找到这个数字的官方原始出处，只能算媒体汇总口径。** 引用时请写"据媒体汇总"，而不是"据教育局公布"。

### 误读二：把"2029年的学位"，读成了"2027年的学位"

可研服务期是 **2026年9月4日 → 2027年9月3日**。也就是说，**这批项目的可行性研究报告，要到2027年9月才出**。

后面还有：初步设计、施工图、概算批复、施工招标、施工。参照深圳同期的项目节奏：

- 平冈中学改扩建，2026年4月施工招标，**计划2028年12月30日竣工**
- 罗湖高级中学改扩建，2026年1月中标，**工期1096天（约3年）**
- 39高、40高的项目文件里写明，**计划总工期36个月**

**所以：这批学校对 2027 届考生基本没有直接影响，2028 届也很勉强。真正的受益者，是 2029—2031 届中考的孩子。**

> 唯一的例外是"借址办学"——比如深圳启元中学，2026年就在借址招生、2027年秋才迁入永久校区。但**目前没有任何官方信息说这8个项目会走这条路**。

**一句话：这是一条关于"深圳未来五年学位储备"的好消息，不是一条关于"你家孩子明年中考"的好消息。**

## 三、那 2027 年，到底新增多少学位？

**答案很朴素：现在没有官方数字，而且不会有。** 但这不代表你什么都看不到——**趋势是清楚的。**

### 第一组：年度计划在稳步加码

2026年，深圳高中阶段学校招生总计划 **约14.7万个**，覆盖180所学校，**比上一年增加约1万个**。这1万个增量里，公办普高占了 **约0.6万**——公办普高计划 **约8万个**，共101所学校。

**学位扩容的主力是公办普高，不是拿中职学位来凑数。**

### 第二组："十四五"的建设成果

**2020—2025年，深圳以四大高中园为代表的49所新改扩建公办高中建成投用，累计新增公办高中学位11.8万个。**

（顺带说一句：《深圳市高中学校建设方案（2020—2025年）》原定任务是新改扩建公办普通高中**55所**，而官方报道里"已建成投用"的口径是**49所**。**方案里是任务目标、报道里是建成数，统计时点不同**，看到有人拿这两个数字互相打脸，你可以不必跟着激动。）

### 第三组："十五五"的规划目标

**2026年2月，深圳市教育局在市人大记者会上明确：「十五五」期间（2026—2030年），深圳将新增公办高中学位10万个以上**，通过新改扩建、存量挖潜等方式持续扩招。

请注意三个限定词：**五年累计、公办高中、规划目标**。

把它除以5当成"每年新增2万"，或者干脆说成"2027年要新增10万个学位"——**这两种说法都是错的，而且错得很常见。**

## 四、新增学位从哪来？现在有名单了

这是本轮信息里最有价值的部分。两条腿，都有据可查。

### 腿一：新建高中——39 到 48 的"高级中学序列"

深圳的高级中学是按序号排的。这几年密集开工的，是一条清晰的序列：

| 项目 | 选址 | 规模 | 投资匡算 | 状态 |
|---|---|---|---|---|
| 39高 | 南山月亮湾大道与棉山路 | 48班 / **2400学位**（含50%走读） | 5.39亿 | "十五五"第一批 |
| 40高 | 坪山石井街道 | 36班 / **1800学位**（含30%走读） | 4.37亿 | "十五五"第一批 |
| 41高 | 坪山坑梓沙田社区 | 未公布 | 6.36亿 | 2026年7月设计招标 |
| 45高 | 宝安（BA05-3地块） | 建面14.21万㎡ / **4800学位** | 11.34亿 | "十五五"重点，"市投市建" |
| 46高 | 光明（GM04-3地块） | 建面5.33万㎡ / **1800学位** | 4.31亿 | "十五五"重点，"市投市建" |
| **42、43、44、47、48高** | **均未公开** | **均未公开** | **未公开** | 2026年9月可研 |
| 深大附中高中部扩建 | 南山（中心校区） | 未公开 | 未公开 | 2026年9月可研 |

两点提醒：

1. **39/40/45/46 高的选址与规模是公开的，42/43/44/47/48 高不是。** 目前已确认的选址分散在**宝安、光明、坪山、南山**，媒体称7所新校还涉及**龙岗、龙华、深汕**——但那是媒体的说法，官方没有逐一公布。
2. 网传"7所新校共1.44万个学位"，是按"每所最低36班/1800学位"倒推的**媒体估算**。对照已公布的实际规模（39高2400、40高1800、45高4800、46高1800），这个估算**不算离谱，但它依然只是估算**。

### 腿二：老校改扩建——这条腿反而更实在

**因为改扩建的学位，来得比新建快。** 目前已进入招标或施工阶段的一批：

| 学校 | 进度 | 投资 |
|---|---|---|
| **深圳第二外国语学校**（龙华） | 扩增24个教学班 | 约3.17亿 |
| 深圳中学泥岗校区（罗湖） | 新建综合楼及校区改造 | 约1.51亿 |
| 深圳市高级中学中心校区（南）（福田） | 新建体育综合楼约2.16万㎡ | 约1.53亿 |
| 宝安中学（集团）高中部 | 新建15层综合楼，约3.27万㎡ | 约2.55亿 |
| 深圳市第二实验学校高中部（罗湖） | 宿舍拆建+综合楼加固，**施工中** | 约2.86亿 |
| 罗湖高级中学 | 已中标，工期约3年 | 约3.24亿 |
| 平冈中学（龙岗） | **计划2028年12月竣工** | 约2.79亿 |

**关键提醒：这一整张表里，目前唯一官方公布了新增学位数的，只有深二外——「3年共新增1200座」。** 2025年该校招生990人，改扩建完成后年招生规模将接近1400人，**增幅超过40%**。

其余学校的"+"，官方一律写的是——**待可研报告**。

另外，**2026年9月1日**，市教育局刚发布了三大高中园（坪山、光明、深汕）改扩建工程的可行性研究招标。**这是三大高中园首次进入改扩建前期程序**，9月11日截标。

**三大高中园要"长大"了——但同样地，学位数要等可研。**

## 五、压力会大幅减轻吗？

这是全文最需要冷静的一段。**答案是：大概率不会"大幅"减轻，更可能是"稳住"——而"稳住"本身已经很不容易。**

原因是一场很朴素的赛跑。

**考生这边：** 2018年7.21万人 → 2022年11.2万人 → 2024年13.52万人 → 2025年14.40万人 → 2026年15.30万人。**8年翻了一倍多。**

**学位这边：** 公办普高招生从2022年约5.9万人，涨到2024年约6.9万人，2026年约8万人。**涨了约35%。**

**录取率这边：** 2024年公办普高录取率超52%，2025年超52%，2026年约52%。**连续三年，几乎纹丝不动。**

三组数字放一起，结论就出来了：

**考生翻了一倍多，公办学位涨了约35%，录取率之所以没崩，是因为学位一直在追着考生跑——但它也没能跑赢。所以录取率是"稳"，不是"升"。**

所以对"2027年压力会不会大幅减轻"：

1. **总量上，供给确实在扩容**——这是确定的方向，不用怀疑；
2. **录取率上，近年稳定在52%上下**——目前没有任何证据支持2027年明显跃升；
3. **心理上，千万别把"扩招"当成"躺赢"**——**扩的是学位数，不是你家孩子的排名。**

最后补一句让人安心的话：**深圳普高录取率（含民办）超过73%**，加上中职技工，2026年14.7万个总计划基本覆盖全部考生。

也就是说，深圳中考真正的焦虑从来不是"有没有高中上"，而是**"上哪一所"**。这个焦虑，扩招缓解不了，只能靠信息和方法缓解。

## 六、对2027届考生，这带来5个实际影响

**第一，选择变多，但判断变难了。** 每年都有新校开门，家长能看到的名字越来越多，但"这所学校到底什么样"的有效信息，往往滞后三年。

**第二，新校首届的分数线，无法预测。** 位置、招生计划数、办学主体、当年志愿热度都会影响分数。**"新校第一年肯定低分"是个很危险的传言。**

**第三，"首届红利"和"首届风险"同时存在。** 新校为了打响第一届，往往在师资、小班化、硬件上舍得下本；但管理制度、课程体系、社团文化都还在成型期。**两者不是二选一。**

**第四，志愿梯度比往年更重要。** 新校一多，往年分数线序列的参考价值就下降。**冲稳保要从"对标去年分数"转向"对标自己的位次"。**

**第五，名额分配（指标生）依然是最大变量。** 公办普高本校招生计划的 **50%** 用于名额分配，覆盖公民办初中——**校内排名，往往比全市分数更能决定你的机会。**（2027年比例与控制线以当年文件为准。）

## 七、家长要注意的6件事

### 1. 分清"论证"和"建成"

**可行性研究报告编制合同 ≠ 施工合同 ≠ 学校建好了。**

这一轮的传播落差（198.5万 vs 47.24亿）就是最好的教材。看到"某某学校开建"的消息，**先问一句：现在是可研、设计、招标，还是施工？**

### 2. 分清"累计"和"当年"

**最典型的话术陷阱，是把"十四五"累计新增的11.8万个学位，说成"某一年新增"。**

这四个词差别巨大：**年度招生计划 / 可用学位 / 在校总容量 / 累计建设数。** 看到数字先问：**这是哪一年的口径？**

### 3. 分清"总学位"和"公办普高学位"

高中阶段学位 = 公办普高 + 民办普高 + 中职技工。

**中职学位不能算进普高，民办普高不能算进公办普高。** 有些宣传把三者加在一起说"学位充足"，听着很美，但和你家孩子的真实选择可能差着一半。

### 4. 新校 ≠ 新校址（这条最容易被忽略）

看一个官方例子。**深圳创新高级中学**（市直属公办，总投资6.7亿元，48个教学班、2400个学位），政府官网写得很清楚：

> **过渡校区（2026年9月入学）**：深圳市龙华区福城街道勤思路1号（借址深圳市益新中学办学）
> **永久校区（2027年9月迁入）**：深圳市深汕特别合作区科教大道1688号

**同一所学校，2026级在龙华上课，2027级起在深汕上课。** 对住在西部片区的家庭，这两个校区的通勤可行性是天壤之别。

**所以报名前一定要查清：孩子入学那一届，到底在哪儿上课。** 官方页面上的"过渡校区/永久校区"就是标准答案。

### 5. 集团冠名 ≠ 办学质量已验证

名校集团化办学的真实含金量，要看**实际派驻的管理团队和骨干教师比例、课程是否独立设置、校区是否独立法人**——而不是看校名里有几个名校的字。

**首届没有中考、高考成绩序列，任何"预期成绩"都只是预测。**

### 6. 一切以当年官方招生计划为准

录取标准、名额分配控制线、招生计划——**每年5—6月教育局的正式文件，才是唯一依据。**

在文件出来之前，任何"2027年新增X个学位"的具体数字，都只是外推。**别用传言，替代你精心设计的志愿梯度。**

## 写在最后

学位这件事，深圳是真在加码的。

2026年同比增加约1万个高中阶段学位；"十四五"累计建成49所新改扩建公办高中、新增11.8万个学位；"十五五"规划再增10万个以上；2026年一年里，从39高到48高，"高级中学序列"一路排下去，改扩建的名单也从深中泥岗排到了平冈中学。

**方向是向上的，这一点值得肯定。**

但也得清醒两件事：

**第一，扩容作用于所有人，不作用于某一个孩子。**
**第二，今天这条"8所新高中"的消息，兑现的是2029年之后的学位，不是明年的。**

对2027届的家长来说，最有用的动作从来不是等一个数字，而是这三件现在就能做的事：

**守住校内排名、盯紧名额分配、把志愿梯度想清楚。**

**关注我，深圳中考系列连载更新中。** 你家孩子是哪一届中考？现在最担心的是学位够不够，还是志愿怎么填？评论区聊聊，下一篇按大家最关心的问题来写。
