# 未来五年，深圳规划新增公办高中学位10万个以上

未来五年（2026—2030），"十五五"期间，深圳**规划新增公办高中学位10万个以上（五年全口径规划目标）**。

这10万个学位，来自两条腿：

**一条是新建。** 从**第三十九高级中学到第四十八高级中学，10所新建公办高中**的番号已经排定。

**一条是扩建。** **超过10所公办高中**正在改扩建——深圳中学泥岗校区、深圳实验学校、深圳市高级中学中心校区（南）、宝安中学（集团）高中部、深圳大学附属中学高中部、深圳市第二实验学校高中部、翠园中学本部、罗湖高级中学、平冈中学、深圳第二外国语学校。此外，**坪山、光明、深汕三大高中园首次进入改扩建程序**，深圳启元中学（二十九高）二期也在其中。

**一句话：深圳不是在"补学位"，是在为孩子的未来提前铺路。**

## 一、新建：10所学校，正在从图纸上站起来

这几年深圳高中的"番号"，家长应该已经熟悉了：三十九高、四十高、四十一高……一直排到四十八高。这不是编号游戏，是**10所新建公办高中的建设序列**。已经能看到轮廓的：

- **第三十九高级中学**——南山月亮湾大道与棉山路交汇处，48个班、**2400个学位**，含**50%走读**名额
- **第四十高级中学**——坪山石井街道，36个班、**1800个学位**，含**30%走读**名额
- **第四十五高级中学**——落地宝安，规划规模**4800个学位**
- **第四十六高级中学**——落地光明，规划规模**1800个学位**

注意那两个"走读"比例。**这意味着一所学校不再只有"住校"一种可能——对家门口就有高中的家庭，是实实在在的便利。**

还有一所值得单独说：**深圳创新高级中学**。市直属公办，总投资6.7亿元，48个教学班、2400个学位。它不是"又一所普通高中"——官方介绍里写明，它承担的是**"新型综合高中"试点改革任务**，课程体系是"高中学术课程 + 前沿技术课程 + 拓展课程"，方向对准人工智能、机器人、无人机、智能网联汽车。

**它代表的是深圳办高中的另一种思路：不只是"多一个学位"，而是"多一种长大的方式"。**

## 二、扩建：老学校也在悄悄长大

新建校从拿地到开学，总要好几年。所以深圳同时在做另一件事——**让已经在办学的老学校，装下更多孩子。**

这两年动工和推进的名单，家长应该很熟：**深圳中学泥岗校区、深圳市高级中学中心校区（南）、宝安中学（集团）高中部、深圳大学附属中学高中部、深圳市第二实验学校高中部、罗湖高级中学、平冈中学、深圳第二外国语学校、深圳实验学校、翠园中学本部……**

这些名字的分量不用多说。更重要的是——**它们很多就在成熟片区里**：罗湖、福田、宝安、龙华、龙岗。

其中推进得比较明确的，**深圳第二外国语学校**：新增建筑面积4万余平方米，**扩增24个教学班**，改扩建完成后年招生规模从990人提高到接近1400人，**增幅超过40%**。

**扩容不只是新区的事。住在老城区的家庭，同样可能等来家门口那所学校的"长大"。**

## 三、但2027届家长，还不能盲目乐观

上面说的都是好消息。但有一句必须说清楚：

**那些新学校，明年还建不好。**

三十九高到四十八高这串序列，推进最快的也还在设计或可行性研究阶段；那批改扩建项目，竣工时间大多落在**2027年之后，甚至2029年、2030年**。

**你家孩子如果是2027届中考，赶上的仍然是"扩容进行时"，不是"扩容完成时"。**

公办普高录取率这几年稳在大约52%。**"稳"意味着没有恶化，但也意味着没轻松多少**；而考生人数这几年一直在涨。

**未来是美好的，现在还不能松懈。**

▍**现在就能做的三件事：**

1. **守住校内排名**——名额分配占公办普高招生计划的**50%**，校内位次往往比全市分数更管用；
2. **盯紧名额分配**——政策细节每年都要重新核一遍，别拿去年的口径套今年；
3. **把志愿梯度想清楚**——新校越多，越要"对标位次"，而不是"对标去年分数"。

**看好深圳的长期，做足孩子的当下。**
