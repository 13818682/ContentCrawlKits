# 同样读三年书，有人花1万，有人花30万：普高和中职的学费差多少？

## 第一部分 · 直接答案

先认清一个事实：**深圳约一半考生进不了公办普高**（公办普高学位约占52%）。你家孩子，有近一半的可能要走民办或中职的路——而这条路，学费可能是公办的好几十倍。

几个数字，先给你心里有数：

- **三年总账：**公办普高约1万、公办中职约3千、民办中职5万-10万、**民办普高21万-36万**。
- **约三分之一考生家庭会读民办**：民办普高33,195人+民办中职17,330人≈5万人，占全市考生（约15.3万）的三分之一；
- **民办普高比公办普高，每年贵约25-40倍**（学杂费口径）；
- **民办普高一年花费7万-12万，≈一个普通打工人一年工资**（深圳私营单位平均工资约9.9万/年）；

同样读三年书，有人花1万，有人花30万。**差的不是孩子的成绩，是家长有没有提前把这条路看清楚。**

## 第二部分 · 完整回答

先说结论，再说为什么。**约一半考生进不了公办普高，这条路不是少数人走，是几万个家庭每年都要面对的现实。** 我理解，很多家长看到"学费"两个字就想划走——孩子还没上考场，谈钱是不是太早？恰恰相反，学费不是"以后的事"，是出分当天就要面对的事。早一年想清楚，就少一分措手不及。这篇文章，我不想只摆数据，我想陪你站在一个家长的位置上，把这笔账一笔一笔算明白。

### 一、先认清现实：约一半考生进不了公办普高

2026年深圳公办普高学位约8万，考生约15.3万，**公办普高录取率约五成出头——约一半考生，注定要走进民办普高或中职。** 这不是谁家孩子不努力，是名额就这么多。

顺便说句实话：大家都说"七成以上考生能上普高（含民办）"，听起来很宽。但把那两成多拆开看，**其中民办普高就招了33,195人——也就是说，约两成考生是靠民办普高才"有普高上"的。能上，但每一分学费，都要家里掏。**

再算一笔更扎心的账：**同样是"普高"两个字，民办的学杂费是公办的25-40倍。** 公办普高一年学杂费2,262元；民办普高一年学杂费5.6万-9.4万。那约两成"靠民办普高才有普高上"的孩子，家里每年都要为"普高"两个字，多掏好几万到十几万。

所以接下来的每一笔账，都值得你现在就看清——尤其是那"一半"孩子的家长。

### 二、三年总账：四类学校到底差多少

把四类学校摆在一起，算三年总账，一目了然（招生人数为2026年全市计划）：

| 学校类型 | 招生人数（2026） | 每年花费（学杂费+住宿） | 三年总花费（约） | 与公办相比 |
|:---|:---:|:---|:---|:---|
| 公办普高 | 80,303人（101所） | 约3,200元/年 | **约1万** | 基准 |
| 民办普高 | 33,195人（49所） | 7万-12万+/年 | **21万-36万** | **贵约25-40倍** |
| 公办中职技工 | 15,924人 | 约900元/年（免学费） | **约3千** | 基准 |
| 民办中职技工 | 17,330人 | 1.6万-3.5万/年 | **5万-10万** | **贵约20-35倍** |

（四类合计146,752人、全市180所；民办普高学费按学期收：2.8万-4.7万/学期，普遍在5.6万-9.4万/年，国际方向更高。数据来源见文末。）

同一个孩子，差不多的分数，两户人家三年下来，可能一个轻轻松松，一个要勒紧裤腰带——**差别不在孩子，在家长有没有提前把这条路看清楚。**

### 三、三个让你清醒的数字

**第一个：约三分之一考生家庭，会走进民办学校。** 2026年深圳民办普高招33,195人、民办中职招17,330人，合计约5.05万人，占全市考生的**三分之一**。平均每3个中考生家庭，就有约1个要面对民办学费。这不是"别人家的事"，很可能就是你。

**第二个：民办比公办，每年贵25-40倍。** 民办普高学费普遍2.8万-4.7万/学期，一年5.6万-9.4万；公办普高一年学杂费仅2,262元。**同样读一年高中，民办普高比公办学杂费贵约25-40倍**；民办中职比公办中职，每年也贵约20-35倍。

**第三个：民办普高一年学费，≈一个普通打工人一年工资。** 深圳2025年城镇私营单位就业人员平均工资99,220元（约8,300元/月）——这比非私营单位的19.1万更接近普通家庭的真实收入。民办普高一年花费7万-12万，**基本等于一个打工人全年工资，甚至还不够**；三年21万-36万，**相当于一个人不吃不喝干2-3年**。哪怕按更高的全市平均工资（非私营单位19.1万/年）算，三年也要吃掉1-2年的全部工资。

对比一下：公办普高一年约3,200元，只占普通打工人年工资的约3%。同样读高中，公办三年约1万，民办三年约25万起——**差的二十几万，可能是很多家庭几年的积蓄。**

### 四、公办普高：三年约1万，为什么值得拼

深圳公办普高学杂费是政府定价，按学校等级分四档：**一般学校905元、区一级996元、市一级1,041元、省一级1,131元/学期**，住宿费450元/学期。大部分公办普高是省一级，所以多数家庭按1,131元/学期算：一年学杂费约2,262元，加住宿900元，**全年约3,200元，三年约1万元**。走读的孩子再省900元/年。

三年一万，给孩子换一个拼本科的机会——对绝大多数深圳家庭，这是最不心疼的一笔教育投入。这也是为什么那么多人挤破头想进公办普高：不只为了那张文凭，也为了一家老小不用为学费发愁。

需要提醒的是：**公办普高不提供"多花钱买学位"的通道**，录取只看分数和志愿。想省下这几十万，唯一的路，就是让孩子分数够上公办线——而这，恰恰是需要家长提前三年就开始规划的事。

### 五、民办普高：三年21万-36万，这笔钱谁扛得动

这是今天最想说清楚的部分。民办普高学费普遍**2.8万-4.7万/学期**，具体差别很大：

| 民办普高 | 学费/学期 | 住宿费/学期 |
|:---|:---:|:---:|
| 松岗中英文实验学校 | 2.8万 | 3,000元 |
| 福桥高级中学 | 2.95万 | 4,000元 |
| 龙岗东升学校 | 3.0万 | 3,500元 |
| 华文高级中学 | 3.68万 | 5,000元 |
| 富源学校 | 3.94万-4.72万 | 4,600元 |
| 滨海高级中学 | 约4.0万 | — |

（以上为2025-2026学年公开公示标准，逐年可能调整，以学校当年公示为准。）

学费之外还有三笔钱别漏算：**住宿费**（3千-5千/学期）、**伙食费**（约1-2万/年）、**校服+教辅+杂费**（首年约5千元起）。七七八八加起来，**三年21万-36万很常见**；个别国际方向学校更高，如深圳(南山)中加学校学费11.8万/学期，三年超70万。

21万到36万是什么概念？按前面算的，它约等于一个普通打工人不吃不喝干2-3年，可能是一家人几年的积蓄，也可能是家里要卖房、借钱、背上贷款才能凑出来的坎。**孩子还小，不懂这些；但家长必须懂。**

但民办普高也不是没有降费的通道，关键在信息差：
1. **部分民办普高设"公办班"**：高分录取的考生可享学费全免或高额减免（如华文高级中学）；
2. **部分学校有奖学金体系**：按中考成绩分档减免学费；
3. **跨区、跨校比价**：同类分数，不同民办普高的学费可能差1-2万/年。

民办普高不是不能选，而是要在出分前就想清楚：这笔钱，我们家扛得动吗？扛不动，有没有更早的安排？

### 六、公办中职技工：免学费是真的，但贯通上本科的名额少得可怜

公办中职免学费是真的：**深圳户籍、农村（含县镇）户籍、城市涉农专业、家庭经济困难等符合条件的学生，读公办中职免学费**，三年基本只花住宿费（约450元/学期），总计约3千元。不符合免学费条件的，学杂费约1,359-1,595元/学期（如博伦1,359-1,534、华强1,595），也远低于民办。符合条件的学生还能申请**国家助学金（约2,300元/年）**，特别优秀的还能评**国家奖学金（6,000元/年）**——公办中职的经济压力，几乎可以忽略。

**但这句话，别理解成"便宜就轻松"。**

说句实话：**公办中职招生约1.6万人，但能直接贯通到本科的名额，少得可怜。** 全市中职的"贯通本科"名额，一年合计也就**约3,000多个**：

- **"3+4"中本贯通：仅300个**名额（6所中职、8个专业，对口深圳技术大学、深职大、深信大等全日制本科；中职3年+本科4年，毕业拿本科文凭）；
- **"3+2"中高贯通：约2,850个**名额（63个专业，其中公办中职约1,960个、民办中职约890个；中职3年+大专2年）。

算得更细一点：**公办中职能贯通到本科的，一年只有约2,300个名额**（3+4的300个 + 3+2中公办部分的约1,960个）。15.3万考生，去抢这两千多个公办贯通名额，**竞争压力不是一般的大。**

所以公办中职这条路，是"低费用+技能+贯通机会"的选项，但它不是捡漏，更不是躺平：**想上好专业、想贯通到本科，一样要靠分数说话，一样要提前研究每个专业的名额和门槛。** 便宜是真便宜，难进也是真难进——这两件事，家长都得知道。

### 七、民办中职技工：三年5万-10万，很多孩子是被动走进来的

说到民办中职，我想先说一句掏心窝的话：**选择民办中职的家庭，大多数不是"稀里糊涂"选的，而是孩子成绩够不上公办线，志愿填下来，能接住他的就是民办中职——这是被动的局面，不是主动的选择。** 这类孩子和家庭，最不该被责备，最该被帮一把。

但现实是，民办中职并不便宜。学费普遍**6,800-15,600元/学期**，加住宿（1,200-2,000元/学期）、伙食等，**三年约5万-10万**：

| 民办中职技工 | 学费/学期 | 备注 |
|:---|:---:|:---|
| 中嘉职业技术学校 | 6,800-8,000元 | |
| 深科技工学校 | 6,800-9,500元 | 免学费补助后口径 |
| 华夏技工学校 | 8,800-9,800元 | |
| 中特技工学校 | 9,500-11,000元 | 住宿费1,200元/期 |
| 宝山技工学校 | 9,500-11,000元 | 符合政策减免4,000元/年 |
| 科迪技工学校 | 1.1万元起 | 住宿费1,200元/期 |
| 携创高级技工学校 | 1.18万-1.47万 | 住宿费2,000元/期 |
| 奋达职业技术学校 | 1.56万 | 住宿费1,500元/期 |

对普通家庭，这是在"孩子没考上公办"的被动处境里，又叠上的一层实实在在的负担。

正因为被动，家长才更要提前做三件功课，别再吃信息亏：
1. **符合免学费政策的学生，可按同类型公办中职标准获补助**——国家规定民办中职符合条件的在读生，按同类型同专业公办中职免学费标准给予补助（约2,200-3,000元/年）。这笔钱，别白白漏掉；
2. **同样的钱，看专业和升学通道值不值**——有的民办中职专业对口、有3+2贯通机会，有的只是收钱。同样花5万-10万，三年后的出路可能天差地别；
3. **早一年知道这些，也许孩子还能冲一冲别的路**——信息差，是唯一能在被动里扳回一局的东西。

### 八、按分数段，分别该怎么想

**公办普高线以上（约前五成）**：最省钱的路线是公办普高，三年约1万。孩子分数越高，越要守住公办；志愿填不好滑到民办，就是一年6位数。这个分段的家长，功课重点在"志愿梯度"和"名额分配（指标生）"，别让填报失误把公办机会拱手让人。

**公办普高线边缘（临界段）**：这是最纠结的群体。孩子可能差几分进公办，一旦滑到民办就是三年20多万。这个分段要做的：一是研究民办普高的"公办班"和高分减免，二是看准走读/住宿计划，三是把公办中职的3+4/3+2贯通名额摸清楚——**有时候，公办中职的贯通本科，比民办普高自费读三年性价比高得多。**

**明显低于公办线的低分段**：如果孩子进公办普高基本无望，就别把希望全押在民办普高上。与其掏三年20-30万读民办普高，不如研究公办中职的贯通专业和技能方向——**公办中职免学费+贯通本科的机会，对普通家庭可能是更好的选择。** 关键是选对专业、选对名额。

### 九、三个常见的误区

**误区一："中职=没出息，还不如花钱读民办普高。"** 这是最贵的一个误区。中职不是没出路，而是"换一条路走到本科"：3+4拿全日制本科文凭、3+2拿大专文凭，公办中职还免学费。盲目花钱读民办普高，不等于就能考上好大学。

**误区二："公办中职免学费=随便就能进。"** 恰恰相反，公办中职的好专业、贯通名额非常抢手，竞争一点不比普高小。便宜是真的，难进也是真的。

**误区三："民办学费贵，所以教育资源一定更好。"** 学费贵不等于值。民办普高之间差别很大，有的靠奖学金和高分班吸引优质生源，有的只是普通办学。**选民办，要按'分数-学费-升学出口'三样一起比，不能只看学费高低。**

### 十、给家长的三句话：现在就该做的事

看到这里，你可能有点慌。但请放心，**路没有断**：七成以上考生能上普高（含民办），公办中职免学费，中职还有贯通本科的通道。真正要警惕的，不是"没学上"，而是"**没算清账，就做了选择**"。

所以，现在就该做这三件事：

1. **现在就开始看数据**：公办普高录取线、民办学费、中职贯通专业，全都摆在明面上。信息是免费的，错过窗口的代价，是白花十几万或者错失一条好路；
2. **先定预算，再谈志愿**：家里三年能扛多少钱，决定了孩子志愿表的下限。别等录取了才发现"上不起"；
