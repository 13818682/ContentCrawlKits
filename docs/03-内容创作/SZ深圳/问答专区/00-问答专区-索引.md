# 问答专区 · 索引

对外平台（今日头条问答/知乎等）的问答回答统一归档于此目录。**每个问题一个独立子目录，完全隔离**；子目录内放该问题的全部素材（回答正文 md / 外部生成 docx / 今日头条配图）。

**平台发布登记**：各问题各平台素材产出状态 + 实际发布进度，见 `00-问答专区-平台内容清单与发布登记表.md`（第二节登记清单，发布一篇填一篇）。

## 目录组织

```
问答专区/
├── 00-问答专区-索引.md                       # 本索引
├── 00-问答专区-平台内容清单与发布登记表.md    # 素材清单 + 平台发布登记
└── {序号}+{提问题目}/                        # 子目录名 = 问题文件名
    ├── {序号}+{提问题目}.md                  # 回答正文（两段式：直接答案 + 完整回答）
    ├── {序号}+{提问题目}.docx                # 外部工具生成的发布文件（如已生成）
    ├── 00-QA-{序号}-选题研究与数据核验.md     # 选题研究/数据核验底稿（如已建）
    ├── 09.参考资料/                          # 一手来源本地归档（官方公示/媒体解读/PDF原件）
    └── _build_qa_images.py + *.png           # 今日头条6张(1200×900) + 公众号7张(900系列)，可复制脚本复用
```

## 文件命名规则

- 子目录与正文文件同名：`{序号}+{提问题目}.md`（序号三位从 001 递增，题目含标点）
- **今日头条配图**（1200×900）：`封面1-主标题` / `封面2-数据对撞` / `封面3-答案大字` / `正文图-5项条件表` / `正文图-三条出路` / `微头条配图-3关键数字`
- **公众号配图**（13-1 规格）：首图 900×383、章节条 900×220、数据卡 900×400，命名 `公众号首图` / `公众号章节条N-主题` / `公众号数据卡N-主题`

## 配图系列设计语言（统一蓝色系家族 + 渐变/光影制造变化）

- **家族常量**：全部深蓝系底色（6 档深浅 navy/royal/steel/cobalt/ink/deep）+ 金色强调、顶部胶囊徽章「深圳中考 · 问答系列 · NNN」、底部数据来源、微软雅黑、版心安全区。
- **变化轴（不换主色，靠光影/渐变）**：蓝色深浅档位 × 渐变方向（v/radial/d1/d2）× 光影效果（glow-tr/glow-bl/spot/beam/center）× 装饰纹理（circles/rings/slash/grid）× 版式（封面大字/数据对撞/条件表/出路卡/三数字卡）。
- ⚠️ 经验坑：半透明卡片必须走 RGBA 覆盖层合成（`card()`），在 RGB 图上直接填 RGBA 会被画成实心白。
- 复制 `_build_qa_images.py` 改 CONTENT/THEME 即可为后续问答产图，保证整套风格统一又不重样。
