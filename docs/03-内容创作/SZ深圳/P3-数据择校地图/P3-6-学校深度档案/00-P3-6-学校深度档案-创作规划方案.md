# P3-6-学校深度档案 — 系列创作规划方案

## 一、定位调整说明

P3-6 在原 P3 规划中定义为"每所学校一篇深度档案（180所）"。实际执行中发现：

- **180所完整深度档案（每篇8000字、7大板块）已存在**于 `E:\1.HSEE\5.CrawlTool\data` 和 DB `school_introductions.full_content` 字段中——这是付费用户的专属内容。
- **P3-6 作为免费引流内容**，不应复制付费产品，而应做"橱窗展示"——精选有故事、有话题、有搜索量的学校和角度，写成引流文章。

### 内容分层架构

```
┌─────────────────────────────────────────────────┐
│  付费墙内（HSEE小程序付费会员）                      │
│  180所学校完整深度档案（full_content，8000字/篇）     │
│  含7大板块、100+数据点、近4年分数线、家长评价         │
├─────────────────────────────────────────────────┤
│  免费引流层（P3-6 公众号/小红书/抖音）                │
│  6篇精选合集 ← 数据对比 + 特色提炼 + 搜索关键词       │
│  → 看完不过瘾 → 打开小程序看180所完整档案            │
└─────────────────────────────────────────────────┘
```

### 选题逻辑

每篇文章对应一个家长高频搜索场景：
- **P3-6-1** → 头部家长："我家孩子580+，四大哪个适合？"
- **P3-6-2** → 中等生家长："考不上四大，哪些学校能把中等生培养好？"
- **P3-6-3** → D类家长："非深户，哪些学校最友好？"
- **P3-6-4** → 所有家长："新建学校靠谱吗？"
- **P3-6-5** → 特长家长："孩子有特长，什么学校对口？"
- **P3-6-6** → 区域家长："不想跨区，本区什么学校最好？"

## 三、内容模板（每篇通用结构）

### 3.1 公众号版本

```
1. Hook（1-2句，锚定家长焦虑或搜索意图）
2. 核心观点（为什么要看这篇？一句话价值主张）
3. 主体内容（数据对比表 + 每校2-3句特色解读）
4. 择校建议（什么样的孩子适合这个类别的学校）
5. CTA → HSEE小程序查看完整档案
6. 数据来源声明
```

### 3.2 数据来源

| 板块 | 来源 |
|------|------|
| 录取分数线（2025/2026） | DB `schools.admission_scores` |
| 招生计划、住宿名额 | DB `schools.enrollment_plan` |
| 学校特色、校风描述 | DB `school_introductions.brief_content` + 完整MD文件 |
| 学校等级、区域 | DB `schools` 表 |
| AC/D分差计算 | DB 数据自动计算 |

### 3.3 统一 CTA

> 以上是精选学校的速览对比。查看深圳180所高中**完整深度档案**（含近4年分数线、指标生控制线、高考成绩、住宿条件、校风评价、适合人群分析），打开 **HSEE小程序 → 学校档案**，180所学校数据全部可查。
