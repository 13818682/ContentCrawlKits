# 深圳各区"地头蛇"：非四大非八大，但本区最强的选择

P3-6-1 讲了四大，P3-3 讲了五个梯队。但很多家长的实际问题是——

> **"不想让孩子跨太远区。福田/南山/宝安/龙岗/龙华……我们家这个区，最好的学校是哪所？"**

跨区择校意味着住宿（或长时间通勤）、离开熟悉的环境、放弃本区指标生优势。对很多家庭来说，**本区最强校可能是比四大八大更务实的选择。**

这篇逐区盘点——每个区最强（或最有特色）的1-2所公办普高，按2026年录取分数降序排列。

### 龙岗区 — 深圳科学高中 / 龙城高级中学

龙岗是深圳公办普高最多的区（17所），有两所学校值得并列推荐：

**深圳科学高中** [579分]：市直属十大名校之一，科技特色鲜明。D类260个名额，零分差。龙岗区录取线第一。

**龙城高级中学** [576分]：龙岗区属"一哥"，省一级+国家级示范性高中。加工能力媲美十大——新校园硬件全市一流，D类245个名额。

| 对比 | 深圳科学高中 | 龙城高级中学 |

| 录取线 | 579 | 576 |

| D类名额 | 260人 | 245人 |
| 特色 | 科技特色 | 全科均衡+加工强 |

**怎么选**：579分段选科高，576分段选龙城。两所差距不大——科高品牌略强，龙城加工更猛。

## 跨区 vs 本区：决策框架

| 你的情况 | 建议 |
|------|------|
| 孩子分数在本区最强校录取线以上 | **本区最强校优先**——减少通勤，指标生优势最大化 |
| 孩子分数在本区最强校边缘（差5-10分） | 跨区找同分段的其他区最强校——比如福田580分也可以看龙华的龙高（574）或宝安的宝中（583） |
| 孩子在本区没有合适的公办普高 | 跨区+全寄宿——深汕合作区的二高深汕、坪山的深高东都是全寄宿选项 |
| D类+本区D类名额太少 | 跨区找D类友好校——P3-6-3的15所D类友好校清单参考 |
| 孩子不想住宿/家长不想让住宿 | **只考虑本区+通勤30分钟内的学校**——走读是硬约束 |
