# P1-3 · S5 小红书图文（AC类别松懈）

## 笔记标题（正文栏）
深户AC类也别大意：3个坎

## 正文（约400字）
看完全网都在讲非深户难，深户家长容易松口气。**但先看结构**：2026 公办普高 8 万+ 学位里，深户（AC类）占 **61,797（约77%）**、非深户 18,506（约23%）。所以深户的坎**不在名额少**，在下面 3 个"位次"上👇 📌建议收藏

🚧 **坎①：AC 线是硬线**
想进哪所公办，普通通道就看那所学校当年的 AC 线——**差一分就是进不去**。深户只是"能报的范围大"，不是免死金牌。

🎯 **坎②：指标生 = 本校 AC 之间抢**
名额分到校、AC 类单列。报同一所校指标生，拼的是**孩子在校内 AC 类里的位次**，不是全市。校内排不上，宽通道也窄。

⚔️ **坎③：顶尖层没户籍差**
四大 2026 **AC/D 同线、0 分差**——冲到最顶尖那层，你孩子的对手里有 D 类尖子，纯拼分。

✅ **深户家长现在做 3 件事**：
1️⃣ 确认孩子**本校 AC 类位次** → 决定指标生通道宽不宽
2️⃣ 把 2-3 所目标校的 **AC 线**查出来贴桌上 → 先定够不够得着
3️⃣ 用 HSEE 小程序**按 AC 类筛校** → 别只看一两所

一句话：**深户不缺公办名额，缺的是在目标校那一层把位次排上去。别躺平，也别被"52%"吓到——那是全体口径。**
