# 深户(AC类)也别大意：不缺公办名额，缺的是目标校位次

看完全网都在讲非深户难，深户家长容易松口气。但先把结构看清楚：

- 2026 公办普高 **8 万+** 学位：AC 类 **61,797（约77%）**、D 类 18,506（约23%）
- 所以深户的坎**不在名额少**，在下面三处：
  - 目标校 **AC 线是硬线**——差一分进不去
  - **指标生 = 本校 AC 之间抢**，看校内位次不是看全市
  - 四大 **AC/D 同线 0 分差**——顶尖层你的对手里有 D 类尖子

一句话：**深户不缺公办名额，缺的是在目标校那一层把位次排上去。**别躺平，也别被"52%"吓到——那是全体口径。

👉 结构数据 + AC 家长该做的 3 件事，见长文。

（数据来源：深圳市教育局 2026 公办普高招生计划 · 逐校求和核对）
