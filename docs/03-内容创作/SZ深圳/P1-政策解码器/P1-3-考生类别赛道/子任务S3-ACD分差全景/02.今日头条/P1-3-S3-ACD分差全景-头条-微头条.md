# 非深户 D 类比深户多考多少分？答案不是定数，看你在哪一层

拿 2026 公办普高住宿线逐校对过，分差是这样往上走的：

- **四大头部：0 分**——深中 592，D 类也是 592，户籍不卡你
- **区属中坚（530-554）：2-9 分**
- **公办边缘（500-529）：15-23 分**——22 所里 16 所 D 类高 10 分以上
- **集团新校/综合高中班：20-31 分**——别信"新校区好考"，2026 它们分差反而最大

一句话：**D 类的坑不在头部，在"勉强能上公办"的那段**。孩子分数落在哪层，直接决定要多考多少。

👉 五层全表 + 分差最大的几所，见长文。

（数据来源：深圳市教育局 2026 第一批录取标准 · 住宿线实测 · 人工核对）
