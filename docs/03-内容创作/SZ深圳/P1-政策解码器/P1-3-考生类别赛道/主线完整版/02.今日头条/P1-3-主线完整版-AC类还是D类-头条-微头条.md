# 深圳中考考生分 ACD 三类，你站哪条赛道？

深圳中考不是一张卷子定所有——孩子先被分成 **A、C、D 三类**，赛道不同，能报的学校、要考的分都不一样。

- **A 类**（深户+同区）：最宽，公办都能报
- **C 类**（深户+跨区）：报名时要"二选一"选身份，别忽略
- **D 类**（非深户）：占考生约 54%，却只竞争约 23% 的公办指标

**关键**：D 类劣势不在头部（四大 AC/D 已持平），而在中下层——50 强校 D 线常比 AC 线高 10-20 分。知道差距在哪，才知道力气往哪使。

D 类家长重点记：5 个报名条件现在就该查（社保满 3 年/居住证有效/租赁凭证/3 年学籍/职业住所），别等报名才手忙脚乱。
