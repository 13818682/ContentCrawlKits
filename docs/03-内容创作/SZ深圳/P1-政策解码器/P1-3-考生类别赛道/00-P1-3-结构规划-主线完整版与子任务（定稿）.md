## 〇、本系列在 P1 与既有内容中的位置（防重复，先讲清楚）

| 相关既有内容 | 覆盖了什么 | P1-3 怎么处理 |
|---|---|---|

| **问答专区 QA-001**《非深户可在深圳参加中考读高中吗》 | D类"能不能在深读" + **5个报名条件细节**（四平台已齐套） | P1-3 主线/子任务**只给"5条件入口 + 指向QA-001"**，不重写材料清单——细节让给 QA-001 |

> **P1-3 的独有增量** = 「**你站哪条赛道 → 这条赛道有多宽/多窄 → 分差在哪一层 → 现在该做什么**」的**全景决策**，而不是单点规则细节。

## 一、总则
- **母本**：`05-P1-3-AC类还是D类…-公众号-终稿.md`（约2500字，官方核验 22/22，⚠️推算项9处须按核验清单口径标注）。
- **两层结构**：① 主线完整版 = 从母本压成 **1 篇读者可见的完整单篇**；② 子任务 = 按"赛道/关卡"切 N 篇深挖。
- **命名（Q2）**：系列旗舰统一叫 **主线完整版**。**精简版/极简版** = 公众号主文的短变体（双方向交付物），不占旗舰名，也不产出在系列目录里（除非公众号按双方向需要时再出）。
- **平台分工（Q1，2026-09-06 修订）**：
  - **公众号 / 今日头条**：出主线完整版**文字旗舰**（头条含微头条 teaser）。
  - **抖音**：主线不出"内容总览/文字"，改为 **1 条"身份定位预告"视频**（互动向，只定位+预告，深度留给子任务），避免与子任务口播打架。
  - **小红书**：主线不出"文字长文"，改为 **1 套"全景长图卡"**（封面 + 若干张 1080×1440），作为**合集置顶/收藏锚点**；细节同样留给子任务。
  - 抖音/小红书的**深度发布单元 = 子任务**（逐条产 抖音口播 / 小红书图文）。
- **口径纪律（沿用 P1-2）**：完整版（公众号/头条长文）可用母本精确数字与区间（含"参考2026"口径）；短载体（微头条/抖音/小红书）只给结论性数字，不给推算区间、不展开表格。

## 四、产出顺序与节奏（Q6 · 运营目标倒推）

> **节奏依据**：运营落地方案（docs/14/01）阶段0·冷启动（现在–12月）核心 = 用内容密度为填报季积累粉丝/曝光。故 P1-3 不拉长温吞周更，也**不做单主题 7 天连发**；而是 7 天窗口快速铺完、与问答区/P2/P5 等**多主题每日轮换**——每平台每天有新内容、但主题每天不同。

**生产批次（7 天窗口先备后发）**
1. **主线完整版**：文字旗舰（公众号+头条长文+头条微头条），配图 1封面+2-3张核心图（Q4）；抖音预告视频/小红书全景长图卡同批备。
2. **S2 D类5条件自查**（材料有半年前置期，宜最早）→ **S3 AC/D 分差**（数据核心、先立口径）。
3. **S1 C类跨区**（决策增量高）→ **S4 D类三张牌**（出路）。
4. **S5 AC类别松懈** → **S6 4件事清单**（行动收口 + CTA + 预告 P1-4）。

**7 天发布窗口（示例排布，主题交错）**
| 天 | 主发 P1-3 单元 | 跨系列补位 |
|---|---|---|
| D1 | 主线完整版（公众号/头条）+ 小红书全景卡 + 抖音预告 | —（系列入口） |
| D2 | S2 D类5条件自查 | 补位 1 篇（问答区/P2/P5） |
| D3 | — | 补位 2 篇（ACD 断档，养推荐池） |
| D4 | S3 AC/D 分差全景 | 补位 1 篇 |
| D5 | S1 C类跨区 | 补位 1 篇 |
| D6 | S4 D类三张牌 | 补位 1 篇 |
| D7 | S5 AC类别松懈 + S6 4件事（收口） | 补位 1 篇，末尾预告 P1-4 |

> 各平台同日最多 1 条 P1-3 内容，其余用跨主题补位；发布走群发（非仅发布）。具体日期排期见 `00-P1-3-任务发布清单与登记表.md` §三。

### 2026-09-06 · 节奏修订（Q6 · 运营目标倒推）
**背景**：第一版建议 P1-3 拉长到 6-7 周，未扣住运营落地方案（docs/14/01）阶段0"为填报季积累粉丝/曝光"的核心矛盾。用户明确：内容供给 P1-P5 充足，发布进度应**由运营目标倒推、按运营数据动态调整**，而非由单系列内容排期倒推。
