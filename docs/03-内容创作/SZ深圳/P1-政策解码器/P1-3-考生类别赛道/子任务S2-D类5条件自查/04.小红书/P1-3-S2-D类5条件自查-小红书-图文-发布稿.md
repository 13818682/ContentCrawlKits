# P1-3 · S2 小红书图文

## 笔记标题（正文栏）
非深户D类想读深圳公办？5个条件先自查这3项

## 正文（约450字）
很多非深户家长以为孩子读不了深圳公办——**不对，满足5个条件就能报**。这篇帮你自查，重点看现在（9月）就要办的3样。📌建议收藏

⚖️ **5个条件（官方，缺一不可）**
· 父母一方：合法稳定职业 + 合法稳定住所
· **持深圳有效居住证**（别过期）
· **社保养老+医疗都缴，只需一个险种累计满3年**（补缴不计，截至当年8月31日）
· 孩子在深 **3年完整初中学籍**

📋 **现在（9月）先查这3项**
① 社保记录——满没满3年？断缴没？（最容易翻车）
② 居住证——过期没？过期赶紧续
③ 租赁凭证——租房家庭办没办？不是普通合同就行

⚠️ **提醒**：条件不全也能参加中考，但只限民办补录或中职注册入学，**读不了公办划线录取**。

✅ **一句话**：职业和学籍一般没问题，重点盯社保、居住证、租赁凭证——这三样要提前办、花时间，9月查一遍最从容。

（来源：深圳市教育局官方文件，人工核对，2026参考；完整材料清单见系列长文）
