# 非深户 D 类想读深圳公办高中？5 个条件缺一不可

很多家长以为"非深户不能读公办"——不对，是**满足 5 个条件就能报**，但材料要提前备：

- 父母一方有职业 + 住所
- **持有效居住证**（别过期）
- **社保养老+医疗都缴，只需一个险种满 3 年**（补缴不计）
- 孩子在深 3 年完整学籍

**现在（9月）最该查 3 样**：社保满没满 3 年、居住证过期没、租赁凭证办没办——这三样都要提前办、花时间，别等 3 月报名才手忙脚乱。

条件不齐也能参加中考，但只限民办补录或中职注册，**读不了公办划线录取**。
