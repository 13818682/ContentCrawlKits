# 非深户D类报考深圳中考：5个报名条件缺一不可

如果你家孩子是非深户（D类），想在深圳参加中考、报考公办高中——**5 个报名条件缺一不可，而且材料要提前准备**。别等报名前才翻箱倒柜，每年都有人因材料不齐手忙脚乱。

这篇给一张自查清单，重点讲现在（9 月）就该确认的 3 件事。（数据为 2026 年参考，2027 以当年公告为准。）

## 一、D类报考的 5 个条件（官方口径）

| # | 条件 | 需要什么 | 常见问题 |
|:---:|------|------|------|
| 1 | 合法稳定职业 | 父母一方在深就业证明 | 灵活就业可用社保记录辅助 |
| 2 | 合法稳定住所 | 租房需租赁凭证/自有房产证明 | 凭证报名前办好 |
| 3 | 持有深圳有效居住证 | 父母一方有效居住证 | 别过期，及时续签 |
| 4 | 社保（养老+医疗两险） | 两险都缴 | 只需一个险种累计满3年；补缴不计，截至当年8月31日 |
| 5 | 3年完整初中学籍 | 在深完成3年完整初中 | 转学手续要齐全 |

**关键提醒**：条件不全也能参加中考，但只限民办普高补录或中职注册入学，**不能参加公办普高划线录取**。

## 二、现在（9月）先自查这 3 项

**1. 社保满没满 3 年（最常翻车）**
要求是养老+医疗都缴、只需一个险种累计满 3 年。别到报名才发现断缴或其中一个险种不够 3 年——**现在拉一下社保记录数一数**。

**2. 居住证过期没**
有效居住证是必要条件，需按时续签。现在看一眼有效期，别到 3 月报名才发现过期。

**3. 租赁凭证/住所证明办没办**
租房家庭要**租赁凭证**（不是普通租房合同），报名前办妥。没办就现在去街道办/社区了解流程。

## 三、剩下 2 项怎么自查

职业与学籍通常问题不大：父母一方在深有正经工作即有职业；孩子在深读了 3 年初中即有学籍。重点盯上面那 3 项。

---

**一句话行动**：现在查三样——社保满没满 3 年、居住证过期没、租赁凭证办没办。这三样是要提前办、花时间的，越早越从容。
