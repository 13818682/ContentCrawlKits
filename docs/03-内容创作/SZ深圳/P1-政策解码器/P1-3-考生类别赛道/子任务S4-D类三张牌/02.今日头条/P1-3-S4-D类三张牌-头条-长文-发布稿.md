# 2026深圳中考：D类非深户孩子只能死磕公办？指标生、民办、3+4中本贯通，三张牌怎么选

非深户（D 类）孩子在深圳，是不是只能死磕公办普高？

先给结论：**不是。** D 类难，难在"约 54% 考生抢两成出头的公办名额、边缘段还要多考 15-23 分"；但 D 类的路不止公办一条——**指标生把竞争池变小，民办把录取线拉平，3+4 中本贯通直接换一条本科赛道。**这篇把三张牌讲全，含 2026 官方数字。

（数据口径：民办/3+4 数字来自深圳市教育局《2026年高中阶段学校招生计划》及第一批录取标准，人工逐条核对；D 类占比等推算口径标 2026参考。）

## 一、D 类难在哪：池子小 + 线更高

1. **池子小**：2026 年约 15.3 万考生里 D 类约占 54%（约 8.3 万），公办给 D 的名额约 18,506——一半以上考生抢两成出头公办名额（2026参考）；
2. **线更高**：公办边缘段（500-530）D 类普遍要比 AC 类多考 15-23 分（分差五层见系列上一篇）。

难在"全市 D 类混战抢少数公办名额"——**三张牌共同逻辑，就是不让你去挤那场混战。**

## 二、第一张牌：指标生——把"和全市比"变成"和同校比"

公办普高把相当一部分招生计划设成**指标生名额分配到各初中（名额到校），其中 D 类单列**。报同一所学校指标生的 D 类孩子，拼的是**本校 D 类同学位次**，不是全市 8 万 D 类一起抢。部分公办给 D 类的名额里，指标生占了大头——**"本校 D 类里排前"比"考过全市非深户"现实得多。**

- 适合谁：目标公办、孩子在校 D 类里排名靠前的；
- 现在做什么：①向学校确认本校 D 类指标生名额；②估孩子校内 D 类位次。名额怎么到校、降分怎么算，另文单讲。

## 三、第二张牌：民办高中——录取线上一视同仁的保底

官方口径很明确：**民办普高面向全市招收 ACD 类考生，一条线，不分 AC/D。**2026 年深圳民办普高 49 所、学位 33,195。同年录取线多数在 335 分一档，少数有分档：福桥高级中学 367、中澳实验学校 402、富源学校 429——**都远低于公办 D 类线**。

所以：D 类和深户孩子走**同一条民办线**，不存在"非深户要多考"；够不着公办 D 线的分数段，仍有一条上普高的路。三句实话：①**线低换学费高**，深圳民办普高学费普遍 3 万–15 万/年（细账见《普高和中职每年学费差多少》）；②多数民办贴线录取，但**办学口碑差异大**，选校看师资管理别只看好进；③**这是兜底不是首选**，经济扛得动、孩子愿意读普高再谈。

## 四、第三张牌：3+4 中本贯通——赛道外的本科直通

三张牌里**知道的人最少**的一张。

- **是什么**：中职 3 年 + 对口本科 4 年，毕业拿**全日制本科文凭**（应用型为主）。2026 深圳第一批试点：**6 所公办中职、8 个专业、共 300 人**。
- **录取口径**：全部**面向全市招收 ACD 类考生**——D 类能报，与 AC 类**同一张线**，不进公办 D 类那 23% 名额池。2026 录取线约 **517–548**。
- **对口本科**：深圳技术大学、深圳职业技术大学（深汕校区）、深圳信息职业技术大学、韩山师范学院。

它不挤公办那条路，用的是**中职批次自己的盘子**；300 个名额、第一批试点、多数家长还没反应过来——**信息差本身就是机会**。三句实话：①读的是**3 年职校**不是普高，先和孩子确认能否接受；②只有 **8 个专业**，要接受"窄"；③拿的是**应用型本科**（多为职业本科），与"考普通本科/985"是两条赛道，别被"本科"二字冲昏头。

## 五、三张牌怎么排

| 孩子的情况 | 先研究哪张 |
|---|---|
| 目标公办，校内 D 类排名靠前 | ① 指标生 |
| 够不到公办 D 线，家里扛得起学费 | ② 民办兜底 |
| 中低分段要本科文凭、能接受职校 | ③ 3+4 |

**三张牌不互斥**：指标生 + 民办、指标生 + 3+4 都能一起研究。

## 六、现在该做的一件事

确认三件事：①孩子校内 D 类大概位次（决定指标生硬不硬）；②家里民办学费预算线（决定民办能不能兜底）；③孩子愿不愿走 3 年职校（决定 3+4 是否选项）。再用 HSEE 小程序按"非深户 D 类"筛一遍目标校。

**一句话：D 类不是死胡同，是选择要比别人多想一层。**
