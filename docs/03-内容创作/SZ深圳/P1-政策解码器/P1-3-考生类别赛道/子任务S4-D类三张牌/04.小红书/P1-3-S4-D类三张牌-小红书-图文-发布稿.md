# P1-3 · S4 小红书图文（D类三张牌）

## 笔记标题（正文栏）
深圳中考：D类还有3条路：指标生/民办/3+4贯通

## 正文（约550字）
非深户（D类）孩子是不是只能死磕公办？上篇发过公办分差实测：500-530段 D 类普遍要多考 15-23 分。**数据是真的，但话不能只讲一半**——D 类还有 3 张牌，帮你绕开"全市非深户抢公办"那场混战👇 📌建议收藏

🃏 **① 指标生：把"全市比"变成"同校比"**
公办把名额按"指标生"分到各初中（名额到校），**D 类单列**。报同一所高中的 D 类孩子，拼的是**本校 D 类位次**，不是和全市 8 万非深户抢。
✅目标公办，先查：本校 D 类指标生名额 + 孩子校内位次。（名额怎么到校/怎么降分，之后单独讲）

🃏 **② 民办：一条 ACD 线，不分户籍**
2026 深圳 **49 所民办、33,195 学位**，录取"面向全市 ACD 类"同一条线——不存在"非深户要多考"。公办 D 线够不着的分数，这里也能上普高。
⚠️前提：学费普遍 3 万-15 万/年，**线低换的是学费高**；是兜底不是首选，办学口碑要挑。

🃏 **③ 3+4 中本贯通：赛道外拿本科**
职校 3 年 + 本科 4 年 = **全日制本科文凭**（应用型为主）。2026 深圳首批试点：**6 所公办中职、8 个专业、共 300 名额，D 类可报、ACD 同线**。知道的人还不多，**信息差=机会**。
⚠️ 3 年读的是职校、专业只有 8 个，先和孩子聊清路径。

✅ **三张牌怎么选**：
·目标公办 + 校内 D 类靠前 → 研究 **指标生**
·够不到公办 D 线 + 扛得起学费 → **民办**兜底
·要本科文凭 + 能接受职校 → 研究 **3+4**
（三张不互斥，可叠加一起排志愿）

一句话：**D 类不是死胡同，是把"分数线的焦虑"换成"三张牌的选择"。**
