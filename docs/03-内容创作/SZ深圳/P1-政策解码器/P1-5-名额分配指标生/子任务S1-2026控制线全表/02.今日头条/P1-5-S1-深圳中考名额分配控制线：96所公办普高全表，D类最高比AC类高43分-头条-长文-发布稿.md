# 深圳中考96所公办普高名额分配控制线全表：D类最高比AC类高43分

名额分配（指标生）能不能用，先看一条线：**名额分配录取控制线**。达不到，志愿直接无效。

但大多数家长不知道：**这不是一条线，是两条。** 同一所高中，AC类和D类各自一条。

把 2026 年深圳 96 所公办普高的控制线全部拉出来看，有三个结论。

## 一、AC 类：96 所的区间是 447 ~ 570

| 学校 | AC类控制线 |
|---|---:|
| 深圳中学 | **570** |
| 深圳实验学校（高中部） | 568 |
| 深圳市高级中学中心校区 | 567 |
| 深圳外国语学校 | 566 |
| 红岭中学 | 563 |
| 宝安中学（集团）高中部 | 562 |
| 育才中学 | 561 |
| 深圳大学附属中学中心校区 | 560 |
| 深圳科学高中 | 558 |
| 南山外国语学校（集团）高级中学 | 555 |
| … | … |
| **全表最低（8 所并列）** | **447** |

> 最低的 8 所是：深圳启元中学、深圳益新中学、深大附中盐田校区、深圳市第二高级中学宝安高中部、深圳理工大学附属中学、深圳市曙光中学（综合高中）、深圳创新高级中学（综合高中）、翠园中学（东门北路校区）。

## 二、关键：79 所的 D 类控制线高于 AC 类

这是全表里最该被看见的一组数：

| 学校 | AC类 | D类 | D − AC |
|---|---:|---:|---:|
| 深圳市第二高级中学深汕实验学校 | 454 | **497** | **+43** |
| 布吉中学 | 449 | **492** | **+43** |
| 龙华中学 | 459 | 501 | +42 |
| 沙井中学 | 459 | 500 | +41 |
| 平湖外国语学校 | 460 | 499 | +39 |
| 深圳中学 | 570 | 571 | +1 |
| 深圳实验学校（高中部） | 568 | 569 | +1 |

**96 所中：D 类更高 79 所 · 持平 13 所 · D 类更低仅 4 所。**

原因不复杂：D 类考生多、计划少，录取线本就高于 AC 类，因此控制线也更高。

**实际含义**：D 类考生走名额分配，**分数门槛比同校 AC 类考生更高**——头部学校只差 1~2 分，**中后段学校能差 40 分以上**。

## 三、三个使用要点

1. **它是资格线，不是录取线。** 达线只代表进入名额分配批次的**校内竞争**，能不能录还要看校内排名与名额数。
2. **与当年第一批录取线无关。** 手册原文：*名额分配录取控制线与该校当年第一批录取分数线无关，不能作为填报当年第一批次志愿的参考。*
3. **每校一条、逐年重算。** 2027 届的线要等 2027 年政策发布，现在只能用 2026 年做参考。

## 四、完整全表

96 所公办普高 AC 类 + D 类控制线，已按官方附件2 逐行转录，见**文末两张全表长图**（第 1–48 所、第 49–96 所，按 AC 类由高到低，金色 = D 类高于 AC 类）。

**给孩子定位时**：先确认类别（AC / D），再查**对应那一列**——别拿 AC 的线去对 D 类的孩子。
