# 深圳中考：你孩子初中分到几个名额？488 所里 163 所是 0 个

名额分配（家长嘴里的"指标生"），占深圳公办普高招生计划的 **50%**，**所有公办普高都参与**，单独批次、单独录取。

但名额**不是平均分到每所初中的**。这篇说清三件事：名额怎么分到学校、**你孩子学校能分几个**、**分到 0 个的学校怎么办**——最后一条最容易被漏掉，也最要紧。

## 一、名额怎么分到学校？按报名人数比例

手册原文：

> 分配原则以**各初中学校相应考生类别报名中考的考生数占全市该类别报名中考的考生数的比例**确定各初中学校的分配名额。

一句话：**按你孩子学校该类别报名人数的"份额"来分。**

所以结论很硬——**学校越大、同类别考生越多，名额越多**；学校越小，名额越少，甚至一个都没有。

**2026 年 AC 类的实测盘子**：

| 指标 | 数值 |
|---|---|
| AC 类名额总数 | **32,710 个** |
| 参与分配的初中 | **488 所** |
| 参与的高中 | 96 所 |
| 每校名额**中位数** | **45 个** |
| 最多的一所 | **888 个** |

**中位 45，最多 888，相差约 19 倍。** 这就是"名额跟学校走，不跟孩子走"的直接后果。

## 二、488 所里，163 所一个名额都没有

**163 所初中，AC 类名额是 0 个，占 488 所的 33.4%。**

拿深圳中学这一列看最直观：

| 初中 | 分到的深中名额 |
|---|---|
| 龙华区新华中学教育集团 | **11 个** |
| 深圳中学初中部 | 10 个 |
| 拿到 **0 个**深中名额的初中 | **163 所** |

拿到 10 个以上的，全深圳只有 **2 所**。

**如果文章到这里就结束，你会得出一个错误结论**——"我孩子学校没名额，这条路断了"。

**没有断。**

## 三、拿到 0 个，不等于没机会：区共享名额

手册第 8 问，专门回答了这件事。原文：

> **有。** 我市在确定名额分配计划分配办法时，遵循"以人为本、机会均等"原则，**对于按公式计算后分得名额为 0 的初中学校，以区为单位作为一个整体，重新按公式进行计算，这些学校的考生具备报考区共享名额的机会。**

拆开看，这条规则做了三件事：

1. 把"0 名额"的初中**以区为单位打包成一个整体**；
2. 对这个整体**重新按公式计算**；
3. 结果就是"**区共享名额**"——这些学校的考生**可以报考**。

**竞争范围变了。** 原来是在**本校**几十个孩子里排；0 名额的学校，变成在**全区**这一组学校里排。范围变大，但不是没有。

**这就是为什么"163 所一个都没有"这句话不能单说——它只是半句。**

## 四、怎么查你孩子学校？两个附件

| 想查什么 | 查哪里 |
|---|---|
| **名额分到各初中的具体数量**（你校几个） | 手册**附件 3** |
| 各高中名额分配**计划数**与**录取控制线** | 手册**附件 2** |

填报志愿前，手册明确要求考生**从附件 3 里查**学校的名额分配招生计划，以及各高中名额分配到各初中的具体情况。

## 五、控制线，一条容易被用错的线

名额分配的**录取控制线**算法是：

> 该校**前三年（2023—2025 年）相应招生类别录取分数线**（同比例换算为满分 630 分对应的分数）的**平均值下降 20 分**。

新建校某年没有本校线的，用该年份**全市公办普高同类别第一批最低线**来算。

⚠️ 手册专门提醒了一句：

> **各公办普高名额分配录取控制线与该校当年第一批录取分数线无关，不能作为填报当年第一批次志愿的参考。**

**这条线只管名额分配批次，别拿去填第一批。**

**投档规则**是"**分数优先，依照志愿顺序**"：达到控制线、且该生所在**初中（或所在区）**的名额计划还没录满，就投档成功；总分相同则走"同分比较"。

另外，**省一级公办普高**录取的名额分配生，**语、数、英、物理与化学、历史、道法单科等级须在 C+ 以上（含 C+），体育单科等级为 C 以上（含 C）**。

## 六、收口：两个最容易搞混的机制

### 1. 名额分配志愿与第一批次，**相互独立**

- 名额分配志愿**只能填 1 所**公办普高；
- 它**仅作为录取该校名额分配的依据**；
- **想读这所学校的普通生计划，第一批次必须再填一次该校。**

**这就是"双保险"的准确含义**——两个批次各填一次，不是填一次管两处。

### 2. 名额没用完，分两种，后果完全不同

| 谁没录满 | 后果 |
|---|---|
| **各初中学校**未完成的名额分配计划 | **自动失效** |
| **各公办普高**未完成的名额分配计划 | **自动转为普通生计划，在第一批次录取** |

**主体不同、后果不同，千万别并成一条记。** 初中没录上的名额是"作废"，高中没录满的名额是"转回第一批"。

## 七、给家长的 3 件事

**① 先去附件 3 查你孩子学校的名额数。** 是 45 个还是 0 个，直接决定策略。

**② 如果是 0 个，别放弃——找区共享名额。** 手册第 8 问已经写明这条路。范围从本校变成全区，但路是通的。

**③ 想读某校，第一批次记得再填一次。** 名额分配志愿不能替代第一批志愿。
