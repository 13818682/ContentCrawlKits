**你孩子初中分到几个指标生名额？488 所初中里，163 所是 0 个。**

先别慌——官方给了出路。往下看第三条。

**一、名额怎么分到学校的？** 不是平均分。手册写得很清楚：按**各初中相应考生类别报名中考的人数，占全市该类别报名人数的比例**来分。所以**学校越大、同类别考生越多，名额越多**。

2026 年 AC 类一共 **32,710 个**名额，分到 **488 所初中**。中位数是 **45 个**，最少的 0 个，最多的一所拿了 **888 个**。

**二、163 所初中，一个名额都没有。** 占 488 所的 **33.4%**。

拿深圳中学这一列看最直观：最多的龙华区新华中学教育集团分到 **11 个**，而 **163 所初中是 0 个**。

**三、⭐ 但是——0 个不等于没机会。** 手册第 8 问原文：

> "对于按公式计算后分得名额为 0 的初中学校，**以区为单位作为一个整体，重新按公式进行计算，这些学校的考生具备报考区共享名额的机会**。"

换句话说：**本校没有名额，就转去区里的共享名额池**。路径还在，只是竞争范围从"本校"变成了"全区"。

**四、怎么查你孩子学校？** 名额分到各初中的具体数量在手册**附件 3**；各高中的名额分配**计划数和录取控制线**在**附件 2**。

**五、填的时候记住两条：**
① 名额分配志愿**只能填 1 所**公办普高；
② 它**与第一批次相互独立**——想读这所学校的普通生计划，**第一批次还得再填一次**。
