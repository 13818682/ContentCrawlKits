# 你孩子初中分到几个名额？488 所里 163 所是 0 个（但还有一条路）

**名额分配（"指标生"）占公办普高计划的 50%，所有公办普高都参与。但它不是平均分到每所初中的。**

这篇四张图讲完：怎么分 / 你校几个 / **0 个怎么办** / 填之前记住什么。

---

## 正文（可直接复制）

```
你孩子初中分到几个指标生名额？先看一组数。

2026 年 AC 类名额一共 32,710 个，分到 488 所初中。
中位数是 45 个，最多的一所拿了 888 个。
——而 163 所初中，是 0 个。占 33.4%。

为什么差这么多？因为名额不是平均分，是按比例分的：
各初中相应类别报名中考的人数 ÷ 全市该类别报名人数。
所以学校越大、同类别考生越多，名额越多。

拿深圳中学这一列看最直观：最多的龙华区新华中学教育集团 11 个；
拿到 10 个以上的，全深圳只有 2 所；163 所是 0 个。

但——0 个不等于没机会。手册第 8 问原文写着：
「对于按公式计算后分得名额为 0 的初中学校，以区为单位作为一个整体，
重新按公式进行计算，这些学校的考生具备报考区共享名额的机会。」

也就是说：本校没名额，就转去区里的共享名额池。
竞争范围从「本校」变成「全区这一组学校」——范围变大了，但路是通的。

怎么查你孩子学校？手册附件 3 查名额数，附件 2 查各高中的计划数和控制线。

填之前记住两件事：
① 名额分配志愿只能填 1 所公办普高；
② 它与第一批次相互独立——想读这所学校的普通生，第一批次还得再填一次。

家里有初中生的，先点个关注。这一系列我拆开讲，主页合集里按顺序排好了。
```
