# P1-5-S2 抖音口播（学籍资格）

> **分镜铁律**：首帧必须是**反差 / 数字断言**。**禁止**"你是A、C还是D"「一篇讲透」式分类开场（09-08 诊断出的留存杀手）。
> **安全区**：1080×1920，内容 ≤ x950 / y1590（右侧留 1/10 图标区、底部留 1/6 字幕区）。

## 镜头 01 · 钩子（0–3s）

**画面文字**
```
（顶部标签）S2 · 学籍自查
指标生资格：
初中三年 6 个学期
中间转过一次就没了
卡片：不是看分数 ／ 是看学籍
底行：指标生资格，初中三年不能转学
```
**口播**
> 指标生能降分录取。但有的孩子，不是输在分数上——是初中三年中间转过一次学，资格就没了。

> ⚠️ **首帧判断题**：本帧是**数字断言 + 反差**（"6 个学期"是数字，"转过一次就没了"是反差），**不是**分类开场。通过。
> ⚠️ **定性前缀（用户 2026-09-18 要求）**：主题文字前必须带 **「指标生资格：」**——否则"初中三年 6 个学期／中间转过一次就没了"会被误读为普遍校规，而非**指标生资格**的限定条件。**此为跨平台硬要求，此后所有抖音首帧、公众号封面一律适用。**

## 镜头 02 · 资格是三条（3–16s）

**画面文字**
```
名额分配（指标生）资格
必须同时满足 3 条

① 应届初中毕业生
② 参加本市当年中考
③ 从初一第一学期起
   一直在报名校就读
   且取得该校三年学籍
```
**口播**
> 手册写明，名额分配资格要同时满足三条：应届毕业生、参加本市中考、从初一第一学期起一直在报名所在初中就读，并且取得该校三年学籍。前两条大多天然满足，卡人的是第三条。

## 镜头 03 · 四种不成立（16–34s）

**画面文字**
```
这 4 种，都不算

✕ 初一才转进来
✕ 初三转出去
✕ 初二转过一次学
✕ 在市内跨校转学
```
**口播**
> 注意第三条要的不是"读过"，是"一直在"。初一才转进来的，不算；初三转出去的，不算；初二因为搬家转过一次学的，不算；在深圳市内跨校转学的，不管哪个学期，换了初中就断。

## 镜头 04 · 为什么卡这么严（34–46s）

**画面文字**
```
为什么要卡这么严？

防止两种现象：
· 投机性非正常转学
· 学籍与就读分离（挂读）
```
**口播**
> 还有一种更隐蔽的——学籍在一所学校，人却在另一所读，也就是挂读。手册专门解释了：卡这么严，就是为了杜绝投机性转学和挂读，维护招生公平。

## 镜头 05 · 为什么现在就要查（46–58s）

**画面文字**
```
为什么不能等初三？

资格是三年攒出来的
初三补不回来
```
**口播**
> 这件事必须现在查。因为资格是三年一点一点攒出来的，初三补不回来。等初二下学期才发现孩子中途转过学，已经无法回头了。

## 镜头 06 · 现在做两件事（58–68s）

**画面文字**
```
现在做 2 件事

① 向初中学校核对
   入学时间 + 有无转学记录
② 留意学校资格公示

转给初一初二的家长
```
**口播**
> 现在就做两件事：一是向孩子初中学校核对自己的入学时间和有没有转学记录；二是留意学校的资格公示——名单里没有你家孩子，就要立刻去问。这条转给身边初一初二的家长，还来得及。
