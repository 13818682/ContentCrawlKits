# 为什么这个脚本被弃用

`_build_p14_s4_all.py` 的 `BASE` 指向**子任务根目录**，没有平台子目录 —— 跑它会往 S4 根目录倒废图，
而 `01.公众号/ 02.今日头条/ 03.抖音/ 04.小红书/` 里的真图**一张都不会更新**；
而且它每张都打印 `OK`（`check()` 打开的是仍然存在的旧文件）。

这与 S2、S3 目录里已废弃的 `_build_p1X_sX_all.py` 是**同一个缺陷**（第 3 次出现）。

# S4 的正确生成器（都在 P1-4 根目录）

| 脚本 | 产出 |
|---|---|
| `_build_p14_dyxhs_rich.py S4` | 抖音 6 分镜 + 小红书封面/正文图1-4 |
| `_fix_tt_covers.py` | 头条 3 图封面（跑全量） |
| `_fix_gzh_covers.py` | 公众号封面（跑全量） |
| `_p14_dyxhs_family.py` | 版式模板库（被上面第一个 import） |

版式参数见记忆 `cover-layout-spec`。
