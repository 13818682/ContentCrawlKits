# P1-4 投档规则全解 · 单篇详版大纲

> **定位**：P1 系列"发动机"，规则地基。用 3 个模拟案例让家长看清录取系统运转。
> **写法原则（14 号定稿）**：单篇专业详实、分节给结论；**不复杂到家长看不懂**；需个性化/动手验证的部分 → 文末引 HSEE"模拟志愿填报"承接。
> **与 P4-1 错位**：P1-4 讲**规则机制**（系统怎么运转）；P4-1 讲**填报操作**（家长怎么填）。本篇不发操作清单。
> **数据**：现有 05 终稿已核验 20/20（五批次表/三案例/四错误/走读决策表/保存确认），口径与 S6 一致（生地合卷100、同分先生地后语数英）。

## 一、单篇详版结构（公众号/头条，约 2600-3000 字）

| 章 | 内容 | 关键点（给结论） |
|---|---|---|
| 导语 | 为什么投档是"发动机" | 不懂投档=闭眼开车；用 3 案例看清系统 |
| 1️⃣ 五批次录取 | 表：五批次×志愿数×录了/没录会怎样 | **一句铁律**：前批录了后批全作废——不退档不转录 |
| 2️⃣ 分数优先·志愿顺序 | **案例一** 分数优先：高分不被低分挤掉<br>**案例二** 志愿顺序：600分也可能去不了最想去的<br>**案例三** 同分PK：生地定胜负 | 排序→按志愿顺序检索→第一个有空位就录取；想去的放最前（非"第1志愿有加分"，是顺序检索） |
| 3️⃣ 四个最容易犯的投档错误 | 错误一 不退档还乱填 / 错误二 扎堆同分段 / 错误三 第1志愿填保底 / 错误四 乱勾走读 | 每个=错误做法→后果→真实案例→正确做法 |
| 4️⃣ 走读调剂决策表 | 勾选逻辑 + 5 种情况决策表 | 只在单程≤45min 且能接受走读才勾；锦上添花非雪中送炭 |
| 5️⃣ 保存≠确认 | 3 次确认机会 / 6月1日18:00截止 | 操作级致命错误 |
| 结尾 CTA | **引 HSEE"模拟志愿填报"** | 看懂规则最好方式=亲手试一次 |

## 二、HSEE 承接点设计（关键——把"复杂"交给小程序）

家长看完规则后最需要的不是更多文章，而是**拿自己的分数/志愿试一次**。HSEE 承接点：

| HSEE 功能 | 承接本文什么 | 话术（文末 CTA） |
|---|---|---|
| **模拟志愿填报** | 3 案例的"动手版"：家长输自己 16 志愿+预估分 → 系统演示会录到哪 | "用今天学的规则试着排一次，看系统会怎么处理你的选择" |
| **历年分数线查询** | 案例里 A/B 校分数 → 家长查自己目标校真实线 | "查你目标校近 4 年 AC/D 线" |
| 同分 PK 规则(数据卡) | 案例三同分 → 已并入 S6，本篇引用即可 | 不强引，避免重复 |

**承接原则**：本篇只讲清"机制 + 给结论"；凡要"个性化试算/查自己学校数据"→ 一步引 HSEE，不在文内堆表格公式。
