# 深圳中考630分，一篇讲透：构成、三大变化、等级、隐形战场

先说结论：深圳中考满分630、考8科。很多家长"知道630"，却说不清这630每一分从哪来、2026年规则动了哪三处、孩子时间该先给哪科。本文一篇讲透，数字都能对得上账。

先立一根记住全篇的线：**630 ＝ 主科笔试 440 ＋ 理化实验 20 ＋ 历史·道法·体育 170。**后面每一节都从这句展开。

## 一、630 分怎么构成：8 科，一分不差

| 科目 | 满分 | 关键信息 |
|------|:---:|------|
| 语文 | 120 | 闭卷120分钟；作文50分，阅读+作文是拉分关键 |
| 数学 | 100 | 闭卷90分钟；区分度最大，压轴大题定 A+ 还是 A |
| 英语 | 100 | 笔试75＋听说25；听说5月人机单独考，练熟可提前锁分 |
| 物理+化学（合卷） | 140 | 笔试120＋实验操作20；物、化实验各考10分钟 |
| 历史 | 70 | 闭卷60分钟 |
| 道德与法治 | 50 | 50分钟，2026年起**开卷** |
| 体育与健康 | 50 | 过程评价14＋现场考试36 |
| **合计** | **630** | **语数英物化笔试＝440，占总分约70%** |

**结论**：语数英物化（笔试部分）440分占总分约70%——上公办还是民办、四大还是八大，基本由这五科决定；史道体加实验合计190分，在480–530的中等段，常常就是"谁上普高"的分水岭。一句话记住：**主科定你站哪档，副科别拖后腿。**

## 二、2026 三大变化：规则变了，动作也要跟着变

**变化一：理化实验操作涨到 20 分。** 物化合卷里的实验操作，从12分涨到20分（净增8分），占物化比重由约8.6%提到约14.3%。这8分是纯操作分——刷题刷不出来：物理、化学各做一个实验，现场动手，每一步都计分。平时"看同学做、抄报告"的孩子，这20分可能丢掉一半以上。**该怎么做**：初三上学期就把实验当主科抓，每节实验课练操作规范；物理重点练电路的连接与测量，化学重点练气体的制取与检验、物质的鉴别与分离。

**变化二：道德与法治改开卷。** 以为"开卷=更简单"是最大误区。开卷后出题方向从"考你记住了什么"变成"考你理解了什么、会不会用"——更灵活综合，书上抄不到现成答案；50分钟，题题翻书根本做不完。**该怎么做**：反而更要搭知识框架——知道每个知识点在书的哪个位置，比死记硬背更重要。帮孩子做一份"快速索引目录"贴在书前面。

**变化三：体育从"考一次"变成"攒三年"。** 总分仍是50，但结构改了：过程评价14分（初一就开始累积）＋现场考试36分（4月考，耐力、技能、球类各选1项，共3项，此前现场为2项）。**该怎么做**：已经初三的孩子，前两年过程分已进档案——确认分数就好，别再纠结。关键是现在就把现场3项定下来（如耐力跑/游泳、引体向上/跳绳/仰卧起坐、篮球/足球/排球），每周至少3次规律训练——体育突击不了一个月。

## 三、单科等级：比分数更准的"全市定位"

每科除了分数，还按全市固定比例给一个等级：

| 等级 | 占全市考生比例 | 含义                           |
| :--: | :------------: | ------------------------------ |
|  A+  |      前5%      | 单科全市顶尖——这门课是你的王牌 |
|  A   |    前5%~25%    | 单科优秀——稳定输出             |
|  B+  |   前25%~50%    | 中等偏上——不拖后腿             |
|  B   |   前50%~75%    | 中等——有一定提升空间           |
|  C+  |   前75%~95%    | 偏下——需要重点关注             |
|  C   |      后5%      | 较弱——必须补短板               |

为什么等级比分数靠谱：试卷难易年年变——去年数学90是A+，今年90可能只是A；等级比例固定，**A+永远代表全市前5%**，用它看孩子的相对位置，比看裸分更准。

省一级学校门槛：报考省一级公办普高（深圳多数公办普高都是），要求**所有科目 C+ 及以上、体育 C 及以上**——换句话说，**任何一科都不能掉到 C**。

## 四、不计总分、却能定生死的"隐形战场"

**生物地理（合卷，初二已考完）**：满分100，不计入630，只在"同分PK"时第一个比。真实案例：2026年某区属高中最后一个学位，两名考生总分同为552分，生地96分的被录取、82分的落榜——**同分差14分，就是差一个学位**。若孩子生地不到85分：不用过度焦虑——只有总分完全相同才轮到比生地；真走到那一步，第二层再比语数英总分，主科分高仍能对冲。

**信息科技与艺术**：同样不计入 630，目前也不是省一级的录取门槛（官方口径：报考省一级须"综合素质评价达标"，详见 S5 单科等级篇）。深圳市教育局拟从 2025 年 10 月起把这两科逐步纳入初中学业水平考试（面向 2027 届起、学校自行命题、成绩不计入中考总分）——属政策趋势，家长按学校安排正常参加即可，不必额外焦虑。

## 五、初三这一年，精力怎么分（给2027届）

| 优先级 | 科目 | 动作 |
|:---:|---|---|
| 🔴 最高 | 语文·数学·英语 | 主战场，黄金时间先给；薄弱科重点突破 |
| 🔴 最高 | 物理+化学（实验操作） | 抓住每节实验课，操作规范烂熟于心 |
| 🟡 重要 | 体育 | 现在定3项，每周≥3次训练 |
| 🟡 重要 | 道德与法治 | 搭知识框架＋快速索引（开卷生命线） |
| 🟢 保持 | 历史 | 跟学校节奏，考前集中背效率最高 |
| ⚪ 已定 | 生物地理 | 已考完，确认分数、心里有数 |

**总纲一句话**：主科优先、实验跟练、副科稳住，两个门槛（单科等级不掉C＋综合素质评价达标）心里有数。
