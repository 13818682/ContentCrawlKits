# S3 · 头条微头条（数字式）

深圳中考有一门课，2026 年变成了**唯一能带纸质材料进考场的笔试科目**：道德与法治改开卷。

先别当"送分"，记住三点：
· 它**50 分、50 分钟都不变**，变的只有考法——从考记忆变考理解与用材料；
· 它**书上抄不到现成答案**，每道题都翻书，50 分钟根本做不完；
· 它能带**教科书等纸质材料**，但手机、电子存储设备不能带——官方还辟谣过"只能带教材"是假的。

孩子真正要练的，是**给书做索引、3 秒找到考点**——开卷的胜负，在考前就定了一大半。

你家孩子觉得道法开卷是送分，还是更慌？评论区聊聊。
