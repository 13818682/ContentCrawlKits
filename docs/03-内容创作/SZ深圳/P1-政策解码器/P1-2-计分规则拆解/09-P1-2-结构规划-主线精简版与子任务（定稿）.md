# P1-2 结构规划（主线精简版 + 子任务）定稿

## 一、总则
- **母本**：`05-P1-2-630分怎么来的…-公众号-终稿.md`（约2400字）。全 P1-2 内容都从它派生。
- **两层结构**：① 主线精简版 = 把全文压成 1 篇**完整版**；② 子任务 = 按主题切 N 篇深挖。
- **平台分工（Q4，2026-09-04 定）**：大长篇只在**公众号 / 今日头条**出完整内容版（头条含微头条 teaser）；**抖音 / 小红书不产"大总览"**——单条装不下、且与子任务重复，改为**拆成子任务、逐条产「文案+图片」**。故 `主线精简版/` 只落公众号＋头条两平台；抖音/小红书的 P1-2 发布单元 = 各子任务目录（S1 已四平台铺开，S2–S6 各自产抖音口播/小红书图文）。
- **口径纪律**：**完整版（公众号/头条长文）**按母本可用"实验从12分涨到20分（+8分）、比重约8.6%→14.3%"（母本完整表·人工复核）；**短载体（微头条/抖音/小红书）**只写"2026 理化实验涨到 20 分"，不引用原分值。8科分值做成**可对账口径**（440笔试＋20实验＋170史道体=630，见 S1 新版本）。
- **与旧结构关系（Q3）**：顶层 `01.公众号 / 02.今日头条 / 03.抖音 / 04.小红书`（旧思路全量）与顶层 01–08 创作记录**保留并存**，本轮只增不改不删；两套以"父目录名不同"区分。
