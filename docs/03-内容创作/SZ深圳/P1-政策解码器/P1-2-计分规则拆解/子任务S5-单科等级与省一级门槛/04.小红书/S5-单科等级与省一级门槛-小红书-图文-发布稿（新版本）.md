## 笔记标题（正文栏）
中考别让任何一科掉C：省一级的隐形门槛

## 正文（约450字）
深圳中考每科除了分数，还会给一个**单科等级**（A+/A/B+/B/C+/C）。很多家长只盯总分，忽略了这六级里藏着一个能"卡录取"的门槛——**想被省一级公办普高录取，不能有任何一科掉到 C**。这篇收藏，帮孩子守住这一科。

📊 **等级怎么划**
· 按**单科原始分**、全市比例切：A+前5% → A前5-25% → B+25-50% → B50-75% → C+75-95% → C后5%；
· **卷子难不难不影响比例**——A+永远是全市前 5%，比绝对分数更能定位孩子位置。

🚪 **那个"隐形门槛"**
· 报**省一级学校**：综合素质评价须"**达标**"（多数孩子都能过）；
· 想被**省一级公办普高录取**：语数英物化历史道法单科须 **C+ 以上**、体育 **C 以上**；
· ⚠️ **总分够线不算数**——有一科掉 C，就不符合录取资格。

🔍 **最容易误判的 3 点**
① 等级是**单科卡线**，不是总分卡线——总分 560 但数学掉 C 也没用；
② 最易悄悄滑到 C 的是**历史、道法**这类"背多分"科目，别让它当"老鼠屎"；
③ **体育反而最宽松**：门槛只要 C 以上（不垫底就行）。

📋 **现在（初三上）做三件事**
① 把最近一次大考**单科等级**拿出来，标出每一科位置；
② **先补"接近 C 的那一科"**，别把时间全给最爱的科；
③ 问学校**综合素质评价**是否达标、有无材料要补。

✅ **一句话**：用单科等级给孩子定位——省一级的门槛卡的就是"接近 C 的那一科"，别让总分好看、栽在一科上。

（数据据《2026年深圳市高中阶段学校考生报考指导手册》（等级比例见"考试安排及要求"、省一级资格见 FAQ-8）整理，人工核对；综合素质评价与录取资格以深圳市招考办当年发布为准。）
