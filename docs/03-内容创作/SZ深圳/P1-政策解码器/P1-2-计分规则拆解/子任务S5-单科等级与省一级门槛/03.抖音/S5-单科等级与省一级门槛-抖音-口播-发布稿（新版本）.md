# S5 · 抖音口播（答案前置版）

## 口播脚本
**（开头大字·前3秒）** A+，永远是前 5%。
**（Hook 0-3秒）** 深圳中考每科除了分数，还会给你一个单科等级，A+、A、B+、B、C+、C。别小看这个等级——它藏着一个能"卡录取"的门槛，很多家长到填志愿才发现。
**（主体·等级机制）** 等级是按单科原始分、全市比例划的：A+永远是前 5%，A 是前 5% 到 25%，一路到 C 是后 5%。卷子难不难，不影响比例——所以看等级，比看绝对分数更能定位孩子位置。
**（主体·门槛）** 关键在这：想被省一级公办普高录取，语文数学英语物理化学历史道法，单科等级得在 C+ 以上，体育 C 以上。**总分够线不算数，有一科掉到 C，就不符合录取资格。**
**（怎么练）** 最容易悄悄掉 C 的，反而是历史、道法这些"背多分"科目。现在该做的：把最近一次大考的单科等级拿出来，哪一科在 C 边缘，就优先补哪一科，别让总分好看、栽在一科上。
**（CTA）** 你家孩子有没有哪科在 C 边缘？评论区聊聊。关注我，下一条讲 P1-2 收官篇：生地同分 PK 和两门"入场券"。
