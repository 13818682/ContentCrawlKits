# S5 · 头条微头条（数字式）

深圳中考每科除了分数，还划一个**单科等级**——它藏着一个能"卡录取"的门槛。

记住三点：
· **A+ 永远是全市前 5%**：等级按单科原始分、全市比例切，卷子难不难不影响——比绝对分数更能定位孩子位置；
· **省一级公办普高录取要卡等级**：语数英物化历史道法须 **C+ 以上**、体育 **C 以上**——总分够线，有一科掉 C 也不符合条件；
· **最易悄悄掉 C 的，是历史、道法**这类"背多分"科目，别让它成那颗"老鼠屎"。

现在（初三上）就做：把最近一次大考的单科等级拿出来，**先补"接近 C 的那一科"**。

你家孩子有没有哪科在 C 边缘？评论区聊聊。
