# 单科等级：比分数更准的"全市定位"，也是省一级的隐形门槛

深圳中考成绩，除了具体分数，每科还会给一个**单科等级**（A+/A/B+/B/C+/C）。很多家长只看分数，忽略等级——但这六级里藏着一个直接影响录取的门槛：**想被省一级公办普高录取，不能有任何一科掉到 C**。

这篇讲清楚三件事：等级怎么划、为什么比分数更靠谱、以及那个"掉 C"的门槛到底卡在哪。

## 一、等级怎么划：按单科原始分，全市统一比例

单科等级根据每科的中考原始分划定，**按全市考生的比例切分**，与试卷难不难无关：

| 等级 | 占全市考生比例 | 一句话含义 |
|------|:---:|------|
| A+ | 前 5% | 单科全市顶尖 |
| A | 前 5%~25% | 单科优秀 |
| B+ | 前 25%~50% | 中等偏上 |
| B | 前 50%~75% | 中等 |
| C+ | 前 75%~95% | 偏下，需留意 |
| C | 后 5% | 该科全市靠后 |

**为什么等级比分数更靠谱**：试卷难度年年变——去年数学 90 分可能是 A+，今年 90 分可能只是 A。但比例是固定的：**A+ 永远是全市前 5%**。用等级看孩子的相对位置，比看绝对分数更稳，也不会被"今年题简单、分数虚高"骗到。

> 一个特殊规定：如果某科满分人数超过全市考生 5%，则所有满分者都算 A+，后面等级的比例相应顺延扣减。这是极特殊情况，但家长要理解等级"看排名不看卷面"的本质。

## 二、那个"隐形门槛"：省一级公办普高的录取资格

这是单科等级最关键的应用。按官方报考问答口径：

1. **报考省一级学校**（含民办、含名额分配批次）：综合素质评价结果须为"**达标**"——这一条绝大多数孩子都能过；
2. **想被省一级公办普高录取**：语文、数学、英语、物理与化学、历史、道德与法治的单科等级须在 **C+ 以上（含 C+）**，体育须在 **C 以上（含 C）**。

**这意味着什么**：省一级公办普高（深圳绝大多数好高中都在这一档）录取时，会卡单科等级。**哪怕总分够线，只要有一科掉到 C，就不符合录取条件**——这是很多家长到填志愿才知道的坑。

## 三、最容易误判的 3 个点，先自查

1. **"总分高就稳"是误区**：等级是单科卡线，不是总分卡线。总分 560 但数学掉到 C，报省一级公办普高就是不合规；
2. **"掉 C 的科目"容易被忽视**：语文数学大家盯得紧，反而**历史、道法**这类"背多分"科目，一旦放松、全市排名滑到后 5%，就成了那颗"老鼠屎"；
3. **体育单独放宽**：省一级门槛里，体育只要 C 以上就行——体育的"最低要求"反而是所有科里最宽松的（门槛只要求不垫底）。

## 四、现在（初三上）能做的三件事

1. **定位孩子每一科的位置**：别只看分数，把最近一次大考的**单科排名/等级**拿出来——哪一科在 C 边缘，哪一科就是省一级门槛的隐患；
2. **优先补"边缘科"，不是"最爱的科"**：目标省一级公办普高的孩子，把时间先给"接近 C、可能掉 C"的科目，别让它到中考滑到后 5%；
3. **确认综合素质评价达标**：问学校是否正常完成、有没有需要补的材料——这条不达标，报省一级连门槛都进不去。

> 家长别做的一件错事：觉得"孩子总分还行，个别科差一点没关系"。深圳中考等级是**单科独立划线**，一科掉 C 就够不上省一级公办普高的录取资格——总分再好看也补不回这一科。

**一句话行动**：用单科等级给孩子定位，把"接近 C 的那一科"当首要补强对象——省一级的门槛，卡的就是这一科。
