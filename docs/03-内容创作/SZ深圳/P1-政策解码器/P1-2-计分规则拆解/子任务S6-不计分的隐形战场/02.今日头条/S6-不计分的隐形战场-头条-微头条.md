# S6 · 头条微头条（数字式）

深圳中考有一门课**不计入 630 分，却可能决定录取**：生物与地理合卷。

记住三点：
· **同分先比生地**——总分相同，官方先比生地合卷分，高者先；生地相同才轮到语数英；
· **生地分已定格**——初二下就考完了，语数英补不回来这道 PK 优势；
· **举个例子**：同分 552，生地 96 的先录、生地 82 的落选——同分之下，这就是一道分水岭。

现在能做的：**确认生地成绩没记错**，再把总分目标设得比心仪学校往年线高一点，尽量别进同分 PK 区。
