# 微头条 · 同样的复习时间，花在哪门课最划算？

深圳中考630分，不是每1分都一样的——**同样的时间砸下去，涨分能力差别很大**。

主战场：**语数英物化=440分**，决定公办民办，全力投入。

性价比王：**理化实验2026涨到20分**，新增8分靠动手练就能拿，刷题反而拿不到。

稳住即可：**历史+道法+体育170分**（70/50/50），别让副科挤占主科时间。

中等生最该做的：把时间从历史题海挪到数学大题和物化实验上——涨分更快、更确定。
