# 微头条 · 看分数会看走眼，看等级不会

深圳中考每科除了分数，还按全市固定比例给一个**等级**——试卷难易不影响等级。

**A+永远是全市前5%**，再看A（前5-20%）、B+、B，一直到C+。

记住这条硬门槛：**报省一级学校，所有科目要 C+ 及以上**（体育C即可）——**任何一科掉到C，连报名的资格都没有**。

分数会骗人，等级不会。哪科在C边缘，哪科就是门槛隐患。

建议现在翻出最近一次大考的单科等级，对照查一遍。
