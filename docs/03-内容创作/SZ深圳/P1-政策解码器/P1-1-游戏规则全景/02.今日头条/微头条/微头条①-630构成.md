# 微头条 · 深圳中考 630 分，怎么构成的？

深圳中考总分630，**语数英物化五科 = 440分，占总分70%——主战场**。

历史+道法+体育 = 170分，中等分段这170分可能决定公办还是民办，别当"副科"。

两个2026年变化划重点：**实验操作从12分涨到20分**；**道法改为开卷**（会抄书≠能得分）。

每1分都有它的位置。目标学校差几分，现在就对应到具体的科目去补。
