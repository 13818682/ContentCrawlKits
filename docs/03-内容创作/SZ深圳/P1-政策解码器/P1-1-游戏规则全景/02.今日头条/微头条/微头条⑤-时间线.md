# 微头条 · 从报名到录取，整整6个月

深圳中考不是6月那2.5天的考试——**3月报名到8月录取，整整6个月**：

- **3月** 中考报名（D类5项材料提前备齐）
- **4月** 体育中考（36分现场）
- **5月** 实验操作20分 + 英语听说25分
- **5月下旬** ⚠️ **志愿填报——全年最重要10天！**（2026为5.23-6.1）
- **6月** 自主招生报名 + 文化课考试（6.26-28）
- **7月16日** 成绩公布
- **7-8月** 分批录取 → 8月录取结束

5个关键节点错过不能回头（报名、体育中考、志愿填报、自招报名、补录）。**志愿填报那10天，是全年最重要的决策窗口**——需要的数据和策略，出分前就能备好。
