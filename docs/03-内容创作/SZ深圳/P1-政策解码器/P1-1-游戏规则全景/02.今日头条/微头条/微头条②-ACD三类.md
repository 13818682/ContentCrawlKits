# 微头条 · 深圳中考考生分 ACD 三类，你站哪条赛道？

深圳中考把考生分三类：

- **A类**（深户+学籍同区）：最宽赛道，所有学校都能报
- **C类**（深户+学籍跨区）：部分学校有跨区限制
- **D类**（非深户）：占考生一半以上，**公办普高指标仅约23%**

D类家长重点记三条：四大名校ACD已持平（深中592/592）；中下层次D类分数线高5-15分；**指标生已覆盖D类——最重要的降分通道**。

信息准备对D类家长更加重要，别用分数去硬扛信息差。
