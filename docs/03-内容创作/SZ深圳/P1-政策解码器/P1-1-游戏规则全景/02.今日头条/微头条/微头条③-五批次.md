# 微头条 · 录取分五个批次，前一批录了后面全作废

深圳中考录取按五个批次依次进行：

- **自主招生批**（1个志愿）
- **名额分配批**（1个志愿，指标生）
- **统一招生第一批**（16个志愿，普高≤12+中职≤4）
- **统一招生第二批**（18个志愿，本市中职技校）
- **统一招生第三批**（6个志愿，外省市中职）

**关键规则只有一条：前一批被录取，后面全部作废——不退档、不转录。**

所以每个批次的志愿都要慎重，别填"录了也不想去"的学校。
