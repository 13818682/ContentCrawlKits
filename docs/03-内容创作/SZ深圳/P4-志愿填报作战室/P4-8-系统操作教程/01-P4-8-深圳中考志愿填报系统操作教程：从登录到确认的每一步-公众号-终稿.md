# 深圳中考志愿填报系统操作教程：从登录到确认的每一步

志愿表设计好了（P4-2到P4-7），最后一步——**在系统里正确提交。**

这一步没有策略，只有操作。但每年都有家长在操作上翻车：保存了没确认、超时被踢出、改了没保存……这些低级错误，一个都不能犯。

这篇带你走完从登录到确认的完整流程。

---

## 一、填报入口与时间

| 项目 | 说明 |
|------|------|
| 系统名称 | 深圳市中考中招管理系统 |
| 登录方式 | 考生号 + 密码（初始密码由学校发放） |
| 填报时间 | 以当年市招考办公告为准（通常6月上旬） |
| 操作提醒 | 填报时间窗口有限，**不要等到最后一天** |

> ⚠️ 具体网址、时间、账号密码以学校和市招考办的正式通知为准。本篇讲的是**通用操作流程**，帮助你在正式填报前心中有数。

## 二、从登录到确认：7步完整流程

| 步骤 | 操作 | 关键提醒 |
|:---:|------|------|
| 1 | 登录系统 | 用考生号和密码登录；首次登录后**立即修改初始密码** |
| 2 | 核对个人信息 | 检查姓名、考生号、户籍类型（AC/D类）是否正确 |
| 3 | 填写志愿 | 按批次依次填写：自招→名额分配→第一批→第二批 |
| 4 | 保存草稿 | 每填完一个批次，**先保存**（此时可继续修改） |
| 5 | 全面检查 | 对照 P4-6 的15项复查清单逐项检查 |
| 6 | 确认提交 | 确认无误后，点击"确认"，**输入验证码** |
| 7 | 截图存档 | 确认成功的页面截图保存，留作凭证 |

---

## 三、每一步的详细说明

### 第1步：登录系统

- 登录账号是**考生号**（不是身份证号）
- 初始密码由学校统一发放，通常印在准考证或通知单上
- **首次登录后立即修改密码**——避免账号被盗用或被误操作

### 第2步：核对个人信息

登录后先别急着填志愿，先核对：

| 核对项 | 错了怎么办 |
|------|------|
| 姓名 | 立即联系班主任 |
| 考生号 | 立即联系班主任 |
| 户籍类型（AC/D类） | **重点核对**——填错类别=看错分数线 |
| 学籍信息 | 确认连续三年本校学籍（指标生资格依据） |

### 第3步：填写志愿

按批次顺序填写。系统通常分几个页面：

| 批次 | 志愿数 | 填写提醒 |
|------|:---:|------|
| 自主招生批 | 1个 | 只有报名了自招的才需要填 |
| 名额分配批 | 1个 | 填1所公办普高（指标生） |
| 第一批 | 16个 | 12普高+4中职试点，**这是重点** |
| 第二批 | 18个 | 中职/技校专业 |

**第一批的填写要点**：
- 志愿之间有明确的顺序（第1志愿、第2志愿……）
- 每所学校通过下拉框或代码选择
- 勾选"接受走读调剂"的学校，单独有勾选框

### 第4步：保存草稿

- 填完一个批次就点"保存"——**防止误关网页丢失**
- 保存后志愿仍是"草稿"状态，可以继续修改
- 保存 ≠ 确认——保存后还可以改

### 第5步：全面检查

对照 P4-6 的15项复查清单逐项检查。**这一步最容易被跳过，但最重要。**

### 第6步：确认提交

这是最关键的一步：

| 操作 | 说明 |
|------|------|
| 点击"确认" | 系统会弹出二次确认提示 |
| 输入验证码 | 防止误操作 |
| 确认后 | 志愿**锁定**，不可再修改（或有限次修改） |

> ⚠️ **保存和确认是两个不同的动作。** 只保存不确认=志愿无效。确认时通常需要手机验证码或图形验证码。

### 第7步：截图存档

- 确认成功页面**截图保存**
- 发到家庭群或存网盘，双重备份
- 以防系统异常或后续纠纷

## 四、四个高频操作问题

### 问题1：填到一半超时被踢出了怎么办？

系统通常有会话超时限制（如20-30分钟无操作自动退出）。**解决**：每填完一个批次就点"保存"，这样即使被踢出，已保存的内容不会丢失。

### 问题2：确认后还能改吗？

通常确认后**不能再修改**（或只有极短时间、极少次数可以改）。**解决**：确认前务必检查到位，不要指望确认后还能改。

### 问题3：密码忘了怎么办？

联系班主任或学校教务，走密码重置流程。**解决**：首次登录改密码后，把新密码记在安全的地方。

### 问题4：系统卡顿/报错怎么办？

填报高峰时段系统可能拥堵。**解决**：
- 错峰填报（避免最后一天的最后一小时）
- 保存后再操作，不要反复刷新
- 遇到报错截图，联系学校技术支持
