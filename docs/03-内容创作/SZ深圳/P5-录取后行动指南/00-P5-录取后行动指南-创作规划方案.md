# P5-录取后行动指南 — 系列创作规划方案

> **版本说明**：v2.1 在 v2.0 基础上，将"滑档补救""复读政策"的认知层前移到 P4（新增 P4-9、P4-10），P5 只保留实操层。v2.0 已将"出路解码"类内容（3+4中本贯通、中职技工出路）前移至 P3。

## 一、系列定位

### 1.1 P5 在内容体系中的位置

```
P1-政策解码器      P2-降分通道        P3-数据择校地图      P4-志愿填报作战室     P5-录取后行动指南
───────────────── ───────────────── ───────────────── ───────────────── ─────────────────
"规则是什么"       "怎么利用规则降分"  "选哪所学校"        "16个志愿怎么排"      "录取之后怎么办"
知道怎么考怎么录   知道指标生填哪所    知道哪所适合我       知道怎么排梯度         出分后/滑档/复盘/衔接
```

**P5 回答的核心问题**：志愿已经提交、录取结果已经出来——**"现在怎么办？"** 从出分那一刻的解读，到滑档补救、复读决策、数据复盘，最后到高一衔接。这是整个内容体系的时间终点。

### 1.2 P5 的定位边界（v2.0 关键调整）

| 维度 | 明确边界 |
|------|------|
| **P5 做什么** | 录取结果出来之后的内容——出分解读、滑档补救、复读、复盘、高一衔接 |
| **P5 不做什么** | 择校、出路科普（这是 P3 的职责，已前移至 P3-5 延伸篇） |
| **时间锚点** | 2027年7月中旬（出分）→ 8月（开学前） |
| **读者锚点** | 已出分/已录取/滑档的家长，不是"正在择校"的家长 |

### 1.3 P5 的战略价值

| 价值 | 说明 |
|------|------|
| **完成闭环** | 家长走完 P1→P5 全流程，从"零基础"到"录取后规划"，HSEE 成为完整陪伴者 |
| **留存起点** | 录取之后家长产生新问题（选科/学考/高考志愿）——P5-6 是 HSEE 延伸到"高中平台"的桥头堡 |
| **信任峰值** | "录取之后还在帮你"的内容最能建立长期信任——口碑传播的种子 |

### 1.4 目标读者

| 读者类型 | 时间阶段 | P5要解决的问题 |
|---------|------|------|
| **已录取家长**（核心） | 7月中旬 | "出分了，这个结果意味着什么？高中怎么规划？" |
| **滑档家长**（重点） | 7月中旬 | "滑档了怎么办？补录/复读/中职怎么选？" |
| **低分段家长** | 7月中旬 | "被中职/技工录取了，接下来怎么走？" |
| **未雨绸缪家长** | 6月-7月初 | "出分后要关注什么？提前了解补救方案" |

## 二、竞品内容差距分析

| 竞品类型 | 覆盖内容 | 缺失 |
|------|------|------|
| 教育局官方 | 录取结果查询、补录通知 | 无解读、无规划、无心态引导 |
| 自媒体/公众号 | 分数线搬运（7月热点） | 碎片化、无系统性、无数据权威 |
| 培训机构 | 高中衔接班（收费） | 只推课不教方法 |
| 小红书/DY | 录取晒单、复读经验 | 情绪化、缺乏数据支撑 |

**HSEE差异化优势**：
1. **出分解读的系统性**——不只报分数，而是帮家长理解"这个结果意味着什么、通向哪里"
2. **数据驱动复盘**——P5-4 的分数线复盘用 HSEE 数据库完整数据，不是搬运截图
3. **滑档补救的决策树**——竞品零散，HSEE 给出"三个窗口+决策树"的系统方案
4. **从"一次性"到"长期"**——P5-6 把用户留存到高中阶段

## 三、内容支柱（Content Pillars）

P5 设立 **3个内容支柱**（v2.0 精简）：

### 支柱1：出分解读（Result Interpretation）
**家长搜索**："深圳中考出分后怎么办""中考录取结果查询""深圳中考滑档怎么办"
**内容**：出分后的第一课——不同录取结果的解读、心态建设、下一步行动。这是7月中旬的刚需峰值。

### 支柱2：补救与兜底（Remedy & Safety Net）—— 实操层
**家长搜索**："深圳中考滑档补救""深圳中考补录""深圳中考复读政策"
**内容**：录取不理想时的三条路——滑档补救（补录/征求志愿/注册入学）、复读。**本支柱聚焦"出分后的实际操作"**——流程、条件、决策树。

> **认知层已前移**：滑档风险认知、复读代价的"认知层"前移到 P4（填报前），编号为 P4-9（滑档风险认知）、P4-10（复读代价）。P5-2/P5-3 只承担"出分后怎么操作"。

### 支柱3：复盘与衔接（Review & Transition）
**家长搜索**："2027深圳中考分数线""深圳中考录取复盘""高一入学准备"
**内容**：数据驱动的年度复盘（分数线+案例）+ 录取后的下一步（高一衔接规划）。复盘建立数据权威，衔接实现用户留存。

## 五、逐篇详细规划

---

### P5-1：出分之后怎么办——录取结果的解读与出路总览

**定位**：P5 的总纲 + 出分后第一课。所有后续文章的"导航地图"。

**家长搜索意图**："深圳中考出分后怎么办""中考录取结果""深圳中考被XX录取了"

**核心角度**：出分那一刻，家长的第一需求不是"看数据"，而是"**我的结果意味着什么？接下来做什么？**" 这篇帮家长从情绪中走出来，建立清晰的下一步认知。

**内容大纲**：
1. Hook："分数出来了，先别急着高兴或难过——先搞清楚这个结果通向哪条路"
2. 四种录取结果的解读（公办普高/民办普高/中职/技工）——每种通向什么出路
3. 出分后立刻要做的3件事（查录取结果/确认注册/准备入学）
4. 不同结果的下一步行动清单（录取满意→衔接规划；不满意→补救窗口；滑档→P5-2）
5. 心态建设：对孩子说的话（结果不是终点）
6. 与P5-2~P5-6的导航关系

**数据需求**：HSEE DB（学校类型）+ P3-5（中职概览）+ 出分时间节点

---

### P5-2：滑档考生补救方案——三个补救窗口怎么用（实操层）

**定位**：7月中旬滑档家庭的"雪中送炭"——P5 中情绪价值最高的单篇。**聚焦实操**：滑档后三个窗口的具体操作。

**前置关系**：认知层见 P4-9《滑档风险认知》（填报前）；本篇假设家长已具备"滑档有救"的认知，直接讲操作。

**家长搜索意图**："深圳中考滑档怎么办""深圳中考补录""滑档补救"

**核心角度**：滑档不是世界末日。深圳中考录取后有**三个补救窗口**——补录、征求志愿（如当年有）、注册入学。每个窗口的时间、条件、能填什么、怎么操作。

**内容大纲**：
1. Hook："滑档了，先别慌——三个补救窗口，按这个顺序操作"
2. 滑档的几种情况（第一批全落/底也滑/没填底）
3. 窗口1：补录（时间+条件+能选什么+怎么填）
4. 窗口2：征求志愿（如果当年有）
5. 窗口3：注册入学（中职兜底）
6. 三个窗口的决策树：什么情况选哪个、时间线怎么排

**数据需求**：报考指导手册补录章节 + 往年补录流程

---

### P5-3：中考复读政策全解——往届生规则与决策矩阵（实操层）

**定位**：复读是滑档后的一个选项，但不是所有人都适合。**聚焦实操**：往届生报考规则 + 出分后的决策矩阵。

**前置关系**：认知层（复读的代价）见 P4-10《复读的代价》（填报前）；本篇假设家长已理解复读代价，直接讲"怎么决策、怎么操作"。

**家长搜索意图**："深圳中考可以复读吗""中考复读政策""复读值不值"

**核心角度**：深圳中考允许复读（往届生），但决策需要理性框架。本篇给出往届生报考规则 + "复读 vs 补录 vs 中职"的决策矩阵。

**内容大纲**：
1. Hook："复读还是补录？先看这份决策矩阵再决定"
2. 深圳中考复读政策（往届生报考规则、资格、流程）
3. "谁适合复读"的判断框架（分数差距/年龄/心态）
4. 复读 vs 补录 vs 中职：三个选项的决策矩阵
5. 决定复读后的实操步骤（找复读学校/报名流程）

**数据需求**：报考指导手册往届生政策 + 决策模型文件

---

### P5-4：2027深圳中考分数线复盘——涨跌背后的规律

**定位**：7月底数据驱动内容——建立 HSEE 的"数据权威"。

**家长搜索意图**："2027深圳中考分数线""深圳中考录取线涨跌"

**核心角度**：用 HSEE 数据库的完整数据，复盘2027年分数线——哪些学校涨了、哪些跌了、涨跌的原因。这是全年搜索峰值内容，也是数据资产的展示窗口。

**内容大纲**：
1. Hook："2027年深圳中考分数线出来了——涨多跌少，但有几所学校跌了"
2. 整体趋势：公办普高分数线涨跌分布
3. 涨幅最大的学校 + 原因
4. 跌幅最大的学校 + 原因
5. 四大/八大/二十大的变化
6. AC/D分差的变化趋势
7. 对2028届家长的启示

**数据需求**：2027年录取分数线（出分后）+ HSEE DB对比

**⚠️ 时效**：依赖2027年7月出分数据，需出分后48小时内产出。

---

### P5-5：年度录取案例复盘——成功与滑档的真实故事

**定位**：8月上旬的 UGC 内容——用真实案例建立信任和口碑。

**家长搜索意图**："深圳中考滑档案例""中考志愿填报成功案例"

**核心角度**：征集真实家长的录取结果（匿名化），复盘成功案例（志愿填对了）和滑档案例（哪里填错了）。真实故事比说教更有说服力。

**内容大纲**：
1. Hook："今年有孩子540分进了理想高中，也有孩子580分滑档了——差在哪？"
2. 3个成功案例：志愿填对的地方
3. 3个滑档案例：志愿填错的地方
4. 共同规律提炼
5. 匿名化UGC征集（下届家长参考）

**数据需求**：家长投稿（UGC）+ HSEE小程序用户数据

**⚠️ 时效**：依赖2027年录取后的真实案例，8月产出。

---

### P5-6：高一入学衔接与三年规划——录取之后的第一课

**定位**：8月中旬峰值——录取后的下一个刚需，也是 HSEE 从"中考平台"延伸到"高中平台"的桥头堡。

**家长搜索意图**："高一入学准备""高中三年规划""深圳高中选科"

**核心角度**：录取不是终点，是高中三年的起点。帮家长建立"高中三年节奏感"——高一适应与选科、高二分科与冲刺、高三备考。同时引出高中阶段的新内容需求。

**内容大纲**：
1. Hook："拿到录取通知书只是开始——高中三年，每个阶段的重点完全不同"
2. 高一：适应+选科（新高考3+1+2模式）
3. 高二：分科+学业水平考试+竞赛
4. 高三：高考冲刺+大学志愿填报
5. 不同录取去向的三年规划差异（普高vs中职）
6. HSEE的高中阶段内容预告（留存钩子）

**数据需求**：广东省新高考政策 + 高中规划通用知识
