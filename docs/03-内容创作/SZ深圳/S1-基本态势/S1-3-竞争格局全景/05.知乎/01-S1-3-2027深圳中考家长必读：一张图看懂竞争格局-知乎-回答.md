# 【知乎回答】2027深圳中考16-18万考生，"一半人没书读"是真的吗？

## 先说结论

**竞争是真的，但"一半人没书读"是误解。** 2027年深圳中考预计16-18万考生，公办普高录取率约52%——这句话没错；但加上民办，全市普高录取率超73%，高中阶段总学位14.7万个、覆盖全部考生。**数据是焦虑最好的解药：把数字一条条摆清楚，你会发现出路远比想象的多。**

上一篇想法里我问"同样一组数据，为什么有人说'太难了'、有人说'出路很多'"——差别就在于：只看到第一层（公办52%），还是看到了全部出路。

## 第一层：竞争是真实的，先面对它

2027年约16-18万考生（2026年为15.30万，来源：2026年体育中考报名人数；2027年按近年增速推估，待官方确认），公办普高约8万个学位（101所）。**8年时间，考生从7.21万涨到15.30万，翻了一倍多**（来源：深圳市招考办公布历年数据）。

录取率多年稳定在52%上下：2022年约53%、2024年约52%、2025年约52%、2026年约52%。

## 第二层：学位在追着考生跑

"考生越来越多"不是全部真相，下半句是"学位也在越来越多"：

- 公办学位从5.9万涨到约8万，增长35%（来源：深圳市教育局各年招生计划）
- "十四五"（2020-2025）完成49所新改扩建公办高中，新增11.8万个学位（来源：深圳特区报，2026-06-24）
- "十五五"规划2026到2030年再新增10万个公办高中学位

录取率稳在52%不是偶然，是学位建设在追着考生增长跑。

## 第三层：出路不止公办

"一半孩子上不了公办"对，但不完全对——2026年高中阶段总学位146,752个，覆盖全部15.30万考生（来源：深圳市教育局2026年招生计划通知）：

- **公办普高**：约8万、101所、约52%
- **民办普高**：33,195人、49所
- **中职及技工**：33,254人、30所——最被低估。2026年"3+4"中本贯通试点落地：深圳一职对口深技大、二职对口深职大，300个名额，中职3年直接升本科，毕业拿全日制本科文凭（来源：深圳市教育局2026年招生计划通知）

所以正确的说法是：约52%上公办普高，**超73%能上普高（含民办）**，几乎所有孩子都有高中阶段学校可读。"一半人没高中读"是需要被纠正的误解。

## 给你的三句话（按情况对号入座）

**非深户（D类）家长**：路确实更窄——公办8万指标里D类仅18,506人、占比约23%，而D类考生占总数约54%。但指标生已实现D类全覆盖，民办和中职对AC/D一视同仁。**路窄，但不是死胡同。**

**孩子成绩400分左右**：你可能是最焦虑的一批，但"3+4"中本贯通正是为你这类家庭开的窗——300个名额不多，却是全新路径，2026年第一年试点，很多家长还不知道。**别只盯着公办一条路。**

**初二家长觉得"还早"**：2027年竞争不会比2026年轻松，但你的优势是时间——现在搞清楚规则、关注2026年录取数据、开始关注体育过程性评价（14分，从初一就开始累积）。**早准备一年，焦虑少一半。**

## 总结：焦虑来自信息不对称

**中考考的不是孩子一个人，是家庭的信息获取和决策能力。** 有人看到52%就焦虑，有人看到73%和14.7万就开始规划——同一份数据，两种心态，差别在信息完整度。
