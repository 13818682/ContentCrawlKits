# 一张图看懂深圳中考竞争格局

深圳中考竞争有多激烈？一张图讲清楚，先看三组数。📊

**① 考生 vs 学位** 👨‍👩‍👧
2027年预计16-18万考生，公办普高约8万学位。公办录取率约52%。

**② 但别慌：学位在追着考生跑** 🏃
从2018年到2026年，考生从7.21万涨到15.30万翻了一倍，公办学位也同步加码，"十四五"新增11.8万。录取率多年稳在52%。

**③ 出路不止公办** 🛣️
- 民办普高：33,195人、49所（含民办普高录取率超73%）
- 中职及技工：33,254人、30所，3+4中本贯通可拿全日制本科

**总盘子**：高中阶段146,752个学位、180所学校，覆盖全部考生。✅

数据来自深圳市教育局公开信息。收藏这张图，填志愿时心里有底。你家娃现在几年级？评论区聊聊。💬
