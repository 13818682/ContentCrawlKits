# 深圳中考不止公办一条路，4层出路146,752个学位一次看全

填志愿最怕眼里只盯着"公办普高"。2026年深圳高中阶段共146,752个学位、180所学校，覆盖全部15.30万考生：

1️⃣ 公办普高：约8万、101所、约52%。AC类61,797人，D类18,506人（占约23%）。

2️⃣ 民办普高：33,195人、49所。AC/D同分录取，对D类是重要补充选项，学费3万-15万/年不等。

3️⃣ 中职及技工：33,254人、30所。最被低估——"3+4"中本贯通300个名额，中职3年→本科4年，拿全日制本科文凭（一职对口深技大、二职对口深职大）；"3+2"中高贯通2,853人·63专业。

4️⃣ 别被吓到的真相：全市普高（含民办）录取率超73%；民办对AC/D一视同仁；中职→大学这条路知道的人还不多。
