# 写作方法论参考（HSEE 适配版）

## 一、论证策略

> 适用于数据驱动型科普文章。S1系列核心方法论。

### 核心理念

断言没有论证是空洞的，论证只有正向是单薄的。**正向与逆向齐上**——正向论证"为什么A是对的"，逆向论证"为什么非A是错的/为什么B行不通"。双向论证同时存在时，读者会产生"无懈可击"的感觉。

### 正向论证四要素

```
[核心观点] → [证据支撑] → [逻辑链条] → [案例验证]
```

**证据类型说服力排序**：

| 证据类型 | 说服力 | HSEE 可用来源 |
|---------|:---:|------|
| 一手数据 | ★★★★★ | HSEE数据表、教育局招生计划 |
| 权威研究 | ★★★★☆ | 教育局官方文件、招考网公告 |
| 行业案例 | ★★★★☆ | 往年录取案例、指标生降分案例 |
| 个人经历 | ★★★☆☆ | 家长真实故事（匿名化） |
| 逻辑推演 | ★★☆☆☆ | 志愿填报策略推演 |
| 常识类比 | ★☆☆☆☆ | 生活化类比解释政策 |

### 逆向论证三种模式

**模式A：反驳常见误解**

结构："很多人认为[常见观点]，但这是一个误解。原因是……"

HSEE 应用示例：
> "很多人认为'一半孩子没高中读'——这是对52%录取率的误解。实际上，全市普高（含民办）录取率超73%，大部分孩子有普高可上。"

**模式B：拆解替代方案**

结构："你可能会想，不如[替代方案]。但这样做有三个问题……"

HSEE 应用示例：
> "你可能会想，不如等2027年政策出来再准备。但这样做有三个问题：第一，指标生资格和初中三年在读挂钩，现在不搞清楚可能错失资格；第二，体育过程性评价从初一就开始累积……"

**模式C：划定边界条件**

结构："我的观点在[特定条件]下成立。如果[例外情况]，那确实是另一回事。"

HSEE 应用示例：
> "说'不用恐慌'有一个前提——你的孩子目前分数在中等以上，并且你从现在开始了解政策。如果孩子分数在普高线边缘，或者你等到填志愿前一周才开始看政策，那确实需要更紧张一些。"

### 论证常见陷阱

| 陷阱 | 说明 | HSEE 避坑 |
|------|------|---------|
| 只有正向没有逆向 | 不回应反驳，说服力弱 | 每提出一个数据观点，附带一个"你可能会问"的逆向回应 |
| 稻草人谬误 | 攻击不存在的观点 | 必须引用真实存在的家长误解（如"一半人没高中读"） |
| 滑坡谬误 | 逻辑链条过长 | 聚焦最核心的一到两步因果关系 |
| 诉诸权威 | "教育局说了"不等于正确 | 权威作为引子，数据作为支撑 |

## 二、写作风格规则（HSEE 适配版）

> ⚠️ **重要说明**：以下规则已针对 HSEE 教育内容平台定位进行适配，与原版个人博客风格规则有所取舍。

### 品牌语言风格

**人格画像**："懂政策的数据控学长"

**核心原则**：
- 专业但不冷冰冰——数据说话，但用口语化方式解释数据
- 数据支撑但不堆砌——每段最多3个数字，关键数字配一句"大白话"解读
- 接地气但不贩卖焦虑——说52%的同时必须说73%，说D类24%的同时必须说指标生全覆盖

### HSEE 内容风格指南

#### 语言风格

- **口语化但不随意**：像在给一位焦虑的家长朋友耐心解释。"说白了就是""你可以把它理解成""举个例子"
- **短句为主**：一句话一个信息点，不绕口
- **段落呼吸感**：每段3-5行，手机屏幕一屏能看完一段
- **设问引导**：多用"你可能会问""这是什么概念？""那怎么办？"

#### 格式规范

- ✅ 中文与英文单词之间加空格："HSEE 小程序""AC 类考生"
- ✅ 中文与数字之间加空格（独立数字时）："约 16 万""共 101 所"
- ❌ 中文数字量词语义单位不加空格："2027年""第1批""80,303人"
- ✅ 使用冒号引出数据和列表
- ✅ 使用破折号做解释说明
- ✅ 适度使用粗体和分隔线突出重点

#### 绝对禁止

| 类别 | 禁止项 | 原因 |
|------|--------|------|
| 合规 | "保证录取""100%""一定""包过" | 教育内容合规红线 |
| 焦虑 | "完了""没救了""来不及了" | 品牌定位——不贩卖焦虑 |
| 对立 | "深户就是好""非深户太惨了" | 避免激化户籍对立 |
| 标题党 | "震惊""崩溃""太可怕了" | 降低品牌信任 |
| 模糊 | "大概""左右""听说""据说" | 数据驱动定位——所有数字必须精确 |

#### 去 AI 味的 HSEE 做法

1. **具体细节**：不写"很多家长"，写"去年有位龙岗妈妈"。每篇至少引用一个真实案例或具体数据场景。
2. **数据说话**：不写"竞争很激烈"，写"2027年约16-18万考生，公办学位约8万，录取率约52%"
3. **跨学科视角**：用心理学解释家长焦虑，用经济学解释学位供需，用博弈论解释志愿填报策略

## 三、S1系列写作自检清单

每篇文章完成初稿后逐项核对：

### 论证检查
- [ ] 核心观点是否清晰可争论？
- [ ] 是否回应了最常见的家长误解？（至少1处逆向论证）
- [ ] 数据来源是否标注？年份是否标注？
- [ ] 有没有使用"稻草人"（攻击不存在的错误观点）？

### 风格检查
- [ ] 读起来像"数据控学长"在讲解？（不是官方文件，不是营销号）
- [ ] 说52%的时候同时提到73%了吗？（不贩卖焦虑原则）
- [ ] 所有数字精确到个位？
- [ ] 有没有使用违规词（"保证""100%""震惊"）？

### 结构检查
- [ ] 每段3-5行？
- [ ] 有至少一处设问引导？
- [ ] CTA自然嵌入，不突兀？
