# 【知乎回答】2026年深圳中考已结束，2027届家长现在该做什么？

## 先说结论

**如果你家孩子9月升初三（2027年6月参加中考），那么"现在"就是开始准备的最佳时机——比明年5月才动手的家长，至少多出9个月的信息优势。**

上一篇想法里我抛了个问题，只给了4个背景条件，让大家先猜答案。今天把答案补上：

**这4个条件共同指向一件事——2027届家长现在唯一该做的，是趁2026年数据最新鲜的时候，把信息优势提前攒起来。** 不是现在刷题，不是现在填志愿，而是先建立一个"认知坐标系"。

## 这事到底跟你有没有关系？

你可能会想："孩子才刚升初三，中考还有快一年，这些跟我有关系吗？"

**有，关系很大。** 2026年的每一份数据，都是你2027年最好的"预习教材"。你以为的"还早"，恰恰是差距开始的地方——真正有信息优势的家长，正在趁数据最全的时候做功课。

那4个背景条件，为什么共同指向"信息优势"？

- **15.3万考生去向落定** → 2027年的竞争规模基本有数（按增长推估16-18万）。数字明确了，焦虑才有参照系。
- **"先填志愿、后考试"，填报窗口只有10天** → 明年5月23日-6月1日（来源：深教〔2026〕34号），10天内要消化分数线、学校梯队、指标生政策，再排出16个志愿——到时候再搜信息、查数据，根本来不及。
- **2026年数据此刻最全** → 分数线涨跌、指标生使用、走读调剂效果，全是刚出炉的第一手参照。等明年3月，要么被新信息淹没，要么已经焦虑到看不进去。
- **体育过程性评价14分从初一就累积** → 一部分分已经在孩子档案里了。现在去确认，等于提前摸清"已到手"的家底。

这4条摆在一起，结论只有一个：**信息越早到手，决策越从容。** 而信息最全的窗口，就是现在。

## 现在具体做什么？3件事，每件5分钟到半小时

### 第一件：花5分钟，记住三组数字

| 数字 | 含义 |
|---|---|
| **16-18万** | 2027年预计考生人数（2026年为15.30万，来源：深圳特区报，2026-06-24） |
| **约8万** | 公办普高招生人数（2026年，101所，来源：2026年招生计划通知） |
| **约52%** | 公办普高录取率；全市普高（含民办）超73%（8万÷15.3万≈52.3%计算） |

有了这个坐标系，再看任何"录取率""分数线"信息，你都知道它大概在什么位置——这就是信息优势的起点。

### 第二件：把2026年录取数据当"教材"看一遍

重点看三样：

- **分数线涨跌的学校**——哪些涨了、哪些跌了、为什么。趋势2027年大概率延续。
- **学校梯队**——"四大""八大""二十大"分别对应什么水平、什么区、什么分。不用会填志愿，先有认知。
- **D类（非深户）通道**——2026年公办普高招生计划中D类约18,506人、占比约23%（来源：2026年招生计划通知）。指标生这条降分通道，值得认真研究。

### 第三件：确认孩子"体育过程性评价"的历史分数

2026年起，深圳体育中考从两项改为三项，新增**过程性评价14分**，从初一就开始累积（来源：深教〔2026〕34号）。

孩子升初三，之前的过程性评价分数已经在档案里了。现在做两件事：①确认历史分数；②规划初三一年的体育训练重点——耐力、技能、球类各选一项。14分在中考总分630分的背景下，相当于一道大题的分数——不是锦上添花，是雪中送炭。

## 同时，3件"现在不必焦虑"的事

**志愿怎么填**——志愿填报的核心依据（一模二模成绩、指标生名额分配、当年招生计划）要到2027年4-5月才清晰。现在要做的是搭框架，不是填志愿。

**孩子分数"够不够"**——离中考还有约300天。一模成绩（初三下学期初，各区1-3月）才是有效定位基准。拿初二期末成绩对标中考分数线，就好比拿毛坯房对标样板间——结论是错的。

**政策会不会变**——2027年具体政策要到2027年3-5月才公布，2026年的规则（总分630分、16个志愿、指标生全覆盖）大概率延续，但任何"2027年肯定这样"的说法都不可信。变了再说，但不让变化变成焦虑。

## 总结：从"做什么"到"为什么现在做"

**中考考的不是孩子一个人，是家庭的信息获取和决策能力。** 从2026年数据里建立认知坐标系，是当下投入产出比最高的一件事——这也是上一篇想法里那个问题的完整答案。
