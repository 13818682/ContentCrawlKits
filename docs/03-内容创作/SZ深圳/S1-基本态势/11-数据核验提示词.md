# 数据核验提示词

> 使用方法：将 `[文件名]` 替换为目标核验清单文件路径，将以下完整提示词发送给 Claude Code。

---

## 提示词正文

```
对 [文件名] 的数据核验清单，逐条检索官方一手来源。

【官方来源优先级】
1. 深圳教育局官网 https://szeb.sz.gov.cn/szzkw/ （政策文件、通知公告）
2. 政府法规文件，以"深教〔年份〕XX号"为权威依据
3. 以上来源无法覆盖时，用 firecrawl_search 补充搜索，优先 gov.cn 域名

【核验结果填写格式】
每项的"核验"列按以下四种格式之一填写：

格式1 — 查到原文：
✅ 原文引用：[文件名]（[文号]）§[章节]："[原文关键句，用原文原话]"
   网址：[URL]

格式2 — 需计算：
✅ 计算验证：[公式] = [结果]
   源数据：[数据A]来自[来源]，[数据B]来自[来源]

格式3 — 推算值：
⚠️ 推算标注：[推算方法说明]
   源数据：[数据来源]，非官方直接发布值
   建议：[如需确认，可补充的方向]

格式4 — 找不到：
❓ 待查：已尝试[来源1]、[来源2]
   建议补充：[方向或可能的文件名称]

【关键官方文件清单】
| 文件名 | 文号 | 网址 |
|--------|------|------|
| 2026年高中阶段学校考试招生工作通知 | 深教〔2026〕34号 | https://szeb.sz.gov.cn/szzkw/zcwj/content/post_12687204.html |
| 2026年报考指导手册 | — | https://szeb.sz.gov.cn/szzkw/qt/tzgg/content/post_12800387.html |
| 改革实施意见 | 深教规〔2024〕3号 | https://szeb.sz.gov.cn/home/xxgk/zdlyxxgkzl/zcfgjjd/zcfg/content/post_12805051.html |
| 2026年招生计划通知 | — | https://szeb.sz.gov.cn/home/xxgk/flzy/wjtz/content/post_12794780.html |
| 深圳特区报（考生人数官方确认） | — | https://www.sz.gov.cn/cn/xxgk/zfxxgj/zwdt/content/post_12856883.html |

【特别注意】
- 招生人数（如80303）在"招生计划表"中（另文下发），不在招生通知正文中——需单独搜索招生计划公告
- 考生总人数通常来自体育中考报名数据或教育局新闻发布会，非同一个文件
- 录取率、普高率等百分比数据——标注为"计算验证"而非"原文引用"
- 指标生降分幅度——非官方精确发布值，标注为"行业经验"或"推算"
- 学费范围——标注"具体以各校招生简章为准"

【输出要求】
- 保留原清单表格结构，只更新"核验"列的内容
- 在核验清单末尾新增"核验方法总结"表（参考格式见附录）
- 如发现稿中数据与官方来源不一致，立即标注"❌ 需修正"并在核对后修改稿件
```

## 附录A：核验方法总结表格式

```markdown
## 核验方法总结

| 核验方式 | 适用数据 | 本清单使用次数 |
|------|---------|:---:|
| 原文引用 | 政策文件中明确写出的数字（分数、日期、志愿数） | X |
| 计算验证 | 需计算得出的比例（录取率、普高率） | X |
| 推算标注 | 非官方直接发布值（D类录取率、推估值） | X |
| 待补充 | 来源文件非一手官方（招生计划另文、体育中考数据） | X |
```

## 附录B：常见数据与官方文件对照表

| 常见数据 | 应在哪个文件中查找 | 文件类型 |
|------|------|------|
| 总分、各科分值 | 招生工作通知（深教〔年份〕XX号）§考试成绩呈现 | 正文 |
| 志愿填报时间 | 招生工作通知 §志愿填报 | 正文 |
| 录取批次规则 | 招生工作通知 §录取 | 正文 |
| 指标生政策 | 招生工作通知 附件1（名额分配实施办法） | 附件 |
| 体育中考规则 | 招生工作通知 §考试 | 正文 |
| 招生人数（公办/民办/中职） | 招生计划表（另文下发公告） | 独立文件 |
| 考生总人数 | 体育中考报名数据新闻 / 教育局新闻发布会 | 新闻报道 |
| 各校录取分数线 | 录取标准公告（7月下旬发布） | 独立公告 |
| 指标生名额分配 | 名额分配招生计划表（另文下发） | 独立文件 |
| 报考条件 | 招生工作通知 §报名 + 报考指导手册 | 正文+PDF |
