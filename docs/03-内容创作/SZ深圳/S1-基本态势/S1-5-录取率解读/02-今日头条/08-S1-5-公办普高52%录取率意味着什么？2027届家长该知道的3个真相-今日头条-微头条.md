# 深圳中考52%录取率，不等于一半人没书读

"深圳一半孩子上不了公办"——这句话被说了多少年，但看3个真相，你的理解会完全不同：

1️⃣ 52%是"公办普高"录取率，不是"普高"录取率。加上民办，全市普高（含民办）录取率超73%——约一半上公办，超过七成能上普高。

2️⃣ 52%是稳定低位，不是下滑悬崖。2022-2026连续稳在52%左右，2020年44%的低点后，是"十四五"11.8万+“十五五”10万学位把它托住的——这不是运气，是规划。

3️⃣ D类家长面对的是另一个数：公办8万指标里D类仅占约23%。但指标生已D类全覆盖、四大AC/D线持平、民办一视同仁——路更窄，但不是死胡同，关键是更早出发。
