# AI内容发布风险评估与应对方案

## 一、风险识别

### 1.1 风险全景

| 编号 | 风险来源 | 风险描述 | 严重程度 | 发生概率 | 风险等级 |
|:---:|------|------|:---:|:---:|:---:|
| R1 | 平台AI检测 | 公众号/小红书/抖音的AI内容检测模型标记"疑似AI生成"，导致推荐量减少、不进入流量池 | 🔴 高 | 🟡 中 | **高** |
| R2 | 原创标识取消 | 微信公众号"原创"标签被取消，影响搜索排名和自然流量 | 🔴 高 | 🟢 低 | **中** |
| R3 | 平台批量下架 | 被认定为"AI批量灌水"，多篇文章同时下架 | 🔴 高 | 🟢 低 | **中** |
| R4 | 读者信任流失 | 读者发现内容有AI痕迹但未标识，质疑专业性和可靠性 | 🟡 中 | 🟡 中 | **中** |
| R5 | 法规违规处罚 | 违反《人工智能生成合成内容标识办法》（2025年9月1日施行），被网信/电信/公安/广电四部门处罚 | 🟢 低 | 🟢 极低 | **低** |
| R6 | 竞品恶意举报 | 竞品以"AI生成内容未标识"为由向平台举报 | 🟡 中 | 🟢 低 | **低** |

### 1.2 风险详解

#### R1：平台AI检测限流（最需要关注）

**触发条件**：
- 文章语言模式、结构、用词被AI检测模型判定为"高概率AI生成"
- 多篇文章发布间隔过短（<2小时/篇），触发"批量生产"模式识别
- 同系列文章结构高度雷同

**影响**：
- 公众号：文章不被推荐到"看一看""搜一搜"，仅靠粉丝阅读
- 小红书：笔记不被推入发现页流量池，曝光量下降80%+
- 抖音：视频不被推入推荐流，仅粉丝可见

**当前HSEE的脆弱性**：
- S1系列文章基于模板生成，存在结构相似风险
- 数据密集型写作风格（大量数字+逻辑论证）可能被部分检测模型误判
- 但人工深度介入（数据核验+润色改稿+结构调整）是强有力的稀释AI特征的手段

#### R2：原创标识取消

**触发条件**：微信公众号检测到AI生成内容标注了"原创"

**影响**：原创标识被取消后，文章在搜一搜中的排名大幅下降，长尾SEO流量断崖式下跌

**当前脆弱性**：低。HSEE文章经过人工核验+改稿，内容具备明显的人工编辑特征。且文末使用"核心数据均来自官方公开信息并逐条人工核对后整理、编辑审核后发布"而非"AI生成"，不自我设限。

#### R3-R6：发生概率低，但需有预案

R5法规风险最低——HSEE内容非高监管领域（医疗/金融/新闻），且文末表述已满足"不虚假宣传"的基本要求。HSEE小程序数据库中自动注入隐式标识（合规清单§1.2），满足法规底线。

## 二、应对措施

### 2.1 对外发布策略

**统一尾部标识**（所有平台）：

```
（核心数据均来自深圳市教育局官方公开信息，逐条人工核对后整理、编辑审核后发布）
```

| 平台 | 标识样式 | 位置 |
|------|---------|------|
| 公众号 | 原文末尾，小号灰色字体 | 文末最后一行 |
| 小红书 | 原文末尾，与正文同字体 | 文案最后一行 |
| 抖音 | 结尾画面叠加文字，停留2秒 | 视频最后3秒 |

**不使用"AI"字样**。理由：人工介入链条完整（数据核验+润色改稿+合规审查），最终内容是人工定稿，真实反映了生产流程。

### 2.2 内部证据留存体系（"人工介入证明"）

每篇文章留存3份核心证据，形成可追溯的编辑过程链：

| 证据 | 文件名 | 内容 |
|------|------|------|
| **证据1** | `05-数据核验清单.md` | 所有数据点的来源对照表，逐条标记核对结果 |
| **证据2** | `人工润色记录` | 至少记录3处措辞调整 + 1处结构调整，含改前/改后对比 |
| **证据3** | `编辑审核签字` | 核验清单底部的核验人签名、核验日期 |

**证据保存期限**：自发布之日起至少12个月。

**证据用途**：
- 平台申诉时的支撑材料（主要用途）
- 读者质疑时的回应依据
- 合规自查时的审计轨迹

### 2.3 发布节奏控制

规避R1中"批量生产"模式识别的措施：

| 规则 | 具体做法 |
|------|---------|
| **最小发布间隔** | 同平台文章发布间隔≥4小时；跨平台同步发布不受此限 |
| **系列多样性** | 同一系列相邻文章在开头句式、段落结构、数据使用方式上保持至少30%的结构差异 |
| **人工改稿力度** | S1系列每篇AI初稿→定稿的文本修改率≥15%（绝非仅改数据数字） |

### 2.4 平台申诉预案

当文章被限流或误判为AI生成时，申诉材料包：

```
申诉材料包/
├── 05-数据核验清单.md        ← 证明数据有人工核查
├── 人工润色改稿记录           ← 证明有人工创作投入
├── 编辑审核签字              ← 证明有编辑流程
└── 参考素材来源列表           ← 证明内容原创性
```

申诉话术模板：
> "本文由HSEE内容团队撰写，使用AI工具作为写作辅助（类比Word的语法检查功能）。所有数据均从深圳市教育局官方公开信息提取并逐条人工核对，经过编辑审核后发布。附件为编辑过程记录，可证明人工创作的实质性投入。"

## 三、风险监控

### 3.1 监控指标

| 指标 | 监控方式 | 正常值 | 告警阈值 |
|------|---------|:---:|:---:|
| 文章推荐量占比 | 公众号后台"流量来源"分布 | 推荐量>粉丝阅读量 | 推荐量<粉丝阅读量的30% |
| 小红书笔记曝光量 | 小红书创作者中心 | 7日内曝光>1000 | 7日内曝光<200 |
| 抖音视频播放量 | 抖音创作者后台 | 48h内播放>500 | 48h内播放<100 |
| 原创标识状态 | 公众号后台"原创管理" | 全部正常 | 任一篇被取消 |
| 文章被投诉次数 | 各平台后台通知 | 0 | ≥1 |

### 3.2 应急响应流程

```
发现异常 → 确认原因 → 分级响应

Level 1（单篇限流）:
  → 检查是否被AI检测标记
  → 提交申诉材料包
  → 下一篇文章加大人工改稿力度

Level 2（多篇限流/原创取消）:
  → 暂停发布，全面排查
  → 逐篇提交申诉
  → 调整AI辅助程度和改稿流程
  → 恢复发布后降为每日1篇

Level 3（批量下架/平台警告）:
  → 立即停止全部AI辅助内容发布
  → 联系平台客服了解具体原因
  → 全部切换为人工撰写，直到问题解决
```

## 四、决策建议

### 4.1 当前策略（推荐）

- 对外：使用统一尾部标识，不主动提AI
- 对内：严格执行数据核验清单 + 人工润色记录
- 节奏：同平台发布间隔≥4小时
- 底线：HSEE小程序数据库注入隐式标识（已满足法规要求）

### 4.2 升级条件

出现以下任一情况时，切换为**显式AI标识策略**（文末标注"AI辅助生成"）：

1. 平台发布新规明确要求必须标注AI
2. 已发布文章被平台警告≥2次
3. 竞品举报导致平台核查
4. 国家层面政策收紧，明确要求所有AI参与内容强制显式标识

### 4.3 下一步行动

| 优先级 | 行动 | 备注 |
|:---:|------|------|
| P0 | 将05-数据核验清单的填写从"建议"升级为"强制"，每篇文章必填 | 证据链核心 |
| P0 | 在编辑流程中新增"人工润色记录"环节，记录改前/改后对比 | 建议≥3处改动 |
| P1 | 完成S1-1全部文章的终稿并发布 | 按照发布节奏控制执行 |
| P2 | 发布后1周，监控各平台推荐量数据，验证策略有效性 | 第一个反馈循环 |
