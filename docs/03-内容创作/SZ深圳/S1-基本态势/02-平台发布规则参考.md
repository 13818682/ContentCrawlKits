# 平台发布规则参考

## 微信公众号

### 结构规范

- 封面图放在标题下方
- 章节插图放在对应章节标题下方
- 信息图放在相关数据/概念描述之后
- 使用相对路径引用图片

### 头部引导文案

可选的关注引导，放在文章开头。HSEE 适用的改写方向：引导关注获取更多中考数据、政策解读。

### 尾部互动

文章结束后的互动引导。HSEE 适用方向：引导打开小程序查数据、关注后续系列文章。

### 配图规则

- 数据类文章必须配数据图表（表格截图或可视化图）
- 信息图放在相关段落之后
- 避免大段纯文字无配图

## 小红书

### 社区合规红线（绝对禁止）

- 涉军涉政、违禁物品、两性敏感、烟草、封建迷信、赌博
- 裸露或性暗示内容
- 站外引流（二维码、微信号、外链等）
- 盗用、抄袭、侵权内容

### 用语规范（必须遵守）

- 禁止绝对化用语：最、第一、顶级、史上最、100%
- 禁止夸大功效：一分钟见效、吃完就变白
- 禁止诱导互动：双击有惊喜、评论抽奖

### 内容风格（建议遵循）

- 真诚分享，避免虚假种草
- 积极正向，不贩卖焦虑
- 客观中立，不拉踩抹黑
- 实用有价值，通俗易懂

### 格式规范

纯文本格式，不适用 Markdown 语法。仅支持：
- 换行（单个换行符）
- 分段（空行）
- 缩进（空格）
- 有序列表（1. 2. 3.）
- 无序列表（• 或 -）
- 表情符号（如适用）

禁止使用：Markdown 语法（#、**、[]() 等）、超链接、特殊符号过多

### 字数限制

| 元素 | 限制 |
|-----|------|
| 标题 | ≤20字 |
| 正文+tag | ≤1000字 |

### 改写原则

1. 标题≤20字，正文+tag总计≤1000字
2. 比原文更加口语化、轻松，像跟朋友聊天
3. 每段3-5行，便于手机阅读
4. 保留最有冲击力的金句
5. 第一句抓住注意力，引发好奇
6. 用通俗语言解释干货，让普通人能看懂、有收获

### 表情符号使用原则

- 可在开头、小标题、重点句后适当使用
- 不要过度使用，保持专业感
- 常用：💡 ✨ 🔥 📌 ⭐ 🎯 💪 🤔

### Hashtag 规则

- 不超过10个
- 与文章主题高度相关
- 选择热门但不泛滥的标签
- 格式：#标签（井号后直接跟文字）
