## 发布正文（小红书图文）

```
自主招生，排在整个录取的第 1 批。

很多家长以为它是"提前上岸"的另一条路。
把官方手册翻出来看，会发现它更像"提前做一次选择"。

一、它在中考之后

普高自主招生考核安排在中考后进行，报名时间和具体办法另行通知。

这里有个容易混的地方：
中等职业学校及技工院校的自主招生考核，安排在中考前。
两类不是一回事。

二、报了它，你照样要中考、照样要填志愿

官方手册最后那张流程图，下面有一行注，原文是：
"有意向参加普通高中自主招生的考生，也须填报中考志愿，并参加中考。"

也就是说，自主招生既不是跳过中考，也不是不用填志愿。

三、被它录取了，后面的批次就跟你无关了

深圳高中阶段学校录取共分五个批次，按顺序依次进行：
自主招生批 → 名额分配批 → 统一招生（第一批、第二批、第三批）

手册原文：凡已被上一批次学校录取的考生，不再参加下一批次学校的录取。
另一条更硬：已被录取的考生，不得退档或转录其他学校。

四、它有多少名额

普高自主招生计划总比例，原则上控制在学校年度招生计划的 10% 以内。
（作为对照：中等职业学校及技工院校自主招生名额，原则上不超过本校当年招生计划的 30%。）

五、谁能报

一类：在理工科技、人文社科方面有专长的学生。
二类：在艺术、体育方面有专长的学生。
报考省一级普通高中自主招生的考生，综合素质评价结果须为"达标"。

所以自招不是"多一条命"，是"提前做一次选择"——选了就得认。

最后一张图是五个批次的顺序图，可以存下来。

（以上为 2026 年官方文件的写法，2027 年以当年发布为准）

数据来源：深圳市教育局《2026年深圳市高中阶段学校考生报考指导手册》、《关于深化高中阶段学校考试招生制度改革的实施意见》（深教规〔2024〕3号）。

免责声明：本文内容仅供参考，不构成任何录取承诺。自主招生的报名、考核与录取办法一律以深圳市教育局当年正式发布文件为准。
```
