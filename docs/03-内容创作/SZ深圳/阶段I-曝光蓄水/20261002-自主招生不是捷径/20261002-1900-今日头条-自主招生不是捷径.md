## 发布正文（微头条）

```
自主招生，排在整个录取的第 1 批。

但它不是"提前上岸"的捷径。官方手册写得很明白：

一、它在中考之后。
考核安排在中考后进行，报名时间和具体办法另行通知。

二、报了它，照样要中考、要填志愿。
手册流程图下那条注：有意向参加普通高中自主招生的考生，也须填报中考志愿，并参加中考。

三、被它录取了，后面的批次就跟你无关。
已被上一批次学校录取的考生，不再参加下一批次学校的录取；已被录取的，不得退档或转录其他学校。

四、有多少名额？
普高自主招生计划总比例，原则上控制在学校年度招生计划的 10% 以内。

所以自招不是"多一条命"，是"提前做一次选择"。

（2026 年官方写法，2027 年以当年发布为准）

数据来源：深圳市教育局《2026年深圳市高中阶段学校考生报考指导手册》、《关于深化高中阶段学校考试招生制度改革的实施意见》（深教规〔2024〕3号）。
```
