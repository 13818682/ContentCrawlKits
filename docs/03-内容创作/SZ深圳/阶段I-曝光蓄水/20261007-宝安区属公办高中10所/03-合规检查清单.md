## 二、🔴 「公办普高总数」与「市直属所数」有二义 —— 本包**故意不使用这两个数**

### 2.1 问题：同一张官方表，两套去重口径差 1

2026-10-06 做熔断复检时把《招生计划表》重数了一遍，发现**同一张表能算出两个"总数"**：

| 去重口径 | 公办普高总数 | 其中「市直属」 | 区属合计 | 宝安区 |
|---|---:|---:|---:|---:|
| 按官方**序号**（序号 1–100，**连续无缺号、无重复**） | **100** | **47** | **53** | **10** |
| 按**校名**去重 | **101** | **48** | **53** | **10** |

**差的这一个，是「深圳市第三高级中学」**——它在官方表里**占一个序号（23），但有两个名字**：
`深圳市第三高级中学（国内高考班）` ／ `深圳市第三高级中学（国家留学基金委自费出国留学班）`。

**其余 99 个条目在两套口径下完全相同。** 所以：
- 总数 = **100 或 101**，市直属 = **47 或 48** —— **取决于口径**；
- **「全市分到各区 = 53 所」和「宝安区 = 10 所」在两套口径下完全一致** ✅

### 2.2 仓库里已有的第三个版本：99

10-04 的计划稿（v2，**从未上线**）写的是「**99 所** ／ 47 市直属 ／ 区属 52」。
**99 比序号口径还少 1** —— 追查下来是**又合并了一次「翠园中学（爱国路校区）／（东门北路校区）」**。但**官方表本身给这两校区各编了一个序号（53、54）** —— 也就是说，**官方是分两所算的**，那个合并是**我方判断，不是官方口径**。

### 2.3 本包的处置：**不用这两个数**

| | |
|---|---|
| **做法** | 发布稿**只使用两套口径一致的 53（全市分到各区）与 10（宝安区）**；总数与市直属所数**一个字都不出现** |
| **为什么** | 这两个数的差值只有 1，**但差值落在"总数"这个读者一定会记住、也最容易被复述的位置**。赌错一次的代价，比少说一个数大 |
| **代价** | 钩子弱了一点（少了「47 所市直属」这个反常识数字），改用「**53 所分到各区**」承担同一功能 |
| **为什么不自作主张改成 100** | 仓库权威记忆 `2026-enrollment-data` 把「**101 所**」挂在深圳市教育局官方通知（`post_12794780`）上，P1-3-S5／P3 系列多份底稿也一律用 101。**该 URL 在本环境无法抓取核实**（`WebFetch` 被整体拦截，与 `official-policy-doc-library` 记的一致），我**没有独立证据推翻 101**，因此**不擅自改**——这正是 10-04 v1 翻车的教训 |

### 3.3 🎯 本条的重诊身份（这一节比前面的合规项更重要）

**背景**：10-06 复检判据触发（`20261006-四平台运营数据分析…md` §1.2/§1.3）。`08-阶段I` §3.3 原文：「**未提升 50% → 停下来重诊，不许继续加量**」。
**但熔断只说了"停下来"，没说"停下来干什么"。** 手里的两个 5 天块（09-26~09-29 好 ／ 10-01~10-05 差）**n=5 对 n=5，任何解释都能自圆其说**——题型、国庆假期、账号推荐疲劳、内容质量，**本期数据区分不了**。

**本条就是那个用来区分的实验**（`08-阶段I` §九 未决项 8 ／ 复检报告 §九 第 8 条）：

| | |
|---|---|
| **做法** | **用 10-04 的题型（分区 + 校名 + 分数线）换一个区，再做一次** |
| **判读 A** | 若本条也落在 **2,400 上下** → **题型可复现** → "分区 + 校名 + 分数线"应当做成系列 |
| **判读 B** | 若本条掉到 **1,200 上下** → **10-04 是运气**，且说明**账号侧（推荐池）确实在收紧** → 方向要转去查账号权重，不是选题 |
| **附加收益** | ① 顺带把「**市直属不划区**」这个口径讲对——这正是 10-04 上线的那条 v1 错的地方；② 复用 `00-阶段I主题计划` §三 里原本就有的「**宝安区**」档位（原 10-09，当时以"证据较弱"撤下，**而 10-04 的新数据把这条翻转了**） |

> ⚠️ **判读时必须扣掉一个混杂**：**10-04 上线的是作废稿**（`20261006-…分析.md` §三），内容是「13 所的分数表」，**与本条的命题并不相同**。所以本条**不能**直接当作 10-04 v2 的复现，只能当作**同一题型的第二次采样**。

`00-阶段I主题计划` §五 未决项 3 原话：「**分区地图是否值得做** —— 搜索词里没有"区"，证据较弱。**先试水 2 条看数据**」。

### 8.3 封面：方向采纳，做法折中

- **豆包说的「信息偏密」是对的**：原封面底部 4 行（8 行内容）。**仓库自家 `gzh-cover-simplified-style` 就要求「城市标识 ＋ 主题句 ＋ 一句钩子」** —— 原封面**超出了自家规范**。

- **未按豆包版全删**：只留疑问句、没有 payoff，等于把这条内容的信息量从封面抽走。
- ⚠️ **同时记一笔**：10-06 复检的结论是**曝光掉了、封面点击率没掉**（10-01~10-05 CTR 5.4%~8.7%，仍在正常带）。所以**这次封面调整是"回归自家规范"，不是"修一个已知的问题"**；若调整后 CTR 反而下滑，应**优先怀疑这次改动**。

### 8.4 一句话

**豆包这一轮的价值不在"改文笔"，在两条我们自己做漏了的事**：① 小红书该用 emoji 分区（我们自己写了规范却没执行）；② 结尾该有互动引导（`13-3` 模板白纸黑字）。**这两条本轮已经回写进发布稿与 §四 自检。**
**它的短板是流程性的**：不跑字数尺、不查仓库规范，且会动"封面钩子"这种**牵一发动全身**的地方。
