## 二、因此本条**刻意不写的东西**（重要）

| 🚫 不写 | 为什么 |
|---|---|
| 「2026 年 A 线 = XXX 分」 | **无官方出处**。写出来就是编 |
| 「A 线总分 552 / A+ 线 588 + 各科拆解」的自媒体换算表 | 来源为聚合站**倒推**，无法回源到官方公告 |
| 「过了 A 线就能上 XX 学校」 | 等级线是**定位线**不是录取线，这种表述本身就是错的 |

**本条给的是能证明的那一半**：A 线是什么（等级线）、比例怎么划（官方固定比例）、对应什么排名（15.3 万池子里的区间）、以及最关键的**认知纠正**。

## 七、格式变更：小红书正文改 ASCII 代码块

**经营者 2026-09-27 定**：**小红书文稿的正文部分，采用与今日头条相同的 ASCII 代码块格式**，便于直接复制粘贴。

| 载体 | 裸 markdown 段落 | ` ``` ` 代码块 |

| `数据来源` / `免责声明` | 在代码块外 | **并入代码块**（复制一次即得完整正文） |
