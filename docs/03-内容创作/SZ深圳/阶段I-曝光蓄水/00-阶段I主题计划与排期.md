# 阶段 I · 主题计划与排期（v2.0）

> **v1.0 作废的原因**：那一版是**从"我们有什么料"正推**的——我发现 62 篇终稿，就把它们排成计划。
> **经营者指出**：那 62 篇是围绕"说明招生政策"设计的，**不是从用户关注的角度设计的**。
> **v2.0 改为从"用户在搜什么"倒推**：先看三平台搜索联想词 → 再回头找料（有的能改造、有的要新产、有的做不了）。

---

## 一、选题判据（v2.0 的排序依据）

| 优先级 | 判据 | 说明 |
|:--:|---|---|
| **1** | **平台搜索联想词里出现** | 联想词是**平台按真实搜索量排序**给的，不是自媒体口径、不是外采估算。**这是最硬的证据** |
| **2** | **三平台共同出现 > 单平台** | 三个平台都有人搜 = 需求最普遍 |
| **3** | **能直接拿走** | 表 / 数 / 清单 / 日期，拿走即用 |
| **4** | **合规安全** | 踩红线的，需求照接、**出口换掉** |
| **5** | 常年有效 > 季节性 | 阶段 I 是低关注期，不要押季节 |

**料的三分**：`♻️ 改造`（有现成终稿）／ `🆕 新产`（没料）／ `🚫 不做`（越定位或踩红线）。

## 二、先定三条边界（本轮新增）

| # | 边界 | 依据 |
|:--:|---|---|
