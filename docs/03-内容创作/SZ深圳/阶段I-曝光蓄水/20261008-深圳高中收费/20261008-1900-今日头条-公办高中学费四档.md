## 发布正文（微头条）

```
深圳公办高中的学费，不是一个数，是四个数。

按学校等级分档，一学期：一般学校 905元、区一级 996元、市一级 1041元、省一级 1131元。最高档比最低档贵 226 元。

这四个数里已经含了课本费和练习本费——学校不能再另收课本资料费、练习本费、证册费、军训费等。住宿生另交住宿费 450 元。

公办中职另有免学费政策：符合条件的学生免学费，深圳市户籍也在范围内。

公办有价目表，是因为政府定价；民办高中没有统一价，因为民办高中收费实行市场调节价，由学校自己定。

（口径：深价联字〔2002〕37号，2002 年秋起执行；据市发改部门答复，现行仍按此执行）

数据来源：深圳市物价局、市教育局、市财政局《关于调整我市中小学收费标准全面实行"一费制"的通知》（深价联字〔2002〕37号）。

转给正在算学费的家长，先分清公办和民办是两套价。
```

> **字数**：见 `03-合规检查清单.md` §六（`_count_words.py` 实测）。**任何改动都要重跑脚本。**
> **四个数与本条的"四个数"钩子对应**：905 / 996 / 1041 / 1131。**末段那句"公办有价目表…民办没有"是收口**，也顺手解释了家长最常问的"为什么查不到民办的统一价"。
