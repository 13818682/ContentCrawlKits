## 二、修改意见

**1. 事实核查（联网）**
- 深价联字〔2002〕37号原文（四档 905/996/1041/1131、一费制、不得另收项）、深价〔2001〕49号住宿费 450 元、市属学校收费公示页、市发改委民办高中定价问答、中职免学费政策（深财教〔2013〕34号，深圳户籍在内）。

**2. 原稿问题与修正（4 处）**
- ① **"军训费"表述有风险**：37号文同时规定高一新生军训生活费（住宿、伙食、服装）按实际收取，正文已回避"军训费"表述。
- ② **"公办中职走另一套"不准确**：公办中职同适用 37号文标准，只是符合条件的学生免学费；免学费范围已按官方文件补全（农村/涉农/家庭经济困难/深圳户籍/持有效居住证非深户，艺术类相关表演专业除外）。
- ③ **"民办收费实行市场调节价"限定为"民办高中"**：民办义务教育实行政府定价/政府指导价，不能笼统说"民办"。
- ④ **补时效说明**：2002 年标准沿用至今，正文注明"深圳公办高中现行收费仍按此执行"。

**正文（可直接复制发布）**

```
深圳公办高中学费，不是一个数，是四个数。

按学校等级分档，每学期：一般学校905元、区一级996元、市一级1041元、省一级1131元，最高档比最低档贵226元。

这四个数已经含了杂费、课本教材费和练习本费——学校不能再另收课本资料费、练习本费、证册费、实习实验费等。住宿生另交住宿费450元/学期。

这套标准是2002年定下的“一费制”，一直沿用到现在，深圳公办高中现行收费仍按此执行。

公办中职是另一套：符合条件的学生免学费——农村（含县镇）学生、涉农专业学生、家庭经济困难学生、深圳户籍学生，以及监护人持有效居住证的非深户学生，都在免学费范围内（艺术类相关表演专业除外）。

公办有价目表，因为公办高中学费、住宿费实行政府定价；民办高中没有统一价，实行市场调节价，由学校根据办学成本、市场需求自主确定，并按规定公示。

转给正在算学费的家长：先分清公办和民办是两套价，别拿民办的价去比公办。

（依据：深价联字〔2002〕37号；民办高中定价依据：粤发改规〔2018〕14号）

#深圳升学 #深圳高中 #高中学费 #深圳家长
```
