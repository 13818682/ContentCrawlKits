## 〇、先纠正一个我自己犯的错

我上一版的主题计划，直接照搬了全仓 **62 篇「公众号-终稿」**。经营者的批评是准的：

> **那 62 篇是围绕"说明和介绍招生政策"设计的，不是从用户关注的角度设计的。**

**那 62 篇不是废料，但不能当计划用。** 它们的正确用法是：**当某个"用户真正在意的问题"确定之后**，回去看有没有现成的料可以直接改造。**顺序是先有问题、再找料，不是先有料、再找问题。**

## 二、用户心理：三条已有证据支持的判断

### 2.1 家长要的是「我该怎么办」，不是「这是什么」

J4 的意图分布是硬证据：

> **找方法（7）> 找数据（5）> 找答案（4）> 找同类（1）**

**决策方法型内容的搜索需求最大。** 这与经营者 2026-09-25 的判断一致：

> 家长要的是你能**解决问题**，而不是让他**又要去学习**。让他确信找我们能快速解决问题，不是找我们来上课学政策。

### 2.2 焦虑来自「差几分、稳不稳」，不是「不懂政策」

J4 抓到的原话样本：

> *"我是深圳的一名初三生，目前564，深中有希望吗？"*

**这是一句典型的问题：他不需要解释录取规则，他需要有人告诉他"够不够"。** 同类焦虑还有：体育中等偏下怕拖总分、模考失常怕无学可上、D 类面对"同校不同计划不同线"。

### 2.3 🔴 身份差异（AC / D）是最强的情绪源

本轮 firecrawl 发现，公共讨论里正在传的核心对比是：

| 说法 | 出处（2026-09-25 采） |
|---|---|
| **「深户 86% vs 非深户 24%」** | 知乎专栏《深圳中考真相来了，深户86%非深户24%》 |
| **「深户公办普高录取率超 85%，非深户只有 24%，同个学校非深户要多考 30~50 分」** | 抖音笔记《非深户VS深户，深圳中考差距太现实！》 |
| **「每 100 个深圳中考生：73 人上普通高中、52 人上公办普高、27 人读中职技校」** | 新浪（2026-09-23 前后） |

⚠️ **这些数字口径未经核验，不得直接采用**（见 §五）。但**它们的传播本身是证据**：家长在转的就是这种"身份 + 百分比 + 差距"的对比。

J3 也二次确认：**D 类 / 非深户方向的系统性供给仍是空白**（距 2026-08-08 的 `dcategory-parent-research` 一个月后再次确认）。

## 三、用户最关注的问题（按「当下能不能用」重排）

J4 已经给了 52 问，但**是按主题分类的，不是按可用性排序的**。选题要用后者。我重排成三档：

### 🟢 A 档 · 9–10 月就能用（阶段 I 主攻）

| 用户在意的问题 | 为什么现在能用 |
|---|---|
| **孩子现在这个分数，能上哪几所高中？** | 初三第一次月考 9 月底考、10 月初出分 → **需求就在眼前** |
| **模考分数怎么换算成中考定位？** | 公开讨论里反复出现（本轮 firecrawl 采到多篇"模考→目标高中"对照表） |
| **四大/八大/十五大到底怎么排？我够得着哪个？** | 常年有人问（J4 #15/#16） |
| **非深户 / D 类到底难多少？差多少分、有多少名额？** | 当下公共讨论最热的对比（§2.3）；也是我们最强的独占领域 |
| **有哪些公办高中在我这个区？分数线多少？** | 分区代入感天然强（J4 #18） |
| **初一二现在该做什么，免得初三来不及？** | J4 #28/#29；初一二家长现在就有行动需求 |
| **体育 / 听说 / 理化实验怎么拿分、要不要报班？** | J4 #41~46；**常年有效、不依赖季节** |

### 🟡 B 档 · 明年 3 月起才真有用（阶段 I 不做，留作库存）

志愿填报梯度、指标生怎么选不撞车、批次与投档规则、滑档补救、补录、复读。

> **这些不是不重要，是"现在发没人看"**——正是经营者指出的季节错位。

### ⚪ C 档 · 官方文件映射的确定性需求（常年可做）

报名时间、分值构成、等级线、成绩查询、招考办节点。

> 注意：**这类内容我们已经发过很多遍**（分值构成在小红书发了 3 次、非深户 3 次、时间线 2 次），**继续发是同题重发**。

## 四、本轮 firecrawl 补采（2026-09-25）

### 4.1 时效信号

| 发现 | 意义 |
|---|---|
| **09-23 生地会考放榜，"朋友圈和家长群都被分数线刷屏了"**（腾讯新闻，09-23） | **证实 09-23 QA-006 抢的那个热点是真的**；也说明"出分/放榜"这类节点是账号最该抢的窗口 |
| **「深户 86% vs 非深户 24%」正在知乎 + 抖音同步传播** | 09-26 头条话题的核心钩子（见 §2.3） |
| **「模考分数 → 目标高中梯队」对照表在多个渠道流传**（A+线 550+ → 深中/实验/外语/高级；534+ → 红岭/宝中） | **验证了"月考出分后发定位"的排期判断**——这是真实存在的公共需求 |
| 民办高中"高一高二一套节奏、高三另一套"的择校角度 | 一个我们没用过的择校切口 |
| "中考比高考难！深圳初中家长拼了"（家长抽背、整理错题） | 家长**参与度**类内容（我们没做过） |

### 4.2 本轮采到的可用规则

- **名额分配控制线的官方算法**：按该校**前三年相应招生类别录取线（同比例换算为 630 分制）的平均值下降 20 分**划定。（深圳市教育局 2026 年招生工作通知）
- 总分 **610 → 630**（2026 年起），理化实验操作单独计分 20 分。（深圳中考改革实施意见）

### 4.3 已确认采不到的

- 小红书垂类账号的粉丝/内容矩阵（J3 已标"未编造榜单"，本轮仍进不去）
- 抖音/视频号的同类数据
- **家长评论区的真实提问**

> **这三块需要你在 App 内看**（成本远低于外采，且比外采准）。**具体要看什么，见 §六。**

## 六、需要你去 App 里看的（我做不了的部分）

按价值排序，**这三件比我再搜十次都值**：

1. **小红书搜索框输入"深圳中考"** → 看下拉 **10 个联想词**（那是平台真实的搜索量排序，外采绝对拿不到）
