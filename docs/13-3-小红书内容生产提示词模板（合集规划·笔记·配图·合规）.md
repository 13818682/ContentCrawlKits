# 小红书内容生产提示词模板（合集规划 · 笔记 · 配图 · 合规）

## 文档概述

本文档定义小红书平台内容生产全流程：**合集规划 → 单篇笔记 → 首图/配图 → 合规自检**，并固化平台规范、命名规则与可复用提示词。

- **参考合集**：`S1-基本态势` 7 主题 → 12 篇笔记（2026-08-22 规划并获批）
- **配套规范**：与 `08-九大平台文案撰写要求说明书.md` 第2.3节「小红书」互为补充；本文档为可执行工作流

## 一、小红书平台规范（强制）

| 要素 | 规范 |
|---|---|
| **标题** | ≤20字，数字+痛点/看点，可用 emoji 点缀，**首行即标题** |
| **正文** | 300-700字（长文≤1000字含标签）；碎片化阅读，单篇浏览30-90秒 |
| **结构** | 痛点钩子（1-2句）→ emoji 分区 3-4 个要点 → 个人建议/总结 → 话题标签 |
| **语气** | "闺蜜分享"感：真实、接地气、不说教；禁用"小编""笔者"官方自称 |
| **配图** | 3-9张，**首图必须带文字标题**（决定点击率）；封面 1080×1440（3:4） |
| **话题标签** | 5-8 个精准标签，放文末；热门但不泛滥 |
| **互动引导** | 结尾提问引导评论（"你家孩子几年级？评论区聊聊"） |
| **合集** | 系列笔记建小红书合集（如「2027届深圳中考家长必看」）串联 |

### 合规红线（小红书社区规范）
- 禁止绝对化用语：最、第一、顶级、100%、史上最
- 不夸大功效、不诱导互动（"双击有惊喜"）
- **不站外引流**：不直接导流 HSEE 小程序/外链/二维码；可软性提示"搜一下HSEE"
- 不贩卖焦虑、不挑起对立；用"风控语言"（帮避坑、消焦虑）
- 内容原创或已获授权；数据标注来源

## 三、内容形态与流量策略（图文 · 视频 · 长文）

小红书有三种内容形态，**本合集以「图文笔记」为主力**，视频与长文做补充放大：

| 维度 | 图文笔记（主力） | 视频（补充） | 长文（深度） |
|---|---|---|---|
| 适合 | 干货/数据/攻略/升学指南 | 破误解/情绪/口播科普 | 重大政策深度解读 |
| 搜索流量 | ⭐⭐⭐⭐⭐ 家长主动搜关键词，图文收录最好 | ⭐⭐ | ⭐⭐⭐ |
| 收藏率 | ⭐⭐⭐⭐⭐ 时间线/清单/数据卡高收藏 | ⭐⭐⭐ | ⭐⭐⭐ |
| 信息密度 | ⭐⭐⭐⭐⭐ 数据表格/对比/时间轴清晰 | ⭐⭐ | ⭐⭐⭐⭐ |
| 推荐流曝光 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ 视频易进推荐 | ⭐⭐ |
| 制作成本 | ⭐⭐⭐⭐⭐ 可批量 | ⭐⭐ | ⭐⭐⭐ |

**混合打法**：
1. **图文笔记先跑搜索+收藏**：12篇按三批发布，用数据复盘哪几篇收藏/互动高
2. **高流量选题转视频放大**（进推荐流）：本系列最值得转视频的——
   - #7 52%录取率=一半没书读？（破误解，有话题性）
   - #1 2026中考结束，2027届家长别空等（口播"现在该做什么"）
   - #10 走读最高降35分（有争议点，易引评论）
3. **重大政策用长文做深度权威**：2027年3-5月新政策发布时，图文+长文联动，建立专业壁垒

## 四、单篇笔记生产提示词

**输入**：对应公众号终版 md / 今日头条长文 md
**输出**：`{序号}-{文章编号}-{标题}-小红书-{角度}.md`

```
你是小红书教育类博主，人设是深圳本地升学规划师/过来人家长。请把下面的{素材}改写成一篇小红书图文笔记。

【小红书要求】
- 标题：≤20字，数字+痛点/看点，可加 emoji
- 正文：300-500字。痛点钩子开头（1-2句）→ 3-4个要点（每点2-3句，emoji 做视觉分区）→ 个人建议/总结 → 话题标签
- 语气：闺蜜式分享，真实接地气不说教；用"你""你家孩子"；禁用"小编/笔者"
- 数据：保留关键数字并标注来源；数据是权威支撑，不夸大
- 合规：不用"最/第一/100%/史上最"绝对化词；不贩卖焦虑；不站外引流（不直接推HSEE）
- 结尾：提问引导评论（"你家孩子几年级？评论区聊聊"）+ 收藏提醒
- 话题标签：5-8个精准标签，如 #深圳中考 #2027中考 #初三 #深圳家长 #升学规划 #非深户 等按主题配

【frontmatter】
platform: "小红书"
series / article / status / word_count / source
title: 笔记标题（≤20字）
tags: [标签列表]
cover: 首图文件名（如 `13-S1-1-{标题}-小红书-{角度}-首图-1080x1440.png`）
images: [正文图文件名列表]（如 `...-正文图-{内容}-1080x1440.png`，与文件一一对应）
note_number: 合集内编号（如 #1/#12）

【输入素材】
{素材 md}

【输出】
1. frontmatter（含 title / tags / cover）
2. 笔记正文（emoji分区 + 标签）
```

## 五、文件命名规则

统一 **`{序号}-{文章编号}-{文章标题}-小红书-{角度}.md`**（序号=同目录下一个空号；文章标题与公众号版本逐字一致）。

| 说明 | 示例 |
|---|---|
| 单篇笔记 | `13-S1-1-2026年深圳中考已结束，2027届家长现在该做什么？-小红书-启点-3件事.md` |
| 同主题多篇 | `07-S1-5-...-小红书-52%真相.md`、`08-S1-5-...-小红书-中职3+4.md` |

## 六、配图规范

- **画布**：首图 1080×1440（3:4），必须带文字标题，决定点击率；正文图同比例 1080×1440，信息流展示统一
- **字号规范（2026-08-22 定稿，保证清晰可读）**：
  - 主标题 44px；大数字 56px；**标签/短标题 34px**；**正文说明统一 30px**（卡片说明/表格单元格/清单描述/时间线说明）
  - **可读性下限 22px**：`fit_font` 缩字不得低于 22px，防止正文被缩到看不清
  - 表格列宽必须与字号匹配（如 2 列"含义"列 ≥590px），避免列宽不足触发自动缩字
- **信息图类型**：数据卡 / 对比表 / 清单 / 趋势图 / 时间线（可复用公众号/今日头条数据图素材裁切适配）
- **风格**：与系列统一（深蓝渐变 + 金色数据 + 微软雅黑），见 13-1/13-2 模板配色
- 每篇建议 2-4 张：首图 + 1-3 张正文信息图
