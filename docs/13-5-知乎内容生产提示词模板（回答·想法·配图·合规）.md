# 知乎内容生产提示词模板（回答 · 想法 · 配图 · 合规）

## 文档概述

本文档定义知乎平台内容生产全流程：**回答（主力）→ 想法（引流钩子）→ 配图 → 合规自检**，并固化平台规范、撰写思路、文件命名与可复用提示词。

- **参考案例**：`S1-1 启点` 知乎双件套（2026-08-23 产出，位于 `03-内容创作-.../S1-1-.../05.知乎/`）
- **配套规范**：与 `08-九大平台文案撰写要求说明书.md` 第2.6节「知乎」互为补充；本文档为可执行工作流
- **内容形态**：回答（高流量问题长尾搜索）+ 想法（提问钩子引流）+ 文章（政策深度期用）

---

## 一、知乎平台规范（强制）

| 要素 | 规范 |
|---|---|
| **用户画像** | 18-40岁，高学历、高收入群体集中；搜索驱动，长尾流量显著 |
| **内容特点** | 先给结论再展开；重逻辑严谨与来源标注；**信息密度要高，水文会被点踩** |
| **回答字数** | 800-2000字（按问题深度）；文章 1500-3000字；想法 150-250字 |
| **结构** | 结论先行 → 分点论证 → 数据支撑 → 来源标注 → 总结 |
| **语气** | 理性、客观、专业；可用第一人称经验分享，但要逻辑自洽；禁营销腔、禁"小编"腔 |
| **数据标注** | **每个引用的数据必须标注来源**，知乎用户对此极为敏感 |
| **标题公式** | 知乎标题 = 问题本身。选题即选"要回答什么问题"（政策解释型/方法指导型/经验分享型） |
| **搜索优化** | 回答高流量问题可获得持续搜索流量；挂到关注者多、浏览高的问题下 |

### 合规红线（知乎社区规范 + 项目策略）

- 数据逐条标注官方来源（深圳市教育局深教〔2026〕34号 / 招生计划通知 / 深圳特区报），来源附文末
- **弱化营销**：不硬广、不软广堆砌；品牌引导一句轻量带过即可（"HSEE小程序免费可查"）；不站外贴链接
- 不绝对化（无"保证录取/100%/一定"）、不预测分数线与录取结果
- 不贩卖焦虑、不挑起户籍对立；用"帮你提前建立认知"代替"你再不准备就来不及"
- AI 内容标识遵循项目策略：对外不提 AI，保留人工核对证据（数据核验清单）

## 二、内容矩阵与双件套打法

### 每个主题 = 回答（主）+ 想法（引流）双件套

| 形态 | 定位 | 产出 | 作用 |
|---|---|---|---|
| **回答** | 主力，完整答案 | 1篇 md | 承接搜索流量，建立专业信任 |
| **想法** | 提问钩子，不给答案 | 1篇 md + 1图 | 引发思考、评论区互动、引流到回答 |
| 文章 | 政策深度期（2027.3-5）用 | 1篇 md | 建立权威壁垒，覆盖长文搜索 |

**双件套联动逻辑**：想法先抛问题 + 给背景条件（钩子）→ 回答承接，首尾呼应地把问题讲透。发布节奏建议同日，想法在前做入口，回答承接完整答案；回答发布后可把链接补充到想法评论区置顶。

### S1 系列应用规划

S1-1~S1-7 每个主题产出「1回答 + 1想法 + 2配图」，分别存至各主题目录下 `05.知乎/` 子目录。已产出：S1-1 双件套（本模板依据）。

## 三、撰写思路（文案方法论）

### 回答：按读者心理旅程组织

不要罗列要点，要陪读者走完一段心理过程：

```
① 先说结论          → 第一句给核心答案（"如果你家孩子9月升初三，现在就是最佳时机……"）
② 点破"还早"错觉    → "你觉得还早？'还早'恰恰是差距开始的地方"（抓住观望/焦虑两类读者）
③ 为什么是现在      → 承接想法的问题/条件，逐条论证"为什么是当下"（数据+来源）
④ 具体做什么        → 2-3件可执行的事，每件配数据+来源（5分钟能做完的颗粒度）
⑤ 卸下焦虑          → 明确"现在不必做/不必焦虑"的事（给读者松一口气）
⑥ 总结升华 + CTA    → 核心金句（中考考的是家庭的信息获取能力）+ 轻量品牌引导 + 评论区互动
⑦ 数据来源背书      → 文末官方来源清单，逐条人工核对
```

**承接想法的关键动作**：若同一主题先发了想法，回答开篇要回扣它——"上一篇想法里我抛了个问题，只给了4个背景条件让大家先猜。今天把答案补上：……"，把设问的答案（唯一该做的一件事）在开篇讲清楚，形成首尾闭环。

### 想法：提问型钩子（不直接回答）

```
① 第一句抛出问题（问题即钩子，如"2026年深圳中考已结束，2027届家长现在该做什么？"）
② 给2-4条背景/条件事实（帮读者理解"为什么现在要问"，制造"原来如此"的认知张力）
③ 留白设问："这N个条件摆在一起，你觉得它们共同指向什么？"
④ 互动引导："我先不说答案。评论区聊聊你的判断"
⑤ 引流："我的详细分析写成了回答，点我主页可看"
⑥ 话题标签：#话题# 格式（知乎想法自动关联话题）
```

**核心原则**：背景条件只做钩子、不展开论证，答案留白，把"想验证答案"的好奇心导向主页回答。

## 四、生产提示词

### 4.1 回答提示词

**输入**：对应公众号终版 md / 今日头条长文 md + 目标问题
**输出**：`{序号}-{文章编号}-{标题}-知乎-回答.md`

```
你是知乎教育领域答主，专业背景为深圳本地升学规划。请把下面的{素材}改写为一篇知乎回答，回答的问题：{目标问题}。

【知乎要求】
- 字数：800-2000字；风格：理性、专业、有据可查
- 结构（按读者心理旅程）：
  ① 先说结论：第一句给核心答案
  ② 点破"还早/跟我没关系"的错觉，抓住读者注意力
  ③ 承接上一篇想法的问题（若有）：用背景条件逐条论证"为什么是现在"
  ④ 具体做什么：分2-3点给可操作建议，每点配数据+来源
  ⑤ 卸下焦虑：明确"现在不必做/不必焦虑"的事
  ⑥ 总结升华 + 核心金句 + 轻量品牌引导 + 评论区互动引导
- 数据必须标注来源（来源：深教〔2026〕34号 / 招生计划通知 / 深圳特区报），文末附数据来源清单
- 信息密度要高，拒绝水文；禁"小编/笔者"营销腔；品牌引导一句轻量带过
- 结尾附2-3个相关推荐问题（可引导进一步阅读）

【frontmatter】
platform: "知乎"
series / article / status / word_count / source
target_question: 目标问题
question_type: 方法指导型 / 政策解释型 / 经验分享型
cover: 回答配图文件名（如 `03-S1-1-{标题}-知乎-回答配图-三组数字-1600x900.png`）
related_questions: [推荐问题列表]

【输入素材】
{素材 md}

【输出】
1. frontmatter（含 target_question / question_type / cover / related_questions）
2. 回答正文
```

### 4.2 想法提示词

**输入**：同主题回答 md（提炼钩子用）
**输出**：`{序号}-{文章编号}-{标题}-知乎-想法.md`

```
你是知乎教育领域答主。请基于下面的{回答素材}，写一条知乎"想法"（短文案），用于为回答引流。

【知乎想法要求】
- 字数：150-250字；纯文本（不含markdown标题/加粗/分隔线），可直接复制粘贴发布
- 结构（提问型钩子，不直接给答案）：
  ① 第一句抛出问题
  ② 给2-4条背景/条件事实（帮读者理解"为什么现在要问"，制造认知张力，不展开论证）
  ③ 留白设问："这N个条件摆在一起，你觉得它们共同指向什么？"
  ④ 互动引导："我先不说答案。评论区聊聊你的判断"
  ⑤ 引流："我的详细分析写成了回答，点我主页可看"
  ⑥ 话题标签：#深圳中考# #2027中考# #升学规划# 等（#话题# 格式）
- 背景事实可含数据，但只作钩子，不展开、不标注详尽的来源

【frontmatter】
platform: "知乎"
series / article / status / word_count / source
related_answer: 同主题回答文件名
cover: 想法配图文件名（如 `04-S1-1-{标题}-知乎-想法配图-三组数字-1080x1080.png`）

【输出】
1. frontmatter
2. 想法正文（用"--- 复制从这里开始 / 复制到这里结束 ---"界定可粘贴范围）
3. 发布说明（配图/话题输入技巧/引流到回答/发布节奏/互动技巧——标注"不粘贴"）
```

### 4.3 复制即贴的文件排版约定

想法 md 与回答 md 都采用"打开即选、复制即贴"结构：
- frontmatter（元数据）→ 正文（发布内容，纯文本）→ 发布说明（标注"不用粘贴"）
- 想法用 `--- 复制从这里开始（本行及以下分隔线不复制） ---` 界定可粘贴范围，分隔线本身不属于正文

## 五、文件命名规则

统一 **`{序号}-{文章编号}-{文章标题}-知乎-{类型}.{ext}`**（序号=同目录下一个空号；文章标题与公众号版本逐字一致），存至各主题目录 `05.知乎/` 下。

| 说明 | 示例 |
|---|---|
| 回答 | `01-S1-1-2026年深圳中考已结束，2027届家长现在该做什么？-知乎-回答.md` |
| 想法 | `02-S1-1-...-知乎-想法.md` |
| 回答配图 | `03-S1-1-...-知乎-回答配图-三组数字-1600x900.png` |
| 想法配图 | `04-S1-1-...-知乎-想法配图-三组数字-1080x1080.png` |
| 构建脚本 | `_build_zhihu_s1_1.py`（保留，便于复改复生成） |

## 六、配图规范

### 6.1 画布与类型

| 配图 | 画布 | 类型 | 用途 |
|---|---|---|---|
| **回答配图** | 1600×900（16:9） | 数据信息图（三组数字卡等） | 插回答中部，提高阅读完成率 |
| **想法配图** | 1080×1080（方形） | 数据卡（数字纵排） | 随想法发布，带图点击率更高 |

### 6.2 字号规范（2026-08-23 定稿，正文放大版）

| 文字层级 | 回答配图 1600×900 | 想法配图 1080×1080 |
|---|---|---|
| 主标题 | 78 bold | 44 bold |
| 副标题 | 34 | 30 |
| 大数字 | 84 bold | 66 bold |
| 标签 | 40 bold | 38 bold |
| 说明 | 32 | 30 |
| 底部金句/次要行 | 38 bold / 26 | 34 bold / 30 / 26 |

**通用规则**：
- **卡片/行内说明文字保持单行短句（8-12字内）**，放大字号后不挤不遮；宁短勿长，长句会被 `put()` 自动缩字反而看不清
- 展示大数字/主标题不缩放；正文（起点≤17px）按 ×1.35 放大规则（与 13-1 长图一致）
- `put()` 带 `maxw` 越界自适应，脚本末尾 `verify()` 0 越界检查
- 卡片高度需随字号加高重排（如回答配图卡片 340→390），避免文字重叠

### 6.3 风格与脚本

- **配色**：深蓝渐变 `TOP=(27,58,92) → BOT=(13,30,48)`；金 `GOLD=(245,198,107)`；卡片 `CARD=(31,66,106)`、描边 `EDGE=(58,100,148)`；浅蓝 `LIGHT=(157,184,212)`、灰蓝 `SUB=(201,217,232)`
- **字体**：微软雅黑 `C:/Windows/Fonts/msyhbd.ttc`（bold）/ `msyh.ttc`
- **构建脚本**：复制 `_build_zhihu_s1_1.py` 改标题/数据/输出路径即可，一次生成回答配图+想法配图两张

## 七、发布前自检清单

- [ ] 回答 800-2000字；结论先行；按心理旅程组织（结论→点破错觉→为什么现在→做什么→不必焦虑→总结→来源）
- [ ] 承接想法的设问，开篇给出"唯一该做的事"的答案（若该主题先发了想法）
- [ ] 每个引用数据标注来源；文末附官方来源清单
- [ ] 无营销腔、无硬广、品牌引导一句轻量带过
- [ ] 想法：提问型钩子，背景只做条件不给答案；纯文本可直接粘贴；150-250字
- [ ] 配图：回答图 1600×900、想法图 1080×1080；正文字号达 6.2 标准；卡片说明为短句；0 越界
- [ ] 话题标签用 `#话题#` 格式；想法可选已有话题更易被搜索
- [ ] 文件名符合第5节命名规则，存放于 `05.知乎/` 子目录
- [ ] 数据全部来自官方公开信息，逐条人工核对（S1 系列数据核验清单 100% 覆盖）
