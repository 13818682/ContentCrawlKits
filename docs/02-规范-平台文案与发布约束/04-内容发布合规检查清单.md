# 内容发布合规检查清单

## 文档概述

本文档是HSEE内容创作平台的内容发布合规底线手册。每篇内容发布前必须通过本清单检查。

### 适用范围

所有发布到外部平台（小红书/抖音/B站/公众号/头条）的内容，以及同步到HSEE小程序的内容。

---

## 一、AI生成内容标识（硬性法规要求）

**法规依据**：《人工智能生成合成内容标识办法》（2025年9月1日施行），国家互联网信息办公室、工业和信息化部、公安部、国家广播电视总局联合发布。

### 1.1 显式标识（第4条）

| 内容类型 | 标识方式 | 示例 |
|---------|---------|------|
| **图文内容**（小红书/公众号/头条） | 文末添加文字提示 | "⚠️ 本文由AI辅助生成，数据经人工核验" |
| **短视频**（抖音/B站） | 视频末尾画面或评论置顶 | "本内容由AI辅助制作" |
| **音频内容** | 音频末尾语音提示 | —（验证阶段不涉及） |

**位置要求**：
- 文本类：文末最后一行，字号不小于正文
- 视频类：结尾画面停留≥2秒

### 1.2 隐式标识（第5条）

发布到HSEE小程序的内容在存入数据库时自动注入元数据：

```json
{
  "ai_generated": true,
  "provider_code": "HSEE-CCP-001",
  "content_id": "{自动生成}",
  "generation_model": "doubao-pro-32k",
  "created_at": "{自动生成}"
}
```

验证阶段人工发布到外部平台时，平台自身不会记录隐式标识。自建阶段通过蚁小二API分发时，在文件元数据中注入。

### 1.3 禁止行为（第10条）

- ❌ 不得删除、篡改、伪造、隐匿AI生成标识
- ❌ 不得为他人删除标识提供工具或服务
- ❌ 不得通过不正当标识手段损害他人合法权益

违反后果：网信、电信、公安、广电四部门联合执法，按各自职责处罚。

## 二、内容红线（禁止事项）

### 2.1 预测类禁止

| 禁止 | 正确做法 |
|------|---------|
| "今年XX学校的录取线应该在575分左右" | "2025年该校录取线为574分（AC类住宿生），今年数据以教育局公布为准" |
| "你家孩子这个分数肯定能上XX学校" | "你的分数在这个区间，近3年录取线在这个范围内的学校有XX、XX、XX" |
| "今年指标生大概能降20分" | "2025年XX学校指标生录取线比正取低18分，今年情况可能会有所不同" |

**核心原则**：只引用已发生的、官方已公布的数据。不对未来结果做任何形式的预测或承诺。

### 2.2 承诺类禁止

| 禁止 | 正确做法 |
|------|---------|
| "保证录取""100%上岸" | 全文绝对不出现这种词汇 |
| "按照这个方案填，稳进" | "这个方案基于近3年数据设计，可以作为参考，最终决策请结合最新官方信息" |
| "内部渠道""特殊名额" | 绝对不出现。你的数据全部来自公开信息 |

### 2.3 虚假信息禁止

- 不得编造学校名称、分数线、招生人数
- 不得编造"某家长""某学生"的真实经历（可以匿名化案例，但必须基于真实事件改编）
- 引用政策时必须标注来源和发布时间，不得引用已废止的政策

### 2.4 免责声明（每篇必加）

```
免责声明：本文内容仅供参考，不构成任何录取承诺。文中数据整理自官方公开发布的文件。志愿填报最终决策请以官方最新发布文件为准。
```

> **2026-09-21 模板修订（v2）**：删去原句中的「**及 HSEE数据平台整理**」，并去掉两个具名机构（原为"深圳市教育局公开信息"＋"深圳市招生考试办公室"）。
> **删的理由**：①「HSEE数据平台」是**第三个名字**——既非注册主体（罗湖旭日领航信息咨询工作室）、非小程序对外名（**HSEE择校助手**）、也非内部仓名，对外没有指称对象；② 免责声明的功能是**划清责任边界**，而"数据来源于自家平台整理"是**主动把责任拉回来**，与本条目的相反，且与 `data-source-attribution`（对外统一写官方来源，不写内部名）冲突；③ 原句前后**混用两个机构名**（教育局 / 招考办），读者不知以谁为准。
> ⚠️ **仍待核**：深圳中考的报考指导手册／招生计划，**实际发布主体是教育局还是招考办**？核出后可在末句具名（如"整理自深圳市招生考试办公室公开发布的文件"）。**核出前不具名，只写"官方"。**
> **影响面**：本条为"每篇必加"，**改模板只影响此后新稿，历史已发稿不回溯**（本仓惯例）。

### 2.5 绝对化用语与比较性宣传（2026-10-08 新增）

**依据**：《广告法》＋市场监管总局《广告绝对化用语执法指南》。原 `04` 只有「不做学校排名」这一条，
覆盖不了通用绝对化用语；本区补齐。

#### 2.5.1 绝对化用语

| ❌ 禁用 | 说明 | ✅ 改法 |
|---|---|---|
| **最**好／最强／最受欢迎／最优 | "最"字族 | 给**可查证的具体事实**（"2026 年 AC 类住宿线 583"） |
| **第一**／顶级／**唯一**／遥遥领先 | 序数与地位断言 | **只有能证明"在全深圳范围确实只有这一个"时才可用**，否则删 |
| **保证**／100%／一定／必然 | 效果与结果承诺 | 删；改"参考""通常" |
| **始终**／每个／永远／全部／一律 | 全称量词 | "通常""大部分""多数" |
| **统一**（用于本非统一之事） | ⚠️ **2026-10-08 实证**：把"省一级那一档 1131"写成"全市公办高中**统一**收费标准" | 说明分档条件；无法穷尽时不用"统一" |
| 「权威」「官方认证」类 | 权威标准是什么？谁来认定？ | 指名到具体文件 |

> **口径**："**唯一**"这类词，只有当**我们真的能在全范围内穷尽验证**时才可用。
> 例：10-04 稿里「10 所里唯一 D 类更低的是宝安中学」——这是**在已列举的 10 所内穷尽**的结果，可用；
> 但若写成「深圳唯一」，就超出我们验证得动的范围，**不可用**。

#### 2.5.2 比较性宣传（**加强审查**）

**直接或暗示与友商／其他主体比较**的表述，逐条过：

| ❌ 风险写法 | 为什么 | ✅ 改法 |
|---|---|---|
| "比 XX 号更全／更快" | 缺可比基准与统计口径 | 用可查证的数据对比，或抽象为"比传统做法…"并附出处 |
| "别家做不到这个" | 若别家也能做 → 涉嫌虚假 | 只做**功能/内容展示**，让读者自己比 |
| "我们的数据最准" | 无法证实 | 说明**数据来源**（官方文件名单），让出处说话 |
| "别的号都在抄" | 贬损同业 | 删；只讲自己怎么做 |

> ⚠️ **易漏点**：**"公办 vs 民办"这类对比不算比较广告**——那是**两个类别**，不是与从业者的竞争比较（2026-10-08 判定）。
> 但**同类别内**（某号 vs 某号、某机构 vs 某机构）的比较，一律按本节审。

### 2.6 未成年人定向（2026-10-08 新增）

**依据**：《广告法》《未成年人保护法》及教育、培训类广告监管要求——
**不得向未满 18 周岁未成年人投放**，**不得宣传在中小学校、幼儿园内及周边进行精准广告推送**。

🔴 **本仓的特殊性**：我们的内容**全部面向中考家长**，但**内容对象是初中生（未成年人）**。
所以判断标准不是"写没写孩子"，而是——**这篇是在对孩子说话，还是在跟家长说话？**

| ❌ 风险写法 | 为什么 | ✅ 改法 |
|---|---|---|
| 「寒暑假就要到啦」一类**以学生为谈话对象**的开场 | 暗示目标人群为学生 | 改成对家长说话（「家里有深圳中考生？」） |
| 「同学们」「学弟学妹们」 | 人称直接指向未成年人 | 改「家长」「你家孩子」 |
| 「同学们快收藏」「转发给同学」 | 诱导未成年人转发／互动 | 改为对家长的引导 |
| 出现**具体学校＋具体年龄/年级**的精准指向 | 近似校园内精准推送 | 只讲全市／全区口径，不指名到班到校到人 |
| 出现学生**个人**信息（姓名／校服照片／成绩单） | 个人信息 + 未成年人 | 绝对禁止（另见 §四） |

**检查项**
- [ ] 人称与呼语**一律指向家长**（"你""你家孩子""家长"），不出现直接对学生说话的口吻
- [ ] 引导动作（收藏/评论/转发）**是请家长做的**，不是请学生做的
- [ ] 无"精准到某校某班某人"的指向
- [ ] 无学生个人信息

> **判据一句话**：**"这段话说给谁听？"** 若答案里出现"孩子/学生"，回去改。

## 三、采集合规

### 3.1 采集行为规范

| 规则 | 具体要求 |
|------|---------|
| 采集目的 | 仅用于选题调研和行文结构参考，不得直接搬运商用 |
| 采集频率 | 间隔≥12秒/条，不突破平台反爬机制 |
| 采集范围 | 仅抓取公开可见内容，不抓取付费/私密内容 |
| 反爬声明 | 如平台或账号明确设置了反爬声明，不抓取其内容 |
| 内容时效 | 仅抓取近3个月内容 |

### 3.2 使用规范

- 采集内容与发布内容的语义相似度必须<30%
- AI改写后必须进行"深度重构"——同义词替换不够，需要换结构、换角度、换观点
- 采集的每一篇素材都保留操作日志：来源URL、采集时间、用途（哪个选题参考）、改写后内容ID

你的平台不收集用户个人信息（用户数据在HSEE侧），但内容中引用的案例需要注意：

| 规则 | 具体做法 |
|------|---------|

## 五、发布前检查清单

每条内容发布前对照：

### A. AI标识检查
- [ ] **发布稿正文不写入 AI 文字标识**（2026-09-16 用户定）：不放 `⚠️ 本文由AI辅助生成，数据经人工核验` 一类的文字行，也不放评论区置顶标识文案
- [ ] 发布时勾选平台自带的"AI辅助创作"声明开关 —— **这是当前 AI 标识的唯一落点**
- [ ] 平台侧声明确认已勾选生效，未被遮挡或折叠

> ⚠️ **与本文件 §1.1 的关系**：§1.1 依据《人工智能生成合成内容标识办法》第4条，要求图文类在**文末加文字提示**。2026-09-16 用户明示决定**不在正文写入文字标识，改由平台声明开关承担**。本清单按用户决定执行；平台若无该开关，该篇即处于无标识状态，**风险由发布人自担**。

### F. 发布稿文件洁净（2026-09-16 新增）

发布稿（`…-发布稿.md` / `…-微头条.md`）是**复制粘贴源**，正文里只留会被贴出去的内容：

- [ ] 正文里**没有** `## 发布前自检` 一类内部区块 —— 自检项归各任务目录下的 `06-…-合规检查清单.md`
- [ ] 正文里**没有** AI 文字标识行（见 A 区）
- [ ] 发布稿正文格式干净：无编号残留、无"待确认/待补"字样、无脚本路径或内部表名

### G. 首图定性前缀（2026-09-18 新增，用户要求）

**问题**：封面／首帧的主题句如果含限定条件，脱离上下文会被读成**普遍规则**。
> 实例：P1-5-S2 公众号封面「初中三年不能转学」、抖音首帧「初中三年 6 个学期／中间转过一次就没了」——**会被读成"初中不允许转学"这条校规**，而真实语义是**"指标生资格要求三年不转学"**。

- [ ] **公众号封面**：主题句含限定条件时，主题文字前必须有**定性前缀**（如「指标生资格：」）
- [ ] **抖音首帧**：同上，前缀以独立金色行置于主题文字上方
- [ ] 短载体（小红书／微头条）标题本身已定性者免加（如「指标生资格自查：这 4 条错 1 条就没了」已含"指标生资格"）

> **判定口径**：若主题句脱离上下文后能被读成"一条普遍规则"（而非"某类考生的某项条件"），就必须加前缀。
> **落地样板**：`docs/03-…/P1-5-名额分配指标生/子任务S2-学籍资格自查/_build_p15_s2_imgs.py` 的 `gzh_cover()` 与 `dy_card(..., pre=)` 参数。

### H. 公众号支持 Markdown 直导（2026-10-06 新增，经营者给定）

**平台事实**：**公众号后台支持从 Markdown 格式直接导入，文档结构与表格均可正常显示。**

- ✅ **表格是合法呈现**——发布稿里可以留 Markdown 表格，导入后台即成表。
  ⚠️ 原先"数字多就必须改叙述"的写法，**自本条起收窄为只针对 bullet 列表**，不针对表格。
- ✅ **怎么选**：需要"扫一眼就懂"的对比 → **优先表格**；需要"感到处境"的 → 叙述。两者都不违规。
- ❌ **仍然禁止**：bullet 堆数字（`- 529 分` / `- 515 分` …）——表格能干的活，用 bullet 干是排版偷懒。

**检查项**
- [ ] 需要对比的数据优先做成 Markdown 表格，不要一行一句、不要 bullet 罗列
- [ ] 表内数字与正文**逐字一致**（表格是错字的常见藏身处）
- [ ] 表格前后有引导句，讲清"这张表要你看什么"

> **连带修订**：`de-ai` 技能 D 层的"连续数字列表超过 2 个 → 改叙述"同步收窄。

### I. 数字溯源审计（2026-10-08 新增）
