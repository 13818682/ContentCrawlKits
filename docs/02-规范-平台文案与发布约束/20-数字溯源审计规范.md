# 数字溯源审计规范

> **一句话**：一条数字主张有三个独立问题——**出处是谁 / 出处是否真的支撑这句话 / 证据有多强**。
> **主题相关不等于支持**；**出处真实不等于用法正确**。

---

## 一、为什么要有它（两个实证，不是理论）

| 事故 | 数字本身 | 错在哪 |
|---|---|---|
| **20261004**（已上线，2 天后更正） | 「龙岗区有 13 所」 | **出处是真的**——`_rows_1001.json` 里确实有一列写着"龙岗"。但那一列**不是官方分区**（是第三方表 `P3-2` 的"区域"列）。**主题相关，不支撑"这是官方分区"这句话** |
| **20261008**（上线前拦下） | 「公办高中统一 1131 元」 | **数字是真的**——1131 确实是公办高中某一档的价。但它**只是省一级那一档**，放到"统一标准"的位置上就错了。**引用真实，不等于引用正确** |

**两次都不是"编数"，是"把真数字放错了位置"。** 查"数字对不对"拦不住这两类，必须查"这句话能不能被这个出处支持"。

---

## 二、审计对象：什么算"一条数字主张"

**不是只看阿拉伯数字**。以下都算：

- 任何**数值**（分数、人数、比例、金额、年份）
- 任何**排名／序数**（第 3 所、最高、最低）
- 任何**计数**（共 N 所、只有 N 条）
- **强断言**：**「首次」「唯一」「全部」「普遍」「统一」「一律」「从来」「必然」**
- **因果／机制**表述：**「导致」「决定」「因为…所以…」**
- **范围外推**：把某区/某校/某年的结论扩到全市/全部/常年
- **制度归属**：说"某政策规定…""某部门要求…"——**这是最容易错的一类**

## 三、三问（每条都要能回答）

### 问 1｜出处是谁？

- 必须能指名到**具体文件 / 具体页面**，不是"网上查的""资料显示"。
- **禁止的出处**：搜索结果摘要、AI 生成的摘要、自媒体聚合站、第三方整理的表格、竞品内容。
- ⚠️ **去重**：同一份数字在多个自媒体上重复出现，**不构成多源交叉验证**——它们往往是同一个源头抄来抄去。

### 问 2｜出处是否**真的**支撑这句话？

逐项比：

| 比什么 | 反例（10-04） | 反例（10-08） |
|---|---|---|
| **对象**是否一致 | 表里的"龙岗"≠ 官方口径的龙岗区 | 1131 是"省一级"≠"全体公办高中" |
| **范围**是否一致 | 13 所 ≠ 官方 8 所 | 一个档位 ≠ 一个统一标准 |
| **口径**是否一致 | 第三方表 ≠ 官方《招生计划表》 | 学杂费 ≠ 学费 |
| **时点**是否一致 | — | 2002 年的标准 **是否现行**要单独确认 |
| **方向**是否一致 | — | 相关性有没有被写成因果 |
| **强度**是否匹配 | "13 所" → 说成"龙岗全部" | "一档" → 说成"统一" |

> **一句话判据**：**把句子里的数字抽掉，问"这个出处能不能替我把这句话说完"**。只能支持半句的，就要拆句或降调。

### 问 3｜证据有多强？（四级）

| 级 | 定义 | 能放哪 |
|:--:|---|---|
| **A 原件级** | 拿到文件**原始载体**（官方 PDF／官网正文／纸质件），逐条比对过 | 正文 + **封面/首屏主视觉** |
| **B 条文级** | 拿到**全文或可靠镜像**，条款可逐字引用 | 正文 + **封面/首屏主视觉** |
| **C 摘要级** | 只有**搜索引擎摘要**，未取原文 | **可进正文，须带限定语**（"以官方公布为准"）；**不进封面主视觉** |
| **D 转述级** | 自媒体／聚合站／第三方表格 | **不进正文**（除非明标来源且仅作背景） |

**强制声明**：稿中**不得**出现"已核对原件""经核实"一类措辞，**除非该项确实是 A 级**。
→ C/D 级数据在稿中的存在感，必须靠**限定语**压回去，不能靠省略。

## 四、第二个轴：这条规则**适用**吗？

证据够强，不代表**规则适用于当前场景**。每条引用规则另标适用性：

| 标记 | 含义 | 处置 |
|---|---|---|
| **【已确认适用】** | 稳定、明确适用于当前场景的法规／规范性文件 | 可直接用 |
| **【需核实是否适用】** | 案例、平台规则、地方执法口径、**已换代但未确认废止的旧文** | **用前单独核**；核不了就**不用** |
| **【我方提供】** | 自家规则／标准 | 标明是自家口径 |

> **10-08 实例**：`粤发改规〔2018〕14号` 与 `粤发改规〔2025〕1号` 同时在网上存在。**旧文未确认废止，就不引旧文**——引最新且注明施行日期。
> **另一实例**：`深价联字〔2002〕37号` 里有「借读生书杂费」一档，**未核现行是否仍收** → 标【需核实是否适用】→ **不用**。

---

## 五、优先深查的五类

审计精力不平均分配。**下列五类必须查到出处原件或条文**，其余可走快速确认：

1. **要上封面／首屏／海报的数字** —— 曝光最大，错了代价最高
2. **家长会据此做决定**的数字（分数、费用、名额、时间）
3. **强断言**（首次／唯一／全部／统一／一律）
4. **因果／机制**表述
5. **制度归属**（"某文件规定…"）

## 六、我们踩过的坑 → 对照表

| 坑 | 表现 | 审计哪一问能拦住 |
|---|---|---|
| **第三方冒充官方** | 拿第三方表的列当官方口径 | 问 1（出处是谁）+ 问 2（口径是否一致） |
| **一档当全体** | 省一级 1131 → "统一标准" | 问 2（范围是否一致） |
| **二手转述当原始** | `_rows_1001.json`（源自 markdown 表）当官方 | 问 1 + 证据级 D |
| **旧文号** | 〔2018〕14号 ↔ 〔2025〕1号 | §四 适用性标记 |
| **主题相关当支持** | "有这一列"≠"支持这个说法" | 问 2 总判据 |
| **没有查清写成没有问题** | 把核不到的当默认正确 | 证据级 + 限定语 |
| **多自媒体重复当交叉验证** | 五个号都写同一个数 | 问 1 去重条 |
