## 一、抖音平台规范（强制）

| 要素 | 规范 |
|---|---|
| **脚本结构** | 开头突出文字（视频前3秒大字显示核心观点）→ 0-3秒 Hook（痛点/悬念/数据冲击）→ 主体（分点讲）→ CTA引导 |
| **开头突出文字** | ⭐ **每个视频必须**在开头用突出大字号显示本视频核心观点（如"中职3+4，400分段的一条本科路"），让受众第一时间记住核心内容。写入脚本（frontmatter `opening_text` + 口播脚本开头段），≤12字、大字清晰 |
| **素材依据** | ⭐ 撰写前先通读对应目录的**公众号极简版**（同主题 `01-公众号/` 下 `*-终版-极简.md`），以它为素材源；口播脚本是"浓缩"，**不是"阉割"**——核心数据点必须保留 |
| **不缩减核心内容** | ⭐ 三组关键数字、对比数据（如 52% vs 73%）、分层结论（如 D类23%、480-530分段）**不得删减**；宁可多拆几条，不可一条里砍掉核心点 |
| **口播风格** | 快节奏、口语化、一句话一个信息点；"像跟朋友说一件很重要的事" |
| **标题** | 10-15字，强吸引，多用"别/千万/竟然/原来"等情绪词 |
| **标签** | 3-5个（#深圳中考 #2027中考 #升学规划 等） |
| **时长** | **黄金档 50-75秒**（口播 220-300字）；上限90秒。**太短（<45秒）说明删了核心内容，需回炉扩充** |
| **转化设计** | 口播引导"点我主页" + 评论区置顶引导语 |

### 标题公式
```
模板1：反常识   "深圳中考填志愿，越保守反而越容易滑档"
模板2：紧迫感   "距离志愿填报还有3天，这5个坑现在知道还不晚"
模板3：数据冲击 "深圳中考15万考生，只有一半能上公办"
模板4：结果承诺 "记住这3个数字，你家孩子的志愿方案不会差"
```

## 三、口播脚本生成提示词

**输入**：公众号终版 md / 今日头条长文 md
**输出**：`{序号}-{文章编号}-{标题}-抖音-{角度}.md`（存入 `04.抖音/`）

```
你是抖音教育类口播博主，受众是刷短视频的深圳家长。请把下面的{素材}改写成一个抖音口播脚本。

【抖音要求】
- 素材依据：先通读同目录**公众号终版-极简**，以它为素材源，不凭空缩写
- 时长：**黄金档 50-75秒**，口播稿 220-300字（勿过短；<45秒即删了核心内容，需扩充）
- 结构：**开头突出文字（视频前3秒大字显示核心观点，≤12字）**→ 0-3秒强Hook（数据冲击/反常识/痛点/紧迫感）→ 主体2-3个信息点（每点1-2句）→ 结尾CTA
- **不缩减核心内容**：三组关键数字、对比数据、分层结论必须保留，宁可拆条不可删点
- 风格：快节奏、口语化、一句话一个信息点；多用"你/你家孩子"
- 标题：10-15字，含情绪词（别/竟然/原来/真相）
- 标签：3-5个精准标签
- 合规：数据准确不夸大、不贩卖焦虑、无绝对化用语
- 数据：保留关键数字，来源可标注（深圳市教育局公开信息）

【frontmatter】
platform: "抖音"
series / article / title / duration / word_count / status / source / tags
cover_text: 封面大字（用于视频封面）
opening_text: 开头突出文字（视频前3秒大字显示的核心观点）

【输出】
1. frontmatter（含 cover_text + opening_text）
2. 抖音视频标题
3. 开头突出文字（≤12字核心观点）
4. 口播脚本（标注 开头突出文字/Hook/主体/CTA 分段）
5. 评论区置顶引导语
6. 封面文字

【输入素材】
{素材 md}
```

## 六、分镜头图片生成规范（1080×1920 9:16 竖屏）——定稿 2026-08-28 / 修订 2026-08-31

> **触发**：仅当用户明确要求"为某任务生成分镜头图"时产出；默认仍走剪映 AI 文本成片自动配图。已产示例：S1-6（9张，`04.抖音/` 下 `_build_shots_s1_6.py` 可复用）。

### 6.1 规格与命名

| 项 | 规范 |
|---|---|
| 尺寸 | **1080×1920（9:16 竖屏）**，每镜头一张 |
| 命名 | `{序号}-{文章标题}-抖音-{角度}-镜头NN-{描述}-1080x1920.png`（示例：`01-S1-6-...-抖音-4条出路-镜头01-核心观点-1080x1920.png`） |
| 脚本 | `_build_shots_s1_X.py` 留在 `04.抖音/`，复制改内容即可复用 |
| 分镜规划 | 对齐口播脚本分段：核心观点大字 → Hook → 各层信息点 → 全景覆盖 → CTA |

### 6.2 背景设计（蓝色基准 + 光影层次，不单调）

以深蓝为基准色，叠加三层视觉变化：

| 层次 | 实现 |
|---|---|
| **色调过渡** | 三段渐变：亮蓝 `#264a7e` → 中蓝 `#16304e` → 深蓝黑 `#0a1628`（纵向） |
| **明暗对比** | 对角明暗：右上亮、左下暗（`0.60+0.40×diag`），制造体积感 |
| **光影变化** | ① 主光斑：亮蓝柔光，4 组位置**轮换**（每镜头不同，整套不重复）；② 青色副光：左下冷色补光；③ 暖金角落光：右下淡金色，冷暖对比 |

### 6.3 文字与边框规范（放大 + 间隙协调）

| 项 | 规范 |
|---|---|
| **正文字号** | 正文整体放大 **1/3**（`SC=4/3`），清晰可读；主标题不放大，保持层级 |
| **行距/间距** | 文字放大后，行距同步加大（数字与标签垂直间距 ≥100px） |
| **卡片边框** | 随文字加大：数据卡 840×220-240、大卡 900×400；圆角 30；卡间距 40-50px |
| **卡内布局** | **所有文字水平居中**（2026-08-31 定稿）：数据卡=数字居中上（金）+标签居中下（浅灰），垂直对称；列表卡=「数字(金)+标题(白)」组合**居中于上半** + 说明**居中于下半**；多行卡以卡心为基准上下均匀排布——避免数字与标签水平重叠 |
| **文字不穿越** | 放在 box 内的文字，渲染边界必须**完整落在 box 内**，一字不得穿越边框（`gap_report()` 逐卡检测） |
| **边框-文字留白** | 四边留白 **上下≥25px、左右≥40px**（2026-08-31 由 ≥15px 上调，保证呼吸感；`gap_report()` 逐卡检测上/下/左/右最小间隙） |
| **卡间距** | ≥30px（`gap_report()` 输出卡间距） |

### 6.4 文字颜色层级（防重叠）

| 层级 | 颜色 | 用途 |
|---|---|---|
| 主标题 | 白 | 核心观点/主信息 |
| 数字强调 | 金 `#f5c66b` | 数据卡数字 |
| 说明文字 | 浅蓝 `#9db8d4` | Hook/说明 |
| 标签/来源 | 浅灰 `#c9d9e8` | 卡片标签、底部来源 |

> ⚠️ **已踩坑**：数据卡若"数字左 + 标签右"同行，大号数字会横向伸出与右侧浅灰标签重叠。**必须垂直排布**（数字上、标签下）。

### 6.5 验收

- [ ] 全部文字 0 越界（`verify()`）
- [ ] 所有文字**水平居中**（含列表卡「数字+标题」组合与说明）
- [ ] 文字**不穿越**文本框；卡内四边留白 **上下≥25px、左右≥40px**（`gap_report()`）
- [ ] 卡间距 ≥30px
- [ ] 数字（金）与标签（浅灰）不重叠
- [ ] 首图：话题+兴趣点放大、含反差数据带与关注 CTA
- [ ] 口播开头大字在前 2 秒兑现标题钩子
- [ ] 背景有光影层次，非纯色平铺

### 6.6 首图（封面）规范——2026-08-31 定稿（QA-001 实测）

首图=镜头01，是信息流缩略图，**决定点击率**。画面节奏一条链：**问题 → 答案 → 数据 → 关注**，缩略图上一眼读完。

| 要求 | 说明 |
|---|---|
| **话题放大** | 核心问题/主题两行大字（62px 级），白字带投影 |
| **兴趣点放大** | 直接答案/反差数据用**巨型金色**（如「能！」200-230px）作视觉焦点，带投影 |
| **数据带** | 1 条反差数据（如 54% vs 23%）金色对撞托底，勾起好奇 |
| **关注 CTA** | 首图底部放金色「关注我」pill，引导关注（对齐北极星获粉转化率） |
| **副钩** | 「5项条件 · 3条路 · 一次讲清」类信息量预告，抬升点击 |

### 6.7 标题钩子前 2 秒兑现——2026-08-31 定稿

- 视频标题/封面提出的钩子（如「非深户能读高中吗？」），**必须在画面出现后 2 秒内给出答案/结论**，不吊胃口。
- 三处落点缺一不可：①口播脚本「开头大字」（前3秒大字显示）= 直接给答案；②镜头01（封面）巨型答案即兑现；③镜头02（Hook）开场第一句重复答案。
- 禁止把结论藏到主体中段才揭晓；镜头01 必须含答案大字。

### 剪映"AI文本成片"流程（约10分钟/条）——脚本适配要求（2026-08-28 定稿）

**脚本侧要求**（交给 AI文本成片前）：
- 时长约 **60秒**（不宜过短）
- 内容**连贯叙述、不要过于间断**——核心要素完整，避免碎片化短句（AI按脚本段落匹配镜头，断句太多成片会跳）
- 开头核心要素以**显眼大字呈现**（frontmatter `opening_text` + 脚本开头段，≤12字，让受众一眼看到）

**剪映操作要求**：
1. 剪映 → AI文本成片 → 粘贴口播脚本
2. AI自动匹配素材 → 替换为 HSEE 数据图（3数字卡/对比表/趋势图，可复用各平台信息图）
3. 选配音音色（成熟女声，适配家长受众）
4. **字幕上移1行**——避开底部按钮/水印遮挡区，字幕勿压画面底部
5. 检查自动字幕（**重点核对数据/校名/数字**）
6. 导出 9:16（抖音竖屏）

> ⚠️ 剪映/智影 API 不一定稳定——先手动验证效果，稳定后再做 API 对接（设计文档既定原则）。

## 十、跨平台视频复用（小红书 / 今日头条）——定稿 2026-08-24

> **决策**：抖音为唯一视频生产源，mp4 产出后复用至小红书、今日头条（同源同题材）。以下为时长与复用策略，已同步至 `00-S1-平台内容发布清单表.md` 与 `00-系列创作规划方案.md §3.3`。

### 10.1 视频时长建议

| 档位 | 时长 | 口播字数 | 适用 |
|---|---|---|---|
| 单点钩子型 | 35-40 秒 | ~150字 | 只讲一个反常识/一个数字 |
| **黄金主档** ⭐ | **50-75 秒** | 220-300字 | 一个钩子点讲透：数据冲击→解释→对家长意义→行动 |
| 数据复盘型 | 60-75 秒 | 240-300字 | 需要完整推理链（如走读降35分、3+4） |
| **上限** | **90 秒** | ~360字 | 超过 90 秒完播率断崖，禁止 |

- **30 秒过短**：中考志愿是高风险决策，30秒（约120字）只够抛一个数据，讲不透。
- **"内容被省"的正解是拆条，不是拉长**：一个主题拆 2-3 条，每条聚焦一个钩子点（S1-1、S1-5 为范例）。**不要为装更多内容拉到 90 秒**——信息过载→划走。

### 10.2 三平台视频定位与复用效果

| 平台 | 定位 | 复用价值 | 关键动作 | 预期 |
|---|---|---|---|---|
| **抖音** | 主战场（拉新、推荐流量） | —（生产源） | 剪映图文成片 9:16，成熟女声 | — |
| **小红书（视频）** | 信任资产（收藏/种草/二次触达） | **高** | ①无水印导出；②换 3:4 封面+标题大字；③换话题标签 | 直发 60-70%，适配后 80-90% |
| **今日头条（视频）** | 长尾覆盖（搜索 SEO / 中视频收益） | **低-中** | 头条偏好横屏16:9；**1分钟以下无中视频分成** | 直发 50-60%，非爆发 |

> **优先级提醒**：小红书视频复用性价比高，值得做；今日头条视频若仅为覆盖而发性价比最低——头条核心阵地是图文长文+微头条。若想拿中视频收益，需单独做横屏 1-3 分钟版（从图文长文改）。

### 10.3 跨平台复用最低动作（三件套）

1. **无水印导出**：剪映导出时关闭抖音水印，避免小红书/头条降权。
2. **封面/标题/标签适配**：小红书换 3:4 封面+大字标题+话题；头条换信息量标题+封面三图。
3. **简介换平台话术**：简介按平台规范改写，勿照搬抖音版。
