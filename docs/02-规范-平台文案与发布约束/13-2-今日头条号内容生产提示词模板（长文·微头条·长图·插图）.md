# 今日头条号内容生产提示词模板（长文 · 微头条 · 长图 · 插图）

## 文档概述

本文档沉淀今日头条号的**一鱼多吃**内容生产全流程：从公众号终版长文出发，一次产出 **今日头条长文 → 微头条短版 → 配套图片（封面3张+正文图）**，并固化文件命名规则、格式要求与可复用提示词。

- **参考样例**：`S1-1`（《2026年深圳中考已结束，2027届家长现在该做什么？》）已按本模板产出全套，可对照使用
- **配套规范**：与 `08-九大平台文案撰写要求说明书.md` 第2.9节「今日头条」互为补充；本文档是可执行的工作流与提示词
- **docx 说明**：今日头条APP后台可直接导入 docx，但 **docx 由发布人员用外部工具生成**（Word/WPS/Typora/在线 Markdown 转换器等），系统不参与 docx 生成，只产出 md 与配图

## 一、文件命名规则（统一前缀）

所有产出统一以 **`{序号}-{文章编号}-{文章标题}-{平台}-{内容类型}.{扩展名}`** 命名。

| 前缀组成 | 说明 | 示例（S1-1） |
|---|---|---|
| `{序号}-` | 同目录内类型序号（01简报/02公众号初稿/…/08今日头条） | `08-` |
| `{文章编号}-` | 系列+编号 | `S1-1-` |
| `{文章标题}-` | 完整标题，含标点 | `2026年深圳中考已结束，2027届家长现在该做什么？-` |
| `{平台}-` | 公众号 / 今日头条 | `今日头条-` |
| `{内容类型}` | 见下表 | `封面1-主标题` |

**图片统一规格**：`1200×900` PNG（头条封面/正文图推荐尺寸）。

### 1.1 内容类型后缀一览（以 S1-1 为例）

| 内容类型 | 命名后缀 | 文件示例 |
|---|---|---|
| 长文 md | `今日头条` | `08-S1-1-{标题}-今日头条.md` |
| 长文 docx | `今日头条` | `08-S1-1-{标题}-今日头条.docx` |
| 微头条 md | `今日头条-微头条` | `08-S1-1-{标题}-今日头条-微头条.md` |
| 微头条 docx | `今日头条-微头条` | `08-S1-1-{标题}-今日头条-微头条.docx` |
| 封面① | `今日头条-封面1-主标题` | `08-S1-1-{标题}-今日头条-封面1-主标题-1200x900.png` |
| 封面② | `今日头条-封面2-录取率数据` | `08-S1-1-{标题}-今日头条-封面2-录取率数据-1200x900.png` |
| 封面③ | `今日头条-封面3-信息优势` | `08-S1-1-{标题}-今日头条-封面3-信息优势-1200x900.png` |
| 正文首图 | `今日头条-微头条配图-3关键数字` | `08-S1-1-{标题}-今日头条-微头条配图-3关键数字-1200x900.png` |
| 正文图2 | `今日头条-正文图2-数据速览` | `08-S1-1-{标题}-今日头条-正文图2-数据速览-1200x900.png` |
| 正文图3 | `今日头条-正文图3-备考时间轴` | `08-S1-1-{标题}-今日头条-正文图3-备考时间轴-1200x900.png` |

> ⚠️ **命名纪律**：标题部分必须与文章标题逐字一致（含"深圳"、含"？"）；平台后缀紧跟标题之后；配图描述放在类型后缀。参考样例中曾出现"标题漏字/漏标点""序号跨段（06/09-12）"等历史偏差，一律以前缀表为准。
>
> 📄 **docx 命名**：docx 为外部工具生成，文件名同样遵循上表（长文 `-今日头条.docx`、微头条 `-今日头条-微头条.docx`），与对应 md 同名同目录，便于导入头条后台后溯源。

## 二、今日头条长文转换提示词

**输入**：公众号终版 md（或任一基础素材 md）
**输出**：`{序号}-{文章编号}-{标题}-今日头条.md`

```
你是今日头条教育领域创作者，专注深圳本地升学资讯。请把下面的{公众号终版文章}转换为符合今日头条格式规范的图文长文。

【今日头条格式要求】
- 标题：20-30字（上限30字），信息量+看点，含数字和关键词，严禁标题党。产出1个主标题+2个备选标题
- 字数：1200-2000字
- 结构：导语钩子（2-3句直抛核心信息）→ 正文3-5段（一级章节用H2、二级用H3）→ 结尾头条式CTA
- 语气：资讯感+实用感，比公众号更"新闻化"，不做观点秀
- 排版：移除公众号式的---分隔线，靠小标题断句；数据类信息转成Markdown表格增强信息密度；关键句用**加粗**
- 数据：所有数据保留完整，标注来源（深圳市教育局/招考办）
- 标题层级：H1只放文章标题（填入头条号标题栏，不粘进正文），正文从导语开始
- 结尾CTA：引导关注 + 评论区互动提问（如"你家孩子升几年级？评论区聊聊"）

【结构红线（2026-08-31 定稿，QA-003 两次反馈）】
1. **禁用"第一部分·直接答案 + 第二部分·完整回答"两段式**——头条读者一次读完，不设"第二部分"。直接答案的结论要点**融入导语**（开头2-3句给核心答案），正文直接进入章节展开
2. **禁用"📖 目录"清单**——头条长文不设目录。正文用 H2/H3 小标题自然分段即可，目录冗余且打断阅读
3. 结论先行保持：导语直抛核心结论 + 关键数字，正文逐节展开，结尾头条式CTA

【frontmatter要求】
- 保留：version / platform(今日头条) / series / article / status / word_count / source
- 新增：title_primary（主标题）/ title_options（2个备选标题）/ summary（头条摘要）/ cover（封面3张1200×900说明）

【输入素材】
{公众号终版文章 md}

【输出】
1. frontmatter
2. 主标题 + 2个备选标题
3. 完整正文（含H2/H3层级、表格、加粗）
```

## 三、微头条生成提示词

**输入**：今日头条长文 md
**输出**：`{序号}-{文章编号}-{标题}-今日头条-微头条.md`

```
你是今日头条创作者。请把下面的{今日头条长文}提炼成一条可单独发布的微头条短帖（300-500字）。

【微头条要求】
- 字数：300-500字（上限800）
- 首句：数据冲击或痛点开场（如"2026深圳中考7月底收官，15.30万考生去向落定"）
- 结构：首句抓人 → 2-4条核心信息（用·或1.分条）→ 不必做的事一句带过 → 引流长文 + 关注CTA
- 风格：口语化、资讯实用感，不做观点秀
- 结尾：挂出长文标题《{长文标题}》引流 + "关注我，{系列}连载持续更新" + 评论区互动提问
- 数据：保留关键数字并标注来源

【frontmatter要求】
platform: 今日头条-微头条
linked_article: {长文文件名}
image: {微头条配图文件名}

【输入素材】
{今日头条长文 md}

【输出】
1. frontmatter
2. 微头条正文
```

## 五、docx 发布文件（外部工具生成）

今日头条APP后台支持直接导入 docx，但 **docx 不在系统生产链路内**，由发布人员用外部工具生成（Word/WPS/Typora/在线 Markdown 转换器等）。本文档仅明确格式要求，供外部工具/发布人员对照：

- **输入**：长文 md / 微头条 md；**输出**：同名 `.docx`（命名见第1节）
- **必须保留**：H1-H3 标题层级、列表、**表格**、`**加粗**`
- **必须剔除**：YAML frontmatter、HTML 注释（`<!-- ... -->`）
- 中文字体正常渲染、无乱码（Word/WPS 打开即按系统字体回退）
- docx 内 H1 为文章标题；头条号标题栏另填 frontmatter 的 `title_primary`
- 导入后逐段核对：标题样式、表格列宽、加粗是否被头条后台正确识别

## 六、标准工作流（一次配齐）

```
① 长文转换        （第2节提示词 → 产出 长文.md）
     ↓
② 微头条提炼      （第3节提示词 → 产出 微头条.md）
     ↓
③ 配图生成        （第4节提示词/附录A脚本 → 产出 封面1/2/3 + 正文图2/3 + 微头条配图）
     ↓
④ 命名核对 + 自检清单（见第7节）
```

> docx 由发布人员在④之后、正式发布前用外部工具生成（要求见第5节），不在系统链路内。
>
> **发布顺序**：先发微头条占位引流 → 同日或随后发长文；封面选三图样式进信息流。

## 七、发布前自检清单

- [ ] 标题：20-30字、含数字/关键词、非标题党；已放入 frontmatter `title_primary`
- [ ] 正文：1000-2500字；H2/H3 层级完整；数据已表格化；加粗了关键结论
- [ ] **结构红线**：无"第一部分·直接答案"两段式（结论已融入导语）；无"📖 目录"清单；正文按 H2/H3 小标题自然分段
- [ ] 数据：全部来自深圳市教育局/招考办公开信息，逐条人工核对
- [ ] 结尾：含关注 CTA + 评论区互动提问
- [ ] 微头条：300-500字；首句抓人；已挂长文标题引流；含 `linked_article` / `image` 字段
- [ ] 配图：封面3张 + 正文图齐备，1200×900，命名前缀统一，安全区内无文字裁切
- [ ] **图文一致 + 字号可读**：正文图内容对应正文章节（如"三组数字"章节配数据卡、不配无关图）；正文文字清晰可读（1080宽画布正文≥30px，1200宽可等比换算），无被缩成小字的文字
- [ ] docx（外部工具生成）：标题层级/表格/加粗保留，无 frontmatter 残留，中文字体正常
- [ ] 命名：所有文件前缀与第1节一致（标题逐字含标点、平台后缀紧随其后）

## 附录A：配图 PIL 生成要点

```python
from PIL import Image, ImageDraw, ImageFont
FB = "C:/Windows/Fonts/msyhbd.ttc"   # 微软雅黑粗体
FR = "C:/Windows/Fonts/msyh.ttc"     # 微软雅黑
W, H = 1200, 900
GOLD = (242, 184, 75)

def gradient(d, top=(20,59,115), bot=(11,37,69)):
    for y in range(H):
        t = y/H
        d.line([(0,y),(W,y)], fill=(int(top[0]+(bot[0]-top[0])*t), int(top[1]+(bot[1]-top[1])*t), int(top[2]+(bot[2]-top[2])*t)))

def badge(d, txt, y=88):            # 顶部胶囊徽章
    f = ImageFont.truetype(FB, 24); bb = d.textbbox((0,0), txt, font=f)
    pad = 24; x0 = (W-(bb[2]+pad*2))/2; x1 = x0+bb[2]+pad*2; y1 = y+bb[3]+pad*1.6
    d.rounded_rectangle([x0,y,x1,y1], radius=30, outline=GOLD, width=2)
    d.text(((x0+x1)/2,(y+y1)/2), txt, font=f, fill=GOLD, anchor="mm")

def center(d, text, font, fill, y, x=W/2):   # 居中文本
    d.text((x, y), text, font=font, fill=fill, anchor="mm")
```

（完整版见 S1-1 目录已产出的 6 张图；脚本模式：封面=渐变+徽章+大字标题，正文表=浅底+深蓝表头+白卡行，时间轴=横线+金色高亮首节点。）
