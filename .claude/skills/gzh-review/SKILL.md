# 公众号稿件审查（管骨）

**腔和骨是两件事。** 本技能查**骨**：类型、信任链、故事线、数据呈现、系列钩子、优先级。**文风与 AI 腔归 `de-ai`。**

> **先跑第一节的硬规矩，再跑后面的通用方法论。** 顺序反了，通用方法论会给出正确但违规的建议。

## 一、本仓硬规矩（先跑，不许破）

| # | 规矩 | 违反了会怎样 |
|:--:|---|---|
| 1 | **专业者不自贬**——❌「我卡了」「我查了半天没弄懂」「我花了一整个下午」。**耗时只能挂在家长身上** | 人设塌 |
| 2 | **⑤ 段形状随篇、相邻不重复**（A 未决事项／B 推进预告／C 方法交付） | 连着三篇同一个收尾 |
| 3 | **产品只亮名字、不亮进度**；产品事实须经营者给口径 | 承诺落空 |
| 4 | 数据必须标**官方来源**；**不估算、不推倒** | 造谣 |
| 5 | 红线：不称"专家／老师／名师"、不承诺、不制造焦虑 | 违规 |
| 6 | **跨篇去重**——同一组数据／同一个人物，**同平台不允许换个角度再说一遍**。定稿前先查同平台发过没有 | 同质化限流 |

## 二、审查顺序

**0. 先判类型** → 1. 信任链 → 2. 故事线回扣 → 3. 数据呈现 → 4. 系列钩子 → 5. 术语门槛 → 6. 发布前清理

### 0. 先判类型，再定标准

| 类型 | 该长什么样 |
|---|---|
| **故事纪实** | 具体的人、具体的时间地点；**结尾要回扣开头那个人** |
| **专业解读** | 概念首次出现给人话；结论要有依据；数据要成体系 |
| **方法清单** | 每一项能带走；结尾要落成"你现在就能用的东西" |
| **进度通报** | 讲清了"到哪一步"和"下一步"；不给时间承诺 |

**类型不匹配是 P1**——故事纪实写成方法清单，读者会走。

### 1. 信任链：一条链，逐环问

```
故事  →  我的判断  →  我凭什么能做  →  产品／下一步预告
```

**每一环断了就是一个 P0：**
- **「我」只有头衔没有经历** → 断。信任靠具体经历，不靠称号。
- **从理念直接跳到决策**（"该有人做这件事" → "我已定下来做 X"）→ 中间缺一环，必须补"这念头从哪来／我拿什么做／我先想清楚了什么"
- **开头的人物后半篇消失、结尾不回来** → 断。**结尾要回扣开头那个提问。**

### 2. 数据：陈列 → 处境

| ❌ 陈列（我告诉你一个数） | ✅ 处境（我让你看见一个处境） |
|---|---|
| 深圳有 150 所普高、30 所中职 | **150 所学校摆在面前，光筛出"哪些值得看"这一步，就足够一个外行走丢** |

**判据**：读者读完这一句，是**知道了一个数**，还是**感到了自己的处境**？

**呈现方式**（见 `docs/02-规范/04` §H）：**需要"扫一眼就懂"的对比 → 表格**（公众号支持 Markdown 直导）；**需要"感到处境"的 → 叙述**。**禁止 bullet 堆数字。**

### 3. 系列钩子（连载特有）

- 结尾要立住**系列格局**（本篇只讲一城 → 点出"四城答案从来不是一个"）
- 给下一篇**明确的期待**，不要只说"我会接着写"
- ⚠️ 但**不许给时间承诺**

### 4. 术语门槛

首次出现的外行看不懂的词，给一句人话括注。
⚠️ **克制**：**共鸣篇不超过 2 处**——再多就从"共鸣篇"变成"科普篇"，抢了讲解篇的活。

## 三、报告必须分级

| 级 | 含义 |
|:--:|---|
| **P0** | **不改文章立不住**——信任链断、事实错、违规 |
| **P1** | **强烈建议改**——类型不匹配、故事不回扣、只有陈列、没有钩子 |
| **P2** | **打磨**——措辞、小节信息量、元信息清理 |

**不分级的清单等于没审。** 交上去先给 P0。

## 四、自认补写（本技能最硬的一条）

**凡是超出原文的补写，逐条单独标出来，并注明"请核实与事实相符"。**

补写可以是合理展开——**但不能不打招呼。**

> **反例**：无标注地补"真实笔记该有的例外、待核痕迹"。**那是拿真实性换手感。**

## 五、发布前清理

- [ ] 删掉文件头部 YAML 内部元信息（`version`／`status`／`doc_id`／内部来源）
- [ ] 拟名与真名混用 → 文末加"部分校名与昵称已做匿名处理"
- [ ] 含糊数字（"十多二十场"）→ 要么给确数，要么去掉
- [ ] 事实边界与免责声明在位

## 六、红旗 —— 出现即停

- 给出了**违反第一节硬规矩**的建议 → **没先跑硬规矩**
- 报告**没有 P0/P1/P2** → 等于没审
- **补写了不标注** → 拿真实性换手感
- **只看文风不看信任链** → 查的是腔不是骨，本技能不干这个
- 建议加术语括注**超过 2 处** → 把共鸣篇改成科普篇
- 建议**整篇替换**而不是逐条筛 → 文字层会碰红线

## 验收

- [ ] 先判了类型
- [ ] 报告按 P0／P1／P2 分级
- [ ] 信任链四环**逐环**检查过
- [ ] 故事线首尾回扣检查过
- [ ] 补写处**全部**标注
- [ ] 未违反第一节六条硬规矩
