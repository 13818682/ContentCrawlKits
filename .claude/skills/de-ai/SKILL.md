# 去 AI 味

把 AI 腔的中文稿改写成**人会说的话**。

**核心原则：删的是腔，不是内容。** 唯一稳定的改法是——**主语先落到具体的人或事，不要先给抽象标签**。

## 铁律：一个都不许动

**下面这些东西照改不误就是事故。** 它们看起来"太整齐""没毛边"，但那是**规则定的，不是 AI 写的**。

| 不许动 | 为什么 |
|---|---|
| 数字、年份、分数线、总分、招生口径 | 是事实。改写即造谣 |
| 来源标注、免责声明 | 合规红线（`docs/02-规范/04`） |
| 文末署名行 | 经营者定稿、全系列逐字统一 |
| 引号内的家长原话 | 是证据，不是修辞 |
| 产品名与产品进度口径 | 产品事实须经营者给口径，不得自行加码 |

**❌ 绝对禁止**：为了让稿子"有毛边、有第一手感"而**补写细节、案例、例外、待核标注**。
那是**拿真实性换手感**。查不到毛边就不补——**宁可整齐**。

## 病灶清单

按"命中即报"分四层。**先报位置，再谈改法。**

**A 词层**（可直接搜）
- AI 套话：值得注意的是／总的来说／此外／综上／不难看出
- 词频轰炸：赋能／抓手／闭环／颗粒度／底层逻辑／方法论／认知升级／降维打击／破圈
- 万能句式：本质上／说白了／某种程度上

**B 句层**
- **"不是 A，是 B"**（含"不是 A——是 B"）——**必须真的有 B**：先立一个假想说法 A，再否定它、给出真答案。
  **光有"不是"不算。**「东莞不是这样。」没有 B —— **不是病灶，不许计入。**
- **对仗／金句**：左手X右手Y／既要X也要Y／最好的X是Y／各归各的A，各归各的B
- **破折号接解释**：破折号后面那半句，多半可以删
- 感叹号连发

**C 结构层**
- **自造小标题 ＋ 冒号**："四座城市，现在各自到哪一步："
- **结构化开头**：第一件事／第二件事／首先／其次／最后，轮流出现
- **主持人腔**："先说一句……""先说能填几个，再说怎么录""进度先说到这儿。"
- **段段金句收尾**：每个小节末尾都加粗砸一句判断
- 每段都"开头—展开—总结"

**D 内容层**
- **bullet 堆数字** → 改叙述**或改成表格**
  ⚠️ **2026-10-06 经营者定**：**公众号后台支持 Markdown 直导，表格正常显示**。
  所以**表格是合法且常常更好的呈现**——四个分数线列成表，比一行一句好扫。
  **要改的是"用 bullet 堆数字"，不是"用表格"。** 见 `docs/02-规范/04` §H
- 结尾泛泛总结或展望 → 换具体判断
- 全篇缺"我"的视角
- 所有观点都平衡中立

## 密度才是判据

**这些手法本身都没问题——真人也用。病在密度：每段都来一遍，就像节拍器。**

所以报告**必须连密度一起报**，写成"共 N 处，分布 M 个小节"，不许逐条罗列凑数。
**一处对仗不是病；六处一个模子才是病。**

⚠️ **但密度只统计确认命中的处数。** 存疑的单列一行、标明"存疑"，**不计入密度**。
拿捏不准就报"可能"——**密度靠宽松命中凑出来的话，结论本身就是假的。**

## 流程：默认只诊断，不改写

1. **扫描全文 → 出报告**，一行一处：

   | 行号 | 命中 | 原文摘录 | 拟改 |
   |:--:|:--:|---|---|

   末尾附**密度行**：`命中 N 处 × M 小节 / 全文 K 小节`。
2. **等对方确认，才动手改。** 对方没说话，就不改。
3. 改完**回读一遍**，确认读起来像人在说话。

## 改法

| 病灶 | 改成 |
|---|---|
| 对仗／排比 | 拆成口语短句，**长短不一** |
| 金句 | 删掉，换**具体的数字或场景** |
| 抽象标签开头 | **主语先落到具体的人或事** |
| "不是 A，是 B" | 直接下判断 |
| 小标题的冒号／自造标签 | 去标签化，让它像正文里的一句话 |
| 主持人腔 | 直接说事，不报幕 |
| 词频轰炸 | 说人话 |
| 破折号接解释 | 删后半句，或拆成独立短句 |

**平台寄存器**：公众号／头条长文可保留书面的准确；小红书／抖音要更短、更口语、更碎。

## 红旗 —— 出现即停

- 为了"去 AI 感"补写细节、案例、例外 → **造谣，停**
- 动了署名行／来源行／免责声明／数字／口径 → **越界，停**
- 一次报二十处，把偶尔用一次的笔法也当病灶 → **没看密度**
- 把没有 B 的普通否定句也算成"不是 A，是 B" → **命中注水，密度虚高**
- 直接开改，没先出报告 → **越权**
- 交上去的报告只有"哪里像 AI"，没有"改成什么样" → **交了半份**

## 验收

- [ ] 报告含：位置 ＋ 病灶 ＋ 原文 ＋ 拟改 ＋ 密度
- [ ] 改后：特征归零，**且事实零变更**（数字／口径／来源／署名逐字未动）
- [ ] 回读一遍像人在说话
