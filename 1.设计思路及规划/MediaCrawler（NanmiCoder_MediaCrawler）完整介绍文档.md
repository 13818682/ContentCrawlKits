## 一、项目整体作用与定位

### 1\. 核心定义

MediaCrawler 是**开源免费、多平台统一自媒体公开数据采集爬虫框架**，基于 Python\+Playwright 浏览器自动化开发，专门抓取小红书、抖音、视频号、B 站、知乎、微博、快手、贴吧公开图文、短视频、文案、评论、互动数据。

### 2\. 核心解决痛点（对比普通爬虫）

1. **无需 JS 逆向**：复用本地 Chrome 浏览器登录态，直接读取平台加密签名，不用拆解各平台复杂加密算法，零基础开发者可部署；

2. **全平台统一框架**：一套代码同时管理 7 大主流内容平台，不用分别维护多套爬虫脚本；

3. **低风控拦截**：模拟真人浏览器行为、缓存登录 Cookie、支持 IP 代理池，大幅降低账号封禁、IP 限制概率；

4. **可视化 WebUI**：自带网页操作后台，不用全程敲命令行，运营人员也能操作；

5. **结构化数据输出**：自动导出文案、标题、点赞收藏、评论、发布时间，可直接对接 Excel/MySQL 用于 AI 内容素材库（适配你的**深圳中考 AI 内容自动化平台**采集底层）。

## 二、完整使用方法（分 3 大阶段：环境部署、基础命令行操作、Web 可视化后台）

### 前置硬件 \& 软件依赖

1. 系统：Windows10\+/macOS10\.15\+/Ubuntu18\.04\+，内存≥8G（推荐 16G）；

2. 软件必备：

    - Python ≥3\.11

    - Node\.js ≥16\.0\.0

    - uv（Python 高速包管理器，推荐）

    - Chrome 浏览器 ≥144 版本（核心，复用登录态）

### 阶段 1：一键环境部署（两种方案，优先 UV 方案）

#### 方案 A：UV 高速部署（推荐，依赖无冲突）

```shell
# 1. 安装uv包管理器
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. 克隆开源项目到本地
git clone https://github.com/NanmiCoder/MediaCrawler.git
cd MediaCrawler

# 3. 自动安装全部Python依赖
uv sync

# 4. 安装Playwright浏览器驱动（可选，CDP模式可跳过）
uv run playwright install
```

#### 方案 B：原生 pip 虚拟环境部署（Windows 新手）

```shell
# 1. 克隆项目
git clone https://github.com/NanmiCoder/MediaCrawler.git
cd MediaCrawler

# 2. 创建独立虚拟环境
python -m venv venv

# Windows激活环境
venv\Scripts\activate
# Mac/Linux激活
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt
playwright install
```

#### 关键前置配置：开启 Chrome CDP 远程调试（降低风控核心）

1. 打开 Chrome 浏览器，地址栏输入：`chrome://inspect/#remote-debugging`

2. 勾选「Allow remote debugging for this browser instance」

3. 页面出现 `127.0.0.1:9222` 即配置完成；

4. 爬虫运行时自动连接本机 Chrome，复用已登录小红书 / 抖音 / B 站账号，无需重复扫码登录。

### 阶段 2：命令行基础采集操作（3 种核心采集指令）

#### 通用指令格式

`uv run main.py --platform 平台标识 --lt qrcode --type 采集类型`

- 平台标识：xhs \(小红书\)、douyin \(抖音\)、bilibili \(B 站\)、zhihu \(知乎\)、weibo \(微博\)

- \-\-lt qrcode：扫码登录当前平台

- \-\-type 可选参数：search（关键词搜索）、detail（单条 ID 抓取）、creator（博主主页全量抓取）

#### 实操示例（适配深圳中考素材采集）

1. **关键词批量搜索（抓取深圳中考相关全网笔记）**

```shell
# 抓取小红书所有含“深圳中考志愿填报”的公开笔记
uv run main.py --platform xhs --lt qrcode --type search
```

配置：修改`config/base_config.py`，在关键词列表填入：深圳中考、深圳志愿填报、深圳指标生、深圳一分一段表。

2. **抓取单个升学博主全部主页内容**

```shell
uv run main.py --platform xhs --lt qrcode --type creator
```

配置：在配置文件填入对标博主主页 ID，自动爬取全部历史图文、文案、互动数据。

3. **抓取单条爆款内容完整文案 \+ 全部评论**

```shell
uv run main.py --platform douyin --lt qrcode --type detail
```

配置：填入爆款视频 ID，自动提取完整口播字幕、评论区家长提问。

#### 数据存储配置

修改`config/base_config.py`，可设置存储格式：

- 本地轻量化：CSV/Excel，直接导入飞书多维表格素材库；

- 长期私有化：MySQL 数据库，对接自建 AI 内容平台素材库。

### 阶段 3：Web 可视化后台（零代码操作，适合运营人员）

无需敲命令，网页端可视化配置爬虫、查看日志、导出素材：

#### 1\. 启动前后端服务

```shell

uv run uvicorn api.main:app --port 8080 --reload

# 终端2：启动前端WebUI
cd webui

npm run dev
```

#### 2\. 访问地址

前端页面：[http://localhost:5173](http://localhost:5173)
生产打包后直接访问：[http://localhost:8080](http://localhost:8080)

#### 3\. WebUI 核心操作功能

1. 可视化选择平台、采集模式、填写关键词 / 博主 ID；

2. 一键扫码登录，自动缓存账号；

3. 实时查看爬虫运行日志、抓取进度；

4. 素材在线预览：标题、全文文案、互动数据；

5. 批量导出 Excel/CSV 素材包，直接导入选题分析工具；

6. 配置定时任务，每日自动抓取深圳中考热点素材。

## 四、常见问题避坑

1. 爬虫登录失败：确认 Chrome 开启 9222 远程调试，浏览器提前手动登录对应平台；

2. 抓取频繁封号：开启 IP 代理池、拉长抓取间隔、多账号轮换采集；

3. 依赖安装报错：使用 uv 工具，不要混用 pip/uv 两套依赖；

4. 短视频无文案：工具自动提取视频字幕，若为空说明视频无内置字幕，仅保留标题素材。
